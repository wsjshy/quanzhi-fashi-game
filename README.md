# 全职法师 - 魔法觉醒 · 开放世界版

基于小说《全职法师》改编的同人网页游戏。

> **开发者请注意**：本项目的开发主入口文档是 [`AGENTS.md`](./AGENTS.md)，所有开发工作请先阅读该文档，了解项目结构、文档体系、开发规范和沉淀经验。

## 游戏简介

你将扮演一名刚觉醒魔法的新生，在博城开始你的魔法之旅。这是一个开放世界，你可以自由探索、修炼、交友、冒险。你的选择会影响这个世界，影响你和 NPC 之间的关系，甚至改变某些人的命运。

**不是扮演莫凡，而是成为你自己。**

## 游戏特色

- 🗺️ **开放世界** - 自由探索，多地点冒险，没有线性剧情
- 💬 **深度对话** - 丰富的对话树系统，不同选择不同结果
- ❤️ **关系系统** - 好感、信任、熟悉度三维关系，14 个关系等级
- 👥 **NPC 社交** - NPC 之间也有关系，你的行为会影响他们
- ⚔️ **策略战斗** - 星子引导、元素克制、打断机制，贴近原著
- 📈 **成长系统** - 升级、觉醒新系、学习技能、装备强化
- ⏰ **时间系统** - 体力限制、昼夜更替、定时大事件
- 🎲 **随机事件** - 探索中的意外惊喜，每次玩都不一样
- 🏛️ **势力声望** - 5 大势力，7 级声望，不同声望不同待遇
- 📋 **情报系统** - 收集情报，提前预警，影响大事件结局
- 🎬 **大事件系统** - 事件链、多结局、伏笔铺垫，你的选择很重要
- 📦 **数据驱动** - 模块化架构，易于扩展内容

## 如何运行

### 直接打开（推荐）

双击 `index.html` 直接用浏览器打开即可运行。

**v0.2+ 版本已优化**：所有数据内嵌到 JS 文件中，无需 HTTP 服务器，无 CORS 问题，双击即玩。

### 本地 HTTP 服务器（可选）

如果遇到问题，可以使用本地服务器：

```bash
# 进入游戏目录
cd quanzhi-fashi-game

# Python 3
python -m http.server 8000
```

然后在浏览器中打开：http://localhost:8000

## 扩展开发

详细的扩展开发指南请查看 `docs/` 目录下的文档。

### 添加新 NPC
1. 在 `engine/data/characters.js` 中添加 NPC 数据
2. 添加性格设定、对话树、关系数据
3. 无需修改代码，数据驱动自动生效

### 添加新对话
1. 在 NPC 的 `dialogueTree` 中添加对话节点
2. 支持条件判断、效果触发、跳转
3. 详细格式见 `docs/对话树与剧情连锁系统设计.md`

### 添加新地点
1. 在 `engine/data/locations.js` 中添加地点数据
2. 添加行动列表、遇敌概率等
3. 详细格式见 `docs/数据格式规范.md`

## 设计理念

### 内容分层架构
```
┌─────────────────────────────────────┐
│  剧情层：大事件时间线 + 伏笔 + 因果  │
├─────────────────────────────────────┤
│  关系层：NPC好感度 + 势力声望 + 关系网 │
├─────────────────────────────────────┤
│  内容层：NPC + 事件 + 任务 + 对话树   │
├─────────────────────────────────────┤
│  基础层：战斗 + 背包 + 时间 + 地图    │
└─────────────────────────────────────┘
```

### 影响力四层设计
1. **态度影响** - NPC 对你态度变化，给小帮助
2. **关系深化** - 成为朋友/挚友，一起冒险
3. **人生影响** - NPC 因你改变决定和人生轨迹
4. **命运改写** - 彻底改变 NPC 的命运，包括感情归属
