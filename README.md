# 全职法师 - 魔法觉醒 · 开放世界版

基于小说《全职法师》改编的同人网页游戏。纯HTML5，双击即玩，数据驱动，可扩展。

> **开发者请注意**：本项目的开发主入口文档是 [`AGENTS.md`](./AGENTS.md)，所有开发工作请先阅读该文档。

## 游戏简介

你将扮演一名刚觉醒魔法的新生，在博城开始你的魔法之旅。这是一个开放世界，你可以自由探索、修炼、交友、冒险。你的选择会影响这个世界，影响你和 NPC 之间的关系，甚至改变某些人的命运。

**不是扮演莫凡，而是成为你自己。**

## 游戏特色

- 🗺️ **2D可视化地图** - 博城大地图12个地点，图形化导航，点击前往，地点描述与功能一目了然
- 🗺️ **开放世界** - 多地点自由探索，没有强制线性流程，大地图随剧情推进扩展
- ⚔️ **策略战斗** - 元素克制、元素反应、状态效果配合（冻结×2/燃烧+30%/麻痹暴击+20%）、元素能量积累、技能冷却、14项战斗机制
- 🔥 **技能体系** - 各系初阶1-3级技能，低级低耗高频、高级高耗战略，图书馆可随机领悟新技能
- 💬 **深度对话** - 260+对话节点，分支选择，条件触发
- ❤️ **关系系统** - 好感/信任/尊敬/畏惧/熟悉度五维关系
- 🔥 **灵种系统** - 47种灵种（凡种/灵种/魂种），炼化提升威力
- ⭐ **星尘魔器** - 成长型魔器，小泥鳅坠等原著器皿
- 🌟 **天赋系统** - 50个天生天赋，5种稀有度
- 🐺 **召唤系统** - 召唤兽战斗，幽狼兽进化
- 👹 **精英妖魔** - 博城灾难精英妖魔（三眼魔狼/进阶期独眼魔狼/巨眼猩鼠王），特殊机制需要策略应对
- 🏆 **成就系统** - 42个成就，隐藏成就
- 📋 **情报系统** - 70条信息碎片，4类情报，伏笔铺垫
- 🎬 **章节系统** - 博城篇+明珠篇，覆盖小说1-230章
- 🎭 **大事件** - 博城灾难完整事件链（异常迹象→预警准备→灾难降临→新的开始），多选择多结局，玩家可真正影响剧情走向
- ⏰ **时间系统** - 时段制，昼夜更替，日常修炼
- 🎲 **随机事件** - 204个事件，探索中的意外
- 🏛️ **势力声望** - 5大势力，7级声望
- ✨ **修炼顿悟** - 修炼时有概率触发顿悟，获得额外经验/技能点/buff
- 🔮 **隐秘地点** - 探索时发现专属修炼地点，每个玩家的机缘不同
- 📅 **NPC自主日程** - 9个关键NPC有自己的生活，你可能在不同地点遇到他们在做自己的事
- 📜 **个人任务线** - 基于你的元素系别/等级/关系自动触发的专属任务，不是莫凡的复刻
- 🔗 **NPC间关系联动** - NPC之间的关系会因你的行为而变化，你是真正的影响者
- 📱 **横竖版自适应** - PC横版与手机竖版双布局，主界面免滚动，额外信息悬停/长按查看
- 📦 **数据驱动** - 模块化架构，加内容不改代码，篇章扩展标准化流程

## 如何运行

双击 `index.html` 即可。所有数据内嵌JS文件，无需HTTP服务器，无CORS问题。

调试模式：URL加 `?debug=1` 或按 `~` 键打开debug面板。

## 魔法元素

- ⚡ 雷系 - 高速高爆发，麻痹
- 🔥 火系 - 高伤害，灼烧DOT
- ❄️ 冰系 - 控制，冻结减速
- 🪨 土系 - 防御，护盾反伤
- 💨 风系 - 连击，高闪避
- 💧 水系 - 治疗，持续恢复
- ✨ 光系 - 净化，克制暗影
- 🌑 暗影系 - 偷袭，控制（巨影钉）
- 🌿 植物系 - 束缚，藤蔓
- 🐺 召唤系 - 召唤兽战斗

## 操作说明

- **地图**：点击地点移动，点击行动按钮执行操作
- **战斗**：点击技能释放魔法，可防御/道具/逃跑
- **对话**：点击选项，不同选择不同结果
- **菜单**：右侧菜单查看角色/背包/任务/情报/成就
- **调试**：`~`键切换debug面板，`?debug=1`开启
