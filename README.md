# 全职法师 - 魔法觉醒 · 开放世界版

基于小说《全职法师》改编的同人网页游戏。数据驱动，可扩展。v3.0.0起采用Vite + ES Modules模块化架构。

> **当前版本：v3.0.0** | **最后更新：2026-08-22**

> **开发者请注意**：本项目的开发主入口文档是 [`AGENTS.md`](./AGENTS.md)，所有开发工作请先阅读该文档。

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式（启动Vite开发服务器，http://localhost:5173）
npm run dev

# 生产构建（输出到dist/目录）
npm run build

# 预览构建产物
npm run preview
```

## 游戏简介

你将扮演一名刚觉醒魔法的新生，在博城开始你的魔法之旅。这是一个开放世界，你可以自由探索、修炼、交友、冒险。你的选择会影响这个世界，影响你和 NPC 之间的关系，甚至改变某些人的命运。

**不是扮演莫凡，而是成为你自己。**

- ⚔️ **策略战斗** - 元素克制、元素反应、状态效果配合（冻结×2/燃烧+30%/麻痹暴击+20%）、元素能量积累、技能冷却、14项战斗机制

- 💬 **深度对话** - 260+对话节点，分支选择，条件触发
- ❤️ **关系系统** - 好感/信任/尊敬/畏惧/熟悉度五维关系
- 🔥 **灵种系统** - 47种灵种（凡种/灵种/魂种），炼化提升威力
- ⭐ **星尘魔器** - 成长型魔器，小泥鳅坠等原著器皿
- 🌟 **天赋系统** - v2.2.0半重写，5种机制类型（资源/状态/形态/触发/光环），11系天赋战斗效果，7系主动技能，10组跨系组合，双主修系装备系统
- 🐺 **召唤系统** - 召唤兽战斗，幽狼兽进化

## 如何运行

双击 `index.html` 即可。所有数据内嵌JS文件，无需HTTP服务器，无CORS问题。

调试模式：URL加 `?debug=1` 或按 `~` 键打开debug面板。

## 魔法元素

- ⚡ 雷系 - 高速高爆发，麻痹
- 🔥 火系 - 高伤害，灼烧DOT
- ❄️ 冰系 - 控制，冻结减速
- 🪨 土系 - 防御，护盾反伤
- 💨 风系 - 连击，高闪避
- 💧 水系 - 治疗，持续恢复
- ✨ 光系 - 净化，克制暗影
- 🌑 暗影系 - 偷袭，控制（巨影钉）
- 🌿 植物系 - 束缚，藤蔓
- 🐺 召唤系 - 召唤兽战斗

## 操作说明

- **地图**：点击地点移动，点击行动按钮执行操作
- **战斗**：点击技能释放魔法，可防御/道具/逃跑
- **对话**：点击选项，不同选择不同结果
- **菜单**：右侧菜单查看角色/背包/任务/情报/成就
- **调试**：`~`键切换debug面板，`?debug=1`开启
