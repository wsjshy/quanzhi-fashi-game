# 全职法师 - 魔法觉醒 · 开放世界版

基于小说《全职法师》改编的同人网页游戏。纯HTML5，双击即玩，数据驱动，可扩展。

> **开发者请注意**：本项目的开发主入口文档是 [`AGENTS.md`](./AGENTS.md)，所有开发工作请先阅读该文档。

## 游戏简介

你将扮演一名刚觉醒魔法的新生，在博城开始你的魔法之旅。这是一个开放世界，你可以自由探索、修炼、交友、冒险。你的选择会影响这个世界，影响你和 NPC 之间的关系，甚至改变某些人的命运。

**不是扮演莫凡，而是成为你自己。**

## 游戏特色

- 🗺️ **开放世界** - 12+地点自由探索，没有强制线性流程
- 💬 **深度对话** - 260+对话节点，分支选择，条件触发
- ❤️ **关系系统** - 好感/信任/尊敬/畏惧/熟悉度五维关系
- ⚔️ **策略战斗** - 星子引导、元素克制、打断机制、6种AI类型
- 🔥 **灵种系统** - 47种灵种（凡种/灵种/魂种），炼化提升威力
- ⭐ **星尘魔器** - 成长型魔器，小泥鳅坠等原著器皿
- 🌟 **天赋系统** - 50个天生天赋，5种稀有度
- 🐺 **召唤系统** - 召唤兽战斗，幽狼兽进化
- 🏆 **成就系统** - 42个成就，隐藏成就
- 📋 **情报系统** - 70条信息碎片，4类情报，伏笔铺垫
- 🎬 **章节系统** - 10章剧情，博城篇+明珠篇，覆盖小说1-230章
- 🎭 **大事件** - 博城灾难等事件链，多阶段多结局
- ⏰ **时间系统** - 8时段制，昼夜更替，日常修炼
- 🎲 **随机事件** - 114个事件，探索中的意外
- 🏛️ **势力声望** - 5大势力，7级声望
- ✨ **修炼顿悟** - 修炼时有概率触发顿悟，获得额外经验/技能点/buff
- 🔮 **隐秘地点** - 探索时发现专属修炼地点，每个玩家的机缘不同
- 📅 **NPC自主日程** - NPC有自己的生活，你可能在不同地点遇到他们在做自己的事
- 📜 **个人任务线** - 基于你的元素系别/等级/关系自动触发的专属任务，不是莫凡的复刻
- 📦 **数据驱动** - 模块化架构，加内容不改代码

## 如何运行

双击 `index.html` 即可。所有数据内嵌JS文件，无需HTTP服务器，无CORS问题。

调试模式：URL加 `?debug=1` 或按 `~` 键打开debug面板。

## 魔法元素

- ⚡ 雷系 - 高速高爆发，麻痹
- 🔥 火系 - 高伤害，灼烧DOT
- ❄️ 冰系 - 控制，冻结减速
- 🪨 土系 - 防御，护盾反伤
- 💨 风系 - 连击，高闪避
- 💧 水系 - 治疗，持续恢复
- ✨ 光系 - 净化，克制暗影
- 🌑 暗影系 - 偷袭，控制（巨影钉）
- 🌿 植物系 - 束缚，藤蔓
- 🐺 召唤系 - 召唤兽战斗

## 操作说明

- **地图**：点击地点移动，点击行动按钮执行操作
- **战斗**：点击技能释放魔法，可防御/道具/逃跑
- **对话**：点击选项，不同选择不同结果
- **菜单**：右侧菜单查看角色/背包/任务/情报/成就
- **调试**：`~`键切换debug面板，`?debug=1`开启
