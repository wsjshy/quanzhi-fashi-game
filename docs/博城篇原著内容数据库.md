## 一、核心机制（必须保留，不可裁剪）

### 1.1 暴躁之泉（第90-93章）

- **本质**：黑教廷炼制的药剂，几乎可以和地圣泉以假乱真
- **效果**：与地圣泉的滋补效果截然不同，暴躁之泉会激化妖魔的野性，让它们变得近乎失去理智的杀戮
- **原理**：以疯狂吸食生物体内营养、能量为代价，让生物变得非常疯狂，没有理智
- **使用方式**：黑教廷将暴躁之泉洒在云雾之中，等到大雨来临，暴躁之泉就成为最可怕的催化剂，使得魔狼族群疯狂进攻博城
- **发现者**：林雨欣副卫长（在巨眼猩鼠洞穴中发现类似地圣泉的水，送药剂师检测后发现真相）
- **重要性**：博城灾难的**根本原因**，没有暴躁之泉就没有妖魔暴动
- **游戏化建议**：作为博城灾难的核心背景机制，可以设计为玩家可以提前发现并阻止的剧情分支

### 1.2 地圣泉（第94章等）

- **本质**：博城几千年的真正底蕴，天地灵泉
- **效果**：自身纯净，可以带给修炼者和妖魔非常大的滋补
- **地位**：整个博城的命脉，魔法师梦寐以求的修炼宝藏
- **现状**：因为岁月变迁，远没有古老时期那么神奇，但在整个国内仍绝对是魔法师梦寐以求的修炼宝藏
- **黑教廷目标**：黑教廷想利用地圣泉将更多统领级妖魔引到博城，彻底毁灭博城
- **莫凡的处理**：莫凡将地圣泉"当水喝了"（实际可能私藏，斩空没有深究）
- **重要性**：博城灾难的**争夺焦点**，白阳叛变就是为了抢夺地圣泉
- **游戏化建议**：作为博城灾难的核心物品，玩家可以参与保护或争夺

### 1.3 黑畜妖（第102章）

- **本质**：黑教廷的标志生物，由人通过黑畜妖之法变成
- **外观**：鬼猴面，畸人之身，遍体通黑得像是穿上了紧身的皮质外衣，丑陋不堪
- **能力**：
  - 速度极快，比巨眼猩鼠还要快上接近一倍
  - 一旦飞窜到有阴影的地方甚至无法看清身形
  - 能准确找到生物的动脉，一旦切开必定血液流干为止
  - 是放血的刽子手
- **弱点**：和主人灵魂相连，主人死亡，它们也跟着毁灭
- **地位**：黑教廷最忠诚的害人恶狗
- **重要性**：白阳叛变时的主要战斗力，何雨牺牲的直接原因
- **游戏化建议**：作为博城灾难的特色敌人，设计"放血"特性（持续掉血，不可治疗）

### 1.4 斩魔具（第104章）

- **本质**：典型的进攻型魔具
- **效果**：激活后便可以爆发出一次巨斩的威力
- **消耗**：消耗的魔能相当大
- **价值**：斩类魔具昂贵程度比铠魔具还高，连魔法师都买不起，更不用说普通人
- **稀有性**：没有哪个家族会交给还未毕业的学生手上
- **穆白的斩魔具**：他叔叔在他十八岁生日那天送的
- **重要性**：穆白的高光时刻，斩杀白阳的关键武器
- **游戏化建议**：作为剧情物品，在白阳BOSS战中自动触发（穆白使用）

## 二、重要角色（必须保留人设，不可OOC）

### 2.1 白阳（第102章，核心反派）

- **身份**：雪峰山驿站的召唤系教官，真实身份是黑教廷卧底
- **表面人设**：和煦俊俏，令小女生痴迷的崇拜光环
- **真实人设**：思想扭曲的疯子，丧心病狂
- **召唤兽**：
  - 幽狼兽（主要战斗力）
  - 两只黑畜妖（隐藏战斗力，平时不显露）
- **叛变经过**：
  1. 遇到莫凡等人，骗取莫凡保管的地圣泉
  2. 莫凡产生怀疑，拒绝交出地圣泉
  3. 白阳直接叛变，命令幽狼兽攻击莫凡
  4. 两只黑畜妖从桥梁边缘飞出，攻击张小侯和何雨
- **结局**：被穆白用斩魔具斩杀，左肩脖颈以上部位被彻底切开，切口冻结寒霜
- **莫凡怀疑他的原因**：
  1. 历练时看到山口泉池的水有饮过的迹象，不止一只
  2. 白阳说没有其他召唤兽，但泉池的迹象说明有
  3. 幽狼兽当初莫名发狂也是一个疑点
- **重要性**：博城灾难高潮的核心反派
- **游戏化建议**：作为BOSS出现，有三只召唤兽（幽狼兽+两只黑畜妖）

### 2.2 何雨（第102-103章，核心牺牲者）

- **身份**：莫凡班级同学，水系法师
- **人设**：
  - 怯弱，紧张不安，梨花带雨
  - 但关键时刻非常勇敢
  - 年度考核成绩A（扮猪吃老虎，考前哭哭啼啼，考后拿A）
  - 只掌握6颗星子（初阶一级水平）
- **牺牲经过**：
  1. 白阳叛变，两只黑畜妖分别扑向张小侯和何雨
  2. 何雨在关键时刻释放了水御（水域）保护了张小侯
  3. 但她自己被黑畜妖切开动脉，血流不止
  4. 张小侯抱着何雨，何雨在生命最后一刻有复杂情绪
- **临终情绪**：
  - 欣慰：终于在危急时刻释放出了水域，像薛老师说的那样保护住了一个人的生命
  - 安然：历练的时候张小侯舍身救自己，今天自己也救了他
  - 眷恋：还有太多太多和其他少女一样美好的愿望没有实现
- **重要性**：博城灾难中最感人的牺牲，张小侯成长的关键动力
- **游戏化建议**：默认剧情牺牲，玩家在特定条件下可以拯救（关系值+反应速度+属性）

### 2.3 穆白（第104章，高光角色）

- **身份**：穆氏世家子弟，冰系法师，莫凡的同班同学
- **人设**：
  - 高傲，怨妇性格，和莫凡势不两立
  - 但关键时刻有担当
  - 世家子弟，有资源（斩魔具）
- **高光时刻**：
  1. 白阳BOSS战胶着时，穆白使用斩魔具
  2. 斩魔具爆发巨斩威力，斩杀白阳
  3. 白阳死亡后，两只黑畜妖也跟着毁灭
  4. 穆白说："我叔叔在我十八岁生日那天送我的斩魔具总算派上了用场。"
- **重要性**：博城灾难中的英雄时刻，穆白角色成长的关键
- **游戏化建议**：在白阳BOSS战中，穆白的斩魔具作为剧情技能在特定回合自动触发

### 2.4 林雨欣（第90章，重要线索人物）

- **身份**：魔法协会副卫长，水系法师
- **人设**：英气，认真负责，不松懈
- **背景**：妹妹一年前失踪（疑似巨眼猩鼠所为），一直在搜寻
- **关键行动**：
  1. 在巨眼猩鼠洞穴中发现类似地圣泉的水
  2. 送药剂师检测，发现是暴躁之泉
  3. 意识到博城灾难的真相
- **重要性**：暴躁之泉的发现者，博城灾难预警的关键人物
- **游戏化建议**：作为NPC出现，提供暴躁之泉的线索和任务

### 2.5 斩空（第105章，军方领袖）

- **身份**：军方总教官，博城城市的真正守护战神
- **人设**：平时吊儿郎当，关键时刻威严冷傲
- **关键行动**：
  1. 博城灾难后指挥军方抵抗
  2. 见到莫凡后说"看到你活着，我很高兴"
  3. 决定诛杀翼苍狼："犯我博城者，虽强必诛"
  4. 九名直属部下齐声响应："诛杀翼苍狼，不死不休！"
- **重要性**：博城灾难后的军方领袖，后续剧情的关键人物
- **游戏化建议**：作为NPC出现，博城灾难后的任务发布者

### 2.6 薛木生（第102章，老师）

- **身份**：莫凡的班主任，光系法师
- **人设**：认真负责，保护学生
- **关键行动**：
  1. 白阳叛变时高声大吼"白教官，你在做什么！"
  2. 使用光耀技能对抗黑畜妖
  3. 白阳死后解释黑畜妖的特性
- **重要性**：学生们的保护者，博城灾难中的正面角色
- **游戏化建议**：作为NPC出现，在白阳BOSS战中协助玩家

### 2.7 唐月（第93章等，审判会审判员）

- **身份**：审判会审判员，莫凡的老师，火系法师
- **人设**：温柔，认真，有正义感
- **关键行动**：
  1. 调查暴躁之泉的来源
  2. 追踪黑教廷成员（如朝赫）
  3. 博城灾难中协助抵抗
- **重要性**：黑教廷线索的关键人物，后续剧情的重要角色
- **游戏化建议**：作为NPC出现，提供黑教廷相关任务

### 2.8 张小侯（第102章，莫凡好友）

- **身份**：莫凡的好友，风系法师
- **人设**：单纯，勇敢，重情义
- **关键行动**：
  1. 历练时舍身救何雨
  2. 博城灾难中被何雨保护
  3. 何雨牺牲后情绪崩溃，泪水奔涌
- **重要性**：何雨牺牲的直接关联者，后续成长的关键动力
- **游戏化建议**：作为NPC和队友出现，何雨牺牲后有明显的情绪变化

### 2.9 翼苍狼（第94章，统领级妖魔）

- **身份**：统领级妖魔，博城灾难的主要威胁
- **实力**：统领级，远超奴仆级和战将级
- **威胁**：虽然强大，但还不足以在一两天内将博城化为血肉池
- **黑教廷的计划**：如果再出现几只跟翼苍狼同一个级别的妖魔，博城即便等待到了增援也会死伤殆尽
- **结局**：被斩空率军诛杀（"犯我博城者，虽强必诛"）
- **重要性**：博城灾难的最终BOSS
- **游戏化建议**：作为博城灾难的最终BOSS出现

### 2.10 宇昂（第32章等，重要角色，博城灾难未出场）

- **身份**：穆卓云的养子，穆氏世家的修炼疯子，冰系法师
- **人设**：对穆卓云唯命是从，就算让他直接杀了莫凡也不会有一点犹豫
- **关键剧情**：
  1. 和莫凡有十八岁的魔法决斗约定
  2. 成年礼非常隆重，胜者获得地圣泉修炼机会
  3. 后续是黑教廷成员，被审判会抓住
  4. 最终被莫凡杀死
  5. 是四大恶魂格之一
- **博城灾难章节出场情况**：**未出场**（第90-105章中没有出现）
- **重要性**：重要角色，但博城灾难中未出场
- **游戏化建议**：现有游戏将宇昂作为博城灾难反派是**游戏改编**，可以保留但需说明是改编
