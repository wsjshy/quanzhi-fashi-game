## 目录用途

本目录是项目自迭代机制的记录存档，包含三类文件：

### 1. 版本反思会记录（每个版本后）
- **命名**：`vX.Y.Z_反思.md`
- **触发**：每个版本发布并提交后，立即执行
- **耗时**：30分钟
- **内容**：做得好的/做得不好的/方法论反馈/玩家体验/下版本重点

### 2. 项目健康度审计报告（每5个版本后）
- **命名**：`健康度审计_vX.Y.Z.md`
- **触发**：每完成5个版本（如v3.15.0、v3.20.0...）
- **耗时**：1小时
- **内容**：文档审计/代码审计/方法论审计/创新审计，发现问题立即创建任务

### 3. 方法论评审会记录（每10个版本后，需用户确认）
- **命名**：`方法论评审_vX.Y.Z.md`
- **触发**：每完成10个版本（如v3.20.0、v3.30.0...）
- **耗时**：2小时
- **内容**：回顾方法论使用情况/评审改进提案/检查创新空间/决定方法论保留修改废弃新增
