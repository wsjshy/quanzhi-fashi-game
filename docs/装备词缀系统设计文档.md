# 装备词缀系统设计文档

> **版本**：v1.0（合并v3.5.0词缀系统 + v3.8.0掉落随机化）
> **最后更新**：2026-09-08
> **相关版本**：v3.5.0装备系统优化、v3.8.0装备掉落与词缀随机化

---

## 一、系统概述

装备词缀系统为装备增加随机属性，让同一件装备因词缀不同而产生差异，给玩家刷装备的追求感。

### 核心设计原则
1. **原著驱动**：装备通过商店购买、任务奖励、锻造获得，妖魔不掉现成装备（仅极少数BOSS极低概率掉落）
2. **实例级存储**：每件装备独立存储词缀，更换装备不丢失词缀
3. **品质分级**：普通/优秀/稀有/史诗四档，词缀数量递增
4. **前后缀分离**：前缀影响主属性，后缀影响特殊属性

## 二、词缀配置

### 2.1 品质等级

| 品质 | 颜色 | 词缀数量 | 掉落概率 |
|------|------|---------|---------|
| 普通 | ⚪ 白 | 0 | 50% |
| 优秀 | 🟢 绿 | 1 | 30% |
| 稀有 | 🔵 蓝 | 2 | 15% |
| 史诗 | 🟣 紫 | 3 | 5% |

### 2.2 前缀池（8种，影响主属性）

| 词缀 | 属性 | 数值范围 | 权重 |
|------|------|---------|------|
| 锋利的 | 攻击 | +5~+15 | 10 |
| 坚固的 | 防御 | +5~+15 | 10 |
| 智慧的 | 魔法 | +5~+15 | 10 |
| 敏捷的 | 速度 | +2~+5 | 8 |
| 活力的 | 最大HP | +20~+50 | 8 |
| 充沛的 | 最大MP | +20~+50 | 8 |
| 精准的 | 命中率 | +3%~+8% | 6 |
| 致命的 | 暴击率 | +2%~+5% | 5 |

### 2.3 后缀池（10种，影响特殊属性）

| 词缀 | 属性 | 数值范围 | 权重 |
|------|------|---------|------|
| 之暴击 | 暴击率 | +3%~+8% | 8 |
| 之穿透 | 防御穿透 | +5%~+10% | 6 |
| 之生命 | 最大HP | +30~+80 | 8 |
| 之魔力 | 最大MP | +30~+80 | 8 |
| 之吸血 | 吸血 | +2%~+5% | 5 |
| 之反伤 | 反伤 | +3~+8 | 5 |
| 之精准 | 命中率 | +5%~+12% | 6 |
| 之迅捷 | 速度 | +1~+3 | 6 |
| 之力量 | 攻击 | +3~+8 | 7 |
| 之坚韧 | 防御 | +3~+8 | 7 |

### 2.4 生成规则
- 按品质决定词缀数量
- 从前后缀池中按权重随机选择
- 同一属性不重复（如已有"锋利的"就不会再有"之力量"）
- 数值在范围内随机生成

## 三、数据结构

### 3.1 装备实例（背包中）
```javascript
{
  itemId: "flame_blade",      // 物品ID
  count: 1,                    // 数量（装备不可堆叠，恒为1）
  instanceId: "inst_xxx",      // 实例唯一ID
  quality: "rare",             // 词缀品质
  affixes: [                   // 词缀列表
    { id: "sharp", name: "锋利的", stat: "attack", value: 10, isPercent: false, isPrefix: true }
  ]
}
```

### 3.2 装备槽位（玩家身上）
```javascript
Player.equipment = { weapon: "flame_blade", armor: null, accessory: null };
Player.equipmentAffixes = {
  weapon: { quality: "rare", affixes: [...] },
  armor: null,
  accessory: null
};
```

### 3.3 强化等级（按槽位，换装备不丢失）
```javascript
Player.enhanceLevels = { weapon: 3, armor: 0, accessory: 0 };
```

## 四、装备获取途径

| 途径 | 说明 | 词缀生成 |
|------|------|---------|
| 商店购买 | 主要途径，各商店有售 | 购买时随机生成 |
| BOSS掉落 | 翼苍狼/三眼魔狼精英，2%-5%概率 | 掉落时随机生成 |
| 任务奖励 | 剧情中获得的魔具 | 固定词缀（后续可改为随机） |
| 锻造（后续） | 用妖魔材料+魔石锻造 | 锻造时随机生成 |

### 4.1 妖魔掉落规范
- **奴仆级**：只掉材料（妖魔核心、皮毛、爪牙），不掉装备
- **战将级**：只掉高级材料、精魄（小概率），不掉现成装备
- **统领级/BOSS**：极低概率（<5%）掉特殊装备，需有原著依据

## 五、属性计算

`Player.getTotalStats()` 中：
1. 基础属性
2. 装备基础属性（含强化加成）
3. **装备词缀属性**（优先使用equipmentAffixes中的实例词缀，无则使用静态词缀）
4. Buff加成
5. 灵种被动加成
6. 天赋效果加成

## 八、后续扩展方向

1. **装备重铸/洗练**：消耗材料重新随机词缀
2. **锻造系统**：用妖魔材料+魔石锻造装备，词缀随机
3. **套装效果**：多件同系列装备触发套装加成
4. **装备绑定**：装备后绑定，避免无限刷
5. **词缀升级**：消耗材料提升词缀数值
