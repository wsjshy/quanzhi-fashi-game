## 一、为什么做穆宁雪线

### 穆宁雪的角色深度
- 冰系天才，穆氏家族千金
- 有家族压力（穆氏内部权力斗争）
- 有个人追求（冰系极致）
- 与穆白有家族关系（NPC间联动潜力）

### 与唐月线的区别
| 维度 | 唐月线 | 穆宁雪线 |
|------|--------|----------|
| 关系性质 | 师生 | 同学/竞争者 |
| 选择核心 | 接受指导 vs 独立 | 介入家族 vs 保持距离 |
| NPC联动 | 较少 | 穆白/穆氏家族 |
| 剧情深度 | 个人成长 | 家族+个人 |

### 设计原则
- **不做恋爱线**：关系是认可、尊重、竞争，不是恋爱
- **不对标莫凡**：穆宁雪的选择基于她自己的判断，不涉及"是否喜欢莫凡"
- **自然发生**：玩家行为影响关系，关系达到阈值触发事件，一切自然

## 二、任务线设计

### 事件1：冰系的认可（好感≥30触发）

**触发方式**：修炼/冥修时概率触发

**事件内容**：
> 你修炼结束时，穆宁雪恰好路过。她看了你一眼，语气平淡："你的冰系...有点意思。基础不错，但星子运转太保守了。"她顿了顿，"放学后训练馆有空，要来切磋一下吗？"

**选择分支**：
1. **接受邀请** → 好感+5，设置flag `mu_ningxue_invite_accepted`，触发任务"冰系切磋"
2. **婉拒，我还需要修炼** → 好感不变，设置flag `mu_ningxue_invite_declined`，穆宁雪点头离开
3. **反问她为什么帮我** → 好感+3，设置flag `mu_ningxue_invite_question`，穆宁雪说"没什么，只是觉得你有潜力"，触发任务"冰系切磋"（但对话内容不同）

**任务"冰系切磋"**（选择1或3后触发）：
- 目标：与穆宁雪对话1次 + 击败1个妖魔（证明实力）
- 奖励：经验200，穆宁雪好感+10，技能点1
- 完成后设置flag `mu_ningxue_invite_done`

### 事件2：穆家的压力（好感≥50触发，完成事件1）

**触发方式**：修炼/对话时概率触发

**事件内容**：
> 你在走廊遇到穆宁雪，她的表情比平时凝重。看到你，她犹豫了一下，开口道："穆家...最近有些事。我可能需要离开一段时间。"她看着你，"你觉得，一个人应该为家族牺牲自己的追求吗？"

**选择分支**：
1. **家族责任更重要** → 好感+3，设置flag `mu_ningxue_family_duty`，穆宁雪若有所思，触发任务"家族的召唤"
2. **追求自己的路更重要** → 好感+5，设置flag `mu_ningxue_own_path`，穆宁雪眼神坚定，触发任务"冰系的执着"
3. **这要看你自己想要什么** → 好感+8，设置flag `mu_ningxue_self_choice`，穆宁雪认真看了你一眼，触发任务"内心的抉择"

**任务"家族的召唤"**（选择1后触发）：
- 目标：与穆白对话1次（了解穆家情况）+ 与穆宁雪对话1次
- 奖励：经验300，穆宁雪好感+5，穆白好感+10
- 完成后设置flag `mu_ningxue_family_done`

**任务"冰系的执着"**（选择2后触发）：
- 目标：冥修5次 + 与穆宁雪对话1次
- 奖励：经验300，穆宁雪好感+10，技能点1
- 完成后设置flag `mu_ningxue_path_done`

**任务"内心的抉择"**（选择3后触发）：
- 目标：图书馆3次（查阅资料）+ 与穆宁雪对话2次
- 奖励：经验400，穆宁雪好感+15，学校声望+10
- 完成后设置flag `mu_ningxue_choice_done`

### 事件3：冰系的极致（好感≥80触发，完成事件2）

**触发方式**：与穆宁雪对话时触发

**事件内容**：
> 穆宁雪找到你，眼神中带着从未有过的认真。"我想清楚了。冰系的极致，不是寒冷，是绝对的宁静。"她看着你，"这条路很难，我一个人走可能会迷失。你愿意...和我一起追求吗？"

**选择分支**：
1. **我愿意和你一起** → 好感+10，设置flag `mu_ningxue_ice_extreme`，触发任务"冰极之路"
2. **我有自己的路，但我支持你** → 好感+5，设置flag `mu_ningxue_support`，穆宁雪点头，"谢谢你"，触发任务"各自的道路"
3. **冰系的极致可能不是你想的那样** → 好感-3，设置flag `mu_ningxue_doubt`，穆宁雪皱眉，"你不懂"，但触发任务"理念的碰撞"

**任务"冰极之路"**（选择1后触发）：
- 目标：冥修10次 + 图书馆5次 + 与穆宁雪对话3次
- 奖励：经验800，穆宁雪好感+20，技能点2，称号"冰极同行者"
- 完成后设置flag `mu_ningxue_extreme_done`

**任务"各自的道路"**（选择2后触发）：
- 目标：与穆宁雪对话1次 + 修炼5次
- 奖励：经验400，穆宁雪好感+10
- 完成后设置flag `mu_ningxue_separate_done`

**任务"理念的碰撞"**（选择3后触发）：
- 目标：与穆宁雪对话3次（辩论）+ 图书馆3次
- 奖励：经验500，穆宁雪好感+5（不打不相识），学校声望+15
- 完成后设置flag `mu_ningxue_debate_done`

## 三、NPC间联动

### 穆白的反应
- 当玩家与穆宁雪关系≥50时，穆白的对话会变化："你和宁雪走得很近？穆家的事...你最好别掺和太深。"
- 当玩家完成"家族的召唤"任务后，穆白好感+10，会说："谢谢你关心穆家的事。"

### 唐月的反应
- 当玩家与穆宁雪关系≥50时，唐月可能触发对话："穆宁雪是个有天赋的学生，但她的压力很大。你如果和她走得近，多照顾她。"

## 四、可玩性分析

### 深度来源
1. **3个事件 × 3个选择 = 9种路线**
2. **事件2的选择影响事件3的内容**：选择家族责任的玩家，事件3中穆宁雪的态度不同
3. **NPC间联动**：穆白、唐月的对话随关系变化
4. **称号系统**："冰极同行者"等称号有实际意义

### 与唐月线的互补
- 唐月线：师生关系，侧重指导与成长
- 穆宁雪线：同学/竞争者关系，侧重理念与选择
- 两条线可以并行，玩家可以同时发展

## 五、技术实现

- 复用v0.61.0关系驱动任务框架
- 在events.js中添加3个穆宁雪事件
- 在quests.js中添加7个对应任务
- 事件触发条件：minRelationship + requireFlag + notFlag
- 任务触发条件：requireFlag
- 任务奖励：setFlag（任务链推进）

## 六、验收标准

1. 穆宁雪好感30时，修炼有概率触发"冰系的认可"事件
2. 事件有3个选择分支，选择后设置对应flag
3. 选择1/3后触发"冰系切磋"任务
4. 完成任务1后，好感50时触发"穆家的压力"事件
5. 事件2有3个选择，触发不同任务
6. 完成任务2后，好感80时触发"冰系的极致"事件
7. NPC间联动：穆白/唐月对话随关系变化
8. node --check语法通过
