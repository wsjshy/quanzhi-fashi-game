## 六、测试建议

### 1. 点击策略
- 优先使用按钮文字/特征识别，而非固定坐标
- 固定坐标仅适用于标题界面等静态布局
- 动态按钮（行动、技能、商品）建议通过DOM查询后点击

### 2. 常见问题
- **点击无反应**：可能是坐标偏差，尝试上下偏移10-20px
- **点击穿透**：消息弹窗关闭后500ms内不要点击
- **按钮被遮挡**：检查z-index和pointer-events设置
- **弹窗未关闭**：检查是否有关闭按钮，或点击弹窗外区域

### 3. 自动化测试脚本示例
```javascript
// 通过文字查找按钮并点击
function clickButtonByText(text) {
    const buttons = document.querySelectorAll('button, div[onclick]');
    for (const btn of buttons) {
        if (btn.textContent.includes(text)) {
            btn.click();
            return true;
        }
    }
    return false;
}

// 示例：点击"修炼"按钮
clickButtonByText('修炼');
```

### 4. 窗口大小影响
- 本文档坐标基于 1280x800
- 窗口最大化时坐标会变化
- 建议测试时保持固定窗口大小
- 响应式布局下，按钮位置可能自适应调整
