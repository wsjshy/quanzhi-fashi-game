> 版本：v0.67.0

> 类型：剧情事件链 / 玩家影响力核心实现

---

## 一、为什么做这个

### 1.1 延续第一阶段的选择影响力
v0.66.0实现了博城灾难第一阶段（异常迹象），玩家有4个选择。第二阶段需要基于这些选择展开不同的应对路径，让玩家真正感受到"我的选择有意义"。

### 1.2 分路线设计
基于第一阶段的选择，分为两条主要路径：
- **有预警路径**（告诉唐月/告诉穆宁雪/自己调查）：玩家提前知道异常，可以主动准备
- **无预警路径**（忽略异常）：玩家没有预警，异常加剧时被动应对

### 1.3 为第三阶段（灾难降临）做铺垫
第二阶段的准备程度将直接影响第三阶段灾难的严重程度和玩家的角色。

## 二、事件设计

### 2.1 事件1：备战的气息（有预警路径）

**触发条件**：
- requireFlag: ["bd_tell_tangyue", "bd_tell_muningxue", "bd_investigate_alone"]（满足任意一个）
- notFlag: bocheng_phase2_done
- minLevel: 16
- weight: 30
- npcId: tang_yue

**事件描述**：
学校的气氛变得有些不同。巡逻的老师多了起来，训练馆的防御法阵被重新加固。唐月找到你，表情严肃："你之前发现的异常...我们调查后确认，博城的地圣泉能量波动异常，可能有大事发生。学校正在秘密准备，你愿意帮忙吗？"

**选择分支（3个）**：

#### 选择1：全力协助学校准备
- effects: { setFlag: ["bd_full_prep", "bocheng_phase2_done"], npcOpinion: { tang_yue: 5 }, reputation: 10 }
- resultText: 你点头："我能做什么？"唐月递给你一份清单："协助巡逻、加固防御法阵、通知同学。你的贡献学校会记住。"唐月好感+5，学校声望+10，进入全面备战状态

#### 选择2：专注提升自己的实力
- effects: { setFlag: ["bd_self_prep", "bocheng_phase2_done"], exp: 100 }
- resultText: 你说："如果真有大事，我需要更强的实力。"唐月理解地点头："也好，实力是根本。去修炼吧，有事我会找你。"经验+100，玩家专注自我提升

#### 选择3：暗中调查真相
- effects: { setFlag: ["bd_secret_investigate", "bocheng_phase2_done"], npcOpinion: { tang_yue: -3 } }
- resultText: 你觉得学校的准备还不够，决定自己暗中调查真相。唐月有些不满："别乱来，这不是你一个学生能承担的。"但你已经下定决心。唐月好感-3，玩家开始秘密调查

### 2.2 事件2：异常加剧（无预警路径）

**触发条件**：
- requireFlag: bd_ignore
- notFlag: bocheng_phase2_done
- minLevel: 16
- weight: 30
- npcId: tang_yue

**事件描述**：
你在修炼时，突然感到地面微微震动。窗外，几只低级妖魔在白天乱窜，学生们惊慌失措。唐月老师匆匆跑来："所有人注意！妖魔活动异常，立刻回到教室！"她看到你，"你也看到了吧？之前那些异常...原来是真的。"她的语气中带着一丝自责。

**选择分支（3个）**：

#### 选择1：主动参与疏散同学
- effects: { setFlag: ["bd_evacuation", "bocheng_phase2_done"], npcOpinion: { tang_yue: 8 }, reputation: 15 }
- resultText: 你立刻行动："大家跟我来，不要慌！"你有序地疏散同学，唐月感激地看了你一眼。唐月好感+8，学校声望+15，玩家在危机中展现领导力

#### 选择2：去调查妖魔来源
- effects: { setFlag: ["bd_investigate_source", "bocheng_phase2_done"], exp: 80 }
- resultText: 你决定冒险去调查妖魔来源。沿着妖魔出现的方向，你发现了空间波动的痕迹——有人在故意引妖魔入城。经验+80，玩家发现关键线索

#### 选择3：先保证自己安全
- effects: { setFlag: ["bd_self_safety", "bocheng_phase2_done"] }
- resultText: 你选择先回到安全的地方。这不是懦弱，只是理智——你还没有准备好面对未知的危险。但你心里知道，这件事还没结束...

## 三、对应任务

### 任务1：备战准备（有预警路径，requireFlag: bd_full_prep）
- 目标：修炼2次 + 探索1次 + 与唐月对话1次
- 奖励：经验300 + 金币200 + 技能点1 + setFlag: bd_prep_complete
- 描述：协助学校备战，巡逻、加固防御、提升实力

### 任务2：危机应对（无预警路径，requireFlag: bd_evacuation 或 bd_investigate_source）
- 目标：击败1个妖魔 + 与唐月对话1次 + 修炼1次
- 奖励：经验250 + 金币150 + setFlag: bd_crisis_handled
- 描述：应对突发的妖魔异常，保护同学或调查真相

## 四、选择的长期影响（第三阶段铺垫）

### 有预警路径
- **全力协助**（bd_full_prep）：学校防御充分，第三阶段灾难伤亡大幅减少，玩家是英雄
- **专注实力**（bd_self_prep）：玩家实力提升，第三阶段能发挥更大作用，但学校准备一般
- **暗中调查**（bd_secret_investigate）：玩家可能发现黑教廷阴谋，第三阶段有机会从根源阻止

### 无预警路径
- **疏散同学**（bd_evacuation）：玩家在危机中展现领导力，第三阶段成为核心人物
- **调查来源**（bd_investigate_source）：玩家发现空间波动线索，第三阶段有特殊应对手段
- **保证安全**（bd_self_safety）：玩家准备不足，第三阶段灾难更严重，但玩家存活概率高

## 六、深度来源

1. **选择的延续性**：第一阶段的选择直接影响第二阶段的剧情路径
2. **准备vs应对**：有预警可以主动准备，无预警只能被动应对
3. **多种应对策略**：协助官方/专注实力/暗中调查，每种策略有不同的长期影响
4. **道德与风险**：无预警路径中，保护他人vs调查真相vs保证安全，有道德选择深度
5. **为第三阶段铺垫**：每个选择都将影响灾难降临的结局
