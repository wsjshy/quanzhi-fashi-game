## 补充原则
1. **小说驱动** - 每个天赋都要有原著依据
2. **单点查找** - 缺什么找什么，不用系统拆解
3. **复用优先** - 能用现有效果类型就用数据配置
4. **逐步完善** - 先做重要的，再做次要的

---

## 补充顺序（优先级从高到低）
1. 第一卷出现频率高的妖魔
2. 玩家经常遇到的妖魔
3. 有特色的妖魔
4. 其他妖魔
