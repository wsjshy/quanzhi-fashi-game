# 剧情系统架构设计

> 版本：v1.0 | 日期：2026-08-14
> 状态：设计中，待实现

---

## 一、设计目标

1. **数据驱动**：剧情内容完全由数据定义，后续拆小说只需加数据，不改引擎
2. **可扩展**：遇到新概念（如三步塔、契约召唤、灵魂战斗）可作为新系统自然插入
3. **有主线感**：玩家始终知道"当前该做什么"，有章节推进感
4. **自由度**：主线之外有支线、NPC互动、随机事件，不强制线性
5. **可回溯**：已完成的章节可回顾（剧情回想）

---

## 二、系统分层

```
卷(Volume) → 章(Chapter) → 节(Beat) → 任务/对话/事件/战斗
```

### 2.1 卷（Volume）
- 大的故事篇章，对应小说卷
- 例：`vol1_bocheng`（博城篇）、`vol2_mingzhu`（明珠篇）
- 包含：主题、主要地点、核心NPC、新系统介绍

### 2.2 章（Chapter）
- **核心推进单位**，对应小说5-20章
- 有明确的开始/结束条件
- 包含：主线任务链、关键对话、解锁内容、章节奖励
- 完成后自动推进到下一章

### 2.3 节（Beat/Scene）
- 章节内的具体剧情节点
- 类型：叙事(narrative)、选择(choice)、战斗(battle)、探索(explore)、教学(tutorial)
- 可由任务、对话、大事件实现

### 2.4 任务（Quest）
- 玩家可追踪的具体目标
- 主线任务（main quest）驱动章节
- 支线任务（side quest）丰富世界
- 角色任务（character quest）深化NPC关系

## 三、章节数据结构

```javascript
chapter_xxx: {
  id: "chapter_01_awakening",
  name: "第一章·觉醒",
  volume: "vol1_bocheng",
  novelChapters: [1, 5],          // 对应小说章节范围
  description: "魔法高考，雷火双系觉醒",
  
  // 开始条件（满足任一即可开始）
  startConditions: {
    gameStart: true,              // 新游戏开始
    // 或 previousChapterCompleted: "chapter_00_prologue"
    // 或 requiredQuests: ["quest_xxx"],
    // 或 minLevel: 5,
    // 或 requiredFlags: ["xxx"]
  },
  
  // 完成条件（全部满足即章节完成）
  completeConditions: {
    allQuestsCompleted: ["quest_awakening"],
    // 或 requiredFlags: ["xxx"],
    // 或 minLevel: 10
  },
  
  // 主线任务（按顺序接取）
  mainQuestChain: ["quest_awakening_ceremony"],
  
  // 支线任务（章节期间可接）
  sideQuests: ["quest_collect_herbs", "quest_hunt_wolf_pack"],
  
  // 关键NPC（本章解锁/重要）
  keyNPCs: ["tang_yue"],
  
  // 解锁内容
  unlocks: {
    locations: ["tianlan_school"],
    systems: ["basic_combat", "cultivation"],  // 新系统教学
    features: ["inventory", "shop"]
  },
  
  // 章节奖励
  rewards: {
    exp: 100,
    gold: 50,
    items: [{ itemId: "health_potion", count: 3 }]
  },
  
  // 下一章
  nextChapter: "chapter_02_school_life",
  
  // 章节开始时的剧情（可选，视觉小说式）
  openingCinematic: null,  // storyId
  
  // 章节结束时的剧情（可选）
  endingCinematic: null,
  
  // 章节标签（用于UI显示）
  tags: ["tutorial", "awakening"]
}
```

## 四、触发与推进机制

### 4.1 章节开始
- 新游戏 → 自动开始第一章
- 上一章完成 → 自动开始下一章
- 检查点：每次切换场景/完成任务/升级时检查

### 4.2 任务接取
- 章节开始后，主线任务自动接取（或提示去找NPC）
- 支线任务通过NPC对话/地点探索接取
- 对话树中通过 `effects.startQuest` 接取

### 4.3 章节完成检查
- 主线任务全部完成 → 章节完成
- 弹出章节完成界面，显示奖励
- 自动推进到下一章
- 如果下一章有openingCinematic，播放

### 4.4 自由度处理
- 主线任务有推荐等级，但不强制
- 玩家可以自由探索、刷怪、做支线
- 高等级可以提前进入某些内容
- 但关键剧情节点需要满足条件

## 五、新系统引入机制

章节可以引入新游戏系统，通过 `unlocks.systems` 标记：

| 系统 | 引入章节 | 方式 |
|------|---------|------|
| 基础战斗 | 第1章 | 教学战 |
| 修炼/星子 | 第2章 | 唐月教学 |
| 装备/背包 | 第2章 | 商店开放 |
| 灵种 | 第6章 | 地圣泉获得 |
| 境界突破 | 第3章 | 中阶突破教学 |
| 天赋 | 第4章 | 天赋觉醒 |
| 第二系觉醒 | 第7章 | 中阶后觉醒 |
| 大事件 | 第5章 | 博城灾难 |
| 三步塔 | 明珠篇 | 修炼加速 |
| 契约召唤 | 明珠篇 | 召唤系中阶 |

引入新系统时：
1. 弹出教学提示
2. 相关UI高亮/引导
3. 可能有教学战斗/任务

## 六、博城篇章节规划（1-120章）

### 第一章·觉醒（小说1-5章）
- **内容**：莫凡穿越，魔法高考，觉醒雷系（明面）+火系（暗），小泥鳅坠
- **主线**：觉醒仪式
- **解锁**：天澜魔法高中，唐月，基础战斗，修炼系统
- **新系统**：觉醒、修炼、基础战斗UI

### 第二章·天澜魔法高中（小说6-20章）
- **内容**：入学，穆宁雪/张小侯，唐月指导，星子修炼，校园生活
- **主线**：修炼到初阶1级，学会火滋
- **解锁**：商店、背包、装备、张小侯、穆宁雪
- **新系统**：技能升级、装备、商店

### 第三章·雪峰山历练（小说21-40章）
- **内容**：雪峰山实践，幽狼兽，第一次实战，罗宋冲突
- **主线**：雪峰山历练任务，击败幽狼兽
- **解锁**：雪峰山，野外地图，猎魔任务
- **新系统**：野外战斗、掉落、经验值

### 第四章·博城暗流（小说41-60章）
- **内容**：黑教廷线索，穆氏家族，宇昂，朝赫，炼兽之血
- **主线**：调查黑教廷踪迹，与宇昂冲突
- **解锁**：宇昂（敌对），朝赫，黑教廷势力
- **新系统**：声望系统、敌对NPC

### 第五章·博城灾难（小说61-85章）
- **内容**：黑教廷发动，妖魔攻城，大逃亡，唐月受伤，莫凡力战
- **主线**：博城灾难大事件（多阶段战斗+选择）
- **解锁**：大事件系统，多阶段Boss战
- **新系统**：大事件、分支选择、多结局

### 第六章·地圣泉（小说86-100章）
- **内容**：地圣泉修炼，小泥鳅进阶，灵种获得，实力大增
- **主线**：进入地圣泉，修炼到中阶
- **解锁**：灵种系统，小泥鳅进阶
- **新系统**：灵种、星尘魔器进阶

### 第七章·离开博城（小说101-120章）
- **内容**：灾后重建，第二系觉醒？不，莫凡已经双系。前往明珠学府
- **主线**：博城善后，前往明珠
- **解锁**：明珠学府（新地图）
- **新系统**：第二系觉醒（其他玩家）、地图切换

## 八、与现有系统的关系

| 现有系统 | 章节系统中的角色 |
|---------|---------------|
| quest.js | 章节内的任务目标，主线任务链驱动章节 |
| dialogue-tree.js | NPC对话，接取/完成任务，条件对话 |
| big-event.js | 章节高潮事件（如博城灾难） |
| event.js | 随机事件，丰富章节期间体验 |
| npc-state.js | NPC好感度，随章节推进变化 |
| world-state.js | 世界状态/声望，章节间持久化 |
| story.js | 章节开场/结局的视觉小说式叙事 |

## 九、实现计划

1. **story-chapter.js** - 章节管理引擎
   - 当前章节追踪
   - 开始/完成条件检查
   - 章节奖励发放
   - 自动推进逻辑
   - 存档/读档

2. **chapters.js** - 章节数据文件
   - 博城篇7章
   - 明珠篇3章（已拆解范围）
   - 后续章节模板

3. **UI集成**
   - 章节标题显示
   - 主线任务追踪面板
   - 章节完成界面
   - 新系统教学提示

4. **数据串联**
   - 把现有任务归入对应章节
   - 补充缺失的主线任务
   - 确保对话树能接取任务
