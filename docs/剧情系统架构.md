# 剧情系统架构设计

> 版本：v1.0 | 日期：2026-08-14
> 状态：设计中，待实现

---

## 一、设计目标

1. **数据驱动**：剧情内容完全由数据定义，后续拆小说只需加数据，不改引擎
2. **可扩展**：遇到新概念（如三步塔、契约召唤、灵魂战斗）可作为新系统自然插入
3. **有主线感**：玩家始终知道"当前该做什么"，有章节推进感
4. **自由度**：主线之外有支线、NPC互动、随机事件，不强制线性
5. **可回溯**：已完成的章节可回顾（剧情回想）

---

## 二、系统分层

```
卷(Volume) → 章(Chapter) → 节(Beat) → 任务/对话/事件/战斗
```

### 2.1 卷（Volume）
- 大的故事篇章，对应小说卷
- 例：`vol1_bocheng`（博城篇）、`vol2_mingzhu`（明珠篇）
- 包含：主题、主要地点、核心NPC、新系统介绍

### 2.2 章（Chapter）
- **核心推进单位**，对应小说5-20章
- 有明确的开始/结束条件
- 包含：主线任务链、关键对话、解锁内容、章节奖励
- 完成后自动推进到下一章

### 2.3 节（Beat/Scene）
- 章节内的具体剧情节点
- 类型：叙事(narrative)、选择(choice)、战斗(battle)、探索(explore)、教学(tutorial)
- 可由任务、对话、大事件实现

### 2.4 任务（Quest）
- 玩家可追踪的具体目标
- 主线任务（main quest）驱动章节
- 支线任务（side quest）丰富世界
- 角色任务（character quest）深化NPC关系

  },

  // 支线任务（章节期间可接）

  // 章节结束时的剧情（可选）

  // 章节标签（用于UI显示）
  tags: ["tutorial", "awakening"]
}

## 四、触发与推进机制

### 4.1 章节开始
- 新游戏 → 自动开始第一章
- 上一章完成 → 自动开始下一章
- 检查点：每次切换场景/完成任务/升级时检查

### 4.2 任务接取
- 章节开始后，主线任务自动接取（或提示去找NPC）
- 支线任务通过NPC对话/地点探索接取
- 对话树中通过 `effects.startQuest` 接取

### 4.3 章节完成检查
- 主线任务全部完成 → 章节完成
- 弹出章节完成界面，显示奖励
- 自动推进到下一章
- 如果下一章有openingCinematic，播放

### 4.4 自由度处理
- 主线任务有推荐等级，但不强制
- 玩家可以自由探索、刷怪、做支线
- 高等级可以提前进入某些内容
- 但关键剧情节点需要满足条件

## 五、新系统引入机制

章节可以引入新游戏系统，通过 `unlocks.systems` 标记：

| 系统 | 引入章节 | 方式 |
|------|---------|------|
| 基础战斗 | 第1章 | 教学战 |
| 修炼/星子 | 第2章 | 唐月教学 |
| 装备/背包 | 第2章 | 商店开放 |
| 灵种 | 第6章 | 地圣泉获得 |
| 境界突破 | 第3章 | 中阶突破教学 |
| 天赋 | 第4章 | 天赋觉醒 |
| 第二系觉醒 | 第7章 | 中阶后觉醒 |
| 大事件 | 第5章 | 博城灾难 |
| 三步塔 | 明珠篇 | 修炼加速 |
| 契约召唤 | 明珠篇 | 召唤系中阶 |

引入新系统时：
1. 弹出教学提示
2. 相关UI高亮/引导
3. 可能有教学战斗/任务

## 十、剧情深度设计（核心原则）

> 剧情不是小说内容的线性填充。每章填充时必须考虑：伏笔、隐藏、分支、人物深度、重复可玩性。

### 10.1 伏笔系统（Foreshadowing）

**定义**：前期不经意出现的细节，后期回收时让玩家恍然大悟。

**伏笔类型**：

| 类型 | 说明 | 例子 |
|------|------|------|
| 物品伏笔 | 早期获得的普通物品，后期觉醒特殊能力 | 小泥鳅坠（第1章→极级器皿→古老王相关） |
| 人物伏笔 | NPC的言行暗示其真实身份/秘密 | 唐月偶尔的神秘电话、超出实习老师的实力 |
| 环境伏笔 | 场景细节暗示未来事件 | 博城地下的异常魔力波动、雪峰山妖魔迁徙的真正原因 |
| 对话伏笔 | NPC无意中说的话，后来才懂含义 | 斩空说"有些事知道了反而危险" |
| 世界观伏笔 | 信息碎片拼凑出隐藏真相 | 黑教廷不是简单的邪教，背后有更深的势力 |

**实现方式**：
- 对话树中设置`foreshadow`标记的节点，条件不满足时显示为普通对话
- 物品描述中暗示（"这枚旧坠子似乎有某种微弱的波动"）
- 地点描述中的环境细节
- 回收时设置flag，触发特殊对话/事件

**博城篇伏笔清单**：

1. **小泥鳅坠**（第1章）
   - 获得时：普通的旧坠子，感觉有微弱波动
   - 第6章地圣泉：吸收泉力后微微发热
   - 后期：觉醒为极级星尘魔器
   - 实现：物品描述随flag变化，特定地点触发反应

2. **唐月的身份**（第2章起）
   - 普通对话：实习老师，火系法师
   - 隐藏对话（高信任）：偶尔接到神秘任务离开
   - 博城灾难时：展现远超中阶的实力
   - 回收：审判会暗部成员身份揭露
   - 实现：条件对话节点，trust>60解锁

3. **黑教廷的渗透**（第3-4章）
   - 雪峰山妖魔异常不是自然现象
   - 博城有内鬼（宇昂、朝赫）
   - 穆氏家族与黑教廷的微妙关系
   - 实现：信息碎片收集，NPC传闻

4. **穆宁雪的天赋**（第2章起）
   - 表面：穆氏家族天才，冰系
   - 隐藏：天生灵体？冰系天生天赋？
   - 实现：特定条件下的战斗表现差异

5. **斩空的秘密**（第5章）
   - 博城军法师，实力深不可测
   - 对古老王/秦始皇陵的异常了解
   - 后期：成为古老王
   - 实现：高好感对话透露线索

6. **地圣泉的秘密**（第6章）
   - 表面：修炼圣地
   - 隐藏：下面是古老王陵墓
   - 实现：探索时发现异常，信息碎片

7. **叶心夏**（第1章提及）
   - 莫凡的义妹，身体虚弱
   - 后期：帕特农神庙女侍，撒朗之女
   - 实现：莫凡偶尔提到，信件

### 10.2 隐藏内容（Secrets）

**定义**：不直接标记，需要玩家主动探索/满足条件才发现的内容。

**隐藏内容类型**：

| 类型 | 触发条件 | 奖励 |
|------|---------|------|
| 隐藏对话 | 特定时间+地点+好感+flag | 世界观信息、伏笔线索 |
| 隐藏任务 | 探索发现/连续选择/特定NPC | 稀有物品、经验、特殊称号 |
| 隐藏商店 | 特定时间/地点/声望 | 稀有商品 |
| 信息碎片 | 多来源收集拼凑 | 揭露隐藏剧情 |
| 隐藏战斗 | 特殊条件触发 | 稀有掉落、成就 |
| NPC秘密 | 高好感/信任+特定事件 | 深入背景故事 |

**实现方式**：
- 对话树中设置`hidden: true`的节点，需要特定flag/好感/时间才显示
- 事件系统中设置低概率/高条件的隐藏事件
- 地点行动中设置隐藏行动（需要探索发现）
- 信息碎片系统：收集N个碎片后解锁特殊对话/事件

**博城篇隐藏内容规划**：

1. **唐月的秘密**（第2-4章）
   - 条件：trust>50 + 晚上去学校
   - 内容：看到唐月在和神秘人说话，提到"审判会"
   - 奖励：信息碎片"审判会的存在"

2. **废弃仓库**（第3-4章）
   - 条件：探索博城旧区
   - 内容：发现黑教廷的仪式痕迹
   - 奖励：隐藏任务"调查黑教廷据点"

3. **穆白的笔记**（第4章）
   - 条件：与穆白切磋胜利后
   - 内容：发现穆白在研究黑魔法
   - 奖励：信息碎片"穆白的秘密"

4. **雪峰山山洞**（第3章）
   - 条件：深入雪峰山探索
   - 内容：发现古代魔法遗迹
   - 奖励：稀有灵种碎片

5. **斩空的故事**（第5章后）
   - 条件：好感>60 + 博城灾难后
   - 内容：斩空讲述他为什么留在博城
   - 奖励：信息碎片"斩空的过去"

### 10.3 分支选择（Branching）

**定义**：玩家的选择影响后续剧情走向，不是假选择。

**分支类型**：

| 类型 | 影响范围 | 例子 |
|------|---------|------|
| 即时分支 | 当前事件结局 | 博城灾难中救A还是救B |
| 关系分支 | NPC关系走向 | 与穆宁雪是敌是友 |
| 道德分支 | 声望/阵营 | 对黑教廷余孽的处置 |
| 信息分支 | 知道/不知道真相 | 是否发现唐月的秘密 |
| 长期分支 | 后续章节内容 | 博城灾难中的选择影响明珠篇NPC态度 |

**实现方式**：
- 大事件系统的choice类型已支持分支
- 对话树的选项设置effects（设置flag、改变好感）
- 后续对话/事件检查flag决定内容
- 章节完成时记录关键选择

**博城篇关键分支**：

1. **博城灾难中的救援选择**（第5章）
   - 救同学 vs 救市民 vs 追击黑教廷
   - 影响：NPC生死、声望、后续感谢/怨恨

2. **对宇昂的态度**（第4-5章）
   - 正面冲突 vs 暗中调查
   - 影响：宇昂的警惕度、战斗难度

3. **是否发现唐月的秘密**（第2-4章）
   - 发现：唐月更信任你，提前知道审判会
   - 未发现：唐月保持距离，但灾难时更惊讶她的实力

4. **与穆宁雪的关系**（第2章起）
   - 友好/竞争/敌对
   - 影响：后续互动、切磋奖励、明珠篇态度

5. **对穆白的态度**（第4章）
   - 和解 vs 敌对
   - 影响：穆白后续走向（黑教廷？）

### 10.4 人物深度（Character Depth）

每个重要NPC不应该是任务发布机器，要有：
- **自己的目标和动机**：唐月不只是老师，她有自己的任务
- **性格多面性**：张小侯看似胆小但关键时刻勇敢
- **成长变化**：经历事件后NPC态度/实力变化
- **人际关系网**：NPC之间有关系，不是孤立的
- **个人故事线**：每个重要NPC有自己的小剧情

### 10.5 信息碎片系统（Lore Fragments）

**设计**：收集分散的信息碎片，拼凑出世界观真相。

**碎片来源**：
- NPC对话（不同NPC说不同部分）
- 书籍/笔记（图书馆、NPC房间）
- 环境探索（墙上的标记、地上的信件）
- 战斗胜利后的敌人供述
- 任务奖励

**碎片分类**：
- 黑教廷相关（组织结构、目的、成员）
- 魔法世界历史（古老王、帕特农、魔法帝国）
- NPC背景（个人故事）
- 妖魔知识（种类、习性、弱点）
- 势力关系（审判会、魔法协会、军方）

**实现**：
- WorldState.infoFragments数组
- 收集足够碎片解锁特殊对话/事件/成就
