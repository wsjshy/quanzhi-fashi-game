# 全职法师同人游戏 - 架构说明

## 设计理念

**数据驱动 + 模块化架构**，代码与内容完全分离。
- 引擎代码一次写好，永久复用
- 所有游戏内容用 JSON 定义，新增内容只需加 JSON 文件
- 按照小说卷数逐步扩充，每卷对应一个内容包

### 数据层设计（v0.4.0 重构）

原 `game-data.js`（9200+行，374KB）已拆分为 `engine/data/` 下的多个模块：

- **拆分原则**：按数据类型分文件，每个文件一个全局常量（如 `DataSkills`、`DataCharacters`）
- **合并入口**：`engine/data/index.js` 将所有模块合并为全局 `GameData` 对象
- **加载顺序**：index.html 中先加载所有数据模块，再加载 index.js，最后加载引擎代码
- **向后兼容**：GameData 对象结构不变，所有引擎代码无需修改
- **工具支持**：`tools/split-game-data.js` 可重新拆分，`tools/verify-split.js` 验证数据一致性

## 核心系统模块

### 1. 玩家系统 (player.js)
- 角色属性：HP、MP、攻击、防御、速度、精神力
- 元素觉醒：已觉醒的元素列表
- 技能列表：已学习的技能
- 背包系统：道具、装备
- 金钱：金币数量
- 等级与经验
- 属性点：升级可分配
- 声望：各势力好感度

### 2. 地图系统 (map.js)
- 地点列表：当前可前往的地点
- 地点功能：每个地点有不同的行动选项
- 移动消耗：时间、金钱
- 解锁条件：某些地点需要满足条件才能进入

### 3. 时间系统 (time.js)
- 天数计数：第 N 天
- 时段：早上、下午、晚上
- 行动消耗时间：不同行为消耗不同时长
- 定时事件：特定天数触发的事件

### 4. 战斗系统 (battle.js)
- 回合制战斗
- 技能释放与冷却
- 元素克制计算
- 状态效果（灼烧、麻痹、减速等）
- 暴击与命中
- 战斗奖励（经验、金币、道具）
- 逃跑机制

### 5. 技能系统 (skill.js)
- 技能数据管理
- 伤害计算
- 状态效果施加
- 技能学习与升级

### 6. 任务系统 (quest.js)
- 任务接取与交付
- 任务进度追踪
- 任务奖励发放
- 任务链支持

### 7. 事件系统 (event.js)
- 随机事件触发
- 选项分支
- 条件判断
- 结果应用

### 8. 商店系统 (shop.js)
- 商品列表
- 购买与出售
- 价格浮动

## 扩展原则

1. **向后兼容**：新增内容不影响已有内容
2. **模块化**：每个内容单元独立成文件
3. **数据驱动**：能用 JSON 配置的就不写代码
4. **渐进式**：从简单到复杂，逐步完善
5. **可复用**：通用内容放在 shared 里
