# v0.49.0 智能目标引导系统设计

> 版本：v0.49.0
> 日期：2026-08-15
> 定位：解决测试反馈"中期目标感不足"，让玩家在Lv.10+之后知道该做什么

---

## 一、问题

黑盒测试反馈：中期（Lv.10+）目标感不足。现有`getCurrentGoalText()`在无任务时只显示"继续修炼或刷怪升级"等通用提示，缺乏具体方向。

### 现有目标逻辑
1. 体力低 → 提示休息
2. HP低 → 提示恢复
3. 有未分配属性点 → 提示分配
4. 有进行中任务 → 显示任务进度
5. Lv.1-3 → 新手提示
6. 其他 → 通用经验进度提示

### 缺失
- Lv.4+无任务时没有有意义的引导
- 不推荐具体行动（找谁聊天、去哪探索、买什么装备）
- 不基于玩家状态动态推荐

---

## 二、设计目标

1. **中期有方向**：Lv.4+无任务时，基于玩家状态推荐2-3个具体行动
2. **不强制**：只是建议，玩家可以忽略
3. **动态变化**：随着玩家状态变化，推荐也变化
4. **自然融入**：在现有目标提示面板中展示，不增加新UI复杂度

---

## 三、实现方案

### 3.1 增强getCurrentGoalText()

在现有逻辑基础上，增加中期目标推荐（Lv.4+且无任务时）：

按优先级检查：
1. **装备缺失**：如果没有武器/防具，推荐"去小卖部购买装备"
2. **药水不足**：如果治愈药水<3，推荐"购买药水"
3. **NPC关系空白**：如果所有主要NPC好感<10，推荐"找人聊天建立关系"
4. **影响力低**：如果影响力<10，推荐"完成任务/帮助NPC提升影响力"
5. **等级突破**：如果可突破境界，推荐"突破境界"
6. **探索度低**：如果当前地点探索度<50%，推荐"探索当前地点"
7. **默认**：基于经验进度的通用提示

### 3.2 推荐行动面板

在目标提示面板下方，增加"推荐行动"区域，显示1-2个最优先的具体行动。

格式：`💡 推荐：{具体行动}（{原因}）`

示例：
- `💡 推荐：找人聊天（你还没有建立任何NPC关系）`
- `💡 推荐：去小卖部买武器（你还没有装备武器）`
- `💡 推荐：突破境界（你已满足突破条件）`

### 3.3 数据驱动

推荐逻辑基于玩家实际状态，不硬编码等级阶段。每个推荐有明确的触发条件和优先级。

---

## 四、验证标准

1. Lv.10无任务时，目标提示显示具体推荐而非通用提示
2. 购买装备后，装备推荐消失
3. 建立NPC关系后，关系推荐消失
4. 有任务时，任务进度优先显示
5. 推荐不重复、不矛盾
6. 手机端显示正常
