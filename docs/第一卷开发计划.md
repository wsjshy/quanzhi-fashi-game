# 第一卷（博城篇）Demo 开发计划

## Demo 目标
打造一个局部完整的第一卷demo，玩家可以体验从觉醒到博城灾难的完整剧情流程。
这是后续所有工作的基础和起点。

---

## 核心剧情线

### 第一阶段：觉醒与入学（第1-7天）
1. 魔法觉醒 - 玩家选择自己的元素
2. 进入天澜魔法高中
3. 认识同学和老师
4. 基础修炼学习
5. 入学考核

### 第二阶段：修炼与成长（第8-20天）
1. 日常修炼与上课
2. 期中测试
3. 同学关系发展
4. 接取基础任务
5. 第一次猎魔

### 第三阶段：深入与探索（第21-35天）
1. 期末考核
2. 雪峰山历练
3. 妖魔异动预警
4. 黑教廷线索
5. 穆氏家族剧情

### 第四阶段：博城灾难（第40-50天）
1. 灾难爆发
2. 城市沦陷
3. 逃亡与救援
4. 重要抉择
5. 撤离博城

## 开发步骤

### 第一步：剧情框架搭建
1. 梳理第一卷主线剧情节点
2. 设计事件链结构
3. 确定主要分支和结局
4. 设计关键抉择点

### 第二步：NPC内容扩充
1. 丰富已有NPC的对话内容
2. 添加NPC个人任务线
3. 添加NPC间互动事件
4. 新增重要NPC

### 第三步：地点扩充
1. 添加新地点
2. 设计地点行动
3. 添加地点专属事件
4. 地点解锁条件

### 第四步：任务系统完善
1. 主线任务链
2. 支线任务补充
3. 任务条件与分支
4. 任务奖励平衡

### 第五步：大事件与结局
1. 博城灾难事件链
2. 多结局设计
3. 玩家选择影响
4. 结局判定与奖励

### 第六步：测试与优化
1. 完整流程测试
2. 平衡性调整
3. Bug修复
4. 体验优化
