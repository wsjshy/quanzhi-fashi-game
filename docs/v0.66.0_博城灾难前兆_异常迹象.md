# v0.66.0 博城灾难前兆事件链（第一阶段：异常迹象）

> 版本：v0.66.0
> 日期：2026-08-15
> 类型：剧情事件链 / 玩家影响力核心实现

---

## 一、为什么做这个

### 1.1 实现玩家真实影响力
用户核心需求："玩家有真实影响力能改变剧情，甚至可以改变原著剧情"。目前的关系系统（个人关系线+NPC联动）实现了玩家对NPC关系的影响，但还没有触及**改变原著重大事件**这个终极目标。

博城灾难是《全职法师》原著中的关键事件，玩家的行为可以影响灾难的走向和损失程度，这是玩家影响力的终极体现。

### 1.2 原著背景
博城灾难发生在开学后不久：
- 黑教廷策划，利用博城的地圣泉吸引妖魔
- 城市被妖魔大军入侵
- 穆宁雪的冰系领域在防御中发挥关键作用
- 莫凡在灾难中表现突出
- 大量学生和居民伤亡

### 1.3 分阶段实现
博城灾难是大事件，分多个版本实现：
- **v0.66.0（本版本）**：第一阶段 - 异常迹象（玩家发现灾难前兆，做出选择）
- **后续版本**：第二阶段 - 预警与准备（基于玩家选择的不同应对）
- **后续版本**：第三阶段 - 灾难降临（玩家参与防御，改变结局）

## 二、第一阶段：异常迹象事件

### 2.1 触发条件
- 玩家等级≥15
- 探索次数≥10（或修炼次数≥15）
- 时间：开学后第5天及以后
- notFlag: bocheng_disaster_phase1_done

### 2.2 事件：异常的妖魔活动

**触发方式**：探索时概率触发（weight: 30），或修炼时遇到NPC提及

**事件描述**：
你在学校附近探索时，发现了一些不寻常的迹象——草丛里有妖魔的爪印，空气中弥漫着淡淡的血腥味，几只低级妖魔在白天出没（通常妖魔只在夜间活动）。唐月老师似乎也注意到了什么，她的表情比平时严肃。

**选择分支（4个）**：

#### 选择1：立刻告诉唐月老师
- effects: { setFlag: ["bd_tell_tangyue", "bocheng_phase1_done"], npcOpinion: { tang_yue: 10 } }
- resultText: 你找到唐月，详细描述了发现的异常。唐月的脸色变得凝重："你说的这些...很不对劲。我会立刻上报学校，加强巡逻。"她拍了拍你的肩膀，"谢谢你，你很敏锐。"唐月好感+10，学校开始秘密调查

#### 选择2：告诉穆宁雪
- effects: { setFlag: ["bd_tell_muningxue", "bocheng_phase1_done"], npcOpinion: { mu_ningxue: 8 } }
- resultText: 你找到穆宁雪，告诉她你的发现。穆宁雪闭上眼睛，冰系星子微微运转："空气中...有空间波动的痕迹。"她睁开眼，"这件事不简单。我会用冰系感知继续监视。"穆宁雪好感+8，穆宁雪开始秘密调查

#### 选择3：自己继续调查
- effects: { setFlag: ["bd_investigate_alone", "bocheng_phase1_done"], exp: 50 }
- resultText: 你决定自己深入调查。连续几天，你在学校周围仔细搜寻，发现了更多线索——地圣泉方向的能量波动异常，还有几个陌生人在学校附近出没。你获得了宝贵的情报，但也引起了某些人的注意。经验+50，玩家掌握独立情报

#### 选择4：可能只是自己多想了
- effects: { setFlag: ["bd_ignore", "bocheng_phase1_done"] }
- resultText: 你觉得可能是自己太敏感了，毕竟博城一直很安全。你把这些异常抛在脑后，继续正常的学习生活。（但异常并没有消失...）

## 三、选择的长期影响

### 3.1 告诉唐月（bd_tell_tangyue）
- 学校提前加强巡逻和防御
- 唐月对玩家信任度大幅提升
- 后续灾难中，学校准备更充分，伤亡减少
- 玩家可以参与官方防御计划

### 3.2 告诉穆宁雪（bd_tell_muningxue）
- 穆宁雪用冰系感知发现空间波动
- 穆宁雪对玩家认可提升
- 后续灾难中，穆宁雪的冰系领域准备更充分
- 玩家可以与穆宁雪联手应对

### 3.3 自己调查（bd_investigate_alone）
- 玩家掌握独立情报（黑教廷线索）
- 可能引起黑教廷注意，增加风险
- 后续灾难中，玩家可以利用情报采取主动行动
- 可能发现黑教廷的阴谋，从根源阻止灾难

### 3.4 忽略（bd_ignore）
- 灾难前兆被忽视
- 后续灾难更严重，伤亡更大
- 但玩家在灾难中的表现机会更多（英雄路线）
- 灾难后玩家可能因"没有提前发现"而内疚

## 四、技术实现

### 4.1 事件数据
- events.js添加1个事件（bocheng_anomaly）
- 4个选择分支，每个设置不同flag

### 4.2 触发条件扩展
- 事件触发系统新增minLevel、minExploreCount条件（如果还没有）
- 探索时触发（探索方法已有事件触发逻辑）

### 4.3 Flag系统
- 复用现有flag系统
- 4个flag：bd_tell_tangyue / bd_tell_muningxue / bd_investigate_alone / bd_ignore
- 通用flag：bocheng_phase1_done

### 4.4 后续版本预留
- 第二阶段事件将基于这些flag触发不同的剧情分支
- 灾难结局将基于玩家的选择计算不同的伤亡和影响

## 五、深度来源

1. **真正的选择权**：玩家的选择不是简单的好感变化，而是影响整个城市的命运
2. **信息差博弈**：告诉官方vs告诉个人vs自己调查vs忽略，每个选择有不同的信息路径
3. **风险与回报**：自己调查获得更多情报但更危险，告诉官方更安全但情报可能被过滤
4. **道德困境**：忽略异常看似轻松，但灾难后会内疚；提前预警可能被认为是"危言耸听"
5. **可重玩性**：4个选择导致完全不同的后续剧情，玩家会想尝试不同路线

---

## 六、与原著的关系

- **不脱离原著**：博城灾难本身是原著事件，黑教廷策划、地圣泉、穆宁雪冰系领域等元素都来自原著
- **玩家有影响力**：玩家可以提前发现异常，影响灾难的准备程度和走向
- **不围绕莫凡**：莫凡只是背景中的一个学生，玩家的行动独立于莫凡
- **可以改变剧情**：如果玩家提前发现黑教廷阴谋，甚至可能阻止灾难发生（后续版本）
