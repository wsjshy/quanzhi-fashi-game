# 战斗技能系统重构设计方案

> 版本：v0.86.0
> 日期：2026-08-16
> 状态：已对齐，实施中

## 一、设计目标

1. **技能UI优化**：技能数量增多时，最外层只显示系别按钮，点击弹出该系技能列表
2. **高级魔法爽感**：高级魔法伤害高、特效华丽，是爆发手段
3. **低级魔法战略价值**：通过状态配合、元素能量、MP管理等机制，让低级魔法在高等级战斗中仍有意义
4. **贴合原著**：冻结中火系伤害×2等设定来自原著

## 二、UI布局设计

### 最外层（战斗界面）
- 只显示已觉醒的**魔法系别按钮**
- 每个系别按钮包含：系别名称+图标、功能描述、MP状态
- 横版：一行排列5-6个系别
- 竖版：两行排列，每行3个

### 系别描述
| 系别 | 描述 |
|------|------|
| 🔥 火系 | 高伤害+燃烧持续伤害 |
| ❄️ 冰系 | 冻结控制+护盾防御 |
| ⚡ 雷系 | 麻痹控制+高爆发 |
| 🪨 土系 | 高防御+束缚控制 |
| 🌪️ 风系 | 高闪避+速度增益 |
| 💧 水系 | 治疗+减速控制 |
| 🌿 植物系 | 持续恢复+中毒 |
| ☀️ 光系 | 治疗+净化+神圣伤害 |
| 🌙 暗系 | 诅咒+吸血+高爆发 |
| 🐺 召唤系 | 召唤兽协同作战 |

### 点击系别后弹出
- 该系所有魔法，按等级排序（初阶→中阶→高阶）
- 每个技能显示：名称、MP消耗、效果简述、冷却状态
- 点击技能释放，点空白处关闭

## 三、技能数据扩展

### 新增字段
- `category`：功能标签（damage/control/heal/buff/debuff/dot/summon/special）
- `castTime`：蓄力回合数（0=瞬发，1=1回合蓄力，2=2回合蓄力）
- `cooldown`：冷却回合数（0=无冷却）

### 等级划分
| 等级 | castTime | cooldown | 定位 |
|------|----------|----------|------|
| 初阶 | 0 | 0 | 瞬发、低消耗、稳定输出/控制 |
| 中阶 | 0 | 1 | 中等伤害、有冷却 |
| 高阶 | 1 | 2 | 高伤害、蓄力、长冷却 |
| 超阶 | 2 | 3 | 毁天灭地、长蓄力、极长冷却 |

## 四、核心机制设计

### 1. MP管理
- 高级魔法MP消耗巨大，一场战斗只能用2-3次
- 低级魔法MP消耗低，可频繁使用
- 玩家需平衡"平时低级输出"和"关键时刻高级爆发"

### 2. 状态配合系统
- 低级魔法擅长挂状态（燃烧、冻结、麻痹）
- 高级魔法吃状态加成：
  - 敌人冻结中 → 火系伤害×2
  - 敌人燃烧中 → 所有伤害+30%
  - 敌人麻痹中 → 暴击率+20%
- 最优连招：低级挂状态 → 高级爆发

### 3. 元素能量系统
- 每次使用低级魔法积累1点元素能量
- 能量满5点后，下一个高级魔法：
  - 伤害+50%
  - 无需消耗MP
  - 必暴击
- 鼓励"低级铺垫→高级爆发"的战斗节奏

### 4. 冷却系统
- 初阶：无冷却
- 中阶：1回合冷却
- 高阶：2回合冷却
- 超阶：3回合冷却
- 高级魔法CD时只能用低级魔法

### 5. 蓄力系统
- 初阶：瞬发
- 中阶：瞬发，有冷却
- 高阶：1回合蓄力（可被打断），蓄力后伤害+30%
- 超阶：2回合蓄力
- 蓄力期间可取消，用低级魔法补刀

## 六、经验准则

- 高级魔法要"爽"：伤害数字大、特效华丽、有独特机制
- 低级魔法要"有用"：通过状态配合、能量积累、MP效率等体现战略价值
- 不要通过"高级魔法miss率高"来限制使用，而是通过"MP消耗大+冷却长"来平衡
- UI要简洁：最外层只显示系别，点击展开技能，避免技能栏占满屏幕
