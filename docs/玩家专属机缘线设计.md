# 玩家专属机缘线设计（v0.24.0）

> 2026-08-15 设计文档。核心原则：玩家有自己的人生，不抢莫凡的机缘，两者平行。

## 一、设计目标

当前游戏中的机缘（地圣泉、唐月指导、小泥鳅坠等）都是莫凡的。玩家要么抢（截取莫凡人生），要么旁观（没有参与感）。

v0.24.0设计**玩家专属的机缘系统**：
- 玩家有自己的修炼机缘、隐藏地点、特殊事件
- 莫凡有自己的机缘线，独立运行，玩家不参与也不影响
- 两者平行，偶尔交汇，但不是零和竞争

## 二、核心机制

### 2.1 修炼顿悟系统

玩家在修炼行动时有概率触发"顿悟"，获得额外收益。

**触发条件**：
- 执行修炼行动时，基础概率5%
- 玩家等级越高，概率略微提升（每级+0.5%）
- 连续修炼同一地点，概率递减（避免刷）
- 特定系别在特定地点有加成

**顿悟效果**：
- 大量经验（当前修炼的3-5倍）
- 概率获得技能点
- 概率获得临时buff（修炼效率提升，持续数次修炼）
- 小概率解锁隐藏信息（关于世界观/设定的碎片）

**设计理念**：顿悟是玩家自己的机缘，与莫凡无关。每个玩家的顿悟体验不同，增加探索感。

### 2.2 隐藏修炼地点

玩家在探索时有概率发现专属隐藏地点。

**地点类型**：
- 元素浓度高的隐秘角落（对应玩家主系别）
- 废弃的修炼室/魔法阵
- 灵脉节点（小范围，不是地圣泉那种级别的）

**发现方式**：
- 探索已有地点时有概率发现（5%）
- 高关系NPC可能透露（"我知道一个地方..."）
- 顿悟时可能感知到附近的灵脉

**专属机制**：
- 每个玩家发现的隐藏地点是独立的（不与莫凡共享）
- 地点有使用次数限制或冷却，避免无限刷
- 地点可能随时间变化（灵脉流动）

### 2.3 NPC自主日程系统

所有重要NPC都有自己的日程和生活，独立于玩家运行。莫凡只是其中一个NPC。

**NPC日程配置**：
- 每个NPC有morning/afternoon/evening的日程（地点+活动+出现概率）
- 当前配置：莫凡、穆宁雪、唐月、张小侯
- 玩家在特定时间出现在特定地点时，可能遇到NPC在做自己的事

**偶遇机制**：
- 每个NPC每天最多遇到一次
- 偶遇时显示"（你看到XX正在这里做YY。他/她似乎在专注于自己的事。）"
- 不强制互动，玩家可以选择打招呼（通过对话功能）或忽略

**设计理念**：
- 世界是活的，NPC有自己的生活
- 莫凡不是特殊的，他和穆宁雪、唐月一样有自己的日程
- 玩家不是来观察莫凡的，而是在同一个世界里过自己的人生
- 偶遇只是背景信息，增加世界真实感

### 2.4 玩家专属导师线

玩家可以建立自己的导师关系，不一定是唐月。

**潜在导师**：
- 学校里的其他老师（萧院长等）
- 猎法师公会的猎法师
- 审判会的成员（通过特定事件接触）
- 隐藏的高人（探索发现）

**导师关系建立**：
- 通过任务/事件/选择建立
- 不同导师提供不同的指导方向
- 导师关系有深度等级，影响可获得的指导

**与唐月的关系**：
- 唐月仍然是学校老师，玩家可以向她请教
- 但唐月的"秘密指导"是莫凡的机缘，玩家不参与
- 玩家有自己的导师线

## 三、实施计划

### Phase 1：修炼顿悟系统（核心）
- 修炼行动添加顿悟概率判定
- 顿悟效果（经验/技能点/buff/信息碎片）
- 顿悟事件的UI反馈
- 顿悟日志记录

### Phase 2：隐藏修炼地点
- 隐藏地点数据结构
- 探索时发现隐藏地点的概率
- 隐藏地点的修炼效果
- 隐藏地点的使用限制

### Phase 3：莫凡自主日程
- 莫凡的日常日程表（按时间段）
- 玩家在特定地点可能遇到莫凡
- 莫凡的成长独立计算
- 遇到莫凡时的对话（他在做自己的事）

### Phase 4：玩家导师线（后续版本）
- 潜在导师NPC
- 导师关系建立任务
- 导师指导系统

## 四、与现有系统的关系

- **不修改**现有莫凡机缘（地圣泉竞争等保留，但重新定位为"莫凡的事，玩家可旁观"）
- **不修改**现有NPC关系系统
- **新增**顿悟系统、隐藏地点系统、莫凡日程系统
- **复用**现有事件系统（顿悟作为特殊事件触发）

## 五、人设检查

- 莫凡的行为符合原著设定（勤奋、有自己的目标）
- 玩家的机缘不破坏原著设定（不是抢莫凡的东西）
- 隐藏地点符合世界观（魔法世界有灵脉、隐秘角落）
- 顿悟符合修炼设定（修炼中可能有领悟）
