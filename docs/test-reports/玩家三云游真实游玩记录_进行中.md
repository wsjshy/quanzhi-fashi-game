## 一、角色创建

### 操作步骤
1. 打开游戏，点击「开始新游戏」
2. 输入角色名：**云游**
3. 天生天赋抽取（3次）：
   - 第一次：治愈传承、自然恢复、魔力强化（全辅助型）
   - 第二次：灵心、自然恢复、生命强化（全辅助型）
   - 第三次：速度强化、技能大师、自然恢复（辅助型+战斗型）
   - 第四次（最后一次）：**魔法共鸣（📚修炼型）** - 灵种效果+30%，灵种吸收成功率+20%
4. 选择元素：**🪨土系**（高防御·护盾控制，适合探索生存）
5. 选择系别天赋：**岩石之躯**（成长型，条件触发）- 受击积累岩力，满层反击眩晕，Lv5有进化抉择（磐石流/地震流/不屈流）

### 角色初始数据
- **角色名**：云游
- **等级**：Lv.1 → Lv.2（旅行到博城市街后自动升级）
- **HP**：120/120 → 132/132（升级后maxHp增加）
- **MP**：60/60 → 66/66（升级后maxMp增加）
- **金币**：50 → 100（升级后增加）
- **元素**：earth（土系）
- **天生天赋**：magic_resonance（魔法共鸣）
- **系别天赋**：earth_talent_basic（岩石之躯）
- **地点**：tianlan_school（天澜魔法高中）→ city_street（博城市街）
- **技能**：basic_attack（普通攻击）、earth_spike（土系地刺）
- **属性点**：2点未分配（升级获得）

### 体验评价
- **可玩性**：⭐⭐⭐⭐ 角色创建流程清晰，天赋抽取增加随机性
- **可优化点**：
  - 天生天赋抽取3次都没有抽到探索型，探索型天赋可能太稀有
  - 土系初始技能只有`earth_spike`（地刺），技能数量较少
  - 系别天赋选择界面的天赋说明可以更详细

## 二、地图旅行测试

### 操作步骤
1. 点击「🗺️ 地图」打开地图界面
2. 地图显示12+个地点：
   - 天澜魔法高中（当前位置，学习中心，安全）
   - 博城市街（商业街，安全，可前往）
   - 穆家庄园（家族领地，安全，需要等级3并和穆白关系不错）
   - 莫凡家（民居，安全，需要和莫凡关系不错）
   - 地圣泉（修炼圣地，极危险，需要地圣泉通行证）
   - 铭文女子中学（女校剧情，极危险）
   - 老榕树街区（旧城探索，极危险）
   - 博城北门（城防关口，极危险，需要等级5并完成城市巡逻任务）
   - 雪峰山（狩猎场，极危险，可前往）
   - 雪峰山深处（危险狩猎区，...）
   - 火车站、百草谷等

### 发现的问题
1. **地图界面"点击前往"文字不可点击**：需要点击地点图标（🏙️）才能旅行，"点击前往"文字只是提示
   - **评价**：UI设计不够直观，玩家可能不知道要点击图标
   - **优化建议**：让"点击前往"文字也可点击，或者添加明显的按钮样式

### 旅行测试
1. 直接调用`Game.travelTo('city_street')`旅行到博城市街
2. 旅行成功，当前位置变为`city_street`
3. 旅行过程中玩家自动升级到Lv.2（可能是因为旅行获得经验）

### 体验评价
- **可玩性**：⭐⭐⭐⭐ 地图设计丰富，地点多样，锁定条件清晰
- **可优化点**：
  - 地图界面的旅行交互不够直观（需要点击图标而不是文字）
  - 可以添加地图可视化（2D地图，地点用图标标注，连线表示连通）
  - 旅行过程可以添加过场动画或描述

## 三、探索功能测试

### 3.1 博城市街可执行行动

博城市街的可执行行动：
1. 🚶 **逛街**（1h）- 有概率捡到钱、遇到神秘商人或商店打折
2. 🏛️ **猎者联盟大厅**（0h）- 接悬赏、加入猎妖队
3. 💬 **找人聊天**（0h）- 和街上的NPC对话
4. 🏪 **魔法商店**（0h）- 购买装备、药水和材料
5. 🔨 **铁匠铺**（0h）- 用妖魔材料锻造魔具装备
6. 🍺 **酒馆**（1h）- 有概率接到猎魔任务或发生冲突
7. 😴 **休息** - 原地休息/充分休息

### 3.2 逛街测试

**操作步骤**：
1. 点击「🚶 逛街」按钮
2. 等待1小时（游戏时间）

**测试结果**：
- 时间从8:30推进到9:30（1小时）
- 经验增加了5（从0到5）
- 金币没有变化（还是100）
- HP/MP没有变化
- 没有触发特殊事件（捡到钱、神秘商人、商店打折）

**体验评价**：
- **可玩性**：⭐⭐⭐ 逛街功能可以正常工作，但随机事件触发概率可能较低
- **可优化点**：
  - 随机事件触发概率可以提高，或者添加事件触发提示
  - 逛街过程可以添加描述或动画，增加沉浸感
  - 可以添加更多类型的随机事件（遇到NPC、发现秘密、触发任务等）
