# 博城篇黑盒测试游玩攻略（三玩家视角）

> **文档目的**：作为完全不知道背景的黑盒测试玩家，从零开始游玩游戏，从三个不同玩家角度记录完整的博城篇游玩流程，包括每一步点击了什么、选择了什么、怎么战斗的。
> **测试目标**：验证游戏流程完整性、发现卡点和体验问题、评估不同玩法风格的可行性。
> **当前版本**：v3.25.0
> **测试日期**：2026-09-14

---

## 玩家一：战斗型玩家「炎烈」

### 玩家画像
- **风格**：专注修炼和战斗，追求实力提升，喜欢挑战强敌
- **口头禅**："实力才是硬道理！"
- **目标**：高等级+强装备+击败宇昂→真相追寻者结局
- **优先级**：修炼 > 战斗 > 任务 > 对话 > 探索

---

### 第一阶段：角色创建（第0天）

#### 步骤1：开始游戏
- **点击**：🎮 开始新游戏
- **输入**：角色名「炎烈」
- **点击**：开始觉醒

#### 步骤2：天生天赋选择
- **界面显示**：3个随机天生天赋
- **选择策略**：优先选择战斗型天赋
- **优先级排序**：
  1. ⚡快速施法（先手概率+20%，技能MP消耗-15%）
  2. 🩸吸血本能（攻击吸血15%，击杀回复10%HP）
  3. ⚔️技能大师（所有技能等级+1，技能伤害+15%）
- **实际选择**：⚡快速施法（如果出现），否则选择🩸吸血本能
- **点击**：选中的天赋卡片

#### 步骤3：元素觉醒选择
- **界面显示**：3个随机元素
- **选择策略**：优先选择高伤害元素
- **优先级排序**：
  1. 🔥火系（高伤害，有燃烧效果）
  2. ⚡雷系（高爆发，有麻痹效果）
  3. ❄️冰系（控制型，有冰冻效果）
- **实际选择**：🔥火系（如果出现），否则选择⚡雷系
- **点击**：选中的元素卡片

#### 步骤4：系别天赋选择
- **界面显示**：5个火系天赋
- **选择策略**：优先选择高伤害/爆发型天赋
- **优先级排序**：
  1. 💥爆炎（火系技能暴击率+8%，暴击伤害+30%）
  2. 🔥焚天（火系技能20%概率产生爆炸，对周围敌人造成50%伤害）
  3. ⭐天生火魂（火系伤害+40%，所有攻击必定点燃）
- **实际选择**：💥爆炎（追求暴击爆发）
- **点击**：💥爆炎天赋卡片

### 第二阶段：新手期（第1-7天，Lv.1→Lv.5）

#### 每日行动优先级
1. **✨修炼魔法**（2小时，消耗HP/MP，获得30经验）— 最高优先级
2. **📚上课：实践课**（下午，消耗HP/MP，获得40经验）— 次高优先级
3. **📚上课：星轨课**（上午，消耗MP，获得30经验）— 第三优先级
4. **📜事件与情报**— 查看可触发事件，有事件就做
5. **💬找人聊天**— 只接任务，不深入对话
6. **😴休息**— HP/MP低于30%时休息

#### 关键任务完成顺序

##### 任务1：觉醒仪式（主线）
- **触发**：自动触发
- **目标**：与唐月老师对话
- **行动**：
  1. 点击「💬找人聊天」
  2. 选择「唐月」
  3. 点击任意对话选项
  4. 任务自动完成
- **奖励**：经验+50，金币+50

##### 任务2：初识魔法（主线）
- **触发**：完成觉醒仪式后
- **目标**：达到Lv.2
- **行动**：
  1. 连续点击「✨修炼魔法」（每次30经验）
  2. 大约2-3次修炼后升级到Lv.2
  3. 升级时分配属性点（优先「攻击」，其次「速度」）
- **奖励**：经验+100，金币+100

##### 任务3：采集草药（主线，博城灾难前置任务）
- **触发**：达到Lv.2后
- **目标**：采集5个草药
- **行动**：
  1. 点击「🗺️地图」
  2. 选择「百草谷」
  3. 点击「🌿采集草药」行动
  4. 每次采集获得1-2个草药，重复直到收集5个
  5. 采集过程中可能遇到妖魔战斗（见战斗策略）
- **战斗策略（遇到低级妖魔）**：
  1. 点击「🔥火系」展开技能列表
  2. 点击「🔥火滋·灼烧」（基础火系技能，MP消耗低）
  3. 重复释放直到敌人死亡
  4. 如果MP不足，点击「⚔️普通攻击」
- **奖励**：经验+150，金币+100，草药x5

##### 任务4：猎杀妖魔（主线）
- **触发**：完成采集草药后
- **目标**：击杀5个奴仆级妖魔
- **行动**：
  1. 点击「🗺️地图」
  2. 选择「雪峰山」
  3. 点击「⚔️猎魔」行动
  4. 每次战斗击杀1个妖魔，重复5次
  5. 优先选择「奴仆级」妖魔（如黑畜妖、白瞳巨鼠）
- **战斗策略**：
  1. 第一回合：点击「🔥火系」→「🔥火滋·灼烧」
  2. 第二回合：继续释放火系技能
  3. 如果敌人血量低于30%，点击「⚔️普通攻击」节省MP
  4. 如果自己HP低于30%，点击「🎒道具」→ 使用「小治疗药水」
- **奖励**：经验+200，金币+150，妖魔材料

##### 任务5：猎杀狼群（主线）
- **触发**：完成猎杀妖魔后
- **目标**：击杀3只幽狼兽
- **行动**：
  1. 点击「🗺️地图」
  2. 选择「雪峰山」
  3. 点击「⚔️猎魔」→ 选择「幽狼兽」（战将级，难度较高）
  4. 重复3次
- **战斗策略（幽狼兽，战将级）**：
  1. 战前准备：确保HP/MP满，携带「小治疗药水」x3
  2. 第一回合：点击「🔥火系」→「🔥火滋·灼烧」（造成伤害+燃烧效果）
  3. 第二回合：点击「🔥火系」→「🔥火滋·爆裂」（如果已解锁，高伤害）
  4. 持续释放火系技能，利用燃烧效果持续掉血
  5. HP低于50%时立即使用治疗药水
  6. 如果打不过，先回去修炼升级到Lv.4-5再来
- **奖励**：经验+300，金币+200，幽狼兽材料

#### 属性点分配策略
- **每次升级获得3点属性点**
- **分配优先级**：
  1. ⚔️攻击（2点）— 提升伤害
  2. 💨速度（1点）— 提升先手概率和闪避
- **不推荐**：防御、精神（战斗型玩家不需要）

### 第三阶段：进阶期（第8-30天，Lv.5→Lv.8）

#### 每日行动优先级
1. **✨修炼魔法**（最高优先级，目标Lv.8）
2. **⚔️猎魔**（雪峰山/雪峰深处，刷经验和材料）
3. **📚上课：实践课**（高经验）
4. **🧘闭关修炼**（3天周期，高经验，有风险）
5. **🛒小卖部**（购买治疗药水和魔法药水）
6. **📜事件与情报**（有事件就做）

#### 关键目标
1. **等级达到Lv.8**（博城灾难前的安全等级）
2. **技能升级**：火系技能升级到Lv.3以上
3. **装备准备**：购买基础武器和防具
4. **道具储备**：治疗药水x5，魔法药水x3

#### 穆白的挑战（支线，可选）
- **触发**：达到Lv.5后，与穆白对话
- **目标**：与穆白决斗
- **行动**：
  1. 点击「💬找人聊天」→ 选择「穆白」
  2. 选择「挑战」选项
  3. 进入决斗战斗
- **战斗策略（穆白，冰系，Lv.5）**：
  1. 穆白是冰系，会使用冰冻技能
  2. 火系克制冰系（伤害x1.5），优先使用火系技能
  3. 如果被冰冻，无法行动，等待解冻
  4. 持续输出，HP低时使用药水
- **奖励**：经验+200，金币+150，穆白关系变化

### 第四阶段：博城灾难（第45天自动触发）

#### 触发条件
- ✅ 等级≥5
- ✅ 完成「采集草药」任务
- ✅ 游戏时间达到第45天
- **触发方式**：自动触发，弹出大事件界面

#### 阶段1：妖魔异动（选择分支）
- **界面显示**：唐月老师告知妖魔异常，5个选项
- **战斗型玩家选择**：「我去调查一下情况」（需要等级≥6）
- **点击**：「我去调查一下情况」
- **效果**：军方声望+5，进入「深入调查」阶段

#### 阶段2：深入调查（战斗）
- **剧情**：来到雪峰山，遭遇幽狼兽
- **战斗**：vs 幽狼兽（战将级）
- **战斗策略**：
  1. 第一回合：🔥火系技能（火滋·灼烧）
  2. 第二回合：🔥火系技能（火滋·爆裂）
  3. 持续输出，利用燃烧效果
  4. HP低时使用药水
- **胜利后**：进入「提前预警」阶段
- **失败后**：进入「受伤撤退」阶段（不影响主线，但奖励减少）

#### 阶段3：提前预警（剧情）
- **剧情**：回到博城报告，军方和学校开始准备
- **点击**：「继续 →」
- **效果**：获得经验和声望奖励

#### 阶段4：博城保卫战（战斗）
- **剧情**：妖魔大规模进攻博城，玩家参与保卫战

- **战斗策略**：
  1. 每场战斗优先击杀血量最低的敌人
  2. 多敌人战斗时，点击敌人选择栏切换目标
  3. 优先使用范围伤害技能（如焚天天赋触发的爆炸）
  4. 注意HP/MP管理，及时使用药水
- **点击**：每场战斗结束后点击「继续 →」

- **战斗策略（多敌人战斗）**：

## 玩家二：社交型玩家「温情」

### 玩家画像
- **风格**：专注NPC对话和关系建设，追求剧情分支，喜欢了解每个人的故事
- **口头禅**："大家的故事，我都想知道。"
- **目标**：高NPC关系+完整剧情分支+拯救何雨→军方盟友/幸存者结局
- **优先级**：对话 > 剧情 > 任务 > 修炼 > 战斗 > 探索

### 第一阶段：角色创建（第0天）

#### 步骤1：开始游戏
- **点击**：🎮 开始新游戏
- **输入**：角色名「温情」

- **选择策略**：优先选择治疗/辅助型天赋
- **优先级排序**：
  1. 💧治愈之心（水系治疗效果+30%，治疗范围扩大）
  2. 🛡️水之护盾（水系技能20%概率为队友添加护盾）
  3. 💧激流（水系伤害+20%，减速效果增强）
- **实际选择**：💧治愈之心（追求治疗和辅助）
- **点击**：💧治愈之心天赋卡片

### 第二阶段：新手期（第1-10天，Lv.1→Lv.5）

#### 每日行动优先级
1. **💬找人聊天**（最高优先级，与所有NPC对话，建立关系）
2. **📜事件与情报**（查看可触发事件，有事件就做）
3. **📚上课**（所有课程都上，提升经验和知识）

## 黑盒测试发现的潜在问题

### 1. 新手引导不足
- **问题**：新玩家进入游戏后，不清楚该做什么，系统没有明确的新手引导
- **影响**：玩家可能迷茫，不知道优先级
- **建议**：增加新手任务链，引导玩家完成基础操作

### 2. 战斗系统教学缺失
- **问题**：第一次进入战斗时，没有教学说明如何使用技能、道具、切换目标
- **影响**：玩家可能不知道多敌人战斗可以切换目标
- **建议**：增加战斗教学关卡，说明基本操作

### 3. 地点解锁条件不明确
- **问题**：玩家不清楚如何解锁新地点，没有明确的提示
- **影响**：探索型玩家可能卡住
- **建议**：在地图界面显示未解锁地点的解锁条件

### 4. NPC关系系统不透明
- **问题**：玩家不清楚与NPC的关系值，也不知道如何提升
- **影响**：社交型玩家可能无法达成拯救何雨的条件
- **建议**：在NPC对话界面显示关系值和提升方法

### 5. 博城灾难触发条件提示不足
- **问题**：玩家不清楚博城灾难需要完成「采集草药」任务，可能错过触发
- **影响**：玩家可能一直等不到博城灾难
- **建议**：在任务界面提示博城灾难的前置条件

### 6. 多敌人战斗UI说明不足
- **问题**：多敌人战斗时，玩家可能不知道可以点击敌人选择栏切换目标
- **影响**：玩家可能一直攻击默认目标，体验不佳
- **建议**：第一次多敌人战斗时，增加提示说明可以切换目标

- ✅ 角色创建流程完整（天赋+元素+系别天赋）
