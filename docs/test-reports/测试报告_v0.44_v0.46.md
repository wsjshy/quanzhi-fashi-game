## 二、发现的问题

### P2 问题（3项，不影响核心玩法但影响体验）

#### 问题1：标题版本号未更新
- **现象**：标题画面版本号停留在"v0.42.0 · NPC社交与影响力"
- **影响**：v0.43-v0.46共4个版本未更新标题版本号
- **建议**：每次版本更新时同步修改ui.js标题版本号

#### 问题2：连续成就弹窗体验不佳
- **现象**：加载存档后，"任务初体验""小有所成""速通达人"等成就一个接一个弹出，玩家需要连续点击多次
- **影响**：削弱了单个成就的成就感，造成操作疲劳
- **建议**：合并多个成就为一个批量显示界面，或增加"全部领取"按钮

#### 问题3：章节完成界面显示英文key
- **现象**：第一章完成界面"新系统"显示为"basic_combat, cultivation, status_panel"，"新功能"显示为"dialogue"
- **影响**：玩家看不懂这些英文key的含义
- **建议**：映射为中文名称（基础战斗/修炼/状态面板/对话）

### 体验问题（2项）

#### 体验1：NPC日常消息门槛偏高
- **现象**：v0.42/v0.45日常消息需要NPC关系opinion≥20才能触发，新玩家几乎体验不到
- **建议**：降低门槛到opinion≥10，或增加低关系档的简单消息

#### 体验2：v0.44提及概率偏低
- **现象**：30%概率在3次对话中未触发，玩家可能不知道有这个功能
- **建议**：首次与某NPC对话时必触发一次提及，后续恢复30%概率

## 三、体验评估

| 维度 | 评分 | 说明 |
|------|------|------|
| **节奏** | 7/10 | 升级较快，前期内容丰富；中期目标感不足，不知道该做什么 |
| **压力** | 6/10 | 资源充足（HP/MP/金币），没有卡关；战斗未测试无法评估战斗压力 |
| **自由度** | 7/10 | 多种行动选择（自习/修炼/冥修/图书馆/小卖部/聊天/休息），NPC对话有分支 |
| **代入感** | 7/10 | NPC有自己的日程和性格，背景NPC出现增加真实感；世界感觉是活的 |
| **成就感** | 6/10 | 升级/成就有反馈，但连续成就弹窗削弱了单个成就的满足感 |
| **想继续玩吗** | 是 | 想看看战斗系统和更多NPC互动 |

### 亮点
1. NPC日程系统让世界感觉真实——晚上找不到莫凡，早上看到穆白在上课
2. 修炼品质系统增加了随机性和期待感
3. 找人聊天功能完善，能看到NPC的出现时间和关系状态
4. 消息弹窗系统稳定，连续多条消息不卡死

### 最想改进的一点
连续成就弹窗应该合并显示，不要一个接一个弹。

### 最喜欢的一点
NPC有自己的日程，不是24小时站在原地等玩家对话。
