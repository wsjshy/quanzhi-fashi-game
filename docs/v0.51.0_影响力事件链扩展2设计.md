# v0.51.0 影响力事件链扩展（赵满延与许昭霆）

> 版本：v0.51.0
> 日期：2026-08-15
> 定位：继续扩展关键NPC的flag驱动事件链，覆盖赵满延和许昭霆

---

## 一、设计原则

1. **不围绕莫凡**——事件是玩家与NPC的自然互动，不提及莫凡
2. **人设不可破坏**——赵满延贪财但讲义气，许昭霆傲冷但认可实力
3. **flag驱动**——事件之间有flag依赖，形成真正的事件链
4. **加量不降质**——每个事件有3个选择分支，结果有差异
5. **关系上限适配**——许昭霆maxOpinion=70，好感提升适度

---

## 二、事件链1：赵满延的友谊

### 核心逻辑
玩家与赵满延建立友谊 → 赵满延分享光系防御心得 → 赵氏修炼资源 → 一起探索 → 关键时刻护盾保护

### 事件1：光系防御的请教
- **触发**：修炼/找人聊天时
- **条件**：minRelationship 15, notFlag("zhao_manyan_approved")
- **描述**：赵满延正在炫耀他的光系防御，"看到没？光佑·圣盾！统领级攻击都能挡下！"他得意地拍着胸脯。
- **选择**：
  1. 赵兄厉害，能教教我防御心得吗 → setFlag, npcOpinion +5, exp +15
  2. 光系防御确实强，但攻击呢 → setFlag, npcOpinion +3（赵满延愣了一下，"你还挺懂行"）
  3. 默默观察，不说话 → setFlag, npcOpinion +2（赵满延觉得你深藏不露）

### 事件2：赵氏的修炼资源
- **触发**：找人聊天/自习时
- **条件**：requireFlag("zhao_manyan_approved"), minRelationship 25
- **描述**：赵满延压低声音，"跟你说个事...我家里有些修炼用的魔石，品质不错。兄弟一场，分你一些？"他虽然贪财，但对朋友很大方。
- **选择**：
  1. 那就不客气了，谢了赵兄 → 获得magic_stone x2, npcOpinion +3
  2. 不用，你自己留着修炼吧 → npcOpinion +6, reputation +3（赵满延："够意思！以后有事尽管找我！"）

### 事件3：一起探索
- **触发**：修炼/找人聊天时
- **条件**：requireFlag("zhao_manyan_approved"), minRelationship 30
- **描述**：赵满延凑过来，"周末要不要一起去雪峰山探索？我听说那边有好东西，有我光系护盾在，安全得很！"
- **选择**：
  1. 好，一起去 → exp +40, npcOpinion +4, reputation +2
  2. 这周有点忙，下次吧 → npcOpinion +1

### 事件4：关键时刻的护盾
- **触发**：探索/修炼后
- **条件**：requireFlag("zhao_manyan_approved"), minRelationship 40, 玩家HP<50%
- **描述**：你刚经历一场苦战，气息不稳。赵满延不知从哪冒出来，一道光盾挡在你面前，"小心！有我在，别怕！"他的光系防御确实名不虚传。
- **选择**：
  1. 谢了赵兄，关键时刻还是你靠谱 → HP恢复30%, npcOpinion +5, reputation +3
  2. 我还撑得住，不过谢了 → npcOpinion +3（赵满延："行，你硬气！不过下次别逞强"）

## 三、事件链2：许昭霆的认可

### 核心逻辑
玩家实力获得许昭霆注意 → 从竞争对手到互相尊重 → 雷系心得分享 → 考核后的认可

### 事件1：雷系的较量
- **触发**：修炼/找人聊天时
- **条件**：minRelationship 10, 玩家等级≥6, notFlag("xu_zhaoting_respected")
- **描述**：许昭霆路过，扫了一眼你的修炼。"八班的？"他语气平淡，带着一丝居高临下，"星子排列...还算稳。"
- **选择**：
  1. 许学长雷系造诣深，能否指点一二 → setFlag, npcOpinion +2（许昭霆："哼，算你有眼光"）
  2. 默默继续修炼，不卑不亢 → setFlag, npcOpinion +4（许昭霆多看了你一眼，"有点意思"）
  3. 雷系虽强，但也不是无敌 → setFlag, npcOpinion +1, reputation +2（许昭霆："口气不小，希望你有对应的实力"）

### 事件2：张老师的比较
- **触发**：上课/自习时
- **条件**：requireFlag("xu_zhaoting_respected")
- **描述**：张建国老师在课上提到，"最近有些同学进步很快，比如八班的那位...许昭霆，你也不要松懈。"许昭霆的表情微微变化。
- **选择**：
  1. 课后向许昭霆表示只是运气好 → npcOpinion +3
  2. 课后不主动提及，保持距离 → npcOpinion +2（许昭霆反而更在意）

### 事件3：雷系心得
- **触发**：修炼/找人聊天时
- **条件**：requireFlag("xu_zhaoting_respected"), minRelationship 25
- **描述**：许昭霆难得主动开口，"雷系星子活跃，难以控制。"他顿了顿，"但你的控制力...比我预想的好。这个技巧，你可以试试。"他演示了一个雷系星子排列的技巧。
- **选择**：
  1. 认真学习，多谢许学长 → exp +45, npcOpinion +3
  2. 提出自己的见解 → npcOpinion +5, reputation +2（许昭霆："...有点道理。你比我想的不简单"）

### 事件4：竞争对手的认可
- **触发**：修炼/找人聊天时
- **条件**：requireFlag("xu_zhaoting_respected"), minRelationship 35, 玩家等级≥10
- **描述**：许昭霆走到你面前，表情依然冷淡，但语气少了几分居高临下。"年度考核快到了。"他看着你，"我不会手下留情。但...你是个值得认真对待的对手。"
- **选择**：
  1. 彼此彼此，考核见真章 → npcOpinion +4, reputation +5
  2. 许学长过奖了，我还需努力 → npcOpinion +2（许昭霆："谦虚？不像你的风格"）
