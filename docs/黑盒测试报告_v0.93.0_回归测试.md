## 三、新发现Bug列表

### Bug 1：天赋选择界面卡住无法退出
- **严重程度：** P1
- **复现步骤：**
  1. 角色创建确认后进入天赋选择界面
  2. 点击任意天赋卡片（如钢铁意志、快速施法）
  3. 弹出"获得天赋"提示，点击确定
  4. 弹窗关闭后仍停留在天赋选择界面，不进入游戏
- **实际表现：** 每次点击天赋都会获得并弹窗，但无法退出选择界面。已选天赋显示蓝色边框，但无确认/下一步按钮。最终需通过debug面板传送才能进入游戏。
- **影响：** 新玩家无法正常完成角色创建流程。

### Bug 2：事件与情报按钮等级门槛不明确且点击无效
- **严重程度：** P1
- **复现步骤：**
  1. Lv.2/Lv.7时主界面无"事件与情报"按钮
  2. Lv.9时按钮出现
  3. 点击按钮无反应
- **实际表现：** 低等级时按钮完全隐藏，无"等级不足"提示；高等级时按钮显示但点击无响应。
- **影响：** 玩家无法访问事件与情报功能。

### Bug 3：战斗道具弹窗数量不实时刷新
- **严重程度：** P3（低）
- **复现步骤：**
  1. 战斗中点击"道具"打开道具弹窗
  2. 使用治愈药水
  3. 弹窗中治愈药水数量不变化（仍显示x5）
  4. 关闭弹窗重新打开后数量正确（x4）
- **实际表现：** 使用道具后弹窗内数量未即时刷新，但实际背包数量正确消耗。
- **影响：** 轻微体验问题，不影响功能。

## 四、总结

### 修复点通过率
- **通过：6/10（60%）**
- **失败：4/10（40%）**

### 各优先级通过情况
- P0：2/2 通过（100%）
- P1：1/5 通过（20%）— NPC对话、事件与情报、休息按钮未修复
- P2：3/3 通过（100%）

### 回归测试
- 全部通过，无功能回归。

### 核心问题
v0.93.0 的P0级阻断bug（角色创建alert、境界突破双弹窗）已成功修复，P2级体验问题也已解决。但**3个P1核心功能（NPC对话、事件与情报、休息按钮）仍未修复**，玩家无法正常进行社交对话、查看事件情报、休息恢复，严重影响游戏体验。

### 建议
1. **优先修复P1未通过项**：NPC对话内容显示、事件与情报面板打开、休息按钮响应
2. **修复天赋选择界面卡住问题**：确保新玩家可正常完成创建流程
3. **明确事件与情报的等级门槛**：低等级时应显示按钮并给出"等级不足"提示，而非直接隐藏
4. **战斗道具弹窗数量刷新**：使用后即时更新显示
