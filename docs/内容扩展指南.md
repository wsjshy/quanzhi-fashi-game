# 内容扩展指南

本文档说明如何向游戏中添加新内容。所有内容都通过 JSON 文件定义，无需修改代码。

---

## 一、添加新技能

**文件位置**：`content/shared/skills.json`

每个技能是一个对象，key 为技能 ID。

```json
{
  "skill_id": {
    "id": "skill_id",
    "name": "技能名称",
    "description": "技能描述",
    "element": "fire",          // 元素类型
    "type": "damage",           // 类型：damage/heal/buff
    "mpCost": 10,               // 魔法消耗
    "baseDamage": 20,           // 基础伤害（伤害类）
    "damageMultiplier": 1.2,    // 伤害倍率
    "baseHeal": 30,             // 基础治疗（治疗类）
    "healMultiplier": 1.0,      // 治疗倍率
    "hitRate": 0.9,             // 命中率
    "critRate": 0.1,            // 暴击率
    "targetType": "enemy",      // 目标：enemy/self
    "cooldown": 0,              // 冷却回合数
    "tier": "初阶",             // 技能阶位
    "statusEffects": [          // 状态效果（可选）
      {
        "name": "灼烧",
        "type": "burn",
        "dotDamage": 5,
        "duration": 3,
        "chance": 0.3
      }
    ]
  }
}
```

**元素类型**：fire/ice/thunder/earth/wind/water/light/dark/neutral

**技能类型**：
- `damage` - 伤害技能
- `heal` - 治疗技能
- `buff` - 增益技能
- `debuff` - 减益技能

## 二、添加新 NPC

**文件位置**：`content/characters/` 目录下，每个 NPC 一个 JSON 文件

**文件名**：`角色英文名.json`，例如 `mo_fan.json`

```json
{
  "id": "mo_fan",
  "name": "莫凡",
  "title": "天生双系",
  "description": "从另一个世界穿越而来的少年...",
  "element": ["thunder", "fire"],
  "level": 1,
  "maxHp": 100,
  "maxMp": 60,
  "attack": 12,
  "defense": 5,
  "speed": 11,
  "skills": ["basic_attack", "thunder_bolt", "fire_bolt"],
  "sprite": "assets/images/characters/mo_fan.png",
  "location": "tianlan_school",
  "dialogue": [
    {
      "trigger": "default",
      "text": "你好，有什么事吗？"
    },
    {
      "trigger": "after_quest_1",
      "text": "谢谢你的帮忙！"
    }
  ],
  "givesQuests": ["quest_id_1", "quest_id_2"],
  "shopItems": null
}
```

## 五、添加新道具

**文件位置**：`content/items/` 目录

```json
{
  "id": "health_potion",
  "name": "治愈药水",
  "description": "恢复 50 点生命值",
  "type": "consumable",
  "icon": "🧪",
  "price": 30,
  "effects": {
    "hp": 50
  },
  "usableInBattle": true,
  "usableOutOfBattle": true
}
```

**道具类型**：
- `consumable` - 消耗品
- `weapon` - 武器
- `armor` - 防具
- `accessory` - 饰品
- `material` - 材料
- `quest` - 任务物品

## 六、添加新任务

**文件位置**：`content/quests/` 目录

```json
{
  "id": "quest_hunt_wolf",
  "name": "猎杀幽狼兽",
  "description": "雪峰山出现了一只幽狼兽，去把它解决掉！",
  "giver": "tang_yue",
  "type": "hunt",
  "objectives": [
    {
      "type": "kill",
      "enemyId": "demon_wolf",
      "count": 1
    }
  ],
  "rewards": {
    "exp": 200,
    "gold": 100,
    "items": [
      {
        "itemId": "health_potion",
        "count": 3
      }
    ]
  },
  "prerequisites": ["quest_intro"],
  "nextQuest": "quest_next",
  "dialogueStart": "你来了，正好有个任务给你...",
  "dialogueInProgress": "怎么样，幽狼兽解决了吗？",
  "dialogueComplete": "干得好！这是你的奖励。"
}
```

**任务类型**：
- `hunt` - 猎杀任务
- `collect` - 收集任务
- `talk` - 对话任务
- `escort` - 护送任务
- `story` - 剧情任务

## 八、添加新商店

在地点配置中引用，商品列表可以直接写在地点里，也可以单独放文件。

```json
{
  "id": "school_shop",
  "name": "学校小卖部",
  "items": [
    {
      "itemId": "health_potion",
      "price": 30,
      "stock": 10
    },
    {
      "itemId": "mana_potion",
      "price": 40,
      "stock": 10
    }
  ]
}
```

## 扩展流程

1. **确定要添加的内容类型**
2. **找到对应的 JSON 模板**（参考上面的格式）
3. **创建/修改 JSON 文件**
4. **测试验证**（打开游戏检查是否正常加载）
5. **记录更新**（在更新日志中记录）

## 注意事项

1. **ID 唯一性**：所有内容的 ID 不能重复
2. **引用一致性**：引用的技能/道具/NPC ID 必须存在
3. **向后兼容**：新增内容不要修改已有 ID
4. **文件编码**：必须使用 UTF-8 编码
5. **图片格式**：推荐使用 PNG 或 JPG，尺寸适中
