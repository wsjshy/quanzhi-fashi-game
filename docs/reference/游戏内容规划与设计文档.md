# 全职法师游戏内容规划文档

## 一、游戏整体阶段划分

### 第一阶段：天澜高中篇（Lv.1 - Lv.7，初阶）
**核心地点**：天澜魔法高中、老榕树街区、雪峰山、猎者联盟
**核心内容**：
- 新手引导、觉醒魔法、基础修炼
- 课程系统、班级声望
- 基础战斗、初级装备
- 第一个大事件：雪峰山历练
**目标**：让玩家熟悉基本玩法，建立角色成长感

### 第二阶段：博城灾难篇（Lv.8 - Lv.14，中阶）
**核心地点**：博城全境、地圣泉、地下城市、各个街区
**核心内容**：
- 中阶觉醒、星云级魔法
- 博城灾难大事件（8个结局）
- 先锋小队、组队战斗
- 装备强化、魔具系统
**目标**：剧情高潮，玩家做出关键选择，影响世界走向

### 第三阶段：古都/全国篇（Lv.15 - Lv.21，高阶）
**核心地点**：古都、帝都、魔都、各个秘境
**核心内容**：
- 高阶魔法、星河级
- 全国性大事件
- 势力争霸、宗门系统
- 更复杂的装备和技能体系
**目标**：世界观展开，玩家成为一方强者

## 二、地图与地点设计

### 设计原则
1. **每个地图有独特主题**：不是简单换皮，每个地点有独特的行动、NPC、敌人、任务
2. **渐进式解锁**：随着等级和剧情推进，逐步解锁新地图
3. **地图间有联系**：任务、NPC、事件会跨地图联动
4. **昼夜差异**：同一个地点白天和晚上有不同的内容

### 各地图特色设计

#### 1. 天澜魔法高中（新手村）
**定位**：新手起点，基础系统教学
**特色行动**：
- 上课（课程表系统，动态课程）
- 冥修、修炼、突破
- 图书馆自习
- 操场体能训练
**特色NPC**：唐月、莫凡、张小侯、王三胖、各班同学
**特色敌人**：无（安全区）
**解锁条件**：初始解锁

#### 2. 老榕树街区
**定位**：第一个城市区域，社交与初级购物
**特色行动**：
- 逛商店（装备店、药店、书店）
- 酒馆打听消息
- 街头偶遇事件
**特色NPC**：书店老板、酒馆老板、各种路人
**特色敌人**：少量地痞流氓（非妖魔）
**解锁条件**：Lv.2

#### 3. 雪峰山
**定位**：第一个狩猎地图，初级战斗
**特色行动**：
- 猎魔行动（不同难度的妖魔）
- 采集草药
- 探索山谷
- 驿站休息
**特色NPC**：猎人李、二秃子（驿站小贩）
**特色敌人**：幽狼兽、火鼠、岩兽、妖藤、暗影怪
**解锁条件**：Lv.3，完成初识魔法任务

#### 4. 猎者联盟
**定位**：任务系统入口，声望系统
**特色行动**：
- 接取猎魔任务
- 提交任务领奖
- 查看排行榜
- 猎人公会活动
**特色NPC**：公会接待员、各种猎人
**特色敌人**：无
**解锁条件**：Lv.4，完成猎杀妖魔任务

#### 5. 地圣泉
**定位**：特殊修炼地图，高收益但有风险
**特色行动**：
- 地圣泉修炼（经验翻倍）
- 泉底探索
- 守护地圣泉
**特色NPC**：守护者、莫凡
**特色敌人**：泉底妖兽
**解锁条件**：Lv.6，特定剧情触发

#### 6. 博城地下
**定位**：灾难篇核心地图，探索与生存
**特色行动**：
- 地下探索
- 搜救幸存者
- 物资搜集
- 地下战斗
**特色NPC**：失散的同学、教官、幸存者
**特色敌人**：大量高阶妖魔、翼苍狼等BOSS
**解锁条件**：博城灾难事件触发

## 三、时间系统扩展设计

### 当前时间系统回顾
- 8时段制：清晨/上午/中午/下午/傍晚/夜晚/深夜/睡眠
- 精确到小时，可操作时间06:00-03:00
- 强制睡眠：03:00未睡则强制昏睡

### 扩展1：多时长修炼/闭关
**问题**：目前修炼都是固定1小时，玩家想快速推进时间要点很多次
**解决方案**：给长时间行动增加时长选择

#### 修炼/冥修时长选项
| 时长 | 体力消耗 | 经验收益 | 适用场景 |
|------|---------|---------|---------|
| 1小时 | 10 | 基础值 | 微调时间、剩一点体力时 |
| 4小时 | 40 | 基础值×4×1.1 | 半天修炼，小加成 |
| 8小时 | 80 | 基础值×8×1.2 | 全天修炼，大加成 |
| 全天（12小时） | 100 | 基础值×12×1.5 | 体力满时闭关修炼，最大收益 |

**设计思路**：
- 时间越长，单位时间收益越高（鼓励连续修炼）
- 但不能中途打断，要一次性完成
- 体力不够时自动按最大可修炼时长调整
- 修炼过程中可能触发随机事件（突破、走火入魔、灵感等）

#### 其他支持多时长的行动
- 图书馆自习：1小时/2小时/4小时
- 睡觉：睡到天亮/睡4小时/睡8小时
- 探索：快速探索（1小时）/深度探索（3小时）

### 扩展2：大事件时间线
**问题**：目前游戏时间是自由流动的，但剧情大事件应该有固定的时间点
**解决方案**：建立大事件时间线系统

#### 大事件触发方式
1. **固定日期触发**：到了第X天自动触发
2. **等级触发**：达到Lv.X自动触发
3. **任务链触发**：完成前置任务链后触发
4. **条件触发**：满足多个条件（等级+声望+任务）后触发

#### 大事件进行规则
- 大事件期间，普通行动被锁定
- 玩家只能进行事件相关的选择和行动
- 事件有多个分支，玩家选择影响结局
- 事件结束后，时间跳到事件结束后的时间点
- 不同结局对世界状态有不同影响

#### 已有的大事件：博城灾难
- 触发条件：Lv.8 + 完成前置任务
- 持续时间：游戏内3天
- 结局数量：8个
- 影响：博城地图变化、NPC存活状态、势力声望变化

### 扩展3：时间跳跃机制
**问题**：有些时候玩家想快速跳到某个时间点（比如等第二天上课）
**解决方案**：增加等待/跳跃时间功能

#### 等待功能
- 等待1小时：消耗少量体力，时间+1小时
- 等到下一时段：直接跳到下一个时段
- 等到第二天早上：直接跳到第二天早上6点

#### 设计注意事项
- 等待期间可能触发随机事件
- 不能跳过正在进行的事件
- 等待也要消耗体力（虽然少）
- 有重要事件即将发生时会提示玩家

## 四、大事件系统设计

### 大事件的特点
1. **剧情驱动**：有完整的故事线，不是普通任务
2. **高风险高收益**：成功奖励丰厚，失败损失惨重
3. **多分支多结局**：玩家选择影响结果
4. **永久性影响**：改变世界状态、NPC命运、地图内容
5. **不可重复**：每个大事件只有一次机会

### 大事件框架设计

#### 事件状态
```
eventState = {
  id: "bo_city_disaster",
  name: "博城灾难",
  status: "not_started", // not_started / in_progress / completed / failed
  currentStage: 0,
  choices: {}, // 玩家做出的选择
  variables: {}, // 事件中的变量
  startTime: null,
  endTime: null,
  ending: null
}
```

#### 事件阶段
每个大事件分为多个阶段，每个阶段有：
- 剧情描述
- 玩家选择
- 选择的后果
- 进入下一阶段的条件

#### 事件结局
- 完美结局：条件苛刻，奖励最好
- 好结局：正常通关，不错的奖励
- 普通结局：勉强过关，一般奖励
- 坏结局：失败，有损失
- 隐藏结局：特殊条件触发

### 已规划的大事件列表

| 事件名称 | 触发等级 | 持续时间 | 结局数 | 核心内容 |
|---------|---------|---------|-------|---------|
| 雪峰山历练 | Lv.5 | 1天 | 3 | 第一次外出历练，遭遇妖魔 |
| 地圣泉争夺 | Lv.7 | 2天 | 4 | 地圣泉的秘密与争夺 |
| 博城灾难 | Lv.8 | 3天 | 8 | 黑教廷袭击，全城危机 |
| 古都浩劫 | Lv.15 | 5天 | 6 | 亡灵大军，古都存亡 |
| 世界学府大赛 | Lv.20 | 7天 | 5 | 各国天才，为国争光 |

## 五、测试策略优化

### 核心问题：上下文窗口过大
之前的测试agent从头玩到尾，上下文越来越大，最后需要压缩，导致信息丢失。

### 解决方案：分段接力测试

#### 分段原则
1. **按等级分段**：每2-3级一段，每段一个新agent
2. **存档接力**：上一段结束时保存存档，下一段从存档开始
3. **每段目标明确**：每段只专注测试该等级范围的内容
4. **并行测试**：多段可以同时进行

#### 分段规划
| 测试段 | 等级范围 | 测试重点 | 预计时长 |
|--------|----------|----------|---------|
| 第一段 | Lv.1 → Lv.3 | 新手流程、前期系统、入门体验 | 短 |
| 第二段 | Lv.3 → Lv.5 | 战斗系统、基础任务、初级探索 | 中 |
| 第三段 | Lv.5 → Lv.8 | 装备系统、属性点、更多地点、中期任务 | 中 |
| 第四段 | Lv.8 → Lv.12 | 觉醒系统、大事件、后期内容 | 长 |
| 第五段 | Lv.12+ | 高阶内容、终极挑战 | 长 |

#### 每个agent的输出要求
- 不用记录每一步操作
- 只输出：测试进度、Bug列表、体验问题、整体评价
- 关键节点截图（发现bug时、重要事件时）
- 结束时保存存档文件，供下一段使用

#### 并行测试策略
- 同时运行2-3个测试agent，分别测不同方向
- 比如：一个测战斗系统，一个测任务系统，一个测探索
- 发现bug后及时修复，修复后安排回归测试

### 黑盒测试原则
1. **纯玩家视角**：不告诉agent任何开发信息
2. **自然游玩**：就像第一次玩游戏一样
3. **重点找bug**：但也要记录体验问题
4. **轻量记录**：不用每步都截图，只在关键节点截
