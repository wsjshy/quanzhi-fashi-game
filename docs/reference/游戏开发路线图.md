# 全职法师游戏开发路线图

基于小说《全职法师》的游戏开发规划。

---

## 整体设计理念

- **数据驱动**：所有内容都通过 JSON 数据定义，易于扩展
- **模块化**：每个系统独立，便于维护和升级
- **渐进式开发**：先做核心玩法，再逐步扩充内容
- **忠于原著**：基于小说内容，还原小说中的经典场景和剧情

---

## 篇章规划

## 开发原则

1. **忠于原著**：所有内容基于小说，还原经典场景
2. **数据驱动**：新增内容只需加数据，不改代码
3. **渐进式**：先做核心，再逐步扩充
4. **可玩优先**：每个版本都保证可玩
5. **玩家选择**：多结局、多分支，玩家选择影响世界
