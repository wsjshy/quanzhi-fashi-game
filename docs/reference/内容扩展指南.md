# 内容扩展指南

本文档说明如何向游戏中添加新内容。所有内容都通过 `engine/data/` 目录下的 JS 文件定义，数据驱动。

---

## 核心原则（小说驱动式开发）

1. **从小说里发现什么，就实现什么** - 不凭空想象机制
2. **非原著内容必须标记** - 游戏原创内容加 `isCanon: false`
3. **能用数据实现的就用数据** - 尽量复用现有效果类型
4. **先有后优** - 先把内容加进去，再慢慢优化

---

## 一、添加新技能

**文件位置**：`engine/data/skills.js`

每个技能是一个对象，key 为技能 ID。

```javascript
// 玩家技能示例
fireball: {
  id: "fireball",
  name: "火滋·灼烧",
  description: "释放火球攻击敌人，造成火系伤害",
  element: "fire",
  type: "damage",
  mpCost: 10,
  baseDamage: 25,
  targetType: "enemy",
  cooldown: 0,
  tier: "初阶"
},

// 妖魔技能示例
crimson_beam: {
  id: "crimson_beam",
  name: "腥红光束",
  description: "从巨大的眼睛中释放腥红色暗光束",
  element: "dark",
  type: "damage",
  mpCost: 0,                    // 妖魔技能不消耗MP
  targetType: "enemy",
  cooldown: 3,
  tier: "奴仆级",
  isDemonSkill: true,           // 标记为妖魔技能
  baseDamage: 25,
  guaranteedHit: true,          // 必定命中
  statusEffects: [
    { name: "暗蚀", type: "curse", duration: 2, chance: 0.3 }
  ]
}
```

**特殊字段说明**：
- `isDemonSkill: true` - 妖魔技能，不消耗MP
- `isCanon: false` - 非原著技能（必须加canonNote）
- `guaranteedHit: true` - 必定命中
- `guaranteedCrit: true` - 必定暴击
- `ignoreDefense: 0.5` - 无视50%防御
- `hitCount: 3` - 多段攻击（3次）
- `power: 1.5` - 伤害倍率（妖魔技能用）

**元素类型**：fire/ice/thunder/earth/wind/water/light/dark/neutral

**技能类型**：
- `damage` - 伤害技能
- `heal` - 治疗技能
- `buff` - 增益技能
- `debuff` - 减益技能

## 二、添加新妖魔/敌人

**文件位置**：`engine/data/enemies.js`

```javascript
one_eye_wolf: {
  id: "one_eye_wolf",
  name: "独眼魔狼",
  title: "奴仆级妖魔",
  description: "小说原文描述...",
  elements: ["dark"],
  level: 4,
  maxHp: 150,
  maxMp: 0,
  attack: 22,
  defense: 8,
  speed: 16,
  skills: ["basic_attack", "wolf_bite", "shadow_assault"],
  aiType: "aggressive",
  spriteColor: "#4a4a4a",
  isEnemy: true,
  demonTier: "servant",         // 妖魔阶级
  expReward: 100,
  goldReward: 50,
  dropItems: [
    { itemId: "demon_core", chance: 0.3, min: 1, max: 1 }
  ]
}
```

**AI类型**：
- `aggressive` - 激进型，优先攻击
- `defensive` - 保守型，低血量防御
- `controller` - 控制型，优先控制技能
- `burst` - 爆发型，攒MP放大招
- `kiter` - 游击型，高速移动
- `tactical` - 战术型，根据情况选择

**妖魔阶级**（demonTier，自动应用加成）：
- `servant` - 奴仆级（HP+20%，攻击+15%，防御+10%）
- `warrior` - 战将级（HP+50%，攻击+30%，防御+20%）
- `commander` - 统领级（HP+100%，攻击+50%，防御+40%）
- `monarch` - 君主级（HP+200%，攻击+100%，防御+80%）

**非原著妖魔标记**：
```javascript
{
  id: "skeleton_warrior",
  name: "骷髅战士",
  isCanon: false,
  canonNote: "非原著妖魔，游戏原创",
  // ...
}
```

## 扩展流程

1. **确定要添加的内容类型**
2. **找到对应的数据文件**（`engine/data/` 目录）
3. **参考现有格式添加数据**
4. **运行 `node -c 文件名` 检查语法**
5. **打开游戏测试验证**
6. **提交代码并更新文档**

## 注意事项

1. **ID 唯一性**：所有内容的 ID 不能重复
2. **引用一致性**：引用的技能/物品 ID 必须存在
3. **非原著标记**：游戏原创内容必须标记 `isCanon: false`
4. **文件编码**：必须使用 UTF-8 编码
5. **语法检查**：修改后用 `node -c` 检查语法
6. **小说依据**：添加妖魔/技能时，description尽量引用小说原文
