## 五、设计原则

1. **小说驱动** - 所有机制/妖魔/技能必须有小说依据，不要自己编
2. **数据优先** - 能用数据配置的不改代码
3. **模块化** - 新效果类型独立，通过注册表管理
4. **先有后优** - 先实现基础，再迭代优化
5. **AI智能** - 越强大的妖魔特殊手段越多，AI要会用
6. **平衡观** - 同级别有强弱差距正常，主要看天赋；妖魔整体比同阶法师强

## 六、测试要点

每次改战斗代码后必测：
1. 手动战斗：施法/防御/道具/逃跑
2. 自动战斗：连续5场以上，看MP消耗和技能选择
3. 元素反应：火+水=蒸发、冰+水=冻结等
4. 引导技能：中阶/高阶引导和打断
5. 状态效果：灼烧/冰冻/麻痹等是否正常结算
6. 战斗模式：决斗/车轮战/狩猎战/Boss战各测一场
7. 魔具使用：战斗中使用魔具技能
8. 召唤兽：召唤和攻击
