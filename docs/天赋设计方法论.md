# 天赋设计方法论

> 指导后续小说拆解和天赋设计 | 最后更新：2026-08-18

## 一、从小说拆解天赋的流程

### 1.1 提取角色核心能力

阅读小说时，关注角色的标志性能力：
- 莫凡：天生双系、恶魔系、雷火双系
- 穆宁雪：冰系、冰晶刹弓
- 赵满延：光系、防御型
- 张小侯：风系、军法师

### 1.2 转化为游戏机制

将小说能力转化为可量化的游戏效果：
- "天生双系" → extraElement: true
- "冰晶刹弓" → 高伤害技能+暴击
- "防御型" → 护盾+减伤+反伤

### 1.3 设计进化路线

根据角色成长轨迹设计进化：
- 初期能力 → 中期特性 → 后期质变 → 终极形态

### 1.4 平衡强度

- 初始强度 vs 成长空间
- 最终强度趋同，但体验路径不同

## 二、天生天赋类型

### 2.1 成长型（growth）

**特点**：弱初始，高成长，4次进化，最终S级

**适合**：大器晚成型角色，后期发力

**设计要点**：
- Lv1效果为同类强天赋的50%
- 每次进化提升30-50%
- Lv10终极效果达到或超过强天赋

**示例**：元素亲和（Lv1 +5%伤害，Lv10 +25%+穿透）

### 2.2 早熟型（early）

**特点**：强初始，少进化，1-2次进化，最终A+级

**适合**：前期强势角色，出生即巅峰

**设计要点**：
- Lv1效果为同类强天赋的100%
- 进化次数少（1-2次）
- 最终效果略低于成长型终极

**示例**：天生双系（Lv1双系，Lv10双系协同）

### 2.3 波动型（volatile）

**特点**：B初始，3次进化，中期崛起，最终S-级

**适合**：有节奏的角色，中期爆发

**设计要点**：
- Lv1效果一般
- Lv3-Lv5有明显提升
- Lv10效果接近成长型

**示例**：战斗直觉（Lv1 +5%暴击，Lv10 +25%+必杀）

### 2.4 特化型（specialized）

**特点**：B+初始，2次进化，特定场景极强

**适合**：特定build核心，有组合联动

**设计要点**：
- 在特定条件下效果翻倍
- 有组合联动空间
- 泛用性较低

**示例**：技能大师（技能等级+，CD缩减）

## 三、系天赋差异化设计

### 3.1 核心机制原则

每个系别有且只有一个核心机制，所有天赋围绕该机制设计：

| 系别 | 核心机制 | 关键词 |
|------|----------|--------|
| 火系 | 燃烧层数 | 叠加、爆炸、持续 |
| 冰系 | 冻结+破冰 | 控制、暴击、层数 |
| 雷系 | 感电+麻痹 | 连锁、扩散、速度 |
| 水系 | 湿润+治疗 | 护盾、恢复、联动 |
| 风系 | 连击+闪避 | 速度、反击、多段 |
| 土系 | 护盾+反击 | 防御、反伤、控制 |
| 光系 | 净化+圣光 | 驱散、累积、爆发 |
| 暗系 | 吸血+潜行 | 续航、暴击、削弱 |
| 治愈 | 治疗+复苏 | 持续恢复、复活、增益 |
| 植物 | 控制+中毒 | 束缚、叠毒、场地 |
| 召唤 | 召唤兽协同 | 多单位、进化、协同 |

### 3.2 进化路线分支

每个系至少3条进化路线，Lv5时选择分支：

**火系示例**：
- 爆发流：引燃→爆燃→焚天（满层爆炸，单次高伤）
- 持续流：火种→烈焰→熔岩（DOT叠加，稳定输出）
- 辅助流：火盾→炎甲→凤凰（护盾+反伤+复活）

### 3.3 分支设计原则

1. **玩法差异**：不同分支操作方式不同
2. **数值趋同**：最终DPS/效用相当
3. **组合空间**：分支与其他天赋/技能有联动
4. **视觉区分**：分支名称和描述有明显差异

## 四、天赋设计检查清单

每个天赋设计完成后，必须通过：

- [ ] 符合原著设定（不编造不存在的能力）
- [ ] 有独特核心机制（不与其他系同质化）
- [ ] 进化路线有意义（每次进化都有新体验）
- [ ] 分支选择有差异（不同路线玩法不同）
- [ ] 最终强度平衡（与其他系/天赋相当）
- [ ] 有组合联动空间（与其他天赋/技能/元素反应配合）
- [ ] 数据结构正确（type/evolutions/branchChoices/branchEffects）

## 五、数据结构规范

### 5.1 天生天赋

```javascript
{
    id: 'talent_id',
    name: '天赋名称',
    rarity: 'common|rare|epic|legendary',
    weight: 1-10, // 随机权重
    icon: 'emoji',
    description: '详细描述',
    effectDesc: '效果简述',
    type: 'growth|early|volatile|specialized', // 天赋类型
    boundElement: 'blessing', // 可选：绑定系别（稀有系天赋）
    evolutions: [
        { level: 1, name: '初始形态', effectDesc: '...', effects: {...} },
        { level: 10, name: '终极形态', effectDesc: '...', effects: {...} }
    ],
    isCanon: true/false,
    canonNote: '原著说明'
}
```

### 5.2 系天赋（带分支进化）

```javascript
{
    id: 'fire_talent_basic',
    name: '烈焰之魂',
    element: 'fire',
    rarity: 'common',
    type: 'growth',
    description: '...',
    maxLevel: 10,
    evolutions: [
        { level: 1, stage: '觉醒', name: '...', effects: {...} },
        { level: 3, stage: '特性', name: '...', effects: {...} },
        {
            level: 5, stage: '进化', name: '分支选择',
            branchChoices: [
                { id: 'explosion', name: '爆燃', description: '...', effects: {...} },
                { id: 'lava', name: '熔岩', description: '...', effects: {...} }
            ]
        },
        {
            level: 7, stage: '延伸',
            branchEffects: {
                explosion: { name: '炎怒', effects: {...} },
                lava: { name: '岩浆护甲', effects: {...} }
            }
        },
        {
            level: 10, stage: '终极',
            branchEffects: {
                explosion: { name: '烈焰领主', effects: {...} },
                lava: { name: '熔岩君主', effects: {...} }
            }
        }
    ]
}
```

## 六、扩展接口

- 新增系别：在talents.js中添加该系的核心机制和天赋
- 新增天生天赋：在innate-talents.js中添加，指定type和evolutions
- 新增进化分支：在天赋的evolutions中添加level:5的branchChoices
- 稀有系绑定：天赋的effects中添加boundElement字段
- 分支选择UI：玩家在Lv5时调用TalentSystem.selectBranch(talentId, branchId)
