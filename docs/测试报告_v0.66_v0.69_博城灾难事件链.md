## 四、发现的问题与优化

### 4.1 问题：候选事件简单随机选择 ⚠️

**问题描述**：
`_findNPCInteraction`方法的候选事件是简单随机选择，没有按weight加权。当NPC有多个待触发事件时，weight高的关键剧情事件（如博城灾难，weight 30-40）与普通关系事件（weight 10-20）有相同的选中概率。

**影响**：
玩家可能需要多次修炼才能触发关键剧情事件，影响游戏节奏和体验。

**优化方案（v0.69.1）**：
将候选事件选择改为按weight加权随机选择：
```javascript
const totalWeight = candidates.reduce((sum, e) => sum + (e.weight || 1), 0);
let rand = Math.random() * totalWeight;
for (const event of candidates) {
    rand -= (event.weight || 1);
    if (rand <= 0) return event;
}
return candidates[candidates.length - 1];
```

**优化效果**：
- weight 40的博城灾难事件 vs weight 10的普通事件，选中概率从50%提升到80%
- 关键剧情事件更容易触发，提升游戏节奏

### 4.2 已知限制

1. **debug面板无flag设置**：debug面板不支持直接设置flag，测试剧情事件链需要手动推进
2. **NPC每天最多遇到一次**：每个NPC每天最多遇到一次，测试需要多日推进
3. **事件触发概率**：遇到NPC后80%概率尝试触发事件，仍有20%不触发
