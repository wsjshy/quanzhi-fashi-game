# v0.80.0 UI全面重构设计方案

> 状态：**已实施完成（v0.82.3）**
> 日期：2026-08-16
> 核心目标：减少滚动、美化布局、强化地点差异化、地图替代文字导航
> 实施版本：v0.80.0 ~ v0.82.3

---

## 一、问题诊断

### 1.1 当前UI问题
| 问题 | 具体表现 | 影响 |
|------|---------|------|
| 过度滚动 | 主界面行动列表+时间+前往地点全部纵向排列，需多次下滑 | 操作繁琐，核心内容被淹没 |
| 布局方正 | 所有内容都是从上往下的矩形卡片，缺乏层次和美感 | 视觉单调，不像游戏 |
| 信息冗余 | "前往其他地点"文字列表与2D地图功能重复 | 占用空间，增加滚动 |
| 地点无说明 | 地图节点只有名字和图标，不知道地点功能 | 新玩家困惑 |
| 妖魔信息位置 | "可能遇到的妖魔"直接列在主界面行动区 | 占用宝贵空间，非核心信息 |
| 地点差异化弱 | 多个地点共享通用行动（探索/聊天/休息），独特性不足 | 场景存在感弱 |

## 二、设计原则（新增，记录到AGENTS.md）

### 2.1 UI设计核心原则
1. **零滚动优先**：核心操作在首屏完成，尽量不需要下滑。必须滚动时限制在一个区域内。
2. **信息分层**：核心信息（行动/状态）常驻，次要信息（妖魔/说明）折叠或图标化。
3. **地图即导航**：2D地图是唯一的地点切换入口，移除文字形式的"前往其他地点"列表。
4. **非对称布局**：避免完全方正的纵向排列，采用左主右辅、卡片错落、浮动元素等游戏化布局。
5. **地点即身份**：每个地点有独特的视觉色调、功能标签、专属行动，进入不同地点有明显不同的体验。
6. **悬停即详情**（v0.81.0新增）：额外信息（行动描述/收益、妖魔详情、地点说明）通过鼠标悬停或手机长按获取，主界面只显示核心信息，减少文字密度。
7. **一屏原则**（v0.81.0新增）：手机竖屏主界面一屏装下，文字按钮放大，减少元素数量。
8. **响应式自适应**（v0.81.0新增）：检测屏幕宽高比，竖版（手机）和横版（电脑）用不同布局。
9. **顶部极简**（v0.82.1新增）：顶部状态栏只保留时间、金币、HP/MP/体力、等级。地点名/大地图名移到地点信息卡，移除探索度/章节名/上课跳转等冗余信息。
10. **功能合并去冗余**（v0.82.0新增）：相似功能合并到统一入口（休息系统合并原地/充分/睡眠，事件与情报合并），行动列表中不重复显示已合并的子功能。
11. **删除低价值功能**（v0.82.3新增）：玩家从未使用、与其他功能重叠、负收益的功能果断删除（如等待时间），不要为了"功能完整"而保留。
12. **境界即身份**（v0.82.3新增）：右侧面板标题显示当前境界（初阶/中阶/高阶魔法师），而非泛泛的"魔法师"，让玩家看到成长。
13. **无折叠UI**（v0.81.0确认）：所有UI内容直接展开，不使用折叠/展开组件，减少点击层级。
14. **核心信息直显，次要信息tooltip**（v0.81.0确认）：行动名称/时间/经验直接显示，详细描述放tooltip；不要把所有信息都藏起来，也不要全部铺开。

## 三、主界面布局重构

### 3.1 整体布局（固定三栏，零滚动）

```
┌─────────────────────────────────────────────────────────┐
│  顶部状态栏（固定）                                        │
│  [当前地点] [时间] [状态] [HP/MP/体力] [Lv] [金币]         │
├──────────────────────────────────┬──────────────────────┤
│                                  │                      │
│  左侧：地点信息卡 + 行动区         │  右侧：菜单面板       │
│  ┌────────────────────────────┐  │  ┌────────────────┐  │
│  │ 📍 地点名 + 功能标签        │  │  │ 🎯 核心功能     │  │
│  │ 地点描述（1-2行）            │  │  │ 角色/背包/任务  │  │
│  │ [妖魔图标] [NPC数] [安全度]  │  │  │ 📚 信息收集     │  │
│  └────────────────────────────┘  │  │ 情报/声望/图鉴  │  │
│                                  │  │ 📅 日常          │  │
│  ┌────────────────────────────┐  │  │ ⚡ 快捷操作      │  │
│  │ 行动列表（按类型分组）        │  │  │ 休息/保存/地图  │  │
│  │ 🔮 修炼类                    │  │  └────────────────┘  │
│  │ 🔍 探索类                    │  │                      │
│  │ 💬 社交类                    │  │                      │
│  │ 😴 休息类                    │  │                      │
│  └────────────────────────────┘  │                      │
│                                  │                      │
├──────────────────────────────────┴──────────────────────┤
│  底部导航栏（固定，手机safe-area适配）                      │
│  [🗺️地图] [🎒背包] [👤角色] [📅日常] [⚙️设置]            │
└─────────────────────────────────────────────────────────┘
```

### 3.2 顶部状态栏（精简）
- 左：地点名 + 大地图标签（博城）+ 探索度
- 中：游戏内时间（第N天 时段）+ 状态buff
- 右：HP/MP/体力条（图标+数字）+ Lv + 金币

### 3.3 左侧地点信息卡（新增）
每个地点进入时显示：
- **地点名 + 功能标签**（如"修炼圣地""狩猎场""商业街"）
- **简短描述**（1-2行，从locations.js的description取）
- **信息条**：妖魔图标（可点击查看详情）、NPC数量、安全等级（安全/危险/极危险）
- **背景色调**：每个地点有独特的背景渐变色（修炼圣地=蓝紫、狩猎场=暗红、商业街=金黄等）

### 3.4 行动列表优化
- **按类型分组**：修炼/探索/社交/休息/特殊，每组有小标题
- **行动卡片**：图标+名称+消耗（时间/体力）+ 收益预览，横向或错落排列
- **地点专属行动高亮**：该地点独有的行动用特殊边框/颜色标记
- **通用行动弱化**：探索/聊天等通用行动用普通样式

### 3.5 右侧菜单面板（固定，可折叠）
- 分组保持现有：核心功能/信息收集/日常/快捷操作
- 增加"🗺️ 打开地图"快捷按钮在顶部

### 3.6 底部导航栏（新增，固定）
- 5个图标按钮：地图、背包、角色、日常、设置
- 手机端适配safe-area-inset-bottom
- 替代部分右侧菜单功能，减少点击层级

## 四、地图系统增强

### 4.1 移除文字前往列表
- 主界面不再显示"前往其他地点"文字列表
- 唯一入口：底部导航栏"🗺️地图"按钮 + 右侧菜单"打开地图"

### 4.2 地图节点详情弹窗（新增）
点击地图上的地点节点（非当前位置）时，弹出详情卡：
- 地点名 + 功能标签
- 完整描述
- 可遇妖魔（图标列表）
- 主要NPC（头像/名字）
- 解锁条件（如未解锁）
- 旅行时间
- **[前往此地]** 按钮

### 4.3 地图视觉增强
- 当前地点：绿色发光脉冲（现有）
- 已解锁可前往：蓝色发光
- 未解锁：灰色 + 锁图标
- 连线：根据地点关系显示不同样式（道路/山路/秘境入口）
- 大地图标题："博城" + 剧情阶段（灾难前/中/后）

## 六、"可能遇到的妖魔"处理

### 6.1 新位置
- 从主界面行动区移除
- 放到**地点信息卡**中，以**图标形式**显示（如🐺🐗👹）
- 点击图标展开妖魔详情（名字/等级/掉落）
- 危险地点用红色边框标记，安全地点不显示或显示"无妖魔"

### 6.2 好处
- 节省主界面空间
- 信息更紧凑（图标比文字省空间）
- 需要时才查看详情，不干扰核心操作

## 九、实施经验与踩坑总结（v0.80.0 ~ v0.82.3）

### 9.1 版本迭代记录

| 版本 | 核心改动 | 经验教训 |
|------|---------|---------|
| v0.80.0 | UI重构设计方案，2D地图，地点信息卡 | 设计先对齐再实施，避免返工 |
| v0.81.2 | 修复页面无法滚动，行动卡片优化 | overflow:hidden是滚动杀手，必须用overflow-y:auto |
| v0.81.3 | 手机端底部导航栏+全功能菜单 | 手机端右侧菜单隐藏后必须有替代入口 |
| v0.81.4 | 手机布局bug修复，电脑端右侧角色面板 | 竖版检测要用matchMedia+宽度双重判断 |
| v0.81.5 | 横向溢出修复 | Flex/Grid子元素默认min-width:auto，必须设min-width:0 |
| v0.81.6 | 手机布局强制修复 | 阈值要足够大（900px），竖版用!important强制覆盖 |
| v0.81.7 | 响应式行动网格 | 手机1列电脑2列，不要用auto-fit导致拥挤 |
| v0.82.0 | 休息系统合并+事件情报合并+背包响应式 | 相似功能合并到统一入口，减少冗余按钮 |
| v0.82.1 | 顶部状态栏精简+宿舍睡眠合并 | 顶部只留核心信息，地点名移到地点信息卡 |
| v0.82.2 | 删除普通冥修 | 功能重叠且效率低的果断删除 |
| v0.82.3 | 删除等待时间+右侧境界显示+加宽 | 玩家从未使用的功能不要保留 |

### 9.2 CSS踩坑记录

1. **页面无法滚动**：body和#game-container设了`overflow:hidden`+`height:100vh`，导致内容超出时无法滚动。修复：`overflow-y:auto; min-height:100vh`。
2. **横向溢出**：Flex/Grid子元素默认`min-width:auto`，长文字不换行导致溢出。修复：子元素加`min-width:0; overflow:hidden`，容器加`overflow-x:hidden`。
3. **手机端右侧内容消失**：竖版检测阈值太小（768px），部分手机宽度超过阈值但仍是竖版。修复：阈值提高到900px，加`window.innerHeight > window.innerWidth`判断。
4. **行动卡片描述被截断**：2列网格在手机上太挤，文字溢出。修复：手机固定1列，电脑固定2列，不要用auto-fit。
5. **顶部状态栏重复显示**：替换HTML时old_string结束位置不对，残留旧内容。修复：替换后检查残留，确保完全替换。
6. **变量作用域错误**：skipActions定义在renderAction函数内部，分组过滤时访问不到导致Script error。修复：变量定义移到外部，确保所有使用处都能访问。

### 9.3 功能设计经验

1. **合并优于新增**：遇到相似功能（如多种休息方式），优先合并到统一入口，用选项区分，而不是增加多个按钮。
2. **删除优于保留**：玩家从未使用、与其他功能重叠、负收益的功能果断删除。"功能完整"不等于"功能好用"。
3. **顶部极简**：顶部状态栏是最宝贵的空间，只放时间/金币/HP/MP/体力/等级。地点名、探索度、章节名、上课跳转等移到其他位置或删除。
4. **右侧面板是角色身份卡**：显示境界（初阶/中阶魔法师）、等级、状态条、属性、装备，让玩家一眼看到自己的成长。
5. **行动列表按类型分组**：修炼/探索/社交/休息/特殊，每组有小标题，空分组不显示。
6. **已合并的行动不在列表重复显示**：休息合并后，宿舍休息/睡觉等子行动从行动列表过滤掉，只保留统一的"休息"入口。

### 9.4 手机端适配准则

1. **底部导航栏必须大**：按钮高度≥50px，图标+文字，方便手机点击。
2. **手机safe-area适配**：底部导航栏要考虑手机系统导航栏遮挡，用padding-bottom适配。
3. **手机竖版1列布局**：行动卡片、背包等在手机上用上下布局，不要左右分栏。
4. **文字按钮放大**：手机端文字≥14px，按钮padding≥12px，避免误触。
5. **一屏原则**：主界面尽量一屏装下核心内容，减少滚动。
6. **悬停改长按**：电脑端mouseover的tooltip，手机端用touchstart/longpress实现。

### 9.5 信息分层准则

| 层级 | 内容 | 展示方式 |
|------|------|---------|
| 核心信息 | 行动名称、时间、经验、HP/MP/体力、等级、金币 | 直接显示在主界面 |
| 次要信息 | 行动详细描述、妖魔详情、地点说明 | tooltip（鼠标悬停/手机长按） |
| 冗余信息 | 探索度、章节名、上课跳转、等待时间 | 删除或移到其他位置 |
| 身份信息 | 境界、地点名、大地图名、功能标签 | 地点信息卡/右侧面板标题 |
