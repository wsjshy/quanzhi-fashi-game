## 五、已知遗留问题（非阻塞）

### 1. 战斗帮助界面残留
- 严重程度：P3（低）
- 说明：战斗中打开"战斗帮助"界面后，离开战斗时帮助界面未自动关闭，导致后续打开境界突破等界面时背景有帮助界面残留
- 影响：不影响功能，仅视觉重叠
- 建议：离开战斗时自动关闭战斗帮助界面

### 2. debug传送后战斗状态未完全清除
- 严重程度：P3（低）
- 说明：战斗中用debug传送离开后，设置等级或点击满血按钮会重新回到战斗界面，需要多次传送才能完全离开
- 影响：仅影响debug测试，不影响正常游戏流程
- 建议：debug传送时彻底退出战斗状态
