# 数据格式规范

本文档详细定义所有游戏数据的格式规范。

---

## 数据文件位置（v0.4.0 起）

原单文件 `game-data.js` 已拆分为 `engine/data/` 下的多个模块：

| 数据类型 | 文件 | 全局变量 |
|----------|------|----------|
| 技能 | `engine/data/skills.js` | `DataSkills` |
| NPC/角色 | `engine/data/characters.js` | `DataCharacters` |
| 地点 | `engine/data/locations.js` | `DataLocations` |
| 物品+装备 | `engine/data/items.js` | `DataItems` |
| 任务 | `engine/data/quests.js` | `DataQuests` |
| 随机事件 | `engine/data/events.js` | `DataEvents` |
| 商店 | `engine/data/shops.js` | `DataShops` |
| 敌人/妖魔 | `engine/data/enemies.js` | `DataEnemies` |
| 势力/情报/事件链 | `engine/data/world.js` | `DataWorld` |
| 合并入口 | `engine/data/index.js` | `GameData` |

新增内容请修改对应模块文件，所有模块最终通过 `index.js` 合并为全局 `GameData` 对象。

## 通用规范

### ID 命名规则
- 使用小写字母 + 下划线
- 见名知意，例如 `fire_bolt`、`demon_wolf`
- 全局唯一，不同类型的内容也不能重名

### 元素类型枚举
| ID | 名称 | 颜色 |
|----|------|------|
| fire | 火系 | #ff6633 |
| ice | 冰系 | #66ccff |
| thunder | 雷系 | #ffcc00 |
| earth | 土系 | #cc9966 |
| wind | 风系 | #99ff99 |
| water | 水系 | #6699ff |
| light | 光系 | #ffffcc |
| dark | 暗影系 | #9966ff |
| neutral | 无属性 | #999999 |

### 元素克制关系
- 火系 克制 冰系、风系
- 冰系 克制 水系、风系
- 雷系 克制 水系、土系
- 土系 克制 雷系、火系
- 风系 克制 土系、雷系
- 水系 克制 火系、土系
- 光系 克制 暗影系
- 暗影系 克制 光系

克制伤害：1.5x
被克制伤害：0.7x

## 一、技能数据格式

**文件**：`engine/data/skills.js`（全局变量 `DataSkills`）

```typescript
interface Skill {
  id: string;                    // 技能ID
  name: string;                  // 技能名称
  description: string;           // 技能描述
  element: ElementType;          // 元素类型
  type: 'damage' | 'heal' | 'buff' | 'debuff';  // 技能类型
  mpCost: number;                // 魔法消耗
  baseDamage?: number;           // 基础伤害（伤害类必填）
  power?: number;                // 伤害倍率（妖魔技能用，默认1.0）
  damageMultiplier?: number;     // 伤害倍率，默认1.0
  baseHeal?: number;             // 基础治疗（治疗类必填）
  healMultiplier?: number;       // 治疗倍率，默认1.0
  hitRate?: number;              // 命中率 0-1
  critRate?: number;             // 暴击率 0-1
  critMultiplier?: number;       // 暴击倍率，默认1.5
  targetType: 'enemy' | 'self' | 'ally';  // 目标类型
  cooldown: number;              // 冷却回合数
  tier: '初阶' | '中阶' | '高阶' | '超阶' | '奴仆级' | '战将级' | '统领级' | '君主级';
  isDemonSkill?: boolean;        // 是否妖魔技能（妖魔技能不消耗MP）
  isCanon?: boolean;             // 是否小说原著技能（默认true，非原著设false）
  canonNote?: string;            // 非原著说明
  guaranteedHit?: boolean;       // 必定命中
  guaranteedCrit?: boolean;      // 必定暴击
  ignoreDefense?: number;        // 无视防御比例 0-1
  hitCount?: number;             // 多段攻击次数
  statusEffects?: StatusEffect[];  // 状态效果
}

interface StatusEffect {
  name: string;                  // 效果名称
  type: string;                  // 效果类型
  duration: number;              // 持续回合数
  chance: number;                // 触发概率 0-1
  dotDamage?: number;            // 每回合伤害（DOT类）
  value?: number;                // 效果数值（如治疗降低比例）
  statModifiers?: {              // 属性修改
    attack?: number;
    defense?: number;
    speed?: number;
    maxHp?: number;
    maxMp?: number;
    evasion?: number;            // 闪避率
    critRate?: number;           // 暴击率
  };
}
```

### 状态效果类型
**基础效果**：
- `burn` - 灼烧（每回合伤害）
- `freeze` - 冻结（无法行动）
- `paralyze` - 麻痹（概率无法行动）
- `slow` - 减速（速度降低）
- `poison` - 中毒（每回合伤害）
- `defense_up` - 防御提升
- `attack_up` - 攻击提升
- `speed_up` - 速度提升
- `defense_down` - 防御降低
- `attack_down` - 攻击降低

**v0.8.x新增效果**：
- `bleed` - 流血（每回合伤害，可叠加）
- `stun` - 眩晕（无法行动）
- `confuse` - 混乱（可能攻击友方或无法行动）
- `bind` - 束缚（无法行动）
- `curse` - 诅咒（属性降低）
- `healing_reduction` - 治疗效果降低
- `dodge_up` - 闪避提升
- `crit_up` - 暴击率提升
- `silence` - 沉默（无法使用技能）
- `purify` - 净化（清除负面效果）

## 二、敌人/妖魔数据格式

**文件**：`engine/data/enemies.js`（全局变量 `DataEnemies`）

```typescript
interface Enemy {
  id: string;                    // 妖魔ID
  name: string;                  // 妖魔名称
  title: string;                 // 称号（如"奴仆级妖魔"）
  description: string;           // 描述（尽量引用小说原文）
  elements: ElementType[];       // 元素列表
  level: number;                 // 等级
  maxHp: number;                 // 最大生命
  maxMp: number;                 // 最大魔法（妖魔一般为0）
  attack: number;                // 攻击力
  defense: number;               // 防御力
  speed: number;                 // 速度
  spirit?: number;               // 精神力
  skills: string[];              // 技能ID列表
  aiType: AIType;                // AI类型
  spriteColor?: string;          // 颜色（无图时用）
  isEnemy: boolean;              // 是否敌人（true）
  
  // 妖魔属性
  demonTier?: 'servant' | 'warrior' | 'commander' | 'monarch';  // 妖魔阶级
  isCanon?: boolean;             // 是否小说原著妖魔（默认true，非原著设false）
  canonNote?: string;            // 非原著说明
  isBoss?: boolean;              // 是否Boss
  isBlackChurch?: boolean;       // 是否黑教廷相关
  isUndead?: boolean;            // 是否亡灵
  isPlant?: boolean;             // 是否植物系妖魔
  canFly?: boolean;              // 是否飞行
  canBurrow?: boolean;           // 是否钻地
  
  // 特殊能力
  specialAbility?: string;       // 特殊能力描述
  ignoreDefense?: number;        // 无视防御比例 0-1
  fireWeakness?: number;         // 火系弱点倍率（如1.8表示受1.8倍伤害）
  thunderResistance?: number;    // 雷系抗性倍率（如0.5表示受0.5倍伤害）
  
  // 召唤能力（Boss用）
  summonSkill?: string;          // 召唤技能ID
  summonEnemy?: string;          // 召唤的敌人ID
  summonCount?: number;          // 召唤数量
  
  // 奖励
  expReward: number;             // 经验奖励
  goldReward: number;            // 金币奖励
  dropItems?: DropItem[];        // 掉落物品
}

type AIType = 'aggressive' | 'defensive' | 'controller' | 'burst' | 'kiter' | 'tactical';
// aggressive: 激进型，优先攻击
// defensive: 保守型，低血量防御/治疗
// controller: 控制型，优先使用控制技能
// burst: 爆发型，攒MP放大招
// kiter: 游击型，高速移动，打了就跑
// tactical: 战术型，根据情况选择最优行动
```

### 妖魔阶级加成（自动应用）
| 阶级 | demonTier | HP加成 | 攻击加成 | 防御加成 |
|------|-----------|--------|----------|----------|
| 奴仆级 | servant | +20% | +15% | +10% |
| 战将级 | warrior | +50% | +30% | +20% |
| 统领级 | commander | +100% | +50% | +40% |
| 君主级 | monarch | +200% | +100% | +80% |

### 非原著内容标记规范
```javascript
// 非原著妖魔必须标记

  // ...

// 非原著技能必须标记
{

  name: "虚体打击",
  isDemonSkill: true,
  isCanon: false,
  canonNote: "非原著技能，游戏设计",

interface Dialogue {
  trigger: string;               // 触发条件
  text: string;                  // 对话文本
  speakerColor?: string;         // 说话人颜色
  next?: string;                 // 下一段对话ID
  choices?: DialogueChoice[];    // 选项
}

interface DialogueChoice {
  text: string;                  // 选项文本
  next: string;                  // 跳转到的对话ID
  effects?: EffectObject;        // 选择后的效果
}

interface DropItem {
  itemId: string;                // 物品ID
  chance: number;                // 掉落概率 0-1
  min: number;                   // 最小数量
  max: number;                   // 最大数量
}

## 三、地点数据格式

**文件**：`content/locations/*.json`

```typescript
interface Location {
  id: string;                    // 地点ID
  name: string;                  // 地点名称
  description: string;           // 地点描述
  background?: string;           // 背景图片路径
  backgroundColor?: string;      // 背景颜色（无图时用）
  unlocked: boolean;             // 是否初始解锁
  unlockCondition?: UnlockCondition;  // 解锁条件
  actions: LocationAction[];     // 可执行的行动列表
  connectedLocations?: string[]; // 相邻地点（可以移动过去）
  enemies?: string[];            // 可能遇到的敌人ID列表
  enemyRate?: number;            // 遇敌概率 0-1
}

interface LocationAction {
  id: string;                    // 行动ID
  name: string;                  // 行动名称
  description: string;           // 行动描述
  icon?: string;                 // 图标（emoji）
  timeCost: number;              // 消耗时间（小时）
  energyCost?: number;           // 消耗体力
  effects?: EffectObject;        // 直接效果
  eventChance?: number;          // 触发事件概率 0-1
  events?: string[];             // 可能触发的事件ID列表
  shopId?: string;               // 商店ID（如果是商店行动）
  battleId?: string;             // 战斗ID（如果是战斗行动）
  questId?: string;              // 任务相关
  npcs?: string[];               // 可对话的NPC列表
}

interface UnlockCondition {
  type: 'quest' | 'level' | 'item' | 'day' | 'flag';
  value: string | number;
}

interface EffectObject {
  hp?: number;                   // 生命值变化
  mp?: number;                   // 魔法值变化
  exp?: number;                  // 经验变化
  gold?: number;                 // 金币变化
  attack?: number;               // 攻击变化（永久）
  defense?: number;              // 防御变化（永久）
  speed?: number;                // 速度变化（永久）
  maxHp?: number;                // 最大生命变化
  maxMp?: number;                // 最大魔法变化
  addItem?: { itemId: string; count: number };  // 添加物品
  removeItem?: { itemId: string; count: number };  // 移除物品
  addSkill?: string;             // 学习技能
  awakenElement?: string;        // 觉醒元素
  setFlag?: string;              // 设置标记
}
```

interface Item {
  id: string;                    // 物品ID
  name: string;                  // 物品名称

  icon?: string;                 // 图标（emoji）

  equipStats?: {                 // 装备属性加成

## 五、任务数据格式

**文件**：`content/quests/*.json`

```typescript
interface Quest {
  id: string;                    // 任务ID
  name: string;                  // 任务名称
  description: string;           // 任务描述
  giver: string;                 // 发布者NPC ID
  type: QuestType;               // 任务类型
  objectives: QuestObjective[];  // 任务目标
  rewards: QuestRewards;         // 任务奖励
  prerequisites?: string[];      // 前置任务ID列表
  nextQuest?: string;            // 后续任务ID
  isMainQuest?: boolean;         // 是否主线任务
  // 对话
  dialogueStart: string;         // 接取任务对话
  dialogueInProgress: string;    // 进行中对话
  dialogueComplete: string;      // 完成对话
  // 触发
  autoStart?: boolean;           // 是否自动接取
  startCondition?: UnlockCondition;  // 开始条件
}

type QuestType = 
  | 'hunt'       // 猎杀
  | 'collect'    // 收集
  | 'talk'       // 对话
  | 'escort'     // 护送
  | 'story'      // 剧情
  | 'explore';   // 探索

interface QuestObjective {
  type: 'kill' | 'collect' | 'talk' | 'reach' | 'use_item';
  enemyId?: string;              // 敌人ID（kill类型）
  itemId?: string;               // 物品ID（collect类型）
  npcId?: string;                // NPC ID（talk类型）
  locationId?: string;           // 地点ID（reach类型）
  count: number;                 // 需要数量
  description: string;           // 目标描述
}

interface QuestRewards {
  exp?: number;                  // 经验奖励
  gold?: number;                 // 金币奖励
  items?: { itemId: string; count: number }[];  // 物品奖励
  unlocks?: string[];            // 解锁的内容
  reputation?: { faction: string; amount: number }[];  // 声望
}
```

## 六、事件数据格式

**文件**：`content/events/*.json`

```typescript
interface GameEvent {
  id: string;                    // 事件ID
  name: string;                  // 事件名称
  description: string;           // 事件描述
  trigger: EventTrigger;         // 触发方式
  chance: number;                // 触发概率 0-1
  conditions?: EventCondition[]; // 触发条件
  once?: boolean;                // 是否只触发一次
  choices: EventChoice[];        // 选项列表
}

type EventTrigger = 
  | 'training'    // 修炼时
  | 'exploring'   // 探索时
  | 'travel'      // 旅行时
  | 'rest'        // 休息时
  | 'shop'        // 购物时
  | 'battle_end'  // 战斗结束时
  | 'day_start'   // 每天开始时
  | 'day_end'     // 每天结束时
  | 'level_up'    // 升级时
  | 'manual';     // 手动触发

interface EventCondition {
  type: 'level' | 'day' | 'gold' | 'item' | 'quest' | 'flag' | 'location';
  value: string | number;
  operator?: '>' | '<' | '>=' | '<=' | '==' | '!=';
}

interface EventChoice {
  text: string;                  // 选项文本
  effects?: EffectObject;        // 选择效果
  resultText: string;            // 结果描述
  nextEvent?: string;            // 后续事件
}
```

## 七、玩家存档格式

```typescript
interface PlayerSave {
  // 基础信息
  name: string;                  // 玩家姓名
  level: number;                 // 等级
  exp: number;                   // 当前经验
  expToNext: number;             // 下一级所需经验
  attributePoints: number;       // 未分配属性点
  
  // 属性
  maxHp: number;
  hp: number;
  maxMp: number;
  mp: number;
  attack: number;
  defense: number;
  speed: number;
  spirit: number;                // 精神力
  
  // 元素与技能
  elements: ElementType[];       // 已觉醒元素
  skills: string[];              // 已学习技能
  
  // 背包
  gold: number;                  // 金币
  inventory: InventoryItem[];    // 背包物品
  equipment: {                   // 装备
    weapon: string | null;
    armor: string | null;
    accessory: string | null;
  };
  
  // 任务
  activeQuests: ActiveQuest[];   // 进行中的任务
  completedQuests: string[];     // 已完成任务
  
  // 进度
  currentLocation: string;       // 当前地点
  day: number;                   // 当前天数
  timeOfDay: 'morning' | 'afternoon' | 'evening' | 'night';  // 时段
  flags: Record<string, boolean>;  // 剧情标记
  unlockedLocations: string[];   // 已解锁地点
  
  // 设置
  version: string;               // 存档版本号
  saveTime: string;              // 保存时间
}

interface InventoryItem {
  itemId: string;
  count: number;
}

interface ActiveQuest {
  questId: string;
  progress: number[];            // 每个目标的进度
  startTime: number;             // 接取时间（天数）
}
```

## 版本兼容性

- 所有数据格式变更必须向后兼容
- 新增字段使用可选字段，有默认值
- 废弃字段保留至少 2 个版本
- 存档格式变更时，版本号递增，并提供迁移逻辑
