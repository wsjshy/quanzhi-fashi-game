## 二、操作步骤

1. 用 Chrome 打开 `index.html?debug=1` 测试页面
2. 点击「开始新游戏」，选择冰系，确认创建角色
3. 选择冰系天赋「冰魂」，进入游戏主界面
4. 打开右侧「调试工具」面板，切换到「战斗」标签
5. 点击「满血满蓝满体力」，然后点击「巨眼猩鼠」触发战斗
6. 按 `F12` 打开开发者工具，切换到 **Console** 标签
7. 点击底部「冰系」卡片展开技能列表，连续点击「冰蔓·冻结」技能卡片释放技能
8. 每次释放后观察 Console 中 `[DEBUG]` 输出，记录结果
9. 战斗结束后重新触发战斗，累计释放 10 次以上

> 说明：第一场战斗角色为1级（HP:120, MP:60），释放2次后因HP不足战败；随后通过调试工具将角色设置为10级（HP:208, MP:104），继续完成剩余测试。
