# v0.52.0 影响力事件链扩展III（穆白）

> 版本：v0.52.0
> 日期：2026-08-15
> 定位：扩展穆白的flag驱动事件链，体现其表面谦逊内心高傲的复杂性格，涉及与穆宁雪的族亲关系

---

## 一、设计原则

1. **不围绕莫凡**——事件是玩家与穆白的互动，不提及莫凡
2. **人设不可破坏**——穆白表面谦逊有礼，内心高傲阴暗，典型"绿茶男"
3. **关系上限适配**——maxOpinion=60，maxTrust=40，好感提升少且难
4. **选择有代价**——与穆白交好可能获得资源，但也可能失去其他NPC好感
5. **族亲关系**——可涉及穆宁雪（族亲），但非恋爱导向，体现家族内部微妙关系

---

## 二、事件链：穆白的认可

### 核心逻辑
玩家引起穆白注意 → 表面客气的试探 → 冰系切磋（想证明自己）→ 家族优越感展示 → 穆宁雪的微妙态度

### 事件1：表面的谦逊
- **触发**：找人聊天/自习时
- **条件**：minRelationship 10, 玩家等级≥5, notFlag("mu_bai_noticed")
- **描述**：穆白面带标准微笑走过来，"你好，我是穆白。最近看你修炼很用功，有什么心得可以交流吗？"他的语气礼貌而得体，但眼神中闪过一丝不易察觉的审视。
- **选择**：
  1. 客气回应，请教冰系修炼 → setFlag, npcOpinion +2（穆白表面热情，内心轻视）
  2. 简单回应，保持距离 → setFlag, npcOpinion +3（穆白觉得你不简单，反而多看一眼）
  3. 直接点破他的虚伪 → setFlag, npcOpinion -5, reputation +3（穆白笑容僵住，但周围同学暗暗佩服你的勇气）

### 事件2：冰系的切磋
- **触发**：修炼/找人聊天时
- **条件**：requireFlag("mu_bai_noticed"), minRelationship 15
- **描述**：穆白"恰好"路过，"这么巧？我正想找人切磋一下冰系技巧，要不要试试？"他的笑容很真诚，但你能感觉到他想通过切磋证明什么。
- **选择**：
  1. 好，请穆学长指教 → npcOpinion +2, exp +20（穆白赢了后表面谦虚，内心得意）
  2. 今天状态不好，下次吧 → npcOpinion +1（穆白："没关系，随时恭候"）
  3. 切磋可以，但点到为止 → npcOpinion +3, reputation +2（穆白意外于你的从容）

### 事件3：家族的优越感
- **触发**：找人聊天/自习时
- **条件**：requireFlag("mu_bai_noticed"), minRelationship 20
- **描述**：穆白不经意地提到，"说起来，穆氏家族最近弄到了一批高品质魔石，修炼效果很不错。"他看了你一眼，"可惜家族资源有限，只能优先给嫡系子弟。"他的语气中带着一丝不易察觉的优越感。
- **选择**：
  1. 穆氏家族确实底蕴深厚 → npcOpinion +2（穆白很受用）
  2. 出身不能决定一切，实力才是关键 → npcOpinion -3, reputation +4（穆白笑容微僵，但周围同学投来赞同的目光）
  3. 沉默不语，不接话 → npcOpinion +1（穆白觉得你识趣）

### 事件4：族亲的关注
- **触发**：修炼/找人聊天时
- **条件**：requireFlag("mu_bai_noticed"), minRelationship 25, 玩家与穆宁雪关系≥15
- **描述**：穆宁雪路过，看到你和穆白在一起，脚步微顿。穆白立刻换上更标准的笑容，"宁雪堂姐，好巧。"穆宁雪淡淡点头，目光在你身上停留了一秒，然后离开了。穆白的笑容有些微妙。
- **选择**：
  1. 假装没注意到穆宁雪的反应 → npcOpinion(mu_bai) +1
  2. 事后找穆宁雪问问穆白的为人 → npcOpinion(mu_ningxue) +3, npcOpinion(mu_bai) -2（穆宁雪提醒你穆白的为人）
  3. 向穆白打听穆宁雪的事 → npcOpinion(mu_bai) +2, npcOpinion(mu_ningxue) -1（穆白觉得你和他是一类人）

---

## 三、设计亮点

1. **穆白的"绿茶"性格**：表面谦逊，内心高傲，事件中通过"眼神中闪过"、"笑容微僵"等细节体现
2. **选择有代价**：与穆白交好可能获得资源，但点破他会失去他的好感却赢得同学声望
3. **NPC间关系影响**：事件4涉及穆宁雪的态度，玩家的选择会同时影响两个NPC的关系
4. **关系上限低**：穆白maxOpinion=60，即使全部选正面选项也达不到亲密，符合人设

## 四、技术实现

- 复用v0.48.0基础设施：requireFlag/notFlag/setFlag
- 事件4同时修改两个NPC的opinion（事件系统支持npcOpinion对象多NPC）
- 事件数据添加到engine/data/events.js

## 五、验证标准

1. 穆白事件链：关系10+等级≥5触发事件1，setFlag后事件2-4依次可触发
2. 人设检查：穆白表面谦逊内心高傲，事件4体现族亲微妙关系
3. 不围绕莫凡：所有事件中不提及莫凡
4. 多NPC关系变化：事件4选择2/3会同时影响穆白和穆宁雪的好感
5. 冒烟测试：游戏不崩溃，事件数据正确加载
