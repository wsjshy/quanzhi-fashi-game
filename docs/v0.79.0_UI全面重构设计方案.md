> 版本：v0.79.0（设计阶段，待对齐）
> 日期：2026-08-16
> 目标：玩家友好，大胆重构，不被现有布局束缚

## 一、当前UI功能清单与问题分析

### 1.1 现有界面清单

| 界面 | 功能 | 当前形式 | 问题 |
|------|------|----------|------|
| 主界面 | 地点行动+右侧菜单+顶部状态栏 | 三栏布局 | 行动列表太长，地点移动是文字列表 |
| 背包 | 物品管理+装备+强化 | 左右分栏 | 基本可用，但强化继承入口深 |
| 角色属性 | 属性/元素/天赋/突破 | 单页多标签 | 信息密度高，重点不突出 |
| 任务 | 进行中/已完成 | 列表 | 基本可用 |
| 情报 | 已知信息/线索/谣言 | 分类列表 | 基本可用 |
| 声望 | NPC关系/势力声望 | 列表 | 与角色属性有重叠 |
| 成就 | 成就列表 | 列表 | 基本可用 |
| 帮助 | 游戏说明 | 文本 | 可合并到设置 |
| 妖魔图鉴 | 妖魔收集 | 卡片列表 | 基本可用 |
| 日常 | 签到+每日任务 | 单页 | 已优化，基本可用 |
| 商店 | 购买/出售 | 左右分栏 | 基本可用 |
| 战斗 | 技能/道具/防御 | 底部操作栏 | 基本可用 |
| **地点移动** | 前往其他地点 | **文字列表** | **核心问题：没有地图感，不直观** |
| 对话 | NPC对话 | 弹窗+选项 | 基本可用 |
| 事件 | 随机事件 | 弹窗 | 基本可用 |

### 1.2 核心问题

1. **没有可视化地图**：地点移动是文字列表，玩家没有空间感，不知道各个地点的相对位置
2. **主界面信息过载**：行动列表+右侧菜单+状态栏，新玩家可能不知所措
3. **功能入口分散**：11个菜单项平铺，核心功能不突出（已部分优化）
4. **缺少全局导航**：进入子界面后返回主界面路径不统一
5. **缺少小地图/位置感**：玩家不知道自己在大世界的哪个位置

## 二、大胆重构方案

### 2.1 可视化地图系统（核心改动）

**设计思路**：把"前往其他地点"从文字列表改成可视化地图，玩家点击地点图标直接前往。

**地图形式**：
- **2D俯视图地图**：博城大地图作为背景，各个地点用图标/节点标注在地图上
- **节点连线**：有通路的地点之间用线连接，直观展示连通性
- **当前位置高亮**：玩家当前所在地点用特殊标记（如发光圆圈）
- **未解锁地点**：灰色显示，鼠标悬停显示解锁条件
- **地点信息**：点击地点显示名称、描述、探索状态
- **前往按钮**：点击已解锁地点直接前往

**地图层级**：
- 大地图（博城）：显示所有大区域（学校、市区、雪峰山等）
- 点击大区域进入区域地图，显示具体地点
- 或者：一张地图显示所有地点，用区域分组

**实现方式**：
- 用HTML/CSS绝对定位实现地点节点
- 背景用渐变或简单的地图底图（不需要复杂美术）
- 地点坐标在locations.js中配置x/y位置
- 连线用SVG或CSS border实现

### 2.2 主界面重构

**当前问题**：行动列表太长，右侧菜单占空间。

**重构方案**：
- **顶部状态栏**：保持，但精简信息（大地图+地点+时间+HP/MP/等级+金币）
- **左侧/中央**：当前地点的行动列表，按类别分组（修炼/探索/社交/休息）
- **右侧**：精简菜单，核心功能用图标按钮，次要功能收进"更多"
- **底部**：可视化地图缩略图，点击展开全屏地图

**或者更大胆**：
- 主界面默认显示**可视化地图**，玩家在地图上点击地点
- 点击当前地点后弹出该地点的行动面板
- 行动面板可以是侧边滑出或弹窗

### 2.3 全局导航优化

**底部导航栏**（参考成熟手游）：
- 固定在屏幕底部，4-5个图标按钮
- 主页（地图）、背包、角色、任务、更多
- 任何界面都能快速切换
- 当前所在界面高亮

**返回按钮统一**：
- 所有子界面左上角有返回箭头
- 点击返回主界面（地图）

### 2.4 其他UI优化

**背包**：
- 装备和物品分标签页
- 强化/继承入口更明显
- 物品分类筛选优化

**角色属性**：
- 核心属性（HP/MP/攻击/防御）大字体显示
- 元素/天赋/突破用标签页切换
- 声望合并到角色属性的"关系"标签

**任务**：
- 主线/支线/日常分标签
- 当前追踪任务显示在主界面侧边

## 三、可视化地图详细设计

### 3.1 地图数据结构

在locations.js中为每个地点添加地图坐标：
```javascript
tianlan_magic_high_school: {
    id: "tianlan_magic_high_school",
    name: "天澜魔法高中",
    mapX: 300,  // 地图上的X坐标
    mapY: 200,  // 地图上的Y坐标
    mapIcon: "🏫",  // 地图图标
    ...
}
```

### 3.2 地图界面布局

```
┌─────────────────────────────────────┐
│  ← 返回    🗺️ 博城地图    🔍 缩放   │
├─────────────────────────────────────┤
│                                     │
│         [雪峰山] ⛰️                  │
│              |                      │
│              |                      │
│  [市区] 🏙️ --[学校] 🏫 --[猎场] 🌲  │
│              |                      │
│              |                      │
│         [金林火车站] 🚂             │
│                                     │
│  📍 当前位置：天澜魔法高中           │
└─────────────────────────────────────┘
```

### 3.3 交互流程

1. 玩家点击底部"地图"按钮或主界面地图缩略图
2. 打开全屏地图界面
3. 地图上显示所有地点图标，当前位置高亮
4. 点击已解锁地点 → 显示地点信息卡 → 点击"前往"
5. 点击未解锁地点 → 显示解锁条件
6. 有通路的地点之间显示连线

### 3.4 地图视觉风格

- 深色背景（符合游戏整体风格）
- 地点用圆形/方形节点，带emoji图标
- 已解锁：亮色边框，可点击
- 未解锁：灰色，半透明
- 当前位置：发光动画效果
- 连线：虚线或实线，表示可通行
