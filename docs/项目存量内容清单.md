## 四、后续开发判断指南

### 新增内容前必查
1. **查此清单**：判断是否已有类似系统/数据
2. **查原文**：Grep全职法师.txt验证设定
3. **查现有数据**：Grep对应data文件确认ID不重复
4. **判断分类**：独立系统/合并扩展/文本带过

### 常见判断
- "这个NPC有对话吗？" → 查characters.js，搜索NPC ID
- "这个地点存在吗？" → 查locations.js，搜索地点ID
- "这个系统有基础吗？" → 查第一节系统清单
- "这个剧情线做了吗？" → 查第三节剧情线清单

### 优先级原则
1. 核心循环（修炼/战斗/剧情）优先
2. 可复用系统优先（后续篇章能用）
3. 完善已有系统优先于新增系统
4. 纯设定展示用文本带过，不造系统
