# 游戏部署经验总结（v3.1.0更新）

> ⚠️ v3.0.0架构改造后：项目采用Vite + ES Modules，部署前需要构建。
> ⚠️ v3.1.0起：**开发在master分支，部署在gh-pages分支**，避免混淆。

## 分支说明（重要！）

| 分支 | 用途 | 内容 | 部署 |
|------|------|------|------|
| **master** | 开发分支 | 源代码（src/、docs/、tests/等） | ❌ 不直接部署 |
| **gh-pages** | 部署分支 | 构建产物（dist/目录内容） | ✅ GitHub Pages部署源 |

**核心原则：**
- 所有开发工作在master分支进行
- 部署时先在master分支执行`npm run build`，然后将dist目录内容推送到gh-pages分支
- 不要在gh-pages分支进行开发工作
- 不要将node_modules、src/、docs/等开发文件推送到gh-pages分支

## v3.1.0 部署流程（Vite构建 + gh-pages分支）

### 开发模式
```bash
npm run dev    # 启动Vite开发服务器，http://localhost:5173
```

### 生产构建
```bash
npm run build  # 构建到dist/目录
npm run preview # 预览构建产物
```

### 部署到GitHub Pages（gh-pages分支）

#### 首次部署（创建gh-pages分支）
```powershell
cd C:\Users\22210\Desktop\quanzhi-fashi-game-master

# 1. 在master分支构建
npm run build

# 2. 创建gh-pages分支（孤儿分支，不继承master历史）
& "D:\Git\cmd\git.exe" checkout --orphan gh-pages

# 3. 清空gh-pages分支的所有文件
& "D:\Git\cmd\git.exe" rm -rf .

# 4. 复制dist目录内容到根目录
Copy-Item -Path "dist\*" -Destination "." -Recurse -Force

# 5. 添加.gitignore（排除node_modules等）
"node_modules/`ndist/`n.vite/`n.netlify/`n.vercel/" | Out-File -FilePath ".gitignore" -Encoding utf8

# 6. 提交并推送
& "D:\Git\cmd\git.exe" add .
& "D:\Git\cmd\git.exe" commit -m "Deploy: v3.1.0 博城篇内容深化"
& "D:\Git\cmd\git.exe" push github gh-pages --force

# 7. 切回master分支继续开发
& "D:\Git\cmd\git.exe" checkout master
```

#### 后续更新部署

### 部署方式
- **GitHub Pages**：部署gh-pages分支（dist/目录构建产物）
- **Netlify**：构建命令`npm run build`，发布目录`dist`
- **静态服务器**：将dist/目录放到任何静态服务器即可

### 注意事项
- 根目录的index.html是Vite开发模式入口（使用ES Modules，引用`/src/main.js`），**不能直接部署**到静态服务器
- 必须运行`npm run build`生成dist/目录后才能部署
- dist/index.html引用的是构建后的`./assets/index-xxx.js`，可以直接部署
- vite.config.js已配置`base: './'`，支持子路径部署
- **开发在master，部署在gh-pages**，不要混淆

### 完整部署流程

#### 1. 创建 GitHub 仓库
- 登录 https://github.com/new
- Repository name: `quanzhi-fashi-game`
- Description: `基于小说《全职法师》的HTML5网页游戏，纯前端实现，Vite构建。包含魔法战斗、修炼升级、探索冒险、NPC对话、任务系统、随机事件、大事件剧情等丰富玩法。`
- 选择 **Public**（GitHub Pages 免费版需要公开仓库）
- **不要**勾选 Add README、Add .gitignore、Add license（项目已有这些文件）
- 点击 Create repository

#### 2. 配置 Git 代理（中国大陆必须）
GitHub 在中国大陆直连不稳定，Git 命令行需要配置系统代理：
```powershell
# 查看系统代理（Clash/V2Ray等通常是 127.0.0.1:7890）
Get-ItemProperty -Path "HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings" | Select-Object ProxyEnable, ProxyServer

# 为 GitHub 设置 Git 代理（关键步骤！）
& "D:\Git\cmd\git.exe" config --global http.https://github.com.proxy http://127.0.0.1:7890
```

**注意**：浏览器能访问 GitHub 不代表 Git 命令行能访问。浏览器自动走系统代理，但 Git 需要单独配置。

#### 3. 添加远程仓库并推送源代码
```powershell
cd C:\Users\22210\Desktop\quanzhi-fashi-game-master

# 添加 GitHub 远程仓库（如果还没添加）
& "D:\Git\cmd\git.exe" remote add github https://github.com/wsjshy/quanzhi-fashi-game.git

# 推送源代码到master分支
& "D:\Git\cmd\git.exe" push -u github master
```

#### 4. 启用 GitHub Pages（选择gh-pages分支）
- 进入仓库 Settings → Pages（或直接访问 https://github.com/wsjshy/quanzhi-fashi-game/settings/pages）
- Source: 保持 "Deploy from a branch"
- Branch: 选择 `gh-pages`，文件夹保持 `/ (root)`

- 等待 1-2 分钟部署完成
- 访问地址：https://wsjshy.github.io/quanzhi-fashi-game/

#### 5. 后续更新部署
每次开发完成后，需要先构建再部署到gh-pages分支：

推送后 1-2 分钟自动生效。

### GitHub Pages 注意事项
1. **必须公开仓库**：免费版 GitHub Pages 不支持私有仓库
2. **分支名**：开发用master分支，部署用gh-pages分支，不要混淆
3. **gh-pages分支只放构建产物**：不要将src/、docs/、tests/、node_modules等开发文件推送到gh-pages分支
4. **HTTPS 强制开启**：Settings → Pages 底部有 Enforce HTTPS 选项，建议开启
5. **404 问题**：刚保存设置后访问会 404，等 1-2 分钟部署完成即可
6. **代理只影响 Git**：部署后的网站用户访问不需要代理（但国内直连 GitHub Pages 速度可能较慢）
7. **相对路径**：游戏中所有资源引用使用相对路径，不要用绝对路径
8. **构建后才能部署**：根目录的index.html是开发入口（引用/src/main.js），不能直接部署，必须npm run build生成dist目录

### 浏览器自动化操作 GitHub 的经验
GitHub 网页上的按钮和下拉菜单用自动化工具点击时经常不响应，解决方案：
- **普通 click 不生效时**：使用 `mouse_down` + `mouse_up` 组合模拟完整点击
- **下拉菜单**：同样需要 mouse_down + mouse_up 才能展开
- **表单提交**：填完表单后也需要 mouse_down + mouse_up 点击提交按钮
- **Tab 键导航**：在 GitHub 表单中 Tab 键焦点移动可能不可见，不推荐
- **直接导航 URL**：Settings 页面可以直接访问 `/settings/pages`，不需要点击导航栏

### 关键踩坑：必须创建干净部署目录
**错误做法**：直接部署项目根目录
```
netlify deploy --prod --dir=.  # 会报错 JSONHTTPError: no records matched 422
```
**原因**：项目根目录包含 `.git/`、`docs/`、`tests/`、`tools/` 等非游戏文件。

**正确做法**：
```powershell
New-Item -ItemType Directory -Path deploy_dist
Copy-Item index.html deploy_dist
Copy-Item -Recurse engine deploy_dist
Copy-Item -Recurse assets deploy_dist
netlify deploy --prod --dir=deploy_dist --site=<site_id>
Remove-Item -Recurse -Force deploy_dist
```

## 六、手机端适配经验

### 适配方案
CSS 媒体查询 + class 标记，仅屏幕宽度 < 768px 时触发手机布局。

### 关键 CSS（index.html）
```css
@media (max-width: 768px) {
    .mobile-main-content { flex-direction: column !important; }
    .mobile-action-panel { flex: none !important; width: 100% !important; }
    .mobile-side-menu { width: 100% !important; border-left: none !important; border-top: 2px solid #444477 !important; }
    .mobile-top-bar { flex-wrap: wrap !important; gap: 8px !important; }
    .mobile-element-grid { grid-template-columns: repeat(2, 1fr) !important; }
    .mobile-popup { max-width: 92vw !important; width: 92vw !important; }
    .mobile-title h1 { font-size: 32px !important; }
    body { overflow-x: hidden; }
}
```

### 注意事项
- 内联样式优先级高于 CSS，必须用 `!important` 覆盖
- viewport meta 标签必须有：`<meta name="viewport" content="width=device-width, initial-scale=1.0">`
- 游戏存档存在浏览器 localStorage，不同设备/浏览器不互通
