## 二、Netlify 部署经验

### 成功部署地址
- 生产地址：https://quanzhi-fashi-game.netlify.app
- 站点ID：29cad1c9-36ed-48fd-854f-2c0052e01ca0
- 管理后台：https://app.netlify.com/projects/quanzhi-fashi-game

### 关键踩坑：必须创建干净部署目录

**错误做法**：直接部署项目根目录
```bash
netlify deploy --prod --dir=.  # 会报错
```
错误信息：`JSONHTTPError: no records matched 422`

**原因**：项目根目录包含 `.git/`、`docs/`、`tests/`、`tools/` 等大量非游戏文件，Netlify 上传时会出错。

**正确做法**：创建干净目录，只复制游戏运行必需的文件
```powershell
# 1. 创建干净目录
New-Item -ItemType Directory -Path deploy_dist

# 2. 只复制必需文件
Copy-Item index.html deploy_dist
Copy-Item -Recurse engine deploy_dist
Copy-Item -Recurse assets deploy_dist

# 3. 部署
netlify deploy --prod --dir=deploy_dist --site=<site_id>

# 4. 清理
Remove-Item -Recurse -Force deploy_dist
```

### 必需文件清单
- `index.html` - 游戏入口
- `engine/` - 核心引擎和数据模块
- `assets/` - 图片等静态资源

**不需要的文件**：`.git/`、`docs/`、`tests/`、`tools/`、`*.md`、`*.txt`、`*.ps1`、`*.json`（配置文件）

### 一键部署脚本
已创建 `tools/deploy.ps1`，自动完成：创建干净目录 → 复制文件 → 部署 → 清理。

使用方法：
```powershell
cd C:\Users\22210\Desktop\quanzhi-fashi-game-master
.\tools\deploy.ps1
```

### 401 未授权问题
**现象**：访问站点返回 `401 Unauthorized`
**原因**：站点可能被设置了密码保护（Password protection）
**解决**：登录 Netlify 后台 → Site settings → Access control → 关闭 Password protection

**注意**：重新部署后 401 问题可能自动消失（本次重新部署后恢复正常）。

## 三、Vercel 部署经验（失败记录）

### 安装与登录
```bash
npm install -g vercel
vercel login  # 会生成设备授权链接，浏览器打开授权
```

### 部署失败原因
连续4次部署均失败，错误信息：
```
Error: fetch failed
AbortError: This operation was aborted
```

**原因分析**：
- Vercel 服务器在海外，从国内 CLI 上传文件网络不稳定
- 即使只有 700KB 的文件也上传失败
- 不是代码问题，是网络连接问题

### 可能的替代方案
1. **连接 GitHub 仓库自动部署**：把代码推到 GitHub，在 Vercel 网页上连接 GitHub 仓库，Vercel 从 GitHub 拉取代码，绕过本地上传
2. **用 Vercel 网页手动上传**：在 Vercel 网页上直接拖拽文件上传
3. **继续用 Netlify**：已经成功部署，国内虽然慢但稳定

### Vercel 项目残留
- 创建了 `quanzhi-fashi-game-master` 项目（部署失败）
- 创建了 `deploy_dist` 项目（部署失败）
- 可在 Vercel 后台删除这些无用项目

## 四、Gitee Pages 部署经验（失败记录）

### 代码推送成功
- 仓库地址：https://gitee.com/wsjshy/quanzhi-fashi-game.git
- 代码已成功推送到 master 分支

### Pages 入口找不到
**问题**：在 Gitee 仓库页面的"服务"菜单中没有"Gitee Pages"选项

**可能原因**：
1. 未完成实名认证（Gitee Pages 必须实名认证）
2. Gitee Pages 需要申请审核（2-5个工作日）
3. Gitee 改版后入口位置变化
4. 仓库必须是公开的

**尝试过的路径**：
- 仓库主页 → 服务 → 无 Gitee Pages 选项
- 仓库主页 → 管理 → 左侧菜单无 Pages 相关选项
- https://gitee.com/profile/identification → 链接不存在

### 建议
如果后续想用 Gitee Pages：
1. 先完成实名认证（入口可能在右上角头像菜单）
2. 确认仓库是公开的
3. 可能需要在 Gitee 上申请 Pages 服务
4. 每次推送代码后需要手动点"更新"重新部署（不会自动更新）

## 五、手机端适配经验

### 适配方案
使用 **CSS 媒体查询 + class 标记** 的方式，仅屏幕宽度 < 768px 时触发手机布局，PC 端完全不受影响。

### 实现步骤
1. 在 `index.html` 的 `<style>` 中添加 `@media (max-width: 768px)` 媒体查询
2. 给 `ui.js` 中需要适配的元素添加特定 class
3. 用 CSS `!important` 覆盖内联样式

### 已适配的内容
| 界面 | 适配前 | 适配后 | class名 |
|------|--------|--------|---------|
| 主界面 | 左右分栏 | 上下布局 | mobile-main-content, mobile-action-panel, mobile-side-menu |
| 顶部状态栏 | 一行显示 | 自动换行 | mobile-top-bar |
| 创建角色 | 4列grid | 2列grid | mobile-element-grid |
| 消息弹窗 | 固定300-500px | 最大92%屏宽 | mobile-popup |
| 标题界面 | 72px大标题 | 32px | mobile-title |
| 通用按钮 | 鼠标尺寸 | 增大触摸区域 | mobile-btn（CSS已定义，部分按钮尚未添加class） |

### 关键 CSS 代码（index.html）
```css
@media (max-width: 768px) {
    .mobile-main-content { flex-direction: column !important; }
    .mobile-action-panel { flex: none !important; width: 100% !important; padding: 15px !important; }
    .mobile-side-menu { width: 100% !important; border-left: none !important; border-top: 2px solid #444477 !important; }
    .mobile-top-bar { flex-wrap: wrap !important; gap: 8px !important; padding: 10px 15px !important; }
    .mobile-element-grid { grid-template-columns: repeat(2, 1fr) !important; }
    .mobile-popup { max-width: 92vw !important; width: 92vw !important; min-width: auto !important; }
    .mobile-title h1 { font-size: 32px !important; }
    body { overflow-x: hidden; }
}
```

### 注意事项
- 内联样式优先级高于 CSS，必须用 `!important` 覆盖
- 用 class 标记而不是直接改内联样式，保证 PC 端不受影响
- 全屏面板（背包/任务/角色等）本身是 100% 宽度，不需要额外适配
- 战斗界面有固定 320px 战斗日志，手机上可能偏宽但能接受
- viewport meta 标签必须有：`<meta name="viewport" content="width=device-width, initial-scale=1.0">`

## 七、后续部署建议

1. **当前使用 Netlify**：已经成功部署，国内访问虽然慢但稳定，适合先用着
2. **如果想更快**：
   - 方案A：把代码推到 GitHub，用 Vercel 连接 GitHub 自动部署（绕过本地上传）
   - 方案B：完成 Gitee 实名认证并申请 Pages 服务
   - 方案C：使用阿里云 OSS / 腾讯云 COS（需付费和备案）
3. **每次更新代码后**：运行 `.\tools\deploy.ps1` 一键重新部署到 Netlify
4. **存档说明**：游戏存档存在浏览器 localStorage，手机和电脑不互通，不同浏览器也不互通

- `site_info.json` - 站点信息
- `gitee_screenshot*.png` - Gitee 截图
