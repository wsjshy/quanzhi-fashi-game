# 玩家个人任务线设计（v0.25.0）

> 2026-08-15 设计文档。核心原则：玩家有自己的人生，任务基于玩家的选择和身份展开，不是莫凡任务的复刻。

## 一、设计目标

当前游戏中的任务大多围绕莫凡的剧情（地圣泉、宇昂决斗等）。玩家要么参与莫凡的事，要么没有任务可做。

v0.25.0设计**玩家个人任务线**：
- 任务基于玩家的元素系别、等级、选择、NPC关系触发
- 每个玩家的任务体验不同
- 任务有分支和多种完成方式
- 任务结果影响玩家的成长和关系

## 二、任务类型

### 2.1 元素系别任务

基于玩家觉醒的元素系别展开的专属任务。

**火系**：
- 初阶：控制火焰不灼伤他人（练习任务）
- 中阶：调查博城附近的火属性妖魔异常
- 高阶：火之感悟（寻找火系传承）

**冰系**：
- 初阶：在严寒中保持体温（生存任务）
- 中阶：帮助穆氏家族处理冰系相关事务
- 高阶：冰之感悟

**其他系别**类似，每个系别有自己的任务线。

### 2.2 关系驱动任务

基于玩家与NPC的关系触发的任务。

**与穆宁雪关系好**：
- 穆宁雪可能邀请玩家一起修炼
- 穆宁雪可能透露家族的一些信息
- 穆宁雪可能在玩家遇到困难时提供帮助

**与唐月关系好**：
- 唐月可能推荐玩家参加某个活动
- 唐月可能私下指导玩家
- 唐月可能委托玩家做一些调查

**与张小侯关系好**：
- 张小侯可能拉玩家一起探险
- 张小侯可能分享风系修炼技巧

### 2.3 选择驱动任务

基于玩家之前的选择和行为触发的任务。

**玩家经常修炼**：
- 可能被老师注意到，获得额外指导机会
- 可能被同学视为竞争对手，引发挑战

**玩家经常探索**：
- 可能发现隐藏的线索，触发调查任务
- 可能遇到需要帮助的人

**玩家经常猎魔**：
- 可能在猎法师公会获得声望
- 可能接到更高级的猎魔委托

### 2.4 随机事件任务

随机触发的小型任务，增加世界的不可预测性。

- 路上遇到需要帮助的人
- 发现异常的魔法波动
- 听到关于某个宝藏的传闻
- 被卷入某个小冲突

## 三、任务系统设计

### 3.1 任务触发条件

任务通过条件检查触发：
- 玩家等级/系别
- 玩家与特定NPC的关系值
- 玩家的行为历史（修炼次数/探索次数/猎魔次数）
- 游戏时间/日期
- 随机概率

### 3.2 任务分支

每个任务有多个完成方式：
- 战斗解决
- 对话说服
- 潜行规避
- 寻求帮助（消耗关系）

不同完成方式有不同的结果和奖励。

### 3.3 任务结果影响

任务结果影响：
- 玩家经验/技能点/物品
- NPC关系变化
- 世界状态变化（某些地点/事件解锁）
- 后续任务的触发

## 四、实施计划

### Phase 1：任务框架
- 任务数据结构（id/name/desc/trigger/steps/rewards/branches）
- 任务触发检查系统
- 任务日志UI
- 任务进度追踪

### Phase 2：元素系别任务（初阶）
- 火系初阶任务线
- 冰系初阶任务线
- 其他系别初阶任务线

### Phase 3：关系驱动任务
- 穆宁雪关系任务
- 唐月关系任务
- 张小侯关系任务

### Phase 4：随机事件任务
- 小型随机事件池
- 事件触发和结果

## 五、与现有系统的关系

- **不修改**现有莫凡相关任务（保留为"莫凡的事，玩家可旁观或参与"）
- **新增**玩家个人任务系统
- **复用**现有NPC关系系统（关系值作为触发条件）
- **复用**现有事件系统（任务作为特殊事件）

## 六、人设检查

- 任务符合世界观设定（魔法高中、猎法师、妖魔等）
- NPC行为符合性格设定
- 任务不围绕莫凡展开
- 玩家的选择有实际影响
