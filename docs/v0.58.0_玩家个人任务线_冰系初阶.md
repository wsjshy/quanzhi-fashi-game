# v0.58.0 玩家个人任务线（冰系初阶）

> 版本：v0.58.0
> 日期：2026-08-15
> 类型：内容开发
> 前置：v0.57.0火系初阶任务线（框架已验证）

---

## 一、设计目标

扩展冰系玩家专属任务线，让冰系玩家有明确的成长目标。任务围绕冰系"冷静、掌控、感悟"的特点展开，深化与穆宁雪（冰系天才）的关系。

---

## 二、任务线设计

### 任务1：寒冰的掌控（quest_ice_control）

- **触发条件**：冰系玩家，等级≥5
- **发布者**：穆宁雪
- **类型**：个人任务
- **目标**：冥修5次（冰系需要冷静冥想）
- **奖励**：经验100，金币50
- **剧情**：穆宁雪注意到你在修炼冰系时心绪浮躁，建议你多冥修静心。"冰系的力量来自冷静，心不静，冰不纯。"

### 任务2：冰系的切磋（quest_ice_duel）

- **触发条件**：冰系玩家，等级≥8，完成任务1
- **发布者**：穆宁雪
- **类型**：个人任务
- **目标**：与穆宁雪对话1次
- **奖励**：经验150，金币100，学校声望+5
- **剧情**：穆宁雪注意到你的冰系进步，主动找你切磋。"你的冰系...有点意思。要不要比比看，谁的冰更纯？"

### 任务3：寒冰的感悟（quest_ice_insight）

- **触发条件**：冰系玩家，等级≥12，完成任务2
- **发布者**：穆宁雪
- **类型**：个人任务
- **目标**：图书馆3次 + 冥修10次
- **奖励**：经验300，金币200，技能点1
- **剧情**：穆宁雪建议你在图书馆查阅冰系典籍，结合冥修感悟寒冰的真谛。"冰的极致不是寒冷，是绝对的宁静。"

---

## 三、技术实现

- 复用v0.57.0个人任务框架
- 任务数据添加到quests.js
- trigger字段：element: "ice", minLevel, prerequisites
- 冰系任务侧重冥修（而非修炼），体现冰系特点

---

## 四、验收标准

1. 冰系玩家等级5时自动触发"寒冰的掌控"
2. 完成任务1后等级8触发"冰系的切磋"
3. 完成任务2后等级12触发"寒冰的感悟"
4. 非冰系玩家不触发
5. 任务奖励正常发放
6. node --check语法通过
