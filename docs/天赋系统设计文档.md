# 天赋系统设计文档

> **版本**：v1.0（基础框架）
> **来源**：小说《全职法师》天生天赋、灵种/魂种、法系进阶设定
> **方法论**：按「新增设定融合流程」设计

---

## 一、小说设定梳理

### 1.1 天生天赋
- **定义**：魔法师觉醒时自带的特殊天赋，因人而异
- **稀有度**：普通天赋 → 灵级天赋 → 魂级天赋 → 更高
- **莫凡的天生天赋**：天生双系（觉醒时多一个系）、天生魂种（元素品质极高）
- **作用**：提升魔法威力、附带特殊效果、改变施法方式

### 1.2 灵种/魂种
- **定义**：元素的进阶形态，带有特殊属性和外观
- **等级**：凡种（普通）→ 灵种 → 魂种 → 更高
- **效果**：
  - 威力提升
  - 特殊效果（燃烧、冰冻、麻痹、减速等）
  - 外观变化（颜色、特效）
- **获取方式**：修炼突破、特殊资源、机缘巧合

### 1.3 法系进阶
- **初阶**：1-7级，基础技能
- **中阶**：8-14级，中级技能，可觉醒第二系
- **高阶**：15级以上，高级技能，可觉醒第三系
- **超阶/禁咒**：更高级别

## 二、游戏化设计

### 2.1 核心设计思路
- **增加重玩价值**：每次觉醒天赋不同，鼓励多周目
- **有意义的选择**：天赋选择影响战斗风格和build
- **成长爽感**：天赋可以升级，效果逐步增强
- **符合小说设定**：基于小说设定，不凭空捏造

### 2.2 天赋系统架构

#### 天赋类型
| 类型 | 说明 | 获取方式 |
|------|------|---------|
| 天生天赋 | 每个系觉醒时获得的基础天赋 | 觉醒时随机/选择 |
| 灵种天赋 | 元素进阶形态，更强的效果 | 任务/探索/商店/修炼突破 |
| 魂种天赋 | 更高级的灵种，稀有强大 | 稀有掉落/特殊任务/大事件奖励 |

#### 天赋稀有度
| 稀有度 | 颜色 | 出现概率 | 效果强度 |
|--------|------|---------|---------|
| 普通 | 白色 | 60% | 基础加成 |
| 优秀 | 绿色 | 25% | 中等加成 |
| 稀有 | 蓝色 | 10% | 较强加成 + 特殊效果 |
| 史诗 | 紫色 | 4% | 强力加成 + 独特效果 |
| 传说 | 橙色 | 1% | 极强加成 + 专属效果 |

#### 天赋等级
- 每个天赋有1-10级
- 通过使用该系技能、修炼、特殊道具提升等级
- 等级提升效果增强（线性或曲线增长）

### 2.3 天赋效果分类

| 效果类型 | 说明 | 示例 |
|---------|------|------|
| 伤害加成 | 提升该系技能伤害 | 火系伤害+10% |
| MP消耗 | 减少该系技能MP消耗 | 火系MP消耗-15% |
| 施法速度 | 提升该系技能施法速度 | 火系施法速度+20% |
| 暴击率 | 提升该系技能暴击率 | 火系暴击率+5% |
| 暴击伤害 | 提升该系技能暴击伤害 | 火系暴击伤害+50% |
| 特殊效果 | 附加独特效果 | 燃烧、冰冻、麻痹、击退等 |
| 被动增益 | 永久属性加成 | 最大MP+50、精神力+10 |
| 组合效果 | 多系组合触发特殊效果 | 火+风=火焰风暴（范围扩大） |

## 六、设计要点与原则

1. **选择有意义**：不同天赋对应不同战斗风格，不是单纯的数值大小
2. **稀有度有价值**：稀有天赋不仅数值高，还有独特效果
3. **成长可见**：天赋升级有明确的反馈和提升感
4. **重玩价值**：每次觉醒天赋不同，鼓励多周目尝试
5. **符合设定**：基于小说设定，不脱离原著世界观
