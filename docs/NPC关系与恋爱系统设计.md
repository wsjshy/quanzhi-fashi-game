# NPC关系与恋爱系统设计方案 v1.0

> 设计日期：2026-08-15
> 目标版本：v0.18.0
> 核心问题：玩家与NPC的关系只有数值，没有阶段感和事件反馈；无法发展恋爱关系
> 设计原则：**基于现有好感度系统扩展，不重写；数据驱动，每个NPC独立配置**

---

## 一、现有基础（已实现，非常完善）

### 关系等级系统（getRelationshipLevel）
- 综合评分 = 好感*0.6 + 信任*0.3 + 熟悉*0.1
- 14个普通等级：死敌→敌视→厌恶→不友善→冷淡→陌生→友善→熟人→熟络→朋友→好友→挚友→知己
- 4个特殊标记：恋人(is_lover)、恩师(is_mentor)、弟子(is_disciple)、宿敌(is_rival)
- 恋人条件：is_lover=true 且 综合评分>=80
- UI已显示关系等级名称和颜色

### 好感度系统
- opinion(-100~100)、trust、respect、fear、familiarity
- changeOpinion含熟悉度衰减、记忆记录
- 送礼系统：giftPreferences、dailyGiftLimit
- 对话树支持opinion条件分支

### 已有可恋爱NPC
- 穆宁雪：canRomance: true，初始opinion -10
- 莫凡：canRomance: true

### 缺失的部分
- ❌ 关系等级变化提示（v0.18.0已添加）
- ❌ 约会系统（主动提升关系的核心玩法）
- ❌ 恋爱事件（各阶段专属剧情）
- ❌ is_lover标记的设置方式（告白事件）
- ❌ 穆宁雪专属恋爱线
- 唐月：canBeMentor: true（待确认canRomance）

## 二、关系阶段系统

### 2.1 阶段定义

基于opinion值划分6个阶段：

| 阶段 | opinion范围 | 名称 | 解锁内容 |
|------|------------|------|---------|
| 0 | < -50 | 敌对 | 特殊敌对对话，可能触发冲突 |
| 1 | -50 ~ -1 | 冷淡 | 基础对话，送礼效果降低 |
| 2 | 0 ~ 19 | 认识 | 正常对话，日常互动 |
| 3 | 20 ~ 49 | 熟悉 | 解锁个人话题，偶尔主动打招呼 |
| 4 | 50 ~ 79 | 好感 | 解锁约会邀请，专属对话 |
| 5 | 80 ~ 100 | 亲密/恋人 | 恋爱事件，专属结局分支 |

### 2.2 阶段转换
- opinion跨越阈值时触发阶段转换事件
- 显示"关系变化：XX → 熟悉"提示
- 可配置每个阶段的转换对话

### 2.3 数据结构
在`npc-state.js`中新增：
```js
getRelationshipStage(npcId) // 返回阶段索引0-5
getRelationshipStageName(npcId) // 返回阶段名称
```

在`characters.js`的relationshipCap中新增：
```js
relationshipStages: {
  2: { unlocks: ["personal_topic"] },
  4: { unlocks: ["date_invite"] },
  5: { unlocks: ["romance_events"] }
}
```

## 三、约会系统

### 3.1 约会邀请
- 好感度≥50时，NPC对话中出现"邀请约会"选项
- 选择约会地点（图书馆、咖啡馆、雪峰山看日落、三步塔修炼等）
- 不同地点有不同的好感度增益和事件触发概率

### 3.2 约会地点配置
```js
dateLocations: [
  { id: "library", name: "图书馆", opinionGain: 3, eventChance: 0.3, timeCost: 2 },
  { id: "xuefeng_sunset", name: "雪峰山看日落", opinionGain: 5, eventChance: 0.5, timeCost: 3 },
  { id: "city_stroll", name: "逛街", opinionGain: 2, eventChance: 0.4, timeCost: 2 },
  { id: "tower_train", name: "三步塔修炼", opinionGain: 4, eventChance: 0.3, timeCost: 2 }
]
```

### 3.3 约会事件
- 每个地点有专属事件池
- 事件可能增加信任度、触发专属对话、获得物品
- 高好感度时可能触发牵手、告白等关键事件

## 四、穆宁雪恋爱线（首个实装NPC）

### 4.1 人物设定
- 穆氏世家千金，冰系天才，外冷内热
- 与玩家是青梅竹马（玩家设定可调整），初始关系冷淡
- 父亲穆卓云势利，打压过莫凡家

### 4.2 恋爱线阶段事件

**阶段2（认识，opinion≥0）**
- 解锁：穆宁雪主动打招呼
- 事件：校园偶遇，简短对话

**阶段3（熟悉，opinion≥20）**
- 解锁：个人话题（家族压力、修炼困惑）
- 事件：穆宁雪修炼遇到瓶颈，玩家帮忙

**阶段4（好感，opinion≥50）**
- 解锁：约会邀请
- 事件1：雪峰山看日落，穆宁雪敞开心扉
- 事件2：穆卓云发现两人来往，施压

**阶段5（亲密，opinion≥80）**
- 解锁：恋爱事件
- 事件1：成年礼后，穆宁雪主动约见
- 事件2：告白事件（玩家选择接受/拒绝）
- 事件3：博城灾难中共同战斗（如果已到该剧情）

### 4.3 与原著的关系
- 穆宁雪在原著中与莫凡有情感线
- 在本游戏中，莫凡是独立NPC，玩家可以与穆宁雪发展关系
- 莫凡与穆宁雪的关系也在独立发展，玩家的选择会影响三角关系
- 不脱离原著设定（穆宁雪的性格、家族背景不变），但玩家可以改变情感走向
