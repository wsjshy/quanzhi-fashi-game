# 战斗系统深度优化设计

## 问题分析

### 当前问题
1. **敌人AI过于简单** - 只是随机放技能，没有策略
2. **数值比拼为主** - 策略性不足，主要靠属性碾压
3. **战斗模式单一** - 只有单挑一种模式
4. **缺少深度机制** - 没有连招、组合、地形等深度玩法

### 小说原著中的战斗精髓
1. **星子引导节奏** - 引导时间把控、打断时机
2. **元素相克运用** - 用对元素事半功倍
3. **多系配合连招** - 不同系别配合打出组合效果
4. **地形环境利用** - 利用地形优势
5. **精神力对抗** - 精神力高→引导快、防控制
6. **战斗经验直觉** - 预判敌人行动
7. **魔具关键时刻** - 魔具是底牌，关键时候用

## 一、敌人AI多样化系统

### 6种AI类型

#### 1. 激进型（aggressive）
- **特点**：全力输出，不顾防御
- **策略**：
  - 优先用最高伤害技能
  - MP不够就普攻
  - 血量低也不防御，继续猛攻
- **代表敌人**：狂暴妖魔、野兽型、独眼魔狼
- **难度**：★★☆☆☆
- **应对方法**：防御反击，消耗其血量

#### 2. 保守型（defensive）
- **特点**：懂得自我保护
- **策略**：
  - 血量 > 70%：正常攻击
  - 血量 30%-70%：攻防交替
  - 血量 < 30%：优先防御/治疗
  - 有治疗技能会及时使用
- **代表敌人**：智慧型妖魔、法师型
- **难度**：★★★☆☆
- **应对方法**：爆发输出，不让其喘息

#### 3. 控制型（controller）
- **特点**：优先控制，再输出
- **策略**：
  - 开局先放debuff（减速、麻痹、诅咒等）
  - 玩家被控住后全力输出
  - 控制效果消失后补控制
  - 会驱散玩家的buff
- **代表敌人**：诅咒系、暗影系、咒法师
- **难度**：★★★★☆
- **应对方法**：快速击杀，或带解控道具

#### 4. 爆发型（burst）
- **特点**：攒MP一波爆发
- **策略**：
  - 前2-3回合：普攻/小技能，攒MP
  - MP足够后：连续释放大招
  - 爆发期：全力输出，不留后手
  - 爆发后：虚弱期，防御/恢复
- **代表敌人**：法师型Boss、炎姬女王
- **难度**：★★★★☆
- **应对方法**：爆发期防御，虚弱期输出

#### 5. 游击型（kiter）
- **特点**：打一下跑一下
- **策略**：
  - 放一个技能后防御/闪避一回合
  - 保持距离，风筝玩家
  - 利用速度优势
  - 玩家血量低时追击
- **代表敌人**：风系妖魔、远程型、翼苍狼
- **难度**：★★★☆☆
- **应对方法**：控制技能，拉近距離

#### 6. 战术型（tactical）
- **特点**：会根据玩家状态调整策略（最智能）
- **策略**：
  - 玩家血量低 → 猛攻，不给喘息
  - 玩家MP低 → 消耗战，逼玩家用普攻
  - 玩家有强力buff → 优先驱散
  - 自己血量低 → 防御/治疗
  - 玩家在引导大招 → 优先打断
  - 会利用元素克制
- **代表敌人**：高阶法师、统领级以上Boss
- **难度**：★★★★★
- **应对方法**：多变的战术，不要一成不变

### AI实现方式
- 每个敌人数据中添加 `aiType` 字段
- 默认为 `aggressive`（保持兼容）
- 不同AI类型有不同的决策逻辑
- 高阶敌人/Boss用战术型AI

## 二、战斗模式多样化

### 模式1：常规战斗（Normal）
- **描述**：普通的单挑
- **特点**：正常规则
- **出现场景**：野外遭遇、普通任务

### 模式2：决斗（Duel）
- **描述**：公平决斗，点到为止
- **特点**：
  - 不能使用道具
  - 不能逃跑
  - 血量降到20%以下判定胜负
  - 胜利有荣誉/声望奖励
- **出现场景**：学校考核、NPC决斗、竞技场

### 模式3：狩猎战（Hunt）
- **描述**：追猎妖魔
- **特点**：
  - 敌人可能会逃跑
  - 敌人血量低时逃跑概率增加
  - 成功击杀奖励更丰厚
  - 有时间限制
- **出现场景**：猎妖任务、悬赏任务

### 模式4：防守战（Defense）
- **描述**：保护目标/阵地
- **特点**：
  - 有需要保护的目标
  - 敌人会分批出现
  - 目标死亡则失败
  - 考验持续作战能力
- **出现场景**：守城、保护任务、博城灾难

### 模式5：车轮战（Gauntlet）
- **描述**：连续战斗
- **特点**：
  - 连续打多个敌人
  - 中间不恢复HP/MP
  - 越往后敌人越强
  - 通关奖励丰厚
- **出现场景**：试炼、考核、秘境

### 模式6：Boss战（Boss）
- **描述**：Boss战，多阶段
- **特点**：
  - Boss有多个阶段
  - 每个阶段技能和策略不同
  - 阶段转换时会有特殊动作
  - 掉落稀有物品
- **出现场景**：主线Boss、副本最终Boss

## 三、战斗深度机制

### 1. 元素反应系统
- **火+水 = 蒸汽**：降低双方命中
- **火+风 = 火势**：火伤害提升50%
- **冰+雷 = 超导**：防御降低30%
- **土+水 = 泥泞**：速度降低50%
- **光+暗 = 湮灭**：双方都受伤害
- **雷+土 = 接地**：雷伤害降低

### 2. 连招系统
- **定义**：特定技能顺序释放有额外效果
- **示例**：
  - 先减防 → 再攻击 = 伤害提升30%
  - 先上灼烧 → 再用风 = 火势蔓延（灼烧层数+2）
  - 先冻结 → 再用雷 = 碎冰（暴击率+50%）
  - 先上诅咒 → 再用暗影 = 暗影侵蚀（伤害提升50%）

### 3. 打断机制深化
- **当前**：30%概率打断
- **改进**：
  - 攻击速度越快，打断概率越高
  - 伤害越高，打断概率越高
  - 某些技能有打断加成
  - 被打断会损失部分MP
  - 连续打断难度递增

### 4. 站位/地形系统
- **地形效果**：
  - 火山地形：火伤害+30%，水伤害-30%
  - 雪地地形：冰伤害+30%，火伤害-30%
  - 水域地形：水伤害+30%，雷伤害+50%（导电）
  - 山地地形：土伤害+30%，风伤害-20%
  - 森林地形：风伤害+30%，木系/召唤+30%
  - 黑暗地形：暗影伤害+50%，光伤害-30%

### 5. 战斗评价系统
- **评级**：S / A / B / C / D
- **评价维度**：
  - 回合数（越少越好）
  - 血量剩余（越多越好）
  - MP使用效率
  - 道具使用（越少越好）
  - 完美闪避/暴击
  - 连招使用
- **奖励**：
  - S级：经验+50%，金币+50%，稀有掉落概率+20%
  - A级：经验+30%，金币+30%
  - B级：经验+15%，金币+15%
  - C级：正常奖励
  - D级：经验-20%，金币-20%

## 四、前中后期体验设计

### 前期（初阶，1-7级）
- **核心体验**：学习基础操作，理解元素克制
- **敌人AI**：激进型为主，简单直接
- **战斗时长**：3-5回合
- **策略深度**：基础的攻击/技能/防御选择
- **目标**：熟悉战斗系统，准备突破中阶

### 中期（中阶，8-14级）
- **核心体验**：技能组合，状态效果运用
- **敌人AI**：保守型、控制型开始出现
- **战斗时长**：5-10回合
- **策略深度**：引导技能使用，打断时机，状态搭配
- **目标**：掌握多系配合，准备突破高阶

### 后期（高阶，15级+）
- **核心体验**：深度策略，完美操作
- **敌人AI**：战术型、爆发型，会用连招
- **战斗时长**：10-20回合
- **策略深度**：元素反应，技能连招，完美时机
- **目标**：挑战高难度Boss，追求S级评价

## 六、敌人AI实现细节

### AI决策流程
```
1. 检查自身状态
   - 是否血量过低？→ 考虑防御/治疗
   - 是否有控制技能可用？→ 考虑控制
   - MP是否足够放大招？→ 考虑爆发

2. 检查玩家状态
   - 玩家是否在引导大招？→ 优先打断
   - 玩家是否血量很低？→ 猛攻
   - 玩家是否有强力buff？→ 考虑驱散
   - 玩家是否被控？→ 全力输出

3. 选择行动
   - 根据AI类型和当前状态
   - 选择最优的行动方案
   - 加入一些随机性，避免太 predictable
```

### AI性格参数
- `aggression`（攻击性）：0-1，影响攻击频率
- `caution`（谨慎性）：0-1，影响防御/治疗时机
- `intelligence`（智能性）：0-1，影响策略复杂度
- `randomness`（随机性）：0-1，影响决策的随机性

## 七、贴近原著的细节

### 星子/星轨/星图
- 初阶魔法：7颗星子，星轨，瞬发/1回合引导
- 中阶魔法：49颗星子，星图，2-3回合引导
- 高阶魔法：343颗星子，星宫，5-7回合引导
- 超阶魔法：2401颗星子，星座，10+回合引导

### 精神力作用
- 影响引导速度：精神力越高，引导越快
- 影响控制抗性：精神力越高，越不容易被控
- 影响打断抗性：精神力越高，越不容易被打断
- 影响感知：精神力高，可以预判敌人行动

### 魔具使用
- 攻击魔具：额外伤害，可主动释放
- 防御魔具：减伤/护盾，被动/主动
- 辅助魔具：回血/回蓝/解控，主动使用
- 魔具有使用次数/冷却，是底牌
