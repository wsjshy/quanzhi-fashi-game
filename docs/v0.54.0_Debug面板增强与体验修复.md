# v0.54.0 Debug面板增强与体验修复

> 版本：v0.54.0
> 日期：2026-08-15
> 类型：debug能力增强 + 体验修复

---

## 一、背景

第四轮黑盒测试（v0.48-v0.53）发现：
1. debug面板的NPC关系设置功能不工作（对象名错误：`NpcState`→应为`NPCStateSystem`）
2. NPC关系设置藏在"剧情"标签页，需要手动输入ID，不易发现且操作繁琐
3. 缺少属性点清零功能，影响智能目标引导中期推荐测试
4. 张小侯称号"莫凡的死党"提到了莫凡，不符合"玩家有自己的人生，不围绕莫凡"原则

这些问题导致26个影响力事件链、5个新NPC互动事件、NPC日常消息等专项测试全部无法高效推进。

---

## 二、目标

1. 修复并增强debug的NPC关系设置功能，使其易用且有效
2. 新增属性点清零/分配功能
3. 修复张小侯称号
4. 为后续专项黑盒测试扫清障碍

---

## 三、具体改动

### 3.1 新增"NPC"独立标签页

将NPC关系设置从"剧情"标签页移至独立的"NPC"标签页，包含：
- 常用NPC下拉选择（穆宁雪、唐月、张小侯、赵满延、许昭霆、穆白、周敏、莫凡等）
- 好感度输入框（-100~100）
- 信任度输入框（-100~100）
- "设置关系"按钮
- "查看当前关系"按钮（显示所有NPC关系列表）
- 快速预设按钮：陌生(0)、友善(30)、亲密(60)、挚友(80)

### 3.2 修复setNpcRel()方法

将`NpcState.getNPCState(npcId)`改为`NPCStateSystem.getNPCState(npcId)`，确保设置生效。

### 3.3 新增属性点清零功能

在"玩家"标签页增加：
- "清零未分配属性点"按钮
- "分配所有属性点到主属性"按钮（快速分配）

### 3.4 修复张小侯称号

将characters.js中张小侯的title从"莫凡的死党"改为"风系学生"或"活泼的同学"。
