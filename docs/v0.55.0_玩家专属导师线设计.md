# v0.55.0 玩家专属导师线（唐月）

> 版本：v0.55.0
> 日期：2026-08-15
> 类型：核心内容开发
> 前置：v0.48.0唐月影响力事件链（已实现"唐月的赏识"任务）

---

## 一、设计目标

让玩家拥有**专属导师关系**，体现"玩家有自己的人生，不围绕莫凡"。唐月作为玩家的启蒙导师，通过师徒关系为玩家提供：
- 专属修炼指导（经验加成、技能指点）
- 个人化剧情（导师的关心、考验、期望）
- 玩家的成长被导师看见和认可

**核心原则**：
1. 唐月是玩家的导师，不是莫凡的附属
2. 师徒关系通过玩家行为自然建立，不刻意
3. 导师指导符合唐月人设（温柔、负责、有秘密）
4. 不破坏原著设定（唐月的身份、背景保留）

---

## 二、导师线阶段设计

### 阶段1：初识（已完成，v0.48.0）
- 唐月的关注（好感25+触发）
- 修炼中的指导（flag驱动，经验加成）
- 唐月的赏识任务（好感50目标）

### 阶段2：拜师（v0.55.0新增）
当玩家与唐月好感达到50时，触发拜师事件：
- **事件：唐月的考验**
  - 触发条件：唐月好感≥50，玩家等级≥8
  - 触发地点：天澜魔法高中（修炼/自习）
  - 内容：唐月观察玩家一段时间后，提出考验
  - 选择分支：
    1. 接受考验 → 进入小战斗（击败训练假人/低阶妖魔）
    2. 请求指点 → 唐月传授修炼心得（临时经验加成）
    3. 婉拒 → 唐月理解，好感+5（尊重玩家选择）

### 阶段3：师徒日常（v0.55.0新增）
拜师成功后，解锁师徒日常互动：
- **事件：师徒修炼**
  - 触发条件：已拜师，修炼时30%概率
  - 效果：唐月在场指导，经验+50%，有概率获得技能心得
- **事件：导师的关心**
  - 触发条件：已拜师，玩家HP<50%时
  - 效果：唐月给予治疗药水，关心玩家
- **事件：月度考核**
  - 触发条件：已拜师，每月1号
  - 效果：唐月检查玩家进度，根据实力给予评价和奖励

### 阶段4：导师的秘密（后续版本）
- 唐月的身世伏笔（图腾守护者）
- 玩家逐渐发现导师的秘密
- 师徒共同面对挑战

## 五、人设检查

- [ ] 唐月的指导符合温柔负责的人设

## 六、验收标准

1. 唐月好感≥50且等级≥8时，修炼触发"唐月的考验"事件
2. 三个选择分支各有不同效果
3. 拜师后flag `tang_yue_mentor` 被设置
4. 拜师后修炼有概率触发"师徒修炼"，经验加成正常
5. 玩家HP低时有概率触发"导师的关心"
6. node --check语法通过
7. 冒烟测试：debug设置唐月好感50→修炼触发考验→选择接受→验证flag设置
