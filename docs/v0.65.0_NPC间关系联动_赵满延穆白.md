# v0.65.0 NPC间关系联动：赵满延×穆白（富家子弟的较量）

> 版本：v0.65.0
> 日期：2026-08-15
> 类型：NPC间关系联动扩展

---

## 一、为什么做这个

### 1.1 扩展关系网络
v0.63.0（穆白×张小侯）和v0.64.0（唐月×穆宁雪）验证了NPC间联动机制的可行性。现在扩展到第三组关系——赵满延×穆白。

### 1.2 差异化的冲突类型
已有的两组联动：
- 穆白×张小侯：背景差异冲突（富家vs普通）
- 唐月×穆宁雪：师生关系张力（稳扎稳打vs追求极致）

赵满延×穆白：**富家子弟的较量**（张扬vs高傲），是同阶层之间的竞争，与前两组有明显差异化。

### 1.3 原著背景
- 赵满延：光系防御法师，性格张扬，喜欢炫耀，家世不错
- 穆白：冰系法师，性格高傲，穆家子弟，实力较强
- 两人都是富家子弟，天然有竞争关系，互相看不顺眼

## 二、事件设计

### 2.1 事件1：富家子弟的较量

**触发条件**：
- minRelationships: { zhao_manyan: 30, mu_bai: 30 }
- notFlag: zmy_mb_rivalry_done
- weight: 40
- npcId: zhao_manyan（遇到赵满延时触发）

**事件描述**：
你在走廊看到赵满延和穆白面对面站着。赵满延抱着胳膊："穆白，别以为你是穆家的就了不起，光系防御可不是吃素的。"穆白冷笑："光系？也就只能躲在后面喊加油了。"两人剑拔弩张。他们看到你，都停下了话头。

**选择分支（4个）**：

1. **支持赵满延**
   - effects: { setFlag: ["zmy_mb_support_zmy", "zmy_mb_rivalry_done"], npcOpinion: { zhao_manyan: 10, mu_bai: -10 } }
   - resultText: 你对赵满延说："光系防御在团队中可是核心，穆白你别小看人。"赵满延得意地笑了，穆白脸色难看。赵满延好感+10，穆白好感-10

2. **支持穆白**
   - effects: { setFlag: ["zmy_mb_support_mb", "zmy_mb_rivalry_done"], npcOpinion: { mu_bai: 10, zhao_manyan: -10 } }
   - resultText: 你对穆白说："冰系的攻击力确实强，赵满延你别光说不练。"穆白满意地点头，赵满延撇了撇嘴。穆白好感+10，赵满延好感-10

3. **中立调解**
   - effects: { setFlag: ["zmy_mb_mediated", "zmy_mb_rivalry_done"], npcOpinion: { zhao_manyan: 3, mu_bai: 3 } }
   - resultText: 你打圆场："都是同学，别伤了和气。光系防御和冰系攻击各有优势。"两人都有些不情愿，但还是点了头。赵满延好感+3，穆白好感+3

4. **提议用实力说话**
   - effects: { setFlag: ["zmy_mb_challenge", "zmy_mb_rivalry_done"], npcOpinion: { zhao_manyan: 5, mu_bai: 5 } }
   - resultText: 你说："光说没用，不如找时间比试一场？"两人眼睛一亮，都同意了。赵满延好感+5，穆白好感+5

### 2.2 事件2：实力的较量

**触发条件**：
- minRelationships: { zhao_manyan: 50, mu_bai: 50 }
- requireFlag: zmy_mb_challenge（选择了"提议用实力说话"）
- notFlag: zmy_mb_match_done
- weight: 40
- npcId: zhao_manyan

**事件描述**：
训练馆里，赵满延和穆白相对而立。赵满延展开光系护盾："来吧，让你看看什么叫绝对防御！"穆白凝聚冰系星子："防御再厚，也挡不住冰系的穿透。"两人看向你："你来当裁判？"

**选择分支（3个）**：

1. **当公正的裁判**
   - effects: { setFlag: ["zmy_mb_referee", "zmy_mb_match_done"], npcOpinion: { zhao_manyan: 5, mu_bai: 5 } }
   - resultText: 你认真观察两人的比试，公正判罚。比赛结束后，两人都对你的公正表示认可。赵满延好感+5，穆白好感+5，经验+80

2. **暗中帮赵满延加油**
   - effects: { setFlag: ["zmy_mb_cheer_zmy", "zmy_mb_match_done"], npcOpinion: { zhao_manyan: 8, mu_bai: -5 } }
   - resultText: 你趁穆白不注意，悄悄给赵满延递了个鼓励的眼神。赵满延士气大振，赢了比试。穆白似乎察觉到了什么，有些不满。赵满延好感+8，穆白好感-5

3. **暗中帮穆白加油**
   - effects: { setFlag: ["zmy_mb_cheer_mb", "zmy_mb_match_done"], npcOpinion: { mu_bai: 8, zhao_manyan: -5 } }
   - resultText: 你趁赵满延不注意，悄悄给穆白递了个鼓励的眼神。穆白冰系攻势更猛，赢了比试。赵满延似乎察觉到了什么，有些不满。穆白好感+8，赵满延好感-5

## 三、对应任务

### 任务1：富家子弟的较量（requireFlag: zmy_mb_challenge）
- 目标：与赵满延对话1次 + 与穆白对话1次 + 修炼2次
- 奖励：经验200 + 金币100 + setFlag: zmy_mb_quest_done
- 描述：赵满延和穆白约定比试，你需要帮他们准备

### 任务2：实力的见证（requireFlag: zmy_mb_referee）
- 目标：击败1个妖魔（作为比试后的实战验证）+ 与赵满延对话1次 + 与穆白对话1次
- 奖励：经验300 + 技能点1 + setFlag: zmy_mb_witness_done
- 描述：比试结束后，两人决定联手实战，你作为见证者参与

## 四、深度来源

1. **同阶层竞争**：两人都是富家子弟，竞争不是背景差异，而是性格和实力的较量
2. **张扬vs高傲**：赵满延喜欢炫耀，穆白内心高傲，性格冲突自然
3. **玩家的立场**：支持任何一方都会得罪另一方，调解需要技巧
4. **从嘴炮到实战**：事件1是言语冲突，事件2是实力较量，叙事完整
5. **公正vs偏袒**：事件2探讨公正和私心的取舍，有道德选择深度
