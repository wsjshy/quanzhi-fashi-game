# v0.71.0 精英妖魔遭遇系统

> 版本：v0.71.0
> 日期：2026-08-16
> 类型：战斗系统 / 探索体验
> 前置：v0.70.2 精英妖魔系统（3种博城灾难精英妖魔）

---

## 一、为什么做这个

v0.70.2已完成3种博城灾难精英妖魔的数据和战斗机制，但目前只能在debug面板中触发，普通玩家在游戏过程中遇不到。这导致精英妖魔系统形同虚设，普通探索的战斗策略性没有提升。

v0.71.0实现普通探索/修炼时的精英遭遇概率，让精英妖魔真正融入游戏体验。

---

## 二、设计方案

### 2.1 遭遇概率

在`triggerRandomBattle`方法中，选择普通妖魔后，有一定概率升级为精英妖魔：

| 玩家等级 | 精英遭遇概率 | 可遭遇的精英 |
|----------|-------------|-------------|
| Lv1-5 | 0% | 无（新手保护） |
| Lv6-9 | 5% | 进阶期独眼魔狼、巨眼猩鼠王 |
| Lv10+ | 8% | 进阶期独眼魔狼、巨眼猩鼠王、三眼魔狼 |

### 2.2 精英选择逻辑

- 低等级区域（enemyLevelBonus ≤ 1）：只遭遇奴仆级精英（进阶期独眼魔狼、巨眼猩鼠王）
- 高等级区域（enemyLevelBonus ≥ 2 或 雪峰山深处等）：可遭遇战将级精英（三眼魔狼）
- 精英选择从符合条件的精英列表中随机选取

### 2.3 遭遇提示

精英遭遇时显示特殊提示：
```
⚠️ 遭遇精英妖魔：三眼魔狼！
💡 弱点：火系
```

玩家可选择战斗或逃跑（逃跑成功率比普通妖魔低）。

### 2.4 逃跑机制

- 普通妖魔逃跑成功率：70%
- 精英妖魔逃跑成功率：40%
- 精英妖魔更强，逃跑更难

## 三、技术实现

### 3.1 修改位置

文件：`engine/map.js`
方法：`triggerRandomBattle(location)`

在获取普通妖魔数据后、应用昼夜影响前，添加精英遭遇判断：

```javascript
// v0.71.0: 精英妖魔遭遇
const playerLevel = Player.level || 1;
if (playerLevel >= 6 && Math.random() < this.getEliteEncounterRate(playerLevel)) {
    const eliteEnemy = this.tryGetEliteEnemy(location, playerLevel);
    if (eliteEnemy) {
        battleEnemy = eliteEnemy;
        battleEnemy.isEliteEncounter = true;
    }
}
```

### 3.2 新增方法

```javascript
getEliteEncounterRate(playerLevel) {
    if (playerLevel < 6) return 0;
    if (playerLevel < 10) return 0.05;
    return 0.08;
},

tryGetEliteEnemy(location, playerLevel) {
    const elites = [];
    // 奴仆级精英（所有区域）
    elites.push('advanced_one_eye_wolf', 'giant_eye_rat_king');
    // 战将级精英（高等级区域）
    if ((location.enemyLevelBonus || 0) >= 2 || playerLevel >= 12) {
        elites.push('three_eye_wolf');
    }
    const eliteId = elites[Math.floor(Math.random() * elites.length)];
    return DataManager.getCharacter(eliteId);
}
```

### 3.3 战斗开始提示

在game.js的startBattle方法中，如果敌人是精英遭遇，显示特殊提示。

实际上battle.js的startBattle中已有精英提示逻辑（v0.70.0添加），不需要额外修改。

## 四、平衡考虑

### 4.1 难度控制
- 新手期（Lv1-5）不遭遇精英，避免新手被劝退
- Lv6-9只遭遇奴仆级精英，难度适中
- Lv10+可遭遇战将级精英，提供挑战

### 4.2 奖励平衡
- 精英妖魔经验和金币是普通妖魔的1.5-2倍
- 精英掉落专属材料（wolf_bone_spike、elite_core等）
- 精英材料后续可用于装备强化

### 4.3 遭遇频率
- 5-8%的遭遇概率，大约每12-20次探索遇到1次精英
- 不会过于频繁打断探索节奏
- 但足够让玩家感受到精英的存在
