# v2.9.0 打断概率系统与魔法分级体系设计

> 版本：v2.9.0 | 状态：设计已对齐，实施中 | 最后更新：2026-08-20

---

## 一、设计背景

### 问题
1. 高等级魔法只是"高伤害+多回合冷却"，没有体现小说中"施法需要专注、可被打断"的感觉
2. 魔法数量少，没有体现小说中"每系有初阶/中阶/高阶多个魔法"的特点
3. 境界提升没有体现在施法掌控力上

### 核心设计理念
**施法速度 = 被打断概率，不是回合引导。境界越高，对低阶魔法掌控越强，打断概率越低。**

---

## 二、打断概率系统

### 2.1 打断概率计算公式

```
实际打断概率 = 魔法基础打断概率 + 敌方打断加成 - 玩家抗打断加成 - 境界压制减免
```

### 2.2 境界压制减免（核心机制）

| 玩家境界 | 释放初阶魔法 | 释放中阶魔法 | 释放高阶魔法 |
|---------|------------|------------|------------|
| 初阶法师 | 基础概率 | 不能释放 | 不能释放 |
| 中阶法师 | -15%（掌控增强） | 基础概率 | 不能释放 |
| 高阶法师 | -30%（几乎瞬发） | -15% | 基础概率 |
| 超阶法师 | -45%（完全瞬发） | -30% | -15% |

### 2.3 打断的具体效果

- 被打断后：魔法释放失败，MP损失50%，本回合行动结束
- 控制技能（眩晕/沉默/硬直）：100%打断
- 普通攻击：按打断概率计算
- 防御姿态：-20%打断概率（但防御时不能攻击）

### 2.4 双向机制

- 玩家施法可以被敌方打断
- 敌方施法也可以被玩家打断——玩家可以用控制技能打断敌方的高阶魔法
- 战斗UI显示敌方正在施法的魔法和剩余时间

## 三、魔法分级体系

### 3.1 魔法分级

每系有9个魔法×3级=27个形态。

| 阶级 | 魔法数量 | 解锁等级 | 基础打断概率 | MP消耗 | 定位 |
|------|---------|---------|------------|--------|------|
| 初阶 | 3个（1/2/3级） | Lv.1-10 | 5-15% | 低 | 战斗基础，快速释放 |
| 中阶 | 3个（1/2/3级） | Lv.11-30 | 20-40% | 中 | 主力输出，有独特效果 |
| 高阶 | 3个（1/2/3级） | Lv.31+ | 45-70% | 高 | 关键时刻，独特机制+高伤害 |

### 3.2 魔法升级

每个魔法1→2→3级，伤害/效果/消耗/打断概率都提升。
- 1级：基础效果
- 2级：效果增强（伤害+50%，附加效果增强）
- 3级：完全体（伤害+100%，独特机制解锁）

## 五、技能数据格式扩展

### 5.1 新增字段

```javascript
{
  id: "fire_mid_1",
  name: "烈拳",
  description: "中阶火系魔法，召唤烈焰巨拳轰击敌人",
  element: "fire",
  type: "damage",
  mpCost: 30,
  baseDamage: 50,
  damageMultiplier: 1.8,
  hitRate: 0.85,
  critRate: 0.1,
  targetType: "enemy",
  cooldown: 0,
  tier: "中阶",           // 初阶/中阶/高阶
  magicLevel: 1,          // 魔法等级 1/2/3
  interruptChance: 0.25,  // 基础打断概率（新增）
  unlockLevel: 11,         // 解锁等级（新增）
  statusEffects: [...],
  specialEffects: {        // 特殊效果（新增，用于独特机制）
    knockback: true,       // 击退
    stunChance: 0,         // 眩晕概率
    ...
  }
}
```

### 5.2 境界判断方法

```javascript
// 根据玩家最高系等级判断境界
Player.getMagicTier = function() {
  const maxLevel = Math.max(...Object.values(this.elementLevels));
  if (maxLevel >= 55) return "超阶";
  if (maxLevel >= 30) return "高阶";
  if (maxLevel >= 10) return "中阶";
  return "初阶";
};

// 获取境界压制减免
Player.getInterruptReduction = function(skillTier) {
  const tier = this.getMagicTier();
  const reductionMap = {
    "初阶": { "初阶": 0, "中阶": null, "高阶": null },
    "中阶": { "初阶": 0.15, "中阶": 0, "高阶": null },
    "高阶": { "初阶": 0.30, "中阶": 0.15, "高阶": 0 },
    "超阶": { "初阶": 0.45, "中阶": 0.30, "高阶": 0.15 }
  };
  return reductionMap[tier]?.[skillTier] ?? 0;
};
```

## 六、战斗系统修改

### 6.1 施法打断检测

在battle.js中，玩家选择技能后：
1. 计算实际打断概率
2. 敌方行动时，如果玩家正在施法，进行打断判定
3. 打断成功：魔法失败，MP损失50%
4. 打断失败：魔法正常释放

### 6.2 敌方施法显示

- 敌方选择高阶魔法时，头顶显示"正在施法：天焰葬礼（2回合后释放）"
- 玩家可以用控制技能打断
- 打断成功显示"打断成功！"

### 6.3 防御姿态

- 玩家选择防御时，打断概率-20%
- 防御时不能攻击，但可以减少受到的伤害

## 十、与现有系统的兼容

### 10.1 天赋系统
- 天赋影响低阶技能效果（如火系天赋让灼烧更强）
- 天赋可以提供抗打断加成（如土系天赋防御姿态抗打断+10%）

### 10.2 元素反应
- 冻结/燃烧/感电等自然融入魔法效果
- 雷系对湿润目标伤害更高（跨系配合）

### 10.3 双主修系
- 可以切换系别释放不同阶级的魔法
- 主修系魔法解锁等级要求降低

### 10.4 机制型妖魔
- 妖魔可以打断玩家施法
- 妖魔可以免疫控制、打破牢笼
- 高阶魔法不是万能的
