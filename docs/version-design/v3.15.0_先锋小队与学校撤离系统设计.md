# v3.15.0 先锋小队与学校撤离系统设计

> **版本**：v3.15.0
> **制定时间**：2026-09-10
> **基于**：博城篇第91-100章深入拆解（学校撤离+先锋小队+张英璐牺牲）
> **目标**：完善博城灾难中的学校撤离事件，建立先锋小队系统，让玩家体验完整的撤离过程
> **方法论**：设计→对齐→实施→测试→回归
> **测试策略**：测试左移（设计文档包含测试要点+开发前写好测试用例）

---

## 一、目标

### 1.1 解决的问题

当前博城灾难大事件中，学校撤离部分过于简化，缺少：
- 先锋小队的完整设定和行为
- 1700学生+100导师撤离的规模感
- 张英璐牺牲事件的情感表达
- 玩家在撤离过程中的可介入点
- 警戒等级系统的完整机制

### 1.2 带来的体验

- 玩家体验完整的学校撤离过程，有紧张感和规模感
- 先锋小队10人都有完整设定，玩家可以与他们互动
- 张英璐牺牲事件有情感表达，让玩家感受到灾难的残酷
- 玩家在撤离过程中有选择和介入点，不是纯旁观者
- 警戒等级系统完整（橙色/蓝色/血色），有明确的触发和效果

## 二、原文依据

### 2.1 先锋小队（第93-96章）

**先锋小队10人**：
- 薛木生（领队，光系，光耀·失明，从过军，对人员调配和队形保持有经验）
- 许昭霆（雷系，有胆识，雷印·狂策）
- 周敏（火系，有胆识，火滋·焚骨）
- 穆白（冰系，穆氏家族，十八岁生日叔叔送的斩魔具乌冰斩）
- 何雨（水系，年度考核扮猪吃老虎A级，灾难中吓傻，最后为保护张小侯释放水御牺牲）
- 王三胖（土系，许昭霆好基友，地波，被巨眼猩鼠咬伤肩头）
- 张小侯（风系，莫凡好兄弟，探路，风轨·闪步，何雨牺牲后立志变强）
- 张英璐（风系，探路，被巨眼猩鼠偷袭咬断脖子牺牲）
- 另外2人（待确认，可能是其他学生）

**先锋小队任务**：
- 学校撤离的先头部队
- 探路，确认安全路线
- 遇到妖魔时先头抵抗
- 为大部队撤离争取时间

### 2.2 学校撤离（第93-95章）

**撤离规模**：
- 天澜魔法高中1700学生+100导师=4000人（包括家属）
- 从学校撤离到安全结界（3公里）
- 先锋小队10人先头探路

**撤离过程**：
- 血色警戒触发
- 学校紧急集合
- 先锋小队先头出发
- 大部队跟随
- 明园小区穿越（高档电梯住户楼，abdc四个区，接近一公里，水池飘着保安尸体）
- 美鑫高架桥（从安全结界到铭文区的最大捷径，被凌乱汽车塞满，有塌方）
- 到达安全结界

### 2.3 张英璐牺牲（第94章）

**牺牲过程**：
- 张英璐是先锋小队风系成员，负责探路
- 穿越明园小区时，巨眼猩鼠偷袭
- 张英璐被巨眼猩鼠咬断脖子牺牲
- 先锋小队第一次出现伤亡
- 薛木生光耀·失明对付巨眼猩鼠腥红光束
- 许昭霆雷印·狂策反击
- 王三胖被巨眼猩鼠咬伤肩头

### 2.4 警戒等级（第91-93章）

**警戒等级**：
- 橙色警戒：三百只以上妖魔，一道光耀信号
- 蓝色警戒：妖魔流窜，两道光耀信号
- 血色警戒：上千只妖魔，城市毁灭级灾难

**光耀信号**：
- 光法师初阶技能，类似信号弹
- 妖魔对光无感知，眼睛注视会灼伤
- 科技设备会暴露位置所以光耀是安全方式
- 一道=橙色警戒，两道=蓝色警戒

**小队行为**：
- 探路：风系成员（张小侯/张英璐）先头探路
- 战斗：遇到妖魔时，各成员按角色行动
- 撤退：伤亡过大时撤退
- 士气：影响战斗表现和对话内容

**玩家介入**：
- 玩家可以加入先锋小队（可选）
- 玩家可以在战斗中帮助先锋小队
- 玩家的选择可以影响先锋小队的伤亡
- 玩家可以与先锋小队成员对话

### 3.2 学校撤离事件

**事件流程**（大事件系统，多phase）：
1. **血色警戒触发**：学校广播，紧急集合
2. **先锋小队出发**：10人先头探路
3. **大部队撤离**：1700学生+100导师跟随
4. **明园小区穿越**：遇到巨眼猩鼠，张英璐牺牲
5. **美鑫高架桥**：被汽车塞满，有塌方，需要绕行
6. **到达安全结界**：撤离完成

**玩家选择**：
- 是否加入先锋小队
- 撤离路线选择（明园小区/其他路线）
- 遇到妖魔时的应对（战斗/躲避/绕行）
- 是否帮助受伤的同学
- 是否拯救张英璐（高难度，可能改变剧情）

**规模感设计**：
- 撤离人数显示（1700学生+100导师）
- 撤离进度条
- 周围同学的对话和反应
- 导师的指挥和安排
- 妖魔的威胁和紧迫感

### 3.3 张英璐牺牲事件

**事件触发**：
- 先锋小队穿越明园小区时
- 巨眼猩鼠偷袭
- 张英璐探路时被偷袭

**事件流程**：
1. 张英璐探路，发现前方安全
2. 巨眼猩鼠从侧面偷袭
3. 张英璐被巨眼猩鼠咬断脖子
4. 薛木生光耀·失明对付巨眼猩鼠腥红光束
5. 许昭霆雷印·狂策反击
6. 王三胖被巨眼猩鼠咬伤肩头
7. 张小侯风轨·闪步躲避
8. 先锋小队第一次出现伤亡，士气下降

**玩家介入**：
- 玩家可以提前发现巨眼猩鼠（感知/寻妖粉）
- 玩家可以帮助对抗巨眼猩鼠
- 玩家可以尝试拯救张英璐（高难度，需要快速反应）
- 如果玩家拯救成功，张英璐存活（特殊剧情分支）

**情感表达**：
- 张英璐牺牲的描述
- 先锋小队成员的反应（薛木生冷静/许昭霆愤怒/张小侯震惊/何雨害怕）
- 士气下降
- 后续对话中提及张英璐

### 3.4 警戒等级系统

**警戒等级**：
```javascript
// 警戒等级定义
const AlertLevels = {
  orange: {
    id: "orange",
    name: "橙色警戒",
    description: "三百只以上妖魔出没",
    signal: 1, // 一道光耀信号
    effects: {
      enemySpawnRate: 1.5, // 妖魔出现率
      npcBehavior: "cautious", // NPC行为：谨慎
      shopOpen: false, // 商店关闭
    }
  },
  blue: {
    id: "blue",
    name: "蓝色警戒",
    description: "妖魔流窜，两道耀光",
    signal: 2, // 两道光耀信号
    effects: {
      enemySpawnRate: 2.0,
      npcBehavior: "nervous",
      shopOpen: false,
      locationLock: ["野外"], // 锁定野外地点
    }
  },
  blood: {
    id: "blood",
    name: "血色警戒",
    description: "上千只妖魔，城市毁灭级灾难",
    signal: "emergency", // 紧急警报
    effects: {
      enemySpawnRate: 5.0,
      npcBehavior: "panic",
      shopOpen: false,
      locationLock: ["野外", "城市街道"], // 锁定多个地点
      bigEventTrigger: "bo_city_disaster", // 触发博城灾难大事件
    }
  }
}
```

**警戒等级变化**：
- 正常→橙色：妖魔数量达到300只
- 橙色→蓝色：妖魔流窜到城市
- 蓝色→血色：妖魔数量达到1000只
- 血色→蓝色：妖魔数量下降到1000以下
- 蓝色→橙色：妖魔数量下降到300以下
- 橙色→正常：妖魔清除完毕

**光耀信号**：
- 光法师可以释放光耀信号
- 一道=橙色警戒，两道=蓝色警戒
- 妖魔对光无感知，眼睛注视会灼伤
- 科技设备会暴露位置，光耀是安全方式
