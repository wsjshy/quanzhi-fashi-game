## 三、生成方式策略

### 3.1 分层生成策略

| 资源类型 | 首选方式 | 备选方式 | 说明 |
|----------|----------|----------|------|
| 魔法特效图 | AI生成（豆包生图） | CSS渐变+滤镜 | 抽象风格，AI生成效果好 |
| 背景图 | AI生成 | CSS渐变+图案 | 场景图，AI生成效果好 |
| NPC头像 | AI生成 | 元素色背景+emoji | 二次元风格，需统一画风 |
| 技能/物品图标 | AI生成 | CSS+emoji/SVG | 简约风格，SVG可缩放 |
| 妖魔立绘 | AI生成 | 元素色背景+emoji | 怪物设计，AI生成效果好 |
| 帧动画 | CSS动画 | Sprite Sheet | 优先CSS动画，性能好 |
| UI特效 | CSS/SVG | 图片 | 优先CSS/SVG，可缩放 |

## 四、动画与特效规划

### 4.1 CSS动画（优先实现，性能好）

| 动画类型 | 应用场景 | 实现方式 | 优先级 |
|----------|----------|----------|--------|
| **按钮悬浮** | 所有可点击按钮 | transform: scale + box-shadow | P0 |
| **面板入场** | 弹窗/面板出现 | opacity + translateY | P0 |
| **伤害数字** | 战斗伤害飘字 | translateY + opacity + scale | P0 |
| **血条变化** | HP/MP条变化 | transition: width | P0 |
| **技能冷却** | 技能图标冷却 | conic-gradient + 旋转 | P1 |
| **元素脉冲** | 天赋/技能图标发光 | box-shadow 脉冲动画 | P1 |
| **战斗受击** | 角色受击抖动 | transform: translateX 抖动 | P1 |
| **施法引导** | 技能引导进度 | 进度条 + 发光 | P1 |
| **状态图标** | Buff/Debuff图标 | 旋转/脉冲/浮动 | P2 |
| **场景切换** | 地点/战斗切换 | 淡入淡出 + 模糊 | P2 |
| **粒子特效** | 魔法释放背景 | CSS粒子动画 | P2 |
| **胜利动画** | 战斗胜利 | 缩放 + 闪光 + 彩带 | P3 |

### 4.2 帧动画（后续实现，资源密集）

| 动画类型 | 应用场景 | 帧数 | 优先级 |
|----------|----------|------|--------|
| 技能释放 | 各系魔法释放 | 8-12帧 | P2 |
| 受击反应 | 角色/妖魔受击 | 4-6帧 | P2 |
| 死亡动画 | 妖魔死亡 | 6-8帧 | P3 |

### 4.3 特效层设计

战斗界面分3层特效：

3. **前景层**：技能释放特效 + 伤害数字 + 屏幕震动/闪光

## 八、性能与优化

### 8.1 图片优化

- 统一使用WebP格式（比JPG小30%，比PNG小50%）
- 图标使用PNG（支持透明）或SVG（可缩放）
- 所有图片压缩到合理质量（背景80%，头像85%，图标90%）
- 使用懒加载（非首屏图片延迟加载）

### 8.2 动画性能

- 优先使用CSS transform和opacity（GPU加速）
- 避免使用left/top/width/height动画（触发重排）
- 动画时长控制在0.2-0.5秒（快速反馈，不拖沓）
- 使用will-change提示浏览器优化
- 减少同时运行的动画数量（战斗中最多5个同时动画）

### 8.3 资源预加载

- 首屏必要资源预加载（标题背景/UI装饰）
- 进入地点前预加载该地点背景
- 进入战斗前预加载战斗背景/角色立绘
- 空闲时预加载后续可能用到的资源
