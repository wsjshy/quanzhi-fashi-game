# v1.8.1 阴谋调查系统设计

> 版本：v1.8.1 | 状态：设计草稿（待用户确认对齐）
> 创建日期：2026-08-18

## 一、设计目标

让玩家在博城灾难前，通过探索、对话、任务逐步收集黑教廷阴谋的线索，体验"山雨欲来风满楼"的悬疑感。调查程度影响博城灾难时的分支选项和结局，增强玩家影响力和剧情代入感。

## 二、核心机制

### 2.1 线索收集

线索分为4类，每类有独立的进度条：

| 线索类型 | 说明 | 获取方式 |
|---------|------|---------|
| 妖魔异常 | 妖魔行为异常、迁徙规律 | 探索雪峰山/城市边缘、猎妖任务 |
| 黑教廷踪迹 | 黑教廷成员活动、可疑物品 | 特定地点探索、NPC对话、任务奖励 |
| 宇昂疑点 | 宇昂的异常行为、身份线索 | 与宇昂/穆氏NPC对话、观察决斗 |
| 地圣泉秘密 | 地圣泉的价值、黑教廷觊觎 | 唐月对话、地圣泉相关任务 |

每类线索0-100%，收集线索时增加对应类型进度。

### 2.2 线索获取方式

1. **探索触发**：在特定地点执行探索行动，概率获得线索（如雪峰山深处发现妖魔异常迁徙痕迹）
2. **对话选项**：与特定NPC对话时选择追问/调查选项，获得线索
3. **任务奖励**：完成调查类任务获得线索
4. **事件触发**：随机事件/剧情事件中获得线索
5. **情报购买**：在特定地点（如酒馆、集市）花费金币购买情报

### 2.3 调查程度与剧情分支

总调查程度 = 四类线索平均值，分为4个等级：

| 等级 | 总进度 | 效果 |
|------|--------|------|
| 一无所知 | 0-25% | 博城灾难按原著发生，玩家无特殊选项 |
| 略有察觉 | 26-50% | 灾难前收到唐月的警告，可选择提前准备 |
| 深入调查 | 51-75% | 可提前发现暴躁之泉的线索，灾难中有特殊行动选项 |
| 接近真相 | 76-100% | 可提前揭露宇昂身份，灾难中可选择阻止部分阴谋，解锁特殊结局 |

### 2.4 宇昂身份发现线

独立于通用线索的特殊线：
- 收集3条宇昂疑点线索 → 触发"宇昂的秘密"特殊事件
- 玩家可选择：①当面质问 ②告诉唐月 ③暗中观察 ④置之不理
- 不同选择影响后续剧情和NPC关系

```javascript
Player.investigation = {
  demon: 0,        // 妖魔异常进度 0-100

```

### 3.3 线索触发配置

在地点动作、对话选项、任务奖励中添加`giveClue`字段：
```javascript
// 地点动作
{
  id: "explore_deep",
  name: "深入探索",
  effects: { exp: 20 },
  clueChance: 0.3, // 30%概率获得线索
  cluePool: ["clue_demon_migration", "clue_demon_agitation"]
}

// 对话选项
{
  text: "你最近有没有发现什么异常？",
  next: "default",
  giveClue: "clue_yu_ang_training"
}

// 任务奖励
rewards: {
  exp: 200,
  gold: 100,
  clue: "clue_black_church_ritual"
}
```

## 五、与现有系统的联动

### 5.1 任务系统
- 新增调查类任务，奖励线索
- 现有猎妖任务可添加线索奖励
- 任务面板可筛选"调查任务"

### 5.2 对话树
- 特定NPC添加调查类对话选项
- 对话选项根据已发现线索解锁新分支
- 宇昂对话根据疑点等级变化

### 5.3 大事件系统
- 博城灾难事件根据调查等级提供不同选项
- 调查等级达到阈值时触发预警事件

### 5.4 NPC关系
- 告诉唐月线索 → 唐月好感+、解锁特殊对话
- 质问宇昂 → 宇昂关系变化、可能触发冲突
- 与穆氏NPC讨论 → 影响穆氏声望

## 六、初始内容规划（v1.8.1最小可用版本）

### 6.1 线索（15-20条）
- 妖魔异常：5条（探索/猎妖获取）

## 八、风险与注意事项

1. **不破坏原著**：线索内容基于原文，不编造黑教廷的核心设定
2. **玩家有自己的人生**：调查是玩家自主选择，不强制，不截取莫凡的机缘
3. **自然发生**：线索获取不刻意提示，通过探索和对话自然获得
4. **可扩展性**：线索系统设计为通用框架，后续篇章可复用
5. **平衡性**：线索获取难度适中，不要求玩家必须满进度才能体验核心剧情
