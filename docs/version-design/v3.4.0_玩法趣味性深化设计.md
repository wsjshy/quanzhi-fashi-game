# v3.4.0 玩法趣味性深化设计文档

> 版本：v3.4.0 | 状态：设计中 | 最后更新：2026-09-07

## 一、版本目标

在v3.3.1对话体验修复基础上，深化玩法趣味性：
1. 解决对话系统"态度选项互斥"的设计缺陷，让玩家可以改变态度
2. 新增闭关修炼长周期行为，丰富游戏节奏
3. 对话进度可视化，让玩家清楚知道还有多少内容没聊

## 二、核心功能设计

### 功能1：对话深度优化（P0）

#### 1.1 态度选项各自独立

**当前问题**：莫凡等NPC的嘲笑/鼓励/请教三个态度选项共享`notMemoryTags: ["player_teased", "player_encouraged", "player_asked_magic"]`，选任何一个后三个选项全部变灰，玩家无法改变态度。

**优化方案**：
- 每个态度选项只排除自己对应的memory tag，不共享排除
- 例如：
  - 嘲笑：`notMemoryTags: ["player_teased"]`
  - 鼓励：`notMemoryTags: ["player_encouraged"]`
  - 请教：`notMemoryTags: ["player_asked_magic"]`
- 玩家选了"请教"后，"嘲笑"和"鼓励"仍然可选，可以改变对NPC的态度
- 已选择的态度选项显示"✓ 已表达态度"，但新态度选项正常高亮

**影响范围**：需要修改characters.js中所有使用共享notMemoryTags的态度选项（目前17处notMemoryTags使用）

#### 1.2 对话进度可视化

**当前问题**：玩家不知道NPC还有多少对话内容没聊，"有新对话"标记不够精确。

**优化方案**：
- NPC列表中每个NPC显示"对话完成度 X/Y"
- X = 已访问的oneTime节点数 + 已选择的态度选项数
- Y = 该NPC对话树中oneTime节点总数 + 态度选项总数
- 完成度100%时显示"✓ 对话已完成"
- 未完成时显示"💬 对话进度 X/Y"

**实现方式**：
- 在dialogue-tree.js中新增`getDialogueProgress(npcId)`方法
- 在game-npc-list.js的NPC列表渲染中显示进度

#### 1.3 已访问选项可重新查看内容

**当前问题**：已访问的oneTime选项变灰后，点击应该能重新查看对话内容（但不重复加好感）。

**当前状态**：v3.3.1已实现此功能（已访问的oneTime选项可点击查看内容，不重复触发effects）。

### 功能2：闭关修炼系统（P1）

#### 2.1 设计理念

符合原著设定：法师经常闭关修炼，长时间专注修炼以获得突破。这是一个**长周期行为**，玩家选择闭关天数，期间跳过时间，获得大量经验和突破概率。

#### 2.2 功能细节

**入口**：地图界面"修炼魔法"选项中新增"闭关修炼"子选项

**闭关时长选项**：
- 闭关1天：消耗全部HP/MP，获得8小时修炼经验（×2效率），有5%概率突破
- 闭关3天：消耗全部HP/MP，获得24小时修炼经验（×2效率），有15%概率突破
- 闭关7天：消耗全部HP/MP，获得56小时修炼经验（×2效率），有30%概率突破

**闭关机制**：
- 闭关期间时间快速跳过（显示"闭关中..."动画）
- 闭关结束后显示结果：获得经验、是否突破、是否有感悟
- 闭关需要在安全地点（学校/家），不能在野外
- 闭关期间不会触发随机事件

**突破事件**：
- 突破成功：等级+1，所有属性提升，显示"突破成功！"特效
- 突破失败：获得额外经验，但等级不变
- 高境界突破概率降低（符合原著设定）

#### 2.3 与现有修炼系统的区别

| 特性 | 普通修炼 | 闭关修炼 |
|------|---------|---------|
| 时长 | 2小时/次 | 1/3/7天 |
| 效率 | 基础 | ×2 |
| 突破概率 | 低 | 中/高 |
| 触发事件 | 可能随机事件 | 无随机事件 |
| 适用场景 | 日常提升 | 专注突破 |

## 四、风险与注意事项

1. **notMemoryTags修改**：需要确保修改后不会导致选项重复触发effects，已选择的态度选项仍然显示"✓ 已表达态度"且不可重复选择
2. **闭关修炼平衡**：经验效率×2可能导致升级过快，需要测试调整
3. **原著一致性**：闭关修炼符合原著设定，但突破概率需要符合境界压制规则
4. **数据唯一性**：新增的闭关动作ID不能与现有动作重复
