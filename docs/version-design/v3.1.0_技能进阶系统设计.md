# v3.1.0 技能进阶系统设计

> 版本：v3.1.0 | 日期：2026-08-22 | 状态：设计中

## 一、背景

当前技能系统已有初阶/中阶/高阶技能数据（tier字段），但玩家无法通过游戏玩法将初阶技能进阶为中阶技能。中阶技能只能通过觉醒/任务获得，缺乏成长感。

## 二、设计目标

1. 让玩家通过修炼/使用将初阶技能进阶为中阶技能
2. 保持原著设定：中阶魔法需要星轨→星云的突破
3. 不破坏现有技能系统的平衡性
4. 可扩展：未来支持高阶/超阶进阶

## 三、进阶机制

### 3.1 进阶条件

初阶技能 → 中阶技能需要满足：
- 玩家等级 ≥ 10（中阶法师门槛）
- 对应元素等级 ≥ 3（元素熟练度）
- 消耗技能点 × 3
- 初阶技能使用次数 ≥ 50（熟练度）

### 3.2 进阶效果

- 技能替换：初阶技能ID → 中阶技能ID（如fire_bolt → fire_rain）
- 威力提升：中阶技能基础伤害/效果显著增强
- 保留熟练度：进阶后使用次数继承

### 3.3 进阶映射表

| 初阶技能 | 中阶技能 | 元素 |
|---------|---------|------|
| fire_bolt（火滋·灼烧） | fire_rain（火滋·焚骨） | 火 |
| ice_spike（冰蔓·冻骨） | ice_storm（冰蔓·冰封） | 冰 |
| thunder_bolt（雷印·蟒痕） | thunder_strike（雷印·轰顶） | 雷 |
| water_bolt（水御·水泡） | water_wave（水御·潮涌） | 水 |
| wind_blade（风轨·飘影） | wind_storm（风轨·疾影） | 风 |
| earth_spike（土波·挪移） | earth_wall（土波·地盾） | 土 |
| light_beam（光耀·守护） | light_shield（光耀·圣盾） | 光 |
| dark_bolt（暗影·遁影） | dark_bind（暗影·巨影钉） | 暗 |
