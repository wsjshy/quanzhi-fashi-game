# v0.48.0 影响力剧情事件链设计

> 版本：v0.48.0
> 日期：2026-08-15
> 定位：实现第一个"玩家选择真正改变游戏世界状态"的事件链，验证影响力系统的深层价值

---

## 一、设计目标

### 问题
当前影响力系统只有数值反馈（称号/特权/NPC对话反应/里程碑），玩家的选择不会真正改变游戏世界的状态。玩家感受不到"我做的事有影响"。

### 目标
实现第一个**flag驱动的事件链**：
1. 玩家在事件A中的选择设置全局flag
2. 后续事件B/C检查该flag，呈现不同内容
3. 选择有实际的游戏影响（不只是数值奖励，还包括NPC态度变化、内容解锁）
4. 一切自然发生，不刻意提示"你的选择改变了XX"

### 核心原则（遵循AGENTS.md）
- 不对标莫凡，不零和竞争
- 一切自然发生，不刻意提示
- 人设不可破坏
- 玩家有自己的人生

## 二、事件链设计："唐月的栽培"

### 事件1：唐月的关注
- **ID**: `influence_tang_yue_attention`
- **触发条件**: 唐月信任≥25，在天澜魔法高中，修炼/自习/上课时20%概率
- **内容**: 唐月注意到玩家的努力，课后留下玩家，说可以提供额外指导
- **选择**:
  - **A. 欣然接受** → setFlag("tang_yue_guidance"), 获得技能经验+20, 唐月信任+5
  - **B. 婉拒，说不想麻烦老师** → 唐月好感+8, 学校声望+3
  - **C. 问能否推荐给其他老师** → 需要影响力≥15, setFlag("tang_yue_referred"), 解锁后续"多位老师指导"事件
- **设计意图**: 第一个选择点，玩家决定是否接受唐月的栽培

### 事件2：修炼中的指导（flag驱动）
- **ID**: `influence_tang_yue_guidance_buff`
- **触发条件**: flag="tang_yue_guidance", 修炼时15%概率
- **内容**: 唐月在玩家修炼时路过，指出一个修炼要点
- **效果**: 本次修炼经验+50%, 随机属性+1
- **设计意图**: 让玩家感受到"接受指导"的实际好处

### 事件3：莫凡的观察（flag驱动的对话变化）
- **ID**: `influence_mofan_notice_guidance`
- **触发条件**: flag="tang_yue_guidance", 与莫凡对话时10%概率
- **内容**: 莫凡随口提到"唐老师最近好像挺关注你的，经常看到她单独和你说话"
- **效果**: 莫凡好感+3（他觉得玩家努力），无负面效果
- **设计意图**: 自然体现玩家行为被NPC观察到，不搞"莫凡不爽"的零和竞争

### 事件4：同学的认可（flag驱动）
- **ID**: `influence_classmate_recognition`
- **触发条件**: flag="tang_yue_guidance" 或 flag="tang_yue_referred", 找人聊天时10%概率
- **内容**: 同学提到"听说唐老师在单独指导你？厉害啊"
- **效果**: 学校声望+2
- **设计意图**: 信息在同学间自然传播

## 三、技术实现

### 基础设施（已具备，无需改代码）
- 事件系统支持`conditions.flag`检查（event.js line 137）
- 事件效果支持`setFlag`（event.js line 247-249）
- Player.flags持久化存储（player.js）

### 数据配置
- 所有事件在`engine/data/events.js`中新增
- 使用现有事件结构（id/name/description/conditions/choices/effects）
- flag命名规范：`influence_<事件名>_<状态>`

### 触发方式
- 事件1：通过随机事件池触发（修炼/自习/上课行动时）
- 事件2-4：通过flag条件检查，在对应行动/对话时触发

---

## 四、验证标准

1. 唐月信任≥25时，修炼有概率触发"唐月的关注"
2. 选择A后，flag="tang_yue_guidance"被设置
3. 有flag后，修炼有概率触发"修炼中的指导"（经验加成）
4. 有flag后，与莫凡对话有概率触发"莫凡的观察"
5. 有flag后，找人聊天有概率触发"同学的认可"
6. 选择B/C不设置guidance flag，后续事件不触发
7. 所有事件符合人设（唐月温柔/莫凡直爽/同学八卦）
8. 无刻意提示"你的选择改变了XX"
