# v1.8.2 星尘魔器分配逻辑设计

> 版本：v1.8.2 | 日期：2026-08-18 | 状态：设计中，待对齐确认

## 一、设计目标

基于小说原文，完善星尘魔器的分配和使用机制，让年度考核的成绩有实际意义，增强玩家追求好成绩的动力。

### 原文依据
- 星尘魔器是修炼滋养类器皿，缩短冥修疲劳期（20%冷却缩减Buff）
- 年度考核排名越高，星尘魔器使用时间越长
- 尖子班学生才有资格分配星尘魔器
- 每季度重新考核排名，重新分配
- 莫凡班级第一本应最长，因目无尊长被惩罚从1个月→10天
- 穆氏家族也有独立的星尘魔器分配给核心弟子

## 二、核心机制

### 2.1 年度考核评级

现有评级：S/A/B/C/D

**评级→排名映射：**
| 评级 | 排名区间 | 星尘魔器使用时长 | 品质 |
|------|---------|----------------|------|
| S | 第1名 | 30天（1个月） | 精品级 |
| A | 第2-5名 | 20天 | 精品级 |
| B | 第6-15名 | 10天 | 普通级 |
| C | 第16-30名 | 5天 | 普通级 |
| D | 30名外 | 无资格 | - |

**特殊情况：**
- 目无尊长/违纪行为：使用时长减半（参考莫凡惩罚）
- 暗石事件揭发者：额外+5天奖励
- 穆氏招揽接受者：额外获得穆氏家族星尘魔器（独立于学校分配）

### 2.2 星尘魔器使用期限机制

**数据结构：**
```javascript
player.starDustArtifact = {
  active: true/false,        // 是否持有
  artifactId: "fire_star_dust", // 魔器ID
  grade: "normal/exquisite",    // 品质
  daysRemaining: 30,            // 剩余使用天数
  totalDays: 30,                // 总分配天数
  source: "school/mu_family",   // 来源
  assignedDay: 45,              // 分配日（游戏内天数）
  expireDay: 75                 // 到期日
}
```

**期限逻辑：**
- 每天0点（游戏内时间）自动减少1天剩余
- 到期后星尘魔器失效，修炼效果消失
- 到期前3天提示玩家"星尘魔器即将到期"
- 季度考核后重新分配（覆盖或续期）

### 2.3 修炼效果联动

**持有星尘魔器时的修炼加成：**
- 普通级：修炼经验+10%，疲劳恢复+15%
- 精品级：修炼经验+20%，疲劳恢复+25%
- 与现有星尘魔器等级系统叠加（成长型魔器）

**修炼时的提示：**
- 持有星尘魔器时，修炼行动显示"✨ 星尘魔器加成中"
- 修炼结果显示加成数值

## 四、与现有系统的关系

- **现有星尘魔器系统**：玩家已拥有的成长型星尘魔器不受影响，学校分配的是临时使用权
- **年度考核大事件**：在phase_6_end添加分配逻辑
- **修炼系统**：修炼时检查是否持有有效星尘魔器，应用加成
- **穆氏招揽**：接受招揽额外获得穆氏星尘魔器（可与学校叠加）

## 五、待确认问题

1. **学校分配 vs 玩家已有魔器**：学校分配的星尘魔器是临时使用权，还是直接给玩家？
   - 方案A：临时使用权，到期收回（更符合原著）
   - 方案B：直接给玩家，永久持有（更简单，但不符合原著）

2. **多系玩家分配**：玩家有多个元素时，分配哪个元素的星尘魔器？
   - 方案A：玩家主修元素（第一个元素）
   - 方案B：玩家选择
   - 方案C：通用型星尘魔器（all元素）

3. **期限计算粒度**：按游戏内天数计算，还是按现实操作次数？
   - 方案A：游戏内天数（每天-1）
   - 方案B：修炼次数（每次修炼-1）

4. **UI布局方向**：角色面板星尘魔器卡片如何显示剩余天数？
   - 方案A：在卡片名称下方显示"剩余XX天"
   - 方案B：进度条形式显示使用进度
