# v2.1.0 重建任务线与离开节点设计

> 版本：v2.1.0 | 日期：2026-08-18 | 状态：设计中，实施中

## 一、设计目标

让"留博城"选择有实际内容，而不是空壳。玩家参与重建后，最终通过自然的剧情节点推送离开博城，进入原著的古都/明珠线。

### 核心原则
- 留博城是**阶段性支线**，不是终局
- 重建任务原创但贴合原著设定（博城灾后重建）
- 完成一定重建后，自然触发离开节点
- 所有路径最终汇聚到原著线

## 二、重建任务线

### 触发条件
- 玩家在灾后审判中选择"留在博城"
- 设置flag: rebuilding_arc_started = true

### 任务列表（12个任务，分3阶段）

**第一阶段：救援与清理（4个）**
1. `quest_rebuild_clear_rubble` - 清理主街道废墟（探索/战斗）
2. `quest_rebuild_rescue_survivors` - 搜救被困幸存者（探索/NPC对话）
3. `quest_rebuild_medical_aid` - 协助医疗队救助伤员（物品收集/对话）
4. `quest_rebuild_patrol` - 夜间巡逻，清除残留妖魔（战斗）

**第二阶段：重建与恢复（4个）**
5. `quest_rebuild_school` - 协助重建天澜魔法高中（物品收集/对话）
6. `quest_rebuild_market` - 帮助集市恢复运营（对话/经济）
7. `quest_rebuild_defense` - 修复城市防御法阵（物品收集/探索）
8. `quest_rebuild_memorial` - 参与灾难纪念碑落成（对话/叙事）

**第三阶段：守护与成长（4个）**
9. `quest_rebuild_hunt_guard` - 猎妖队守护重建区域（战斗/连续）
10. `quest_rebuild_train_students` - 指导新生修炼（对话/教学）
11. `quest_rebuild_investigation` - 调查残留黑教廷踪迹（探索/战斗）
12. `quest_rebuild_final_report` - 向唐月汇报重建成果（对话/叙事）

### 任务奖励
- 博城声望（rebuilding reputation）
- 经验、金币
- 部分任务给装备/物品
- NPC关系提升（唐月、张小侯、薛木生等）

## 三、离开节点

### 触发条件
- 完成8个以上重建任务
- 或玩家等级达到Lv.15
- 或游戏内天数达到灾后第30天

### 离开剧情
唐月找到玩家：
> "博城的重建已经步入正轨了。但你也知道，博城的资源有限，想要突破中阶，你需要更大的舞台。"
> 
> "审判会在古都有个任务，需要有人协助调查。斩空教官也推荐你去古都的陵墓遗迹历练。明珠学府的入学考核也快开始了。"
> 
> "你怎么打算？"

### 选项
1. **接受审判会任务，去古都** - 解锁古都篇前置，获得审判会推荐信
2. **报考明珠学府，去上海** - 解锁明珠篇前置，获得入学推荐
3. **再留一段时间** - 继续重建任务，之后再次触发离开节点
