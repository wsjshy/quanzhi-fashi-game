# v1.4.0 天赋系统重构设计

> 版本：v1.4.0 | 状态：设计中 | 最后更新：2026-08-18

## 一、设计目标

1. **觉醒流程重构**：先随机天生天赋，天赋决定系别（稀有天赋绑定稀有系）
2. **天生天赋强度平衡**：弱天赋高成长，强天赋少进化，最终强度趋同
3. **系天赋差异化**：每个系有独特核心机制，进化路线多样化
4. **方法论沉淀**：天赋设计指南，指导后续小说拆解和天赋设计

## 二、觉醒流程重构

### 2.1 新流程

```
1. 开始新游戏
2. 随机3个天生天赋候选（加权随机）
3. 玩家选择1个天生天赋
4. 根据天赋决定系别：
   - 普通天赋 → 随机3个系别候选，玩家选择
   - 绑定系天赋 → 第一系固定为该系（如祝福系天赋→祝福系）
   - 双生天赋 → 两个系别都随机
5. 选择系天赋（该系3个候选）
6. 进入游戏
```

### 2.2 天赋-系别绑定规则

- 普通天赋：不绑定系别，玩家自由选择
- 系专属天赋：绑定特定系别，选择后第一系固定
- 双生天赋：两个系别都随机，每次升级双系都获得天赋点

### 2.3 稀有系觉醒方式

- 心灵系、祝福系等稀有系：**只能通过绑定系天赋觉醒**
- 不在普通随机系别列表中
- 符合原著设定（稀有系不是普通人能觉醒的）

## 三、天生天赋进化系统

### 3.1 设计原则

| 类型 | 初始强度 | 进化次数 | 最终强度 | 设计意图 |
|------|----------|----------|----------|----------|
| 成长型 | C | 4次 | S | 大器晚成，后期发力 |
| 早熟型 | A | 1次 | A+ | 前期强势，后期平稳 |
| 波动型 | B | 3次 | S- | 中期崛起，有节奏 |
| 特化型 | B+ | 2次 | A | 特定场景极强 |

### 3.2 进化触发条件

- Lv3：第一次进化（特性）
- Lv5：第二次进化（形态质变）
- Lv7：第三次进化（延伸能力）
- Lv10：第四次进化（终极形态）

### 3.3 天赋分类与示例

#### 成长型（弱初始，高成长）

**元素亲和**
- Lv1：所有元素伤害+5%
- Lv3：所有元素伤害+10%，元素抗性+5%
- Lv5：所有元素伤害+15%，解锁元素共鸣（双系技能伤害+10%）
- Lv7：所有元素伤害+20%，元素反应伤害+30%
- Lv10：所有元素伤害+25%，无视20%元素抗性

**修炼天才**
- Lv1：经验获取+15%
- Lv3：经验获取+25%，修炼速度+20%
- Lv5：经验获取+35%，突破成功率+10%
- Lv7：经验获取+45%，每日修炼次数+1
- Lv10：经验获取+60%，突破必定成功

#### 早熟型（强初始，少进化）

**天生双系**（原著莫凡天赋）
- Lv1：创建角色时额外觉醒一个随机系
- Lv10：双系协同（同时释放两系技能，伤害+20%）

**施法专注**
- Lv1：先手概率+50%，技能CD-1
- Lv10：先手必定，技能CD-2，施法不被打断

#### 波动型（中期崛起）

**战斗直觉**
- Lv1：暴击率+5%
- Lv3：暴击率+10%，暴击伤害+15%
- Lv5：暴击率+15%，连续暴击叠加伤害（每层+5%，最多5层）
- Lv7：暴击率+20%，暴击后速度+10%（持续2回合）
- Lv10：暴击率+25%，必定暴击时触发"必杀"（伤害x1.5）

#### 特化型（特定场景）

**技能大师**
- Lv1：所有技能等级+1
- Lv5：所有技能等级+2，技能伤害+10%
- Lv10：所有技能等级+3，技能CD-1

## 四、系天赋差异化设计

### 4.1 核心机制

每个系别有独特的核心机制，所有天赋围绕该机制设计：

| 系别 | 核心机制 | 设计关键词 |
|------|----------|-----------|
| 火系 | 燃烧层数 | 叠加、爆炸、持续伤害 |
| 冰系 | 冻结+破冰 | 控制、暴击、层数 |
| 雷系 | 感电+麻痹 | 连锁、扩散、速度 |
| 水系 | 湿润+治疗 | 护盾、恢复、联动 |
| 风系 | 连击+闪避 | 速度、反击、多段 |
| 土系 | 护盾+反击 | 防御、反伤、控制 |
| 光系 | 净化+圣光 | 驱散、累积、爆发 |
| 暗系 | 吸血+潜行 | 续航、暴击、削弱 |
| 治愈 | 治疗+复苏 | 持续恢复、复活、增益 |
| 植物 | 控制+中毒 | 束缚、叠毒、场地 |
| 召唤 | 召唤兽协同 | 多单位、进化、协同 |

### 4.2 进化路线分支

每个系至少3条进化路线，Lv5时选择分支：

**火系示例**：
- 路线A（爆发流）：引燃→爆燃→焚天（满层爆炸，单次高伤）
- 路线B（持续流）：火种→烈焰→熔岩（DOT叠加，稳定输出）
- 路线C（辅助流）：火盾→炎甲→凤凰（护盾+反伤+复活）

### 4.3 火系天赋重做示例

#### 天赋1：烈焰之魂（爆发流）
- Lv1 觉醒：火系伤害+10%，攻击附加1层燃烧
- Lv3 特性：燃烧每层+3%伤害，最多5层
- Lv5 进化【分支选择】：
  - A 爆燃：满层燃烧时爆炸，造成50%攻击力伤害
  - B 烈焰：燃烧持续时间+2回合，伤害+50%
- Lv7 延伸：火系技能暴击率+15%
- Lv10 终极：
  - A路线 焚天：爆炸伤害提升至100%，爆炸后刷新燃烧
  - B路线 熔岩：燃烧变为真实伤害，每层+5%

#### 天赋2：燃烧之心（持续流）
- Lv1 觉醒：火系技能30%概率附加2层燃烧
- Lv3 特性：对燃烧目标伤害+20%
- Lv5 进化【分支选择】：
  - A 火种：每回合开始对所有敌人附加1层燃烧
  - B 烈焰：燃烧伤害可暴击
- Lv7 延伸：燃烧目标速度-10%
- Lv10 终极：
  - A路线 焚天：燃烧上限+5层，满层时目标防御-30%
  - B路线 炽焰：燃烧暴击伤害+50%

#### 天赋3：火盾护体（辅助流）
- Lv1 觉醒：受到攻击时20%概率对攻击者附加燃烧
- Lv3 特性：获得护盾时，护盾期间反伤10%火系伤害
- Lv5 进化【分支选择】：
  - A 炎甲：护盾吸收量+30%，反伤提升至20%
  - B 凤凰：HP低于20%时，获得等于最大HP30%的护盾（每场战斗1次）
- Lv7 延伸：火系技能治疗效果+20%（燃烧伤害的10%转化为治疗）
- Lv10 终极：
  - A路线 不灭：护盾破碎时爆炸，对所有敌人造成护盾量的伤害
  - B路线 涅槃：凤凰护盾触发时，同时恢复30%HP

## 五、方法论：天赋设计指南

### 5.1 从小说拆解天赋

1. **提取角色核心能力**：该角色在原著中的标志性能力是什么？
2. **转化为游戏机制**：这个能力如何用数值/机制表达？
3. **设计进化路线**：能力如何成长？有哪些分支方向？
4. **平衡强度**：初始强度 vs 成长空间 vs 最终强度

### 5.2 天赋设计检查清单

- [ ] 符合原著设定（不编造不存在的能力）
- [ ] 有独特核心机制（不与其他系同质化）
- [ ] 进化路线有意义（每次进化都有新体验）
- [ ] 分支选择有差异（不同路线玩法不同）
- [ ] 最终强度平衡（与其他系/天赋相当）
- [ ] 有组合联动空间（与其他天赋/技能/元素反应配合）

### 5.3 天赋类型模板

| 类型 | 适合场景 | 设计要点 |
|------|----------|----------|
| 伤害型 | 输出角色 | 层数机制、暴击联动、元素反应 |
| 控制型 | 辅助角色 | 状态效果、命中率、持续时间 |
| 防御型 | 坦克角色 | 护盾、减伤、反伤、复活 |
| 续航型 | 持久战斗 | 吸血、恢复、MP回复、续航 |
| 特化型 | 特定build | 技能强化、CD缩减、特定条件爆发 |

## 七、扩展接口

- 新增系别：在talents.js中添加该系的核心机制和天赋
- 新增天生天赋：在innate-talents.js中添加，指定type（growth/early/volatile/specialized）和evolutions
- 新增进化分支：在天赋的evolutions中添加level:5的choices数组
- 稀有系绑定：天赋的effects中添加boundElement字段
