# v0.56.0 导师系统深化

> 版本：v0.56.0
> 日期：2026-08-15
> 类型：系统深化
> 前置：v0.55.0 玩家专属导师线（唐月）

---

## 一、为什么深化

v0.55.0的导师线只是3个概率触发的事件，缺乏稳定收益，玩家感知弱。从游戏整体看，师徒关系应该是"持续成长buff+专属资源+技能传承"的系统，让玩家有明确的获得感。

---

## 二、核心机制

### 2.1 稳定修炼加成（系统级）
- 拜师后（flag: tang_yue_mentor），所有修炼经验**固定+10%**
- 师徒等级每升1级，额外+5%（Lv.1: +10%, Lv.2: +15%, Lv.3: +20%）
- 实现方式：在`performCultivate`中检查flag，计算经验时加成

### 2.2 师徒等级系统
- 师徒等级（mentorLevel）：1-3级
- 升级条件：
  - Lv.1→Lv.2：师徒互动5次 + 唐月好感≥70
  - Lv.2→Lv.3：师徒互动10次 + 唐月好感≥90 + 玩家等级≥15
- 每次师徒修炼/导师关心事件触发时，互动次数+1
- 等级提升时触发事件：唐月的认可

### 2.3 月度资源支持
- 拜师后，每月1号可触发"导师的月度支持"事件
- 内容：唐月给予修炼药水x2 + 魔法草药x1
- 每月仅一次（flag控制）

### 2.4 技能传授（Lv.2解锁）
- 师徒等级达到2级时，触发"唐月的传承"事件
- 唐月传授专属火系技巧："星子紧凑排列法"（被动：火系技能伤害+5%）
- 通过flag标记，战斗系统中检查加成

### 2.5 UI展示
- 角色属性界面新增"导师"栏：显示"导师：唐月（Lv.X）"
- 师徒等级进度条
