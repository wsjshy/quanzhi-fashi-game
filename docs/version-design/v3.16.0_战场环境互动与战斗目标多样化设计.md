# v3.16.0 战场环境互动与战斗目标多样化设计

> **版本**：v3.16.0
> **日期**：2026-09-16
> **定位**：提升战斗策略深度和玩法多样性，让每场战斗都有独特的体验

---

## 一、设计目标

1. **战场环境互动**：不同地点有不同的环境效果，影响元素伤害、状态概率、战斗节奏
2. **战斗目标多样化**：不只是击杀敌人，还有保护、限时、生存、逃脱、破坏等多种胜利条件
3. **数据驱动**：所有效果通过数据配置，不硬编码，便于扩展和平衡
4. **向后兼容**：不破坏现有战斗逻辑，新系统作为扩展层

---

## 二、战场环境互动系统

### 2.1 数据结构

在地点数据（`src/data/locations.js`）中添加`battleEnvironment`字段：

```javascript
{
  id: "xuefeng_mountain",
  name: "雪峰山",
  battleEnvironment: {
    id: "snow_mountain",
    name: "雪山环境",
    icon: "❄️",
    effects: [
      { type: "element_boost", element: "ice", value: 1.3, desc: "冰系伤害+30%" },
      { type: "element_weaken", element: "fire", value: 0.8, desc: "火系伤害-20%" },
      { type: "status_chance", status: "frozen", value: 1.5, desc: "冰冻概率+50%" },
      { type: "weather", weather: "snow", desc: "降雪天气" }
    ]
  }
}
```

**效果类型定义**：

| 效果类型 | 字段 | 说明 |
|---------|------|------|
| element_boost | element, value | 指定元素伤害提升（value为倍率，如1.3=+30%） |
| element_weaken | element, value | 指定元素伤害降低（value为倍率，如0.8=-20%） |
| status_chance | status, value | 指定状态施加概率提升（value为倍率，如1.5=+50%） |
| status_resist | status, value | 指定状态抗性提升（value为倍率，如0.5=抗性+50%） |
| hp_regen | value | 每回合HP恢复（value为数值或百分比） |
| mp_regen | value | 每回合MP恢复 |
| damage_per_turn | value, target | 每回合受到伤害（target: player/enemy/both） |
| speed_mod | value | 速度修正（value为倍率） |
| crit_chance | value | 暴击概率修正 |

### 2.3 引擎实现

**修改文件**：
1. `src/engine/battle-start.js`：战斗开始时加载地点环境配置
2. `src/engine/battle-damage.js`：计算伤害时应用环境加成/减益
3. `src/engine/battle-status.js`：状态施加时应用环境概率修正
4. `src/engine/battle.js`：存储当前环境配置，提供查询接口

**实现逻辑**：

```javascript
// battle-start.js: 加载环境
startBattle(enemy, locationId) {
    // ... 现有逻辑 ...
    
    // 加载战场环境
    this.currentEnvironment = this.loadEnvironment(locationId);
}

loadEnvironment(locationId) {
    const location = DataManager.getLocation(locationId);
    return location?.battleEnvironment || null;
}

// battle-damage.js: 应用环境伤害修正
calculateDamage(attacker, target, skill, baseDamage) {
    let damage = baseDamage;
    
    // 环境元素加成/减益
    if (this.currentEnvironment) {
        for (const effect of this.currentEnvironment.effects) {
            if (effect.type === 'element_boost' && skill.element === effect.element) {
                damage *= effect.value;
            }
            if (effect.type === 'element_weaken' && skill.element === effect.element) {
                damage *= effect.value;
            }
        }
    }
    
    return damage;
}

// battle-status.js: 应用环境状态概率修正
applyStatus(target, statusType, chance) {
    let finalChance = chance;
    
    if (this.currentEnvironment) {
        for (const effect of this.currentEnvironment.effects) {
            if (effect.type === 'status_chance' && effect.status === statusType) {
                finalChance *= effect.value;
            }
        }
    }
    
    // ... 现有状态施加逻辑 ...
}
```

## 三、战斗目标多样化系统

### 3.1 数据结构

在战斗配置（敌人数据/大事件战斗阶段）中添加`battleObjective`字段：

```javascript
{
  id: "battle_protect_heyu",
  name: "保护何雨",
  battleObjective: {
    type: "protect",           // 目标类型
    target: "npc_heyu",         // 保护目标ID
    targetName: "何雨",         // 目标显示名称
    targetHp: 100,              // 目标HP
    duration: 5,                // 需要保护的回合数（可选）
    description: "保护何雨存活5回合"
  },
  enemies: [...]
}
```

### 3.2 目标类型定义

| 类型 | 胜利条件 | 失败条件 | 必需字段 | 可选字段 |
|------|---------|---------|---------|---------|
| annihilate | 击败所有敌人 | 玩家HP=0 | - | - |
| protect | 保护目标存活，击败敌人 | 目标HP=0 | target, targetHp | duration, targetName |
| survive | 存活N回合 | 玩家HP=0 | duration | - |
| timed | N回合内击败所有敌人 | 超过回合数/玩家HP=0 | duration | - |
| escape | 逃跑值达到100 | 玩家HP=0 | - | escapeRate |
| destroy | 破坏特定目标 | 玩家HP=0 | destroyTarget, destroyTargetHp | - |
| duel | 1v1击败敌人 | 玩家HP=0 | - | noItems（禁止道具） |
| capture | 敌人HP<20%时使用捕获道具 | 敌人HP=0/玩家HP=0 | - | captureItemId |

### 3.3 博城篇应用

| 战斗 | 目标类型 | 配置 |
|------|---------|------|
| 博城灾难·保护同学 | protect | 保护薛木生老师存活8回合 |
| 博城灾难·坚守前线 | survive | 存活6回合直到援军到达 |
| 地圣泉·阻止阵法 | timed | 5回合内击败黑教廷执事 |
| 雪峰山·幽狼兽（初期） | escape | 逃跑值达到100可逃跑 |
| 穆氏决斗 | duel | 1v1，禁止道具 |
| 年度考核·实战 | timed | 3回合内击败训练傀儡 |
| 猎魔悬赏·捕获 | capture | HP<20%使用捕获道具 |

### 3.4 引擎实现

**修改文件**：
1. `src/engine/battle-start.js`：加载战斗目标配置，初始化目标状态
2. `src/engine/battle-check-end.js`：扩展胜负判定逻辑
3. `src/engine/battle.js`：存储目标状态，提供进度查询
4. `src/engine/battle-turn.js`：每回合更新目标进度（生存回合数、逃跑值等）

**胜负判定逻辑**：

```javascript
// battle-check-end.js
checkBattleEnd() {
    const objective = this.battleObjective;
    
    // 通用失败条件：玩家HP=0
    if (this.player.hp <= 0) {
        return this.endBattle(false, "玩家战败");
    }
    
    // 根据目标类型判定
    switch (objective?.type) {
        case 'annihilate':
        default:
            // 所有敌人HP=0则胜利
            if (this.enemies.every(e => e.hp <= 0)) {
                return this.endBattle(true, "敌人全部击败");
            }
            break;
            
        case 'protect':
            // 保护目标HP=0则失败
            if (objective.targetHp <= 0) {
                return this.endBattle(false, `${objective.targetName}倒下了`);
            }
            // 所有敌人击败则胜利
            if (this.enemies.every(e => e.hp <= 0)) {
                return this.endBattle(true, `成功保护${objective.targetName}`);
            }
            break;
            
        case 'survive':
            // 存活达到指定回合数则胜利
            if (this.turnCount >= objective.duration) {
                return this.endBattle(true, "成功坚守到援军到达");
            }
            // 敌人无限刷新（如果配置了）
            this.maybeSpawnEnemies();
            break;
            
        case 'timed':
            // 超过回合数则失败
            if (this.turnCount > objective.duration) {
                return this.endBattle(false, "时间耗尽");
            }
            // 所有敌人击败则胜利
            if (this.enemies.every(e => e.hp <= 0)) {
                return this.endBattle(true, "限时内击败敌人");
            }
            break;
            
        case 'escape':
            // 逃跑值达到100则成功逃跑
            if (this.escapeValue >= 100) {
                return this.endBattle(true, "成功逃脱", { escaped: true });
            }
            break;
            
        case 'duel':
            // 1v1，敌人HP=0则胜利
            if (this.enemy.hp <= 0) {
                return this.endBattle(true, "决斗胜利");
            }
            break;
    }
    
    return null; // 战斗继续
}
```

## 四、测试要点

### 4.1 功能测试用例

1. **环境加载测试**：在不同地点进入战斗，验证环境配置正确加载
2. **环境伤害修正测试**：在雪山环境使用冰系/火系技能，验证伤害加成/减益正确
3. **环境状态概率测试**：在雪山环境使用冰冻技能，验证冰冻概率提升
4. **无环境测试**：在学校操场战斗，验证无环境效果（伤害正常）
5. **保护战测试**：保护目标存活时胜利，目标HP=0时失败
6. **生存战测试**：存活达到指定回合数时胜利，玩家HP=0时失败
7. **限时战测试**：限时内击败敌人胜利，超过回合数失败
8. **逃跑战测试**：逃跑值达到100时成功逃跑
9. **目标UI显示测试**：验证不同目标类型的UI正确显示
10. **向后兼容测试**：没有配置battleObjective的战斗按默认歼灭战逻辑

### 4.2 体验测试维度

1. **策略深度**：环境效果是否真的影响玩家的技能选择和战术
2. **目标多样性**：不同目标类型是否带来不同的战斗体验
3. **UI清晰度**：环境效果和战斗目标是否清晰可见，不遮挡战斗
4. **平衡性**：环境加成是否过于强势或弱势，是否需要调整数值
5. **代入感**：在不同地点战斗是否有不同的氛围和感觉

### 4.3 Debug支持

- Debug面板添加"设置战场环境"功能，可快速切换环境测试
- Debug面板添加"设置战斗目标"功能，可测试不同目标类型
- 控制台输出当前环境效果和战斗目标进度

### 4.4 边界情况

1. 地点没有配置battleEnvironment时，使用默认无效果
2. 战斗没有配置battleObjective时，使用默认歼灭战
3. 环境效果叠加（多个效果同时影响同一元素）
4. 保护目标同时也是敌人（目标叛变情况）
5. 生存战中敌人全部击败但回合数未到（提前胜利）
6. 逃跑战中玩家同时击败了所有敌人（双重胜利条件）
