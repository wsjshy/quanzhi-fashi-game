# v0.57.0 玩家个人任务线（火系初阶）

> 版本：v0.57.0
> 日期：2026-08-15
> 类型：内容开发
> 前置：v0.25.0个人任务触发框架（已存在，未使用）

---

## 一、设计目标

让玩家的元素选择有意义，给火系玩家专属的成长任务线。任务基于玩家系别自动触发，不围绕莫凡，体现"玩家有自己的人生"。

---

## 二、任务线设计

### 任务1：火焰的控制（quest_fire_control）

- **触发条件**：火系玩家，等级≥5
- **发布者**：唐月
- **类型**：个人任务
- **目标**：修炼5次
- **奖励**：经验100，唐月好感+5
- **剧情**：唐月注意到你在修炼火系时控制力不足，建议你多加练习。"火焰的力量很强，但如果控制不好，会伤到身边的人。"

### 任务2：火系的较量（quest_fire_duel）

- **触发条件**：火系玩家，等级≥8，完成任务1
- **发布者**：周敏
- **类型**：个人任务
- **目标**：与周敏对话1次
- **奖励**：经验150，金币100，学校声望+5
- **剧情**：周敏注意到你的火系进步，主动找你切磋。"听说你火系练得不错，要不要比比看？"

### 任务3：火焰的感悟（quest_fire_insight）

- **触发条件**：火系玩家，等级≥12，完成任务2
- **发布者**：唐月
- **类型**：个人任务
- **目标**：探索图书馆3次 + 修炼10次
- **奖励**：经验300，技能点+1，唐月好感+10
- **剧情**：唐月建议你在图书馆查阅火系典籍，结合修炼感悟火焰的真谛。

---

## 三、技术实现

- 复用现有个人任务触发框架（checkQuestTriggers）
- 任务数据添加到quests.js
- trigger字段：element: "fire", minLevel, prerequisites
- objectives支持cultivate/explore/talk类型

---

## 四、验收标准

1. 火系玩家等级5时自动触发"火焰的控制"
2. 完成任务1后等级8触发"火系的较量"
3. 完成任务2后等级12触发"火焰的感悟"
4. 非火系玩家不触发这些任务
5. 任务奖励正常发放
6. node --check语法通过
