# v0.59.0 玩家个人任务线（风系初阶）

> 版本：v0.59.0
> 日期：2026-08-15
> 类型：内容开发
> 前置：v0.57.0火系 + v0.58.0冰系（框架已验证）

---

## 一、设计目标

扩展风系玩家专属任务线，围绕风系"速度、灵活、感知"的特点展开，深化与张小侯（风系同学）的关系。

---

## 二、任务线设计

### 任务1：风的速度（quest_wind_speed）

- **触发条件**：风系玩家，等级≥5
- **发布者**：张小侯
- **类型**：个人任务
- **目标**：修炼5次（风系需要速度训练）
- **奖励**：经验100，金币50
- **剧情**：张小侯注意到你在修炼风系时节奏太慢，建议你多加练习。"风系的核心是速度，星子运转要快，快到别人跟不上。"

### 任务2：风系的竞速（quest_wind_race）

- **触发条件**：风系玩家，等级≥8，完成任务1
- **发布者**：张小侯
- **类型**：个人任务
- **目标**：与张小侯对话1次
- **奖励**：经验150，金币100
- **剧情**：张小侯注意到你的风系进步，主动找你竞速。"你的风系...有点意思。要不要比比看，谁的风更快？"

### 任务3：风的感悟（quest_wind_insight）

- **触发条件**：风系玩家，等级≥12，完成任务2
- **发布者**：张小侯
- **类型**：个人任务
- **目标**：图书馆3次 + 修炼10次
- **奖励**：经验300，金币200，技能点1
- **剧情**：张小侯建议你在图书馆查阅风系典籍，结合修炼感悟风的真谛。"风的极致不是快，是无处不在的感知。"

---

## 三、技术实现

- 复用v0.57.0个人任务框架
- 任务数据添加到quests.js
- trigger字段：element: "wind", minLevel, prerequisites
- 风系任务侧重修炼（速度训练），与冰系的冥修形成对比

---

## 四、验收标准

1. 风系玩家等级5时自动触发"风的速度"
2. 完成任务1后等级8触发"风系的竞速"
3. 完成任务2后等级12触发"风的感悟"
4. 非风系玩家不触发
5. 任务奖励正常发放
6. node --check语法通过
