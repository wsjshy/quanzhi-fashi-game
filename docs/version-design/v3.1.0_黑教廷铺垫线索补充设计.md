# v3.1.0 黑教廷铺垫线索补充设计

> 版本：v3.1.0 | 状态：实施中 | 最后更新：2026-08-22

## 一、背景

已有黑教廷铺垫：
- `event_black_church_encounter`：可疑黑衣人（第20天+，Lv3+）
- `event_black_church_ritual`：神秘仪式（第30天+，Lv5+）
- `event_spring_anomaly`：地圣泉异常（地圣泉地点）

缺失的关键铺垫：
1. **暴躁之泉线索**：原著中黑教廷炼制暴躁之泉洒在云雾中，大雨时催化魔狼攻城。玩家应在灾难前发现药剂痕迹
2. **宇昂身份暗示**：宇昂是黑教廷卧底，玩家应有机会发现他与黑衣人接触
3. **妖魔聚集预警**：安界外魔狼异常聚集，军方已有察觉但未重视

## 二、新增事件设计

### 事件1：暴躁之泉痕迹（event_violent_spring_trace）
- **触发**：雪峰山/野外探索，第25天+，Lv4+
- **概率**：0.12，once
- **描述**：你在岩壁上发现了一片暗红色的结晶，散发着令人不安的气息。附近的妖魔表现得异常狂躁，甚至同类相残。
- **选择**：
  1. 采集结晶样本 → exp+25，获得线索"violent_spring_sample"，hp-10（结晶有腐蚀性）
  2. 观察妖魔行为 → exp+15，获得情报"妖魔异常狂躁"
  3. 远离此处 → 无效果

### 事件2：宇昂的秘密（event_yu_ang_secret）
- **触发**：穆氏庄园/决斗场附近，第35天+，Lv5+
- **概率**：0.10，once
- **描述**：你深夜路过穆氏庄园侧门，看到宇昂与一个黑衣人低声交谈。黑衣人递给他一个小瓶，宇昂神色凝重地点头。两人似乎没有注意到你。
- **选择**：
  1. 继续偷听 → exp+30，获得情报"yu_ang_black_church"，有概率被发现（hp-20）
  2. 悄悄离开 → exp+10，获得线索"yu_ang_suspicious"
  3. 直接 confront → 触发与宇昂的战斗（难度高）

### 事件3：安界警戒（event_boundary_warning）
- **触发**：学校/城市任意地点，第40天+，Lv5+
- **概率**：0.15，once
- **描述**：你听到军方的紧急通告——安界外发现大量魔狼聚集，数量远超往年。斩空总教官已加强巡逻，但官方仍称"一切正常"。唐月老师神色凝重，似乎知道更多。
- **选择**：
  1. 向唐月老师询问 → exp+20，获得情报"boundary_warning"，唐月关系+5
  2. 去安界查看 → exp+15，hp-15，获得线索"wolf_gathering"
  3. 不放在心上 → 无效果

## 三、与博城灾难的联动

- 收集到3条以上黑教廷线索的玩家，在博城灾难开始时会有额外对话选项（"我早有预感"）
- 发现宇昂身份的玩家，在灾难中可选择揭露宇昂（影响剧情分支）
