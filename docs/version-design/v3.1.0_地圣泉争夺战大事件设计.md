# v3.1.0 地圣泉争夺战大事件设计

## 一、设计目标

还原原著博城篇地圣泉争夺战剧情，让玩家通过决斗或任务获得地圣泉的修炼机会，影响博城灾难的结局。

## 二、原著关键引用

- 第62章：地圣泉是博城的修炼圣地，相当于加强版的星尘魔器，可以让修炼速度飞驰
- 第73章：每届只为一名学生开启，魔法家族、世家子弟也要进入竞争争夺
- 独眼魔狼偷食了地圣泉的能量，差点进阶到更高级别
- 穆卓云想让宇昂得到地圣泉的机会
- 地圣泉是一辈子只有一次的绝佳修炼机会

## 三、大事件设计

### 事件ID
`big_event_earth_spring_contest`

### 触发条件
- 玩家等级≥8
- 完成年度考核大事件
- 未获得地圣泉修炼机会

### 阶段设计

#### 阶段1：地圣泉消息
- 朱校长宣布地圣泉争夺战开始
- 每届只为一名学生开启
- 竞争者包括：宇昂（穆氏养子）、其他世家子弟
- 玩家可以选择参加或放弃

#### 阶段2：预选赛
- 玩家需要通过预选赛（击败3名竞争者）
- 宇昂直接晋级（穆氏势力）
- 其他竞争者包括：穆白、赵满延等

#### 阶段3：决赛
- 玩家vs宇昂
- 宇昂是冰系法师，Lv10，使用冰蔓·凝结
- 战斗难度较高，需要策略
- 胜利：获得地圣泉修炼机会
- 失败：宇昂获得地圣泉修炼机会

#### 阶段4：地圣泉修炼（胜利分支）
- 玩家进入地圣泉修炼7天
- 获得大量经验（500）和技能点（3）
- 随机觉醒一个新元素（概率30%）
- 修炼结束后，地圣泉能量被黑教廷觊觎

#### 阶段5：黑教廷觊觎（胜利分支）
- 修炼结束后，黑教廷成员出现，试图抢夺地圣泉
- 玩家可以选择：
  - 战斗：击败黑教廷成员，保护地圣泉
  - 撤退：地圣泉被黑教廷抢走，影响博城灾难结局
- 战斗胜利：获得黑教廷线索，博城灾难中妖魔攻击-10%
- 战斗失败/撤退：地圣泉被抢，博城灾难中妖魔攻击+10%

#### 阶段6：后续影响
- 胜利分支：玩家获得地圣泉修炼，实力提升，博城灾难中获得优势
- 失败分支：宇昂获得地圣泉修炼，实力提升，后续剧情中宇昂更强
- 地圣泉被抢分支：博城灾难难度提升，但可获得黑教廷线索

## 四、新增数据

### 敌人
- `yu_ang_duel`：宇昂（冰系法师，Lv10，warrior级，weakness:fire）
- `black_church_member`：黑教廷成员（暗系法师，Lv9，warrior级，weakness:light）

### 物品
- `earth_spring_pass`：地圣泉修炼凭证（任务道具，maxStack:1）

### 奖励
- 胜利：经验500，技能点3，地圣泉修炼凭证，随机觉醒新元素（30%概率）
- 失败：经验100，安慰奖

## 五、与现有系统联动

- 年度考核大事件：完成年度考核后触发
- 博城灾难大事件：地圣泉是否被抢影响博城灾难难度
- 阴谋调查系统：击败黑教廷成员获得黑教廷线索
- 技能进阶系统：地圣泉修炼可获得技能点，用于技能进阶
