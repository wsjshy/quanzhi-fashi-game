# v3.15.0 觉醒系统重构设计文档

> 版本：v3.15.0
> 日期：2026-09-10
> 核心目标：让觉醒有仪式感，雷系稀缺但可追求，落地设定贴合度分级方法论

---

## 一、设计背景

### 1.1 当前问题

- 觉醒只有基础实现，缺乏仪式感
- 觉醒概率完全按照小说设定（雷系0.1%），玩家几乎不可能觉醒雷系
- 缺乏NPC互动和玩家选择
- 没有重新觉醒机制

### 1.2 设计理念

**一切为了游戏性，但不违背核心设定**

- 铁律设定：元素七系/星尘星子星轨/觉醒仪式（不可违背）
- 可调整设定：觉醒概率（0.1%→3%基础，为了游戏体验）
- 保持稀缺感：雷系仍然稀有，只是不是"完全不可能"

---

## 二、觉醒概率设计

### 2.1 基础觉醒概率

| 系别 | 基础概率 | 稀有度 | 小说依据 |
|------|---------|--------|---------|
| 火系 | 15% | 普通 | 常见系 |
| 冰系 | 15% | 普通 | 常见系 |
| 土系 | 15% | 普通 | 常见系 |
| 风系 | 15% | 普通 | 常见系 |
| 水系 | 15% | 普通 | 常见系 |
| 光系 | 10% | 较少 | 较少见 |
| 雷系 | 3% | 稀有 | 小说千分之一，调整为3%基础 |

**调整理由**：
- 小说设定雷系千分之一（0.1%），玩家平均需要1000次尝试，完全不现实
- 调整为3%基础概率，玩家平均需要33次尝试，仍然稀缺但可追求
- 雷系是小说核心系别（莫凡就是雷系），玩家应该有机会体验
- 可以通过条件提升概率，给玩家明确目标

### 2.2 雷系概率提升条件

| 条件 | 提升 | 获取方式 |
|------|------|---------|
| 唐月指导 | +5% | 完成任务"雷系感悟"（唐月指导） |
| 雷系觉醒石 | +10% | 稀有道具（特殊任务/商店限量/事件奖励） |
| 雷暴夜觉醒 | +7% | 特殊事件"雷暴夜"（随机触发，雷暴天觉醒） |
| 莫凡指导 | +3% | 莫凡好感≥50（莫凡也是雷系，会指导你） |

**最高概率**：3% + 5% + 10% + 7% + 3% = **28%**

**设计原则**：
- 即使满足所有条件，也不是100%，保持稀缺感和惊喜感
- 每个条件都有明确的获取方式，给玩家目标
- 条件之间可以叠加，鼓励玩家多探索

### 2.3 其他系别概率

其他系别（火/冰/土/风/水/光）没有概率提升条件，保持基础概率。

## 三、觉醒流程设计

### 3.1 觉醒仪式流程

```
阶段1：准备
- 唐月讲解觉醒仪式
- 玩家选择是否准备好

阶段2：觉醒
- 玩家将手放在觉醒石上
- 动画：觉醒石发光，星子浮现
- 根据概率随机觉醒系别

阶段3：结果
- 显示觉醒结果（系别/稀有度）
- NPC反应（根据系别不同，反应不同）
- 玩家选择（接受/重新觉醒/询问/交流）

阶段4：后续
- 如果接受，开始修炼
- 如果重新觉醒，消耗精神力，最多3次
```

### 3.2 NPC反应设计

| 系别 | 穆白反应 | 莫凡反应 | 唐月反应 | 其他同学 |
|------|---------|---------|---------|---------|
| 火系 | "哼，火系而已" | "不错，爆发力强" | "火系常见，修炼好一样强" | 普通反应 |
| 冰系 | "冰系？还可以" | "冰系控制强" | "冰系适合控制" | 普通反应 |
| 雷系 | "什么？雷系？！"（震惊→嫉妒） | "哇！雷系！"（兴奋→会心一笑） | "千分之一……"（复杂→认真） | 议论纷纷 |
| 光系 | "光系？少见" | "光系辅助强" | "光系稀少，珍惜" | 惊讶 |
| 其他 | 普通反应 | 普通反应 | 普通反应 | 普通反应 |

### 3.3 玩家选择设计

| 选择 | 效果 |
|------|------|
| 接受系别，开始修炼 | 结束觉醒，进入游戏 |
| 重新觉醒 | 消耗精神力10，最多3次，第3次后必须接受 |
| 询问唐月修炼要点 | 唐月指导，该系熟练度+5 |
| 找莫凡交流（雷系专属） | 莫凡好感+10，雷系熟练度+5 |

## 四、重新觉醒机制

### 4.1 规则

- 最多3次重新觉醒
- 每次消耗精神力10
- 重新觉醒后，之前的系别消失
- 第3次觉醒后必须接受（不能再重新觉醒）
- 精神力不足时不能重新觉醒

### 4.2 设计理由

- 给玩家追求稀有系别的机会
- 限制次数，避免无限刷
- 消耗精神力，有成本
- 第3次后必须接受，避免玩家一直刷

### 5.1 分级定义

| 级别 | 定义 | 示例 | 能否调整 |

| 可扩展设定 | 小说无详细描述，可自由扩展 | 玩家专属剧情/NPC互动/小游戏/地图细节 | ✅ 自由扩展 |

## 七、引擎模块设计

### 7.1 觉醒系统引擎（src/engine/awakening.js）

```javascript
export const AwakeningSystem = {
  // 计算最终觉醒概率
  calculateProbabilities(player) {
    const probs = { ...DataAwakening.baseProbabilities };
    
    // 应用概率提升条件
    for (const [element, boosts] of Object.entries(DataAwakening.probabilityBoosts)) {
      for (const boost of boosts) {
        if (this.checkCondition(boost.condition, player)) {
          probs[element] += boost.boost;
        }
      }
    }
    
    return probs;
  },

  // 检查条件
  checkCondition(condition, player) {
    // 解析条件格式："type:value"
    const [type, value] = condition.split(':');
    
    switch (type) {
      case 'questComplete':
        return player.completedQuests?.includes(value);
      case 'hasItem':
        return player.inventory?.some(item => item.id === value);
      case 'event':
        return player.activeEvents?.includes(value);
      case 'npcOpinion':
        const [npcId, op] = value.split('>=');
        return player.npcRelations?.[npcId]?.opinion >= parseInt(op);
      default:
        return false;
    }
  },

  // 执行觉醒
  performAwakening(player) {
    const probs = this.calculateProbabilities(player);
    const total = Object.values(probs).reduce((a, b) => a + b, 0);
    let random = Math.random() * total;
    
    for (const [element, prob] of Object.entries(probs)) {
      random -= prob;
      if (random <= 0) {
        return element;
      }
    }
    
    return 'fire'; // 默认
  },

  // 重新觉醒
  reAwaken(player) {
    const config = DataAwakening.reAwakening;
    
    if (player.awakening.reAwakeningTimes >= config.maxTimes) {
      return { success: false, message: `最多只能重新觉醒${config.maxTimes}次` };
    }
    
    if (player.mentalPower < config.mentalCost) {
      return { success: false, message: `精神力不足，需要${config.mentalCost}点` };
    }
    
    player.mentalPower -= config.mentalCost;
    player.awakening.reAwakeningTimes++;
    
    const newElement = this.performAwakening(player);
    player.awakening.element = newElement;
    player.awakening.awakeningHistory.push(newElement);
    
    return { success: true, element: newElement };
  },

  // 接受觉醒
  acceptAwakening(player, element) {
    player.awakening.awakened = true;
    player.awakening.element = element;
    player.elements = [element];
    // 初始化该系技能等
  }
}
```
