## 一、为什么做这个

### 1.1 事件链高潮
博城灾难是原著中的关键事件，也是玩家影响力的终极体现。前两阶段玩家的所有选择（发现异常→预警准备）将在第三阶段汇聚，决定灾难的结局。

### 1.2 真正的选择权
玩家不是旁观者，而是灾难中的关键角色。玩家的准备程度、选择的行动路径，将直接影响：
- 灾难的伤亡程度
- 玩家的角色定位（英雄/幸存者/揭秘者）
- 后续剧情的走向

### 1.3 为后续剧情铺垫
博城灾难后，玩家将离开博城，进入更广阔的世界。第三阶段的结局将影响玩家的声望、人际关系和后续机遇。

## 二、事件设计

### 2.1 事件：灾难降临

**触发条件**：
- requireFlag: bocheng_phase2_done（第二阶段完成）
- notFlag: bocheng_phase3_done
- minLevel: 17
- weight: 40
- npcId: tang_yue

**事件描述**：
博城的天空突然变暗。地圣泉方向爆发出强烈的能量波动，空间裂缝撕开，无数妖魔从裂缝中涌出。尖叫声、爆炸声、魔法光芒交织在一起。唐月老师冲到你面前，衣服上沾着灰尘："灾难来了！黑教廷引爆了地圣泉，空间裂缝正在扩大！你打算怎么做？"

**选择分支（3个）**：

#### 选择1：加入前线防御
- effects: { setFlag: ["bd_hero_frontline", "bocheng_phase3_done"], reputation: 20 }
- resultText: 你握紧拳头："我去前线！"唐月点头："小心，跟紧老师的队伍。"你冲向战场，火焰在你手中绽放。你挡住了一只进阶妖魔的攻击，为同学争取了撤退时间。声望+20，你成为前线的英雄

#### 选择2：组织同学疏散
- effects: { setFlag: ["bd_hero_evacuation", "bocheng_phase3_done"], reputation: 15, npcOpinion: { tang_yue: 10 } }
- resultText: 你大喊："所有人跟我走，不要慌！"你组织起混乱的同学，有序地向安全区撤退。途中你用魔法挡住了几只低级妖魔的袭击。唐月感激地看着你："多亏了你，很多孩子才能活下来。"声望+15，唐月好感+10，你是疏散中的领导者

#### 选择3：寻找灾难根源
- effects: { setFlag: ["bd_hero_investigate", "bocheng_phase3_done"], exp: 200 }
- resultText: 你注意到空间裂缝的能量来源——地圣泉方向有一个黑袍人在施法。你决定绕到后方，寻找灾难的根源。你悄悄接近，发现了黑教廷的祭坛。虽然无法阻止，但你记住了关键信息。经验+200，你掌握了黑教廷的关键情报

## 三、结局差异化（基于前两阶段选择）

### 3.1 结局文本逻辑
事件的resultText为基础文本，实际结局根据玩家的准备flag有差异化：

**如果玩家有bd_full_prep（全面备战）**：
- 前线防御：学校防御充分，你加入后前线稳住，伤亡大幅减少
- 组织疏散：疏散路线提前规划，几乎无人伤亡
- 寻找根源：学校提供支援，你成功获取更多情报

**如果玩家有bd_self_prep（自我提升）**：
- 前线防御：你实力强劲，独自挡住一只进阶妖魔
- 组织疏散：你用强大实力开路，疏散顺利
- 寻找根源：你有能力自保，深入调查获得更多线索

**如果玩家有bd_secret_investigate（秘密调查）**：
- 前线防御：你提前知道黑教廷战术，有效反击
- 组织疏散：你知道安全路线，疏散高效
- 寻找根源：你之前的调查派上用场，直接定位祭坛

**如果玩家有bd_evacuation（疏散经验）**：
- 组织疏散：你有经验，疏散零伤亡

**如果玩家有bd_investigate_source（调查经验）**：
- 寻找根源：你之前发现的空间波动线索派上用场

**如果玩家有bd_self_safety（无准备）**：
- 所有选择：灾难更严重，你勉强存活，结局更沉重

### 3.2 技术实现说明
由于事件resultText为固定文本，结局差异化通过以下方式实现：
1. 事件选择设置基础结局flag
2. 后续任务/剧情根据玩家的组合flag给出差异化内容
3. 当前版本先实现基础事件和结局flag，后续版本可扩展结局文本差异化

## 五、长期影响（后续剧情铺垫）

### 5.1 三种结局定位
1. **前线英雄**（bd_hero_frontline）：战斗型玩家，后续有更多战斗机遇
2. **疏散英雄**（bd_hero_evacuation）：领导型玩家，后续有更多社交/领导力机遇
3. **揭秘英雄**（bd_hero_investigate）：调查型玩家，后续有黑教廷剧情线

### 5.2 准备程度的影响
- 全面备战（bd_full_prep）：博城伤亡少，玩家声望更高
- 自我提升（bd_self_prep）：玩家实力更强，后续战斗更轻松
- 秘密调查（bd_secret_investigate）：掌握黑教廷情报，后续有特殊剧情
- 无准备（bd_self_safety）：博城伤亡重，玩家有内疚感，后续有救赎剧情

### 5.3 后续剧情方向
- 博城灾难后，玩家将前往古都/其他城市
- 黑教廷将成为长期反派
- 玩家在灾难中的表现将影响NPC对玩家的看法
