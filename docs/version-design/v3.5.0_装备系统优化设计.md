# v3.5.0 装备系统优化设计文档

> 版本：v3.5.0 | 状态：设计中 | 最后更新：2026-09-07

## 一、版本目标

解决"低级装备不舍得强化，想留给高级装备"的心理痛点，增加装备系统深度和追求感：
1. **强化继承可视化**：明确显示强化等级永久保留，更换装备不丢失
2. **装备词缀系统**：每件装备有随机词缀，增加装备多样性和追求感
3. **装备评分系统**：直观显示装备强弱，帮助玩家做替换决策

## 二、核心功能设计

### 功能1：强化继承可视化（P0）

**当前问题**：强化等级实际已绑定槽位（换装备不丢失），但玩家不知道，心理上觉得在低级装备上强化是浪费。

**优化方案**：
- 装备界面强化区域明确显示"🔒 强化等级永久保留（更换装备不丢失）"
- 替换装备时显示提示："新装备已继承+X强化等级"
- 强化按钮旁显示当前槽位强化等级，而非装备强化等级

**实现方式**：
- 修改ui-inventory.js的装备界面，添加强化保留提示
- 修改装备替换逻辑，替换时显示继承提示

### 功能2：装备词缀系统（P1）

**设计理念**：参考暗黑破坏神/流放之路的词缀系统，每件装备除基础属性外，还有1-3条随机词缀，让同一件装备也有强弱之分。

**词缀类型**：
- **前缀**（影响主属性）：
  - 锋利的：攻击+5~15
  - 坚固的：防御+5~15
  - 智慧的：魔法+5~15
  - 敏捷的：速度+2~5
- **后缀**（影响特殊属性）：
  - 之暴击：暴击率+3%~8%
  - 之穿透：防御穿透+5%~10%
  - 之生命：最大HP+20~50
  - 之魔力：最大MP+20~50
  - 之吸血：吸血+2%~5%

**词缀生成规则**：
- 普通装备（白色）：0词缀
- 优秀装备（绿色）：1词缀
- 稀有装备（蓝色）：2词缀
- 史诗装备（紫色）：3词缀
- 词缀数值在范围内随机生成
- 同一件装备不会有重复词缀类型

**词缀显示**：
- 装备名称按品质变色（白/绿/蓝/紫）
- 装备详情中词缀用对应颜色显示
- 词缀属性计入角色总属性

### 功能3：装备评分系统（P1）

**设计理念**：用一个直观的数字表示装备强弱，帮助玩家快速判断是否替换。

**评分公式**：
```
装备评分 = 基础属性评分 + 词缀属性评分 + 强化等级评分
```
- 基础属性评分：攻击×2 + 防御×1.5 + 魔法×1.5 + 速度×3
- 词缀属性评分：每条词缀属性按对应权重计算
- 强化等级评分：每级+5分

**显示方式**：
- 装备详情中显示"⚔️ 装备评分：XXX"
- 背包中装备角标显示评分
- 替换装备时显示"新装备评分 +XX（提升）/ -XX（下降）"

## 五、风险与注意事项

1. **词缀平衡性**：词缀数值需要测试，避免过强或过弱
2. **存档兼容性**：旧存档的装备没有词缀，需要默认处理为0词缀
3. **UI空间**：词缀显示可能增加装备详情长度，需要合理布局
4. **数据唯一性**：新增词缀ID不能与现有物品ID冲突
