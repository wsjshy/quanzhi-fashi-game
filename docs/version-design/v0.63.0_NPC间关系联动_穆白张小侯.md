# v0.63.0 NPC间关系联动系统（穆白×张小侯）

> 版本：v0.63.0
> 日期：2026-08-15
> 类型：系统深化
> 前置：v0.61-v0.62关系驱动任务系统（框架已验证）

---

## 一、为什么做这个

### 问题
- 当前关系系统是"玩家↔NPC"的单向关系，NPC之间没有互动
- 玩家的选择只影响自己和单个NPC，不影响NPC之间的关系网络
- 世界不够"活"，NPC像是独立的个体，没有彼此的联系

### 解决方案
**NPC间关系联动**：当玩家与两个NPC关系都达到阈值时，触发他们之间的互动事件。玩家的选择：
- 影响两个NPC对玩家的关系
- 影响两个NPC之间的关系（新增NPC间关系值）
- 可能触发后续事件链

### 为什么有深度
1. **玩家是关系网络的节点**：不只是"和A好""和B好"，而是"A和B因为你而改变"
2. **选择有代价**：支持A可能得罪B，调解可能双方都不讨好
3. **世界有反应**：NPC间关系变化后，他们的对话、事件触发概率都会变
4. **可重玩性**：不同选择导致不同的关系网络格局

---

## 二、系统架构

### 触发机制
- 玩家与NPC_A关系≥阈值，且与NPC_B关系≥阈值
- 修炼/探索/对话时概率触发联动事件
- 事件有选择分支，玩家选择后：
  - 改变NPC_A对玩家的关系
  - 改变NPC_B对玩家的关系
  - 设置flag标记NPC间关系状态（如mu_bai_zhang_xiaohou_friends / rivals / neutral）

### NPC间关系状态
- `friends`：朋友，后续事件中他们会互相支持
- `rivals`：对手，后续事件中他们会互相竞争
- `neutral`：中立，无特殊互动
- 状态通过flag存储，影响后续事件触发条件

## 三、穆白×张小侯冲突事件设计

### 背景
- 穆白：穆氏家族子弟，高傲，实力强
- 张小侯：普通家庭，朴实，努力型
- 两人因背景差异和性格不同，容易产生摩擦

### 事件1：走廊的冲突（双方好感≥30触发）

**触发方式**：修炼/对话时概率触发

**事件内容**：
> 你在走廊看到穆白和张小侯对峙。穆白冷笑："乡下来的就是没规矩，训练馆的器材是你随便碰的？"张小侯脸涨红："我明明排队了！是你插队！"两人看到你，都看向你。

**选择分支**：
1. **帮张小侯说话** → 张小侯好感+10，穆白好感-15，设置flag `mx_zxh_support_xiaohou`，穆白和张小侯关系变为rivals
2. **帮穆白说话** → 穆白好感+10，张小侯好感-15，设置flag `mx_zxh_support_mubai`，穆白和张小侯关系变为rivals
3. **中立调解** → 双方好感各+5，设置flag `mx_zxh_mediated`，穆白和张小侯关系变为neutral（有机会成为friends）
4. **趁火打劫，暗示穆白你能"教训"张小侯** → 穆白好感+5但信任-20，张小侯好感-20，设置flag `mx_zxh_manipulated`

**选择3的后续**：如果调解成功，后续可能触发"一起训练"事件，两人关系可能提升为friends

### 事件2：训练馆的合作（调解成功后，双方好感≥50触发）

**触发方式**：requireFlag: mx_zxh_mediated，修炼时概率触发

**事件内容**：
> 穆白和张小侯在训练馆遇到。穆白难得没有嘲讽："上次的事...算了。"张小侯挠头："我也有不对的地方。"两人看向你，"既然你在，要不一起训练？"

**选择分支**：
1. **鼓励他们一起训练** → 双方好感各+10，设置flag `mx_zxh_friends`，两人关系变为friends，触发任务"团队训练"
2. **自己训练，让他们自己决定** → 双方好感不变，设置flag `mx_zxh_neutral`，两人保持neutral
3. **故意挑起竞争** → 穆白好感+5，张小侯好感+5，设置flag `mx_zxh_rivals`，两人关系变为rivals，触发任务"良性竞争"

### 任务"团队训练"（选择1后触发）
- 目标：与穆白对话1次 + 与张小侯对话1次 + 修炼3次
- 奖励：经验300，双方好感各+5，学校声望+10
- 完成后设置flag `mx_zxh_team_done`

### 任务"良性竞争"（选择3后触发）
- 目标：击败2个妖魔 + 与穆白对话1次 + 与张小侯对话1次
- 奖励：经验400，双方好感各+10，技能点1
- 完成后设置flag `mx_zxh_rivalry_done`

## 四、NPC间关系的影响

### 对话变化
- 如果两人是friends：穆白对话会提到"张小侯虽然笨，但还算努力"，张小侯对话会提到"穆白其实人不坏"
- 如果两人是rivals：穆白对话会嘲讽"别和那个乡下人走太近"，张小侯对话会说"穆白太高傲了"
- 如果两人是neutral：无特殊对话

### 事件触发变化
- friends状态：后续团队事件触发概率提升
- rivals状态：后续竞争事件触发概率提升
- neutral：无特殊影响

## 五、技术实现

- 复用v0.61关系驱动事件框架
- 在events.js中添加2个联动事件
- 在quests.js中添加2个对应任务
- 事件触发条件：双方minRelationship + requireFlag/notFlag
- NPC间关系通过flag存储（mx_zxh_friends / rivals / neutral）
- 对话变化通过现有对话系统的flag条件实现（后续版本扩展）

## 六、验收标准

1. 玩家与穆白、张小侯好感都≥30时，修炼有概率触发"走廊的冲突"事件
2. 事件有4个选择分支，选择后设置对应flag
3. 选择3（调解）后，双方好感≥50时触发"训练馆的合作"事件
4. 事件2有3个选择，触发不同任务
5. 任务完成后设置flag标记NPC间关系状态
6. node --check语法通过
