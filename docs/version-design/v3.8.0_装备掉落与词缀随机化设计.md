# v3.8.0 装备掉落与词缀随机化设计

> 版本：v3.8.0 | 状态：设计中（待对齐） | 日期：2026-09-07

## 一、现状分析

### 已有基础
- v3.5.0已实现装备词缀系统（6前缀+6后缀，4档品质）
- 14件装备有静态词缀
- 战斗奖励系统已有dropItems框架
- 词缀生成函数 `generateAffixes(quality)` 已实现

### 存在问题
1. **词缀是静态的**：同一件装备词缀永远相同，没有刷装备的动力
2. **掉落装备少**：大多数妖魔只掉材料/消耗品，不掉装备
3. **品质无区分**：所有掉落装备都是普通品质，没有稀有度追求
4. **词缀系统价值未发挥**：玩家无法通过刷怪获得更好的词缀组合

## 二、设计目标

1. **刷装备有动力**：不同妖魔掉落不同品质/词缀的装备
2. **词缀随机化**：每次掉落的装备词缀随机生成
3. **品质有追求**：普通→优秀→稀有→史诗，稀有装备更强
4. **不破坏平衡**：掉落概率合理，不会让玩家很快毕业

## 三、实施方案

### P0：装备掉落随机词缀（核心）

**修改战斗奖励系统**：
- 当掉落物品是装备（有equipStats字段）时，自动随机生成品质和词缀
- 品质概率：普通50%、优秀30%、稀有15%、史诗5%
- 词缀数量由品质决定（普通0、优秀1、稀有2、史诗3）
- 掉落的装备实例存储随机词缀（需要修改背包数据结构支持实例级数据）

**背包数据结构调整**：
- 当前背包只存 `{itemId, count}`，无法存储实例级词缀
- 方案：装备类物品添加 `instanceId` 和 `affixes` 字段
- 不可堆叠物品（装备本来就不可堆叠）每个实例独立存储

### P1：妖魔掉落表扩充

**为妖魔添加装备掉落**：
- 奴仆级妖魔：小概率掉落普通/优秀装备
- 战将级妖魔：中概率掉落优秀/稀有装备
- 统领级妖魔：较高概率掉落稀有/史诗装备
- 精英怪：掉落品质提升一档

**掉落装备类型**：
- 武器类妖魔掉武器
- 防御类妖魔掉防具
- 特殊妖魔掉饰品

### P2：掉落界面优化

**战斗结算界面**：
- 掉落装备按品质显示颜色
- 显示词缀列表
- 与当前装备对比（评分高低）

**背包界面**：
- 装备按品质排序
- 显示词缀数量
- 快速对比功能

## 四、可玩性评审

| 维度 | 评估 |
|------|------|
| 追求感 | ✅ 刷史诗装备、刷极品词缀组合 |
| 策略性 | ✅ 不同词缀适合不同build（暴击流/吸血流/肉盾流） |
| 可感知性 | ✅ 品质颜色+词缀列表，一眼看出好坏 |
| 平衡性 | ⚠️ 需控制掉落概率，避免太快毕业 |
| 原著契合 | ✅ 猎魔获得战利品符合原著设定 |

## 五、技术风险

1. **存档兼容性**：旧存档的背包数据没有instanceId/affixes，需要迁移处理
2. **背包数据结构**：从 `{itemId, count}` 改为支持实例数据，影响范围较大
3. **物品堆叠**：装备不可堆叠，所以每个实例独立存储，问题不大
4. **UI适配**：背包/装备界面需要显示实例级词缀，而非静态词缀

## 六、待确认问题

1. 掉落概率是否合理？（史诗5%会不会太低/太高？）
2. 是否需要"装备绑定"机制（避免无限刷）？
3. 词缀是否可以重铸/洗练？（后续版本考虑）
4. 背包数据结构改动是否会影响现有存档？
