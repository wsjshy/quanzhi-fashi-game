# 雪峰山历练副本 · 详细设计文档

> **版本**：v1.0 设计稿
> **对应原著**：第41-50章
> **优先级**：P1（最高，博城篇最重要的中期高潮）
> **设计原则**：玩家不是旁观者，而是亲历者；不是复刻莫凡的剧情，而是创造玩家自己的历练故事

---

## 一、设计目标

1. **还原原著名场面**：河谷悬崖、妖藤狭道、幽狼兽遭遇、洞窟环境击杀
2. **玩家有意义的选择**：战斗/逃跑/救人/利用环境，不同选择有不同后果
3. **多结局重玩价值**：英雄/幸存者/救援/死亡，不同评分和奖励
4. **引入新机制**：环境互动战斗、恐惧/勇气系统、历练评分
5. **深化NPC关系**：与莫凡、穆白、张小侯等同学的互动影响关系

---

## 二、触发条件与入口

### 触发条件
- 玩家等级 ≥ Lv.3
- 完成前置任务"年度考核"（或达到尖子班资格）
- 游戏内日期到达"历练日"（可通过debug快速触发）

### 入口
- 天澜魔法高中 → 事件与情报 → "雪峰山历练"
- 或 唐月老师对话 → "参加历练"

---

## 三、副本结构（4阶段）

### 阶段1：集结与出发

**场景**：天澜魔法高中操场
**内容**：
- 100名尖子生集合，教官（罗云波、潘丽君）讲解规则
- 分组：玩家可以选择加入莫凡组、穆白组、或随机分配
- 不同组有不同的NPC组合和剧情分支
- 出发前往雪峰山

**玩家选择**：
- 选择加入莫凡组 → 与莫凡、张小侯、周敏等同行
- 选择加入穆白组 → 与穆白、赵坤三等同行
- 随机分配 → 可能遇到不同组合

**影响**：分组影响后续阶段的NPC互动和剧情分支

---

### 阶段2：河谷悬崖（探索挑战）

**场景**：百草谷入口，10米宽悬崖
**原著还原**：风系学生跳崖拉绳索，张小侯挺身而出

**机制**：
- 玩家需要通过悬崖
- 风系玩家：可以使用风轨·疾行跳过去（需要技能等级足够）
- 其他系玩家：可以帮助拉绳索、保护同学、或等待别人搭桥
- 有胆小的同学（张英璐）不敢跳，玩家可以选择鼓励/帮助/无视

**玩家选择与后果**：
| 选择 | 后果 | 评分影响 |
|------|------|---------|
| 风系跳崖带头 | 获得同学敬佩，勇气+ | 勇气+ |
| 帮助拉绳索 | 团队贡献，NPC好感+ | 团队+ |
| 鼓励胆小同学 | 善良声望+，NPC好感+ | 团队+ |
| 无视直接过 | 无负面影响，但错过关系提升 | 无 |

**失败条件**：无（设计为引导阶段，不会卡关）

---

### 阶段3：妖藤狭道（环境战斗）

**场景**：百草谷入口狭道，布满会动的妖藤
**原著还原**：妖藤攻击学生，火系克制植物系，周敏火系大展神威

**机制**：
- 妖藤（植物系妖魔）会攻击玩家
- 元素克制：火系伤害+50%，雷系伤害+30%，水系伤害-30%
- 妖藤有倒刺，近战会受到反伤
- 可以选择战斗通过、或绕路（绕路会遇到更多妖魔）

**玩家选择与后果**：
| 选择 | 后果 | 评分影响 |
|------|------|---------|
| 火系玩家主力输出 | 战斗贡献+，周敏好感+ | 战斗+ |
| 辅助队友（治疗/控制） | 团队贡献+ | 团队+ |
| 绕路通过 | 避免战斗但遇到随机妖魔 | 智慧+ |
| 被妖藤困住 | 需要队友救援，关系变化 | 无（负面） |

---

### 阶段4：幽狼兽遭遇（高潮·恐惧机制）

**场景**：独眼魔狼巢穴附近
**原著还原**：幽狼兽出现，学生们第一次面对真正的妖魔，全军溃逃，穆白第一个施法

**核心新机制：恐惧/勇气系统**
- 玩家第一次面对战将级妖魔时，获得"恐惧"debuff
- 恐惧效果：施法成功率降低30%，攻击力降低20%
- 随着战斗进行，恐惧逐渐消退（每回合-5%）
- 如果玩家成功释放魔法或造成伤害，恐惧消退更快（勇气提升）
- 如果玩家选择逃跑，恐惧会持续到下次战斗

**战斗设计**：
- 幽狼兽（战将级，HP约500，攻击高，速度快）
- 玩家不是一个人战斗：队友（莫凡/穆白/许昭霆等）会参与
- 莫凡会使用火滋·焚骨（如果在莫凡组）
- 穆白会第一个施法冰蔓（如果在穆白组）
- 许昭霆会使用雷印麻痹

**玩家选择与后果**：
| 选择 | 后果 | 评分影响 |
|------|------|---------|
| 正面战斗 | 高风险高回报，战斗贡献+ | 战斗+，勇气+ |
| 救受伤同学 | 善良声望+，NPC好感+ | 团队+，勇气+ |
| 战术撤退 | 保存实力，无死亡风险 | 智慧+ |
| 利用环境（引到洞窟） | 触发阶段5环境击杀 | 智慧+，战斗+ |

**死亡处理**：如果玩家HP归零，不会直接游戏结束，而是被队友救下（扣评分，获得"历练重伤"debuff）

---

### 阶段5：洞窟BOSS战（环境互动·最高潮）

**场景**：洞窟深处，钟乳石密布
**原著还原**：莫凡烧断钟乳石，贯穿击杀幽狼兽

**核心新机制：环境互动战斗**
- 洞窟中有可互动的环境元素：钟乳石（可以被火系技能烧断）、落石（可以被土系技能震落）、水池（可以被冰系冻结）
- 玩家可以使用对应元素技能触发环境效果，造成大量伤害
- 环境伤害：钟乳石坠落造成200点固定伤害（无视防御）

**战斗设计**：
- 幽狼兽发狂（HP<50%时攻击力+50%）
- 玩家需要配合环境击杀，或硬打
- 莫凡会尝试烧断钟乳石（如果在莫凡组）
- 玩家可以协助：火系增强莫凡的火焰、土系震落更多石头

**玩家选择与后果**：
| 选择 | 后果 | 评分影响 |
|------|------|---------|
| 协助环境击杀 | 高伤害，快速结束战斗 | 智慧+，战斗+ |
| 硬打输出 | 考验实力，高风险 | 战斗+，勇气+ |
| 保护队友 | 团队贡献，NPC好感+ | 团队+ |
| 最后一击 | 获得额外奖励和声望 | 战斗+ |

**结算**：幽狼兽被击杀后，斩空风之翼登场救援，历练结束

## 四、评分系统

### 评分维度（每项1-5分）

| 维度 | 评分依据 |
|------|---------|
| 战斗贡献 | 造成的伤害、击杀贡献 |
| 勇气 | 是否克服恐惧、是否正面战斗 |
| 智慧 | 是否利用环境、是否战术撤退 |
| 团队 | 是否帮助队友、是否团队合作 |

### 评分等级

| 总分 | 等级 | 奖励 |
|------|------|------|
| 16-20 | S | 大量经验+金币+稀有物品+斩空的认可+高声望 |
| 12-15 | A | 较多经验+金币+不错的物品 |
| 8-11 | B | 基础经验+金币 |
| 4-7 | C | 少量经验+金币 |
| 0-3 | D | 几乎无奖励，被教官批评 |

### 多结局

| 结局 | 条件 | 特色奖励 |
|------|------|---------|
| 英雄结局 | S级评分+击杀幽狼兽+救同学 | 幽狼兽精魄+斩空的推荐信+莫凡/穆白深度好感 |
| 幸存者结局 | C级以上评分+存活 | 基础奖励，无特殊 |
| 救援结局 | 团队评分最高+救3人以上 | 善良声望+大量NPC好感 |
| 智者结局 | 智慧评分最高+环境击杀 | 智慧声望+特殊物品 |
| 重伤结局 | 战斗中HP归零 | debuff+低评分，但获得同学关心 |

## 五、NPC关系影响

### 莫凡
- 同组+协助环境击杀 → 好感大幅提升，解锁后续剧情
- 同组+抢最后一击 → 好感微降（莫凡有点不爽但认可实力）
- 不同组+历练中偶遇 → 基础关系

### 穆白
- 同组+战斗中表现出色 → 穆白的认可（从高傲到尊重）
- 同组+救穆白 → 关系大幅改善
- 不同组 → 竞争关系

### 张小侯
- 同组+帮助跳崖 → 死党关系
- 救张小侯 → 生死之交

### 周敏
- 同组+火系配合 → 好感提升
- 救周敏 → 好感大幅提升

### 斩空
- S级评分 → 获得斩空的认可，后续可能获得军方资源
- 环境击杀 → 斩空特别欣赏（"这小子有点意思"）

## 六、与现有系统的集成

### 需要新增的系统
1. **恐惧/勇气系统**：debuff机制，影响施法和攻击
2. **环境互动战斗**：特定场景的可互动元素
3. **历练评分系统**：多维度评分→奖励
4. **副本/事件系统**：多阶段事件，支持NPC队友

### 可以复用的系统
- 战斗系统（battle.js）
- NPC关系系统（npc-state.js）
- 任务系统（quests.js）
- 事件系统（events.js）
- 声望系统
