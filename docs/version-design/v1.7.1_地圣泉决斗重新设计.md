# v1.7.1 地圣泉决斗重新设计

> **设计原则**：设定基于原文，玩家是主角，莫凡是NPC；不编造原文没有的设定，也不完全复刻莫凡经历

---

## 一、原文设定（必须准确）

### 地圣泉
- 博城修炼圣地，相当于**加强版星尘魔器**
- **一年开启一次**，一次只提供**一个人七天**修炼时间
- 每届只给一名学生，学校和世家子弟都要竞争
- 效果：缓解修炼疲劳+修炼速度飞驰，可帮助初阶冲击中阶
- 地圣泉泄露的温泽会让周边妖魔变强（独眼魔狼因此恐怖）

### 宇昂
- 穆卓云养子，穆氏"修炼疯子"
- 决斗时掌握**3级冰蔓·覆盖**（大面积寒冰蔓延）
- 有**地波履魔具**（土系魔具，可躲避攻击）
- 穆卓云原本打算把地圣泉资格给他作为成年礼

### 决斗背景
- 时间：莫凡18周岁/毕业前夕
- 起因：莫凡当众骂穆卓云，穆宁雪提出决斗，穆卓云换成宇昂
- 彩头：胜者获得**地圣泉一周修炼资格**
- 公证人：邓凯（猎者联盟大长老）
- 观战五大势力：朱校长（天澜高中）、邓凯（猎者联盟）、杨作河（魔法协会）、斩空（军方）、穆卓云（穆氏）

### 莫凡的表现（原著，作为背景事件）
- 用1级火滋·灼烧破2级冰蔓·冻结
- 宇昂释放3级冰蔓·覆盖，全场震惊
- 莫凡最后释放**3级火滋**+暴露**天生双系**（雷火），震惊全场获胜

## 二、去莫凡中心化设计

### 核心思路
- 莫凡vs宇昂是**背景事件**，玩家是参与者/观察者，不是复刻者
- 玩家有自己的选择和机缘，不截取莫凡的机缘
- 如果玩家不参与，莫凡按原著路线获胜
- 如果玩家参与，走玩家自己的支线，不影响莫凡主线

### 玩家的4种立场

#### 1. 支持莫凡（草根立场）
- 为莫凡加油，获得莫凡好感+草根声望
- 决斗后莫凡获胜，玩家可以分享地圣泉修炼的部分心得（莫凡教玩家一些技巧）
- 不影响莫凡主线

#### 2. 支持宇昂（世家立场）
- 看好穆氏，获得穆氏声望
- 如果宇昂获胜（玩家不干预的话莫凡会赢，所以这个选择主要是立场表达）
- 后续穆氏可能招揽玩家

#### 3. 中立观战（学习立场）
- 专注观察高手对决，获得心境+经验
- 学习到冰系和火系的高级技巧
- 最安全的选择

#### 4. 自己争取地圣泉资格（玩家机缘）
- **前置条件**：玩家在年度考核中表现优异（评级A以上），且有决斗约定flag
- 玩家向穆卓云/朱校长提出："我也要争取地圣泉资格"
- 触发**玩家vs宇昂**的决斗（不是莫凡vs宇昂）
- 如果玩家获胜：获得地圣泉一周修炼资格（玩家自己的机缘）
- 如果玩家失败：虽败犹荣，获得经验和声望，莫凡继续和宇昂决斗（原著路线）
- **关键**：玩家的参与不截取莫凡机缘——如果玩家赢了，莫凡可以通过其他方式成长（比如萧院长的特殊指导），或者地圣泉资格在玩家使用后莫凡仍有机会（但原文说一年一次，所以需要合理处理）

### 关于"不截取莫凡机缘"的处理
- 原则1：玩家不对标莫凡，不零和竞争，不截取他的机缘
- 地圣泉是公共资源，玩家公平竞争赢了，是"玩家自己的机缘"，不是截取
- 莫凡有天生双系+小泥鳅坠，即使没地圣泉，游戏可以给他其他成长路径：
  - 萧院长看中玩家魄力，同时给莫凡安排特殊资源（三步塔提前开放/特殊指导）
  - 小泥鳅坠加速修炼
  - 系统根据flag调整莫凡实力曲线，确保灾难前达到足够实力
- 不需要"让给莫凡"选项——玩家赢了就是赢了，莫凡走替代成长路线

## 三、大事件结构（5阶段）

### 阶段1：决斗前夕（narrative）
- 描述决斗背景、五大势力齐聚、地圣泉资格的珍贵
- 玩家选择立场（4种）

### 阶段2：玩家挑战分支（battle，条件触发）
- 如果玩家选择"自己争取"，触发玩家vs宇昂
- 宇昂实力：3级冰蔓·覆盖+地波履魔具（高难度）
- 胜利：进入阶段3A（玩家获胜）
- 失败：进入阶段3B（玩家失败，莫凡继续）

### 阶段3A：玩家获胜（narrative）
- 玩家击败宇昂，全场震惊
- 获得地圣泉资格+凡级星尘魔器+草根声望
- 莫凡虽然没得到地圣泉，但萧院长安排了其他资源（三步塔/特殊指导），莫凡走替代成长路线
- 玩家进入地圣泉修炼（一周修炼，大量经验+可能突破中阶）

### 阶段3B：莫凡vs宇昂（narrative，默认路线）
- 描述莫凡的战斗过程（1级火滋破2级冰蔓→3级冰蔓覆盖→3级火滋+天生双系）
- 玩家根据立场有不同反应
- 莫凡获胜，获得地圣泉资格

### 阶段4：决斗结束（auto）
- 结算声望、好感、经验
- 设置flag：earth_spring_duel_completed
- 如果玩家获得地圣泉资格，解锁地圣泉修炼地点

## 四、地圣泉修炼机制（新增）

### 如果玩家获得地圣泉资格
- 解锁特殊地点"地圣泉"（临时，7天）
- 在地圣泉修炼：经验×5，修炼速度大幅提升
- 7天后地圣泉关闭，地点消失
- 有概率突破境界（初阶→中阶）

### 地圣泉修炼的数值设计
- 每次修炼（1小时）：基础经验×5，HP/MP消耗减半
- 连续修炼7天（每天最多8小时）：总经验约=普通修炼35天
- 有20%概率触发"地圣泉顿悟"：直接获得1级技能提升
- 有30%概率突破境界（如果接近突破阈值）
