# v0.50.0 影响力事件链扩展（穆宁雪与张小侯）

> 版本：v0.50.0
> 日期：2026-08-15
> 定位：在v0.48.0唐月事件链基础上，扩展穆宁雪和张小侯的flag驱动事件链，让玩家影响力覆盖更多NPC

---

## 一、设计原则

1. **不围绕莫凡**——事件是玩家与NPC的自然互动，不提及莫凡、不对标莫凡
2. **不恋爱导向**——穆宁雪事件链是基于实力的认可和同学关系，非恋爱
3. **一切自然发生**——NPC因玩家行为自然产生态度变化，不刻意提示"XX不再关注YY"
4. **flag驱动**——事件之间有flag依赖，形成真正的事件链
5. **人设不可破坏**——穆宁雪高冷不主动热情，张小侯活泼热心但不背叛莫凡

---

## 二、事件链1：穆宁雪的认可

### 核心逻辑
玩家通过修炼展现实力和态度 → 穆宁雪注意到玩家 → 基于实力的认可 → 互动加深 → 同学关注

### 事件1：修炼中的偶遇
- **触发**：修炼/冥修时，穆宁雪路过
- **条件**：minRelationship 15, 玩家等级≥5, notFlag("mu_ningxue_noticed")
- **描述**：你正在专注修炼，星子运转稳定。穆宁雪路过时停下脚步，看了一会儿。她没有说话，但眼神中多了一丝注意。
- **选择**：
  1. 点头致意，继续修炼 → setFlag("mu_ningxue_noticed"), npcOpinion +3
  2. 主动请教冰系修炼 → npcOpinion +1, exp +10（穆宁雪冷淡但简短回答）
  3. 不理会，继续修炼 → setFlag("mu_ningxue_noticed"), npcOpinion +5（穆宁雪欣赏专注）

### 事件2：冰系心得
- **触发**：修炼/自习时
- **条件**：requireFlag("mu_ningxue_noticed"), minRelationship 20
- **描述**：穆宁雪走到你旁边，"你的星子排列比上次稳定了。冰系的关键在于控制，不是力量。"她难得主动开口。
- **选择**：
  1. 认真聆听，请教细节 → exp +40, npcOpinion +3
  2. 提出自己的见解 → npcOpinion +5, reputation +2（穆宁雪惊讶于你的思考）
  3. 谢谢，我自己再琢磨 → npcOpinion +2

### 事件3：切磋邀请
- **触发**：修炼/找人聊天时
- **条件**：requireFlag("mu_ningxue_noticed"), minRelationship 30, 玩家等级≥8
- **描述**：穆宁雪抱着手臂看着你，"你的进步速度...比我预想的快。要不要切磋一下？我想看看你的实战水平。"
- **选择**：
  1. 好，请指教 → 触发战斗（穆宁雪切磋），胜利后npcOpinion +8, reputation +5
  2. 现在还不是时候 → npcOpinion +2（穆宁雪点头，"有自知之明也好"）

### 事件4：同学的关注
- **触发**：自习/聊天时
- **条件**：requireFlag("mu_ningxue_noticed"), minRelationship 25
- **描述**：赵满延凑过来，"哎，我最近看到穆宁雪跟你说话了？可以啊兄弟，她平时可不理人的。"周围同学投来好奇的目光。
- **选择**：
  1. 只是讨论修炼而已 → reputation +3
  2. 她人其实没那么冷 → npcOpinion(赵满延) +3, reputation +2

## 三、事件链2：张小侯的友谊

### 核心逻辑
玩家帮助张小侯解决修炼困惑 → 建立友谊 → 一起修炼 → 张小侯分享情报 → 关键时刻提供帮助

### 事件1：风系困惑
- **触发**：修炼/找人聊天时
- **条件**：minRelationship 10, notFlag("zhang_xiaohou_helped")
- **描述**：张小侯蹲在一旁，一脸苦恼地抓头发。"风系的星子怎么老是连不稳啊...莫凡哥那么厉害，我怎么就这么笨呢..."
- **选择**：
  1. 风系讲究速度，试试缩短星子间距 → setFlag("zhang_xiaohou_helped"), npcOpinion +8, exp +15
  2. 别着急，每个人节奏不同 → setFlag("zhang_xiaohou_helped"), npcOpinion +5
  3. 你可以去问问其他老师 → npcOpinion +2（张小侯有点失落）

### 事件2：一起修炼
- **触发**：修炼时
- **条件**：requireFlag("zhang_xiaohou_helped"), minRelationship 20
- **描述**：张小侯跑过来，"嘿！上次你说的方法真有用！我星子连稳多了！要不要一起修炼？我可以帮你望风！"
- **选择**：
  1. 好，一起修炼 → exp +35, npcOpinion +4
  2. 今天有点事，下次吧 → npcOpinion +1

### 事件3：消息灵通
- **触发**：找人聊天/自习时
- **条件**：requireFlag("zhang_xiaohou_helped"), minRelationship 25
- **描述**：张小侯神秘兮兮地凑过来，"我跟你说个秘密...我听说学校后面的雪峰山深处有个隐秘的修炼洞，魔力浓度特别高！一般人我不告诉他！"
- **选择**：
  1. 谢了，改天去看看 → setFlag("knows_secret_cave"), reputation +3
  2. 真的假的，你别骗我 → npcOpinion +2, 张小侯急着证明

### 事件4：关键时刻
- **触发**：探索/战斗后
- **条件**：requireFlag("zhang_xiaohou_helped"), minRelationship 35, 玩家HP<50%
- **描述**：你刚经历一场苦战，有些狼狈。张小侯不知从哪冒出来，"你没事吧！快，我这里有药水！"他递过来一瓶治愈药水。
- **选择**：
  1. 谢谢，关键时刻还是你靠谱 → 获得health_potion, npcOpinion +5, reputation +2
  2. 不用，我还撑得住 → npcOpinion +3（张小侯："逞强...不过你确实厉害"）

## 四、技术实现

- 复用v0.48.0基础设施：`requireFlag`/`notFlag`/`setFlag`
- 事件数据添加到`engine/data/events.js`的DataEvents对象
- NPC偶遇系统已支持检查所有NPC，无需修改
- flag持久化：Player.setFlag()已支持

## 五、验证标准

1. 穆宁雪事件链：关系15+修炼触发事件1，setFlag后事件2-4依次可触发
2. 张小侯事件链：关系10+触发事件1，setFlag后事件2-4依次可触发
3. 人设检查：穆宁雪不主动热情，张小侯活泼热心但不背叛莫凡
4. 不围绕莫凡：事件中不提及莫凡（张小侯事件1原文提到莫凡，需修改为不提及）
5. flag驱动：未setFlag时后续事件不触发
6. 冒烟测试：游戏不崩溃，事件数据正确加载
