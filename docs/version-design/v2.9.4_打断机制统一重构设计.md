## 一、问题分析

当前存在**两套独立的打断机制**，计算逻辑不一致，数据字段浪费：

### 机制A：瞬发技能自打断（castSkillImmediate）
- **触发**：castTime ≤ 1 的技能（初阶魔法在精神力≥30时）
- **公式**：实际打断概率 = `skill.interruptChance` - 境界压制减免 - 防御姿态(-20%)
- **效果**：技能失败 + 损失50% MP
- **范围**：仅玩家

### 机制B：引导技能被攻击打断（enemyTurn/playerAttack）
- **触发**：目标正在引导（castTime > 1），被攻击命中时
- **公式**：每回合打断概率 = 20%基础 + (攻击者精神力 - 目标精神力) × 0.5%，范围10%-60%
- **效果**：引导取消，**无MP损失**
- **范围**：玩家和敌方法师

### 四个具体问题

| # | 问题 | 说明 |
|---|------|------|
| 1 | **中阶魔法interruptChance未使用** | 中阶魔法castTime>1走引导流程，不会进入castSkillImmediate的打断判定，44个技能的interruptChance字段中，中阶/高阶的完全无效 |
| 2 | **与设计目标偏差** | 目标是"施法速度体现在被打断概率上"，但当前引导机制中施法速度只体现在引导回合数（等更久），每回合打断概率与技能无关 |
| 3 | **初阶魔法interruptChance可能无意义** | 精神力≥30时初阶castTime=1瞬发，interruptChance生效；但精神力<30时初阶走引导，interruptChance失效。同一技能在不同精神力下用两套完全不同的打断逻辑 |
| 4 | **两套公式不一致** | 瞬发基于技能字段(0.1-0.3)，引导基于精神力对抗(10%-60%)，数值范围和决定因素完全不同 |

## 二、设计目标

1. **统一公式**：所有技能（无论瞬发/引导）的打断概率基于同一套框架
2. **施法速度决定风险**：castTime越长 → 每回合被打断概率越高 → 累计风险越大
3. **精神力有价值**：精神力高 → castTime短 → 每回合打断概率低 + 被攻击回合数少（双重收益）
4. **技能差异化**：interruptChance字段作为"技能难度系数"，不同技能打断难度不同
5. **效果统一**：被打断一律技能失败 + 损失50% MP
6. **向后兼容**：保留控制技能100%打断、境界压制减免、防御姿态抗打断

---

## 三、统一方案

### 3.1 核心公式

```
每回合被打断概率 = 基础概率(castTime) × 技能难度系数(interruptChance)
                  + 精神力差修正
                  - 目标境界压制减免
                  - 防御姿态抗打断(-20%)
```

#### 基础概率（由castTime决定）

| castTime | 基础打断概率 | 对应阶段 |
|----------|-------------|---------|
| 1（瞬发） | 8% | 初阶满精神力 |
| 2 | 15% | 初阶普通/中阶满精神力 |
| 3 | 22% | 中阶普通/高阶满精神力 |
| 4 | 30% | 高阶普通 |
| 5 | 38% | 超阶 |

> 设计意图：castTime每增加1回合，基础概率提升约7-8%。瞬发(8%)风险很低，高阶(30%)每回合有近1/3概率被打断，引导3回合累计风险约66%。

#### 技能难度系数（interruptChance字段重新定义）

**当前含义**：绝对打断概率（0.15-0.30）
**新含义**：难度系数乘数，默认1.0

| 系数 | 含义 | 适用技能 |
|------|------|---------|
| 0.7 | 易打断（施法动作大） | 部分初阶 |
| 1.0 | 普通（默认） | 大多数技能 |
| 1.3 | 难打断（施法凝练） | 部分中阶/高阶 |
| 1.5 | 极难打断 | 终极技能/领域类 |

> 数据迁移：现有44个技能的interruptChance值（0.15-0.30）需要转换为系数。0.25→1.0（基准），0.15→0.6，0.30→1.2。具体映射见第五节。

#### 精神力差修正

```
修正 = (攻击者精神力 - 目标精神力) × 0.3%，范围 ±10%
```

> 从当前的0.5%/±20%下调到0.3%/±10%，因为castTime已经是主要因素，精神力作为次要修正。

#### 境界压制减免（保留现有）

| 目标境界 \ 技能阶级 | 初阶 | 中阶 | 高阶 |
|---------------------|------|------|------|
| 初阶 | 0 | 不能释放 | 不能释放 |
| 中阶 | -15% | 0 | 不能释放 |
| 高阶 | -30% | -15% | 0 |
| 超阶 | -45% | -30% | -15% |

#### 防御姿态抗打断（保留现有）
- 上回合防御 → 本回合打断概率 -20%

### 3.2 控制技能100%打断（保留）

眩晕/沉默/冰冻/麻痹/束缚等控制效果命中时，**100%打断**正在引导的魔法，不受上述公式影响。

### 3.3 统一被打断效果

- 引导取消 / 技能失败
- **损失50% MP**（补上引导机制当前缺失的MP损失）
- 战斗日志提示 + 视觉反馈（红色闪烁）

### 3.4 敌方NPC法师

敌方法师也使用同一套公式：
- 敌方引导时，玩家攻击命中 → 按公式计算打断概率
- 敌方瞬发魔法（castTime≤1）→ 也按公式计算自打断概率（敌方法师也会施法失败）
- 敌方精神力从enemy.spirit读取（当前已有默认20）

## 四、累计打断风险示例

以中阶魔法（castTime=2，基础15%，系数1.0，精神力差0，无减免）为例：

| 场景 | 每回合概率 | 引导回合数 | 累计被打断概率 |
|------|-----------|-----------|--------------|
| 中阶满精神力(castTime=1瞬发) | 8% | 1 | 8% |
| 中阶普通(castTime=2) | 15% | 2 | 28% |
| 中阶被攻击1次(castTime=2) | 15% | 2 | 28%（只在被攻击时判定） |
| 高阶普通(castTime=3) | 22% | 3 | 53% |

> 注意：引导期间**只有被攻击命中时才进行打断判定**，不是每回合自动判定。所以castTime长的技能风险在于"有更多回合可能被攻击"，而非每回合自动扣血。

## 五、数据迁移计划

### 5.1 interruptChance字段转换

现有44个技能的interruptChance值需要从"绝对概率"转换为"难度系数"：

```
新系数 = 旧值 / 0.25
```

| 旧值 | 新系数 | 数量（预估） |
|------|--------|------------|
| 0.15 | 0.6 | 初阶易打断 |
| 0.20 | 0.8 | |
| 0.25 | 1.0（基准） | 大多数 |
| 0.30 | 1.2 | 中阶难打断 |

> 实施时用脚本批量转换，然后人工审核极端值。

### 5.2 新增字段（可选）

- `castTimeOverride`：允许特定技能覆盖默认castTime（如某些施法极快的技能）
- `interruptImmune`：标记完全免疫打断的技能（如被动/瞬发buff类，当前已通过type=buff跳过）
