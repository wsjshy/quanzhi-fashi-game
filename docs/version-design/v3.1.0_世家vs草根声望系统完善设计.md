# v3.1.0 世家vs草根声望系统完善设计

> 版本：v3.1.0 | 日期：2026-08-22 | 状态：已实施

## 一、背景

声望系统已有基础框架（world-state.js的getReputation/changeReputation/getReputationLevel，ui-reputation.js的声望界面，shop.js的声望折扣），但存在以下问题：

1. **势力定义不全**：factions中只定义了5个势力（天澜高中/穆氏/猎魔公会/魔法协会/黑教廷），但事件中大量使用grassroots（草根）、military（军方）、inquisition（审判会）等声望，导致这些声望在界面中不显示
2. **世家vs草根对立未体现**：穆氏世家线（鸿门宴/穆氏招揽）和草根线缺乏对应的声望势力定义
3. **声望效果未完全应用**：questRewardBonus（任务奖励加成）因任务数据无factionId字段暂未应用

## 二、完善内容

### 2.1 新增势力定义（src/data/world.js）

#### grassroots（草根阶层）
- **定位**：出身平凡的法师和普通民众，崇尚努力与自立，对世家垄断资源不满
- **颜色**：#88cc88（绿色，代表生机与自立）
- **图标**：🌱
- **声望效果**：
  - 友好：任务奖励 +5%
  - 尊敬：任务奖励 +10%，商店 95折
  - 崇拜：任务奖励 +20%，商店 9折，NPC互动加成

#### military（军方）
- **定位**：博城守军，以斩空总教官为首，负责城市防御和妖魔作战
- **颜色**：#6688aa（军蓝）
- **图标**：🛡️
- **声望效果**：
  - 友好：任务奖励 +5%
  - 尊敬：任务奖励 +15%，军方支援
  - 崇拜：任务奖励 +25%，军方支援，专属装备

#### inquisition（审判会）
- **定位**：魔法协会的最高执法机构，专门缉拿触犯公约的法师和黑教廷成员
- **颜色**：#aaaacc（银灰）
- **图标**：⚖️
- **声望效果**：
  - 友好：考核奖励 +5%
  - 尊敬：考核奖励 +10%，情报访问
  - 崇拜：考核奖励 +15%，情报访问，审判会支援

## 三、世家vs草根对立设计

### 3.1 对立机制

- **穆氏世家声望高** → 草根声望可能降低（部分事件中对立）
- **草根声望高** → 穆氏世家可能不满
- 玩家选择影响两边声望，形成不同的剧情路线

### 3.2 已联动的事件

| 事件 | 世家声望 | 草根声望 |
|------|---------|---------|
| 穆氏招揽（接受） | mu_family +20 | grassroots -10 |
| 穆氏招揽（拒绝） | mu_family -15 | grassroots +15 |
| 鸿门宴（隐忍） | mu_family +5 | grassroots -5 |

| 博城灾难（英雄） | 多势力 + | grassroots +20 |
