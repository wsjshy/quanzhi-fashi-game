# v1.9.0 博城灾难分支深化设计

> 版本：v1.9.0 | 日期：2026-08-18 | 状态：设计中，待对齐确认

## 一、设计目标

深化博城灾难大事件的分支多样性，让玩家的前期选择（关系/调查/实力）在灾难中有更明显的影响，增强 replay value 和代入感。

### 现有基础
- 5个结局：真相追寻者/军方盟友/博城英雄/幸存者/艰难求生
- 阴谋调查领先分支（v1.8.1）：充分准备+唐月夹击宇昂
- 宇昂身份线：追击/有准备追击/报告斩空/忽略

### 原文依据
- 地圣泉是博城核心修炼资源，黑教廷目标之一
- 暴躁之泉洒在云雾中，大雨时催化妖魔疯狂进攻
- 翼苍狼统领级妖魔，号令成百上千妖魔
- 唐月是审判员，暗中调查黑教廷
- 斩空是军部首领，博城最强战力

## 二、新增分支

### 2.1 地圣泉守护分支

**触发条件**：灾难前完成"地圣泉守卫异动"调查任务，或与唐月关系>50

**分支流程**：
- 第五阶段（发现宇昂后）新增选项："地圣泉可能有危险，我去守护"
- 玩家前往地圣泉，发现黑教廷成员试图释放地圣泉温泽
- 战斗：黑教廷执事（中阶法师，HP500）
- 胜利：阻止地圣泉温泽释放，博城伤亡大幅减少，获得地圣泉一周修炼资格
- 失败：地圣泉温泽部分释放，引来更多妖魔，但玩家尽力了

**影响**：
- 胜利 → 新增结局"地圣泉守护者"
- 失败 → 现有结局，但描述中增加地圣泉受损的内容
- 与宇昂线互斥（选择守护地圣泉就不能追击宇昂）

### 2.2 NPC命运分支

**根据前期关系影响NPC在灾难中的命运**：

| NPC | 关系>50 | 关系20-50 | 关系<20 |
|-----|---------|-----------|---------|
| 唐月 | 战斗中唐月来救玩家，共同战斗 | 唐月在远处支援 | 唐月专注自己的任务 |
| 张小侯 | 张小侯在灾难中存活，战后感谢玩家 | 张小侯受伤但存活 | 张小侯失踪（后续可找回） |
| 穆宁雪 | 穆宁雪在灾难中保护平民，与玩家并肩 | 穆宁雪独自战斗 | 穆宁雪与穆氏家族一起撤离 |
| 莫凡 | 莫凡在关键时刻支援玩家 | 莫凡专注自己的战斗 | 莫凡与玩家无交集 |

**实现方式**：
- 在灾难战斗阶段，根据NPC关系添加支援事件
- 结局描述中根据NPC关系调整内容
- 战后NPC关系变化（共同战斗+好感，见死不救-好感）

### 2.3 暴躁之泉调查分支

**触发条件**：灾难前收集到"暴躁之泉"相关线索

**分支流程**：
- 第一阶段预警时，玩家可以指出"可能是暴躁之泉"
- 唐月确认后，军方提前准备防化措施
- 妖魔攻击力降低20%（战斗中敌人攻击-20%）
- 获得"提前识破黑教廷阴谋"成就

## 三、结局深化

### 新增结局：地圣泉守护者
- 条件：守护地圣泉成功
- 奖励：地圣泉一周修炼资格（修炼经验×3），唐月+30好感，军方+40声望
- 描述：玩家守护了博城最珍贵的资源，虽然没有亲手揭露宇昂，但博城因你而减少了大量伤亡

### 现有结局差异强化
- 真相追寻者：增加"宇昂死前透露的黑教廷线索"，为后续剧情铺垫
- 军方盟友：斩空邀请玩家加入军方特别行动队
- 博城英雄：增加市民欢呼和NPC祝贺场景
- 幸存者：增加灾后重建的参与感

## 四、实施步骤

### 阶段1：地圣泉守护分支
1. 新增敌人：黑教廷执事（black_church_deacon）
2. 新增阶段：phase_5_earth_spring_guard / phase_5_earth_spring_battle / phase_5_earth_spring_success / phase_5_earth_spring_failed
3. 在phase_5_discovery的choices中新增"地圣泉可能有危险"选项
4. 新增结局：earth_spring_guardian

### 阶段2：NPC命运分支
1. 在phase_4_battle_begin前添加NPC支援检查
2. 根据关系添加临时队友或支援效果
3. 结局描述中根据关系动态调整

### 阶段3：暴躁之泉分支
1. 在clues.js中添加暴躁之泉线索
2. 在phase_1_warning中新增"可能是暴躁之泉"选项
3. 战斗中应用敌人攻击-20%效果

### 阶段4：结局深化
1. 调整5个现有结局的描述和奖励差异
2. 新增地圣泉守护者结局
3. 战后NPC关系变化

## 五、待确认问题

1. **地圣泉守护与宇昂追击互斥**：是否合理？玩家只能选一个，还是可以都做？
   - 方案A：互斥（时间不够，更真实）
   - 方案B：可以都做但难度提升（玩家更强）

2. **NPC命运分支的复杂度**：4个NPC×3种关系=12种组合，是否全部实现？
   - 方案A：全部实现（内容丰富但工作量大）
   - 方案B：只实现唐月和张小侯（核心NPC）

3. **暴躁之泉线索**：是否需要新增线索到阴谋调查系统？
   - 方案A：新增2条暴躁之泉线索
   - 方案B：复用现有"黑教廷踪迹"线索

4. **版本规模**：v1.9.0是否包含全部3个分支，还是分批实现？
   - 方案A：全部实现（大版本，内容丰富）
   - 方案B：先做地圣泉守护+结局深化（v1.9.0），NPC命运和暴躁之泉放v1.9.1

## 六、预期效果

- 博城灾难分支从5个结局扩展到6个，选择路径从4条扩展到7条
- NPC关系在灾难中有实际影响，增强关系系统的意义
- 阴谋调查系统的线索有更多用武之地
- 玩家有更强的"我的选择很重要"的感觉
