# v3.1.0 雪峰山历练副本完善设计

> 版本：v3.1.0 | 状态：设计中 | 最后更新：2026-08-22

## 一、背景与问题

雪峰山历练副本（big_event_xuefeng_training）是博城篇中期高潮事件，但当前实现存在以下问题：

1. **NPC队友AI未使用**：战斗系统已有allyTurn()基础实现，但历练副本的战斗中没有添加NPC队友
2. **环境互动未实现**：phase_5_cave的battleOptions中有environment: "cave"，但战斗系统没有处理环境互动（钟乳石砸落）
3. **评分系统未生效**：ratings定义了S/A/B/C四级，但结束时没有统一应用评分奖励，各phase各自硬编码奖励
4. **战斗体验单一**：洞窟决战只是普通战斗，没有体现"利用钟乳石"的策略性

## 二、设计目标

1. **NPC队友参战**：洞窟决战中莫凡作为NPC队友参战，有简单AI和战斗风格
2. **环境互动机制**：洞窟战斗中可触发钟乳石砸落，造成大量伤害，增加策略性
3. **评分系统统一**：结束时根据表现计算评分，统一应用奖励
4. **向后兼容**：旧存档和已有流程不受影响

## 三、NPC队友设计

### 3.1 队友数据结构

```js
allies: [
  {
    id: 'mo_fan',
    name: '莫凡',
    element: 'fire',
    hp: 200, maxHp: 200,
    attack: 25, defense: 10, speed: 12,
    style: 'aggressive', // aggressive/defensive/balanced
    acted: false
  }
]
```

### 3.2 队友AI（复用现有allyTurn）
- 进攻风格：伤害+25%
- 防御风格：伤害-25%，有概率减伤
- 平衡风格：正常伤害

### 3.3 历练副本中的队友
- phase_5_cave（洞窟决战）：莫凡作为队友参战
- 其他战斗（妖藤狭道）：可选添加1-2名同学队友

## 四、环境互动机制设计

### 4.1 洞窟环境（environment: "cave"）

战斗开始时初始化环境状态：
```js
this.environment = {
  type: 'cave',
  stalactites: 3, // 可触发的钟乳石数量
  stalactiteCooldown: 0 // 冷却回合
};
```

### 4.2 钟乳石砸落触发条件

玩家在洞窟战斗中有一个特殊按钮"利用钟乳石"：
- 消耗：需要火系魔法（或火系技能命中）点燃支撑
- 效果：造成敌人最大HP 25%的伤害（上限100）
- 冷却：2回合
- 次数：最多3次（洞窟中钟乳石有限）

### 4.3 实现方式

在战斗UI中添加环境互动按钮（仅当environment: "cave"时显示）
点击后：
1. 检查是否有可用钟乳石和冷却
2. 播放钟乳石砸落动画/日志
3. 造成伤害
4. 减少钟乳石数量，设置冷却

## 五、评分系统细化

### 5.1 评分维度

| 维度 | 评分依据 | 分值 |
|------|---------|------|
| 战斗表现 | 是否击杀幽狼兽 | 击杀+40，被救+20，撤退+10 |
| 勇气表现 | 是否跟随莫凡进入洞窟 | 是+20，帮助撤退+15，逃跑+0 |
| 团队贡献 | 悬崖/妖藤阶段表现 | 风系跳跃+10，帮助同学+10，普通+5 |
| 受伤情况 | 是否在战斗中受伤 | 未受伤+10，受伤+0 |

### 5.2 评级划分

- S级：总分>=80（击杀幽狼兽+勇气+团队贡献）
- A级：总分>=60（帮助撤退+团队贡献）
- B级：总分>=40（被救+基本表现）
- C级：总分<40（逃跑）

### 5.3 奖励统一

结束时根据评分统一发放奖励，替代各phase硬编码的奖励。
