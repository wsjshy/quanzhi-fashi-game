# v0.61.0 关系驱动任务系统（唐月线）

> 版本：v0.61.0
> 日期：2026-08-15
> 类型：系统深化
> 前置：v0.48-v0.53影响力事件链 + v0.55-v0.56导师线

---

## 一、为什么做这个

### 问题
- 系别任务线（v0.57-v0.60）虽然覆盖了4个系别，但模式完全相同（修炼→对话→图书馆+修炼），只是"做X次Y"
- 没有选择分支、没有剧情深度、没有与其他系统联动
- 继续扩展只会让游戏冗余

### 解决方案
**关系驱动任务**：当玩家与NPC关系达到阈值，触发有选择分支的专属任务。选择影响：
- NPC好感/信任
- 世界状态（flag）
- 其他NPC的关系
- 任务奖励和后续剧情

### 为什么有深度
1. **选择有意义**：不同选择导致不同后果，不是线性任务
2. **关系有回报**：提升关系不只是数字变化，而是解锁专属内容
3. **世界有反应**：玩家选择影响世界状态，NPC行为随之改变
4. **可重玩性**：不同选择路线体验不同

---

## 二、系统架构

### 触发机制
- NPC关系达到阈值（好感30/50/80）时，修炼/探索/对话时有概率触发关系事件
- 事件有选择分支，玩家选择后设置flag，触发对应任务
- 任务完成后给奖励，并可能触发后续事件

### 技术实现
- 复用**事件系统**：选择分支、flag设置、NPC关系变化
- 复用**任务系统**：目标追踪、奖励发放
- 两者结合：事件触发选择 → 设置flag → 任务追踪目标 → 完成奖励

## 三、唐月关系任务线设计

### 任务1：唐月的邀请（好感≥30触发）

**触发方式**：修炼时概率触发事件

**事件内容**：
> 唐月注意到你最近的进步，课后叫住了你。
> "你的修炼很认真，我注意到了。放学后有空吗？我想给你一些单独指导。"

**选择分支**：
1. **欣然接受** → 好感+5，设置flag `tang_yue_invite_accepted`，触发任务"课后辅导"
2. **婉拒（有其他安排）** → 好感不变，设置flag `tang_yue_invite_declined`，唐月表示理解
3. **询问能否带朋友** → 好感+3，设置flag `tang_yue_invite_friend`，触发任务"集体辅导"（与其他NPC联动）

**任务"课后辅导"**（选择1后触发）：
- 目标：与唐月对话3次
- 奖励：经验200，唐月好感+10，技能点1

**任务"集体辅导"**（选择3后触发）：
- 目标：与唐月对话1次 + 与任意同学对话2次
- 奖励：经验150，唐月好感+5，学校声望+10

### 任务2：实践考核（好感≥50触发，完成任务1）

**触发方式**：完成任务1后，修炼时概率触发事件

**事件内容**：
> 唐月找到你，表情认真。
> "你的基础已经不错了。下周有一次魔法实践考核，我推荐你参加。这是证明自己的机会，但也有风险。"

**选择分支**：
1. **接受挑战** → 好感+5，设置flag `tang_yue_exam_accepted`，触发任务"实践考核"
2. **请求降低难度** → 好感-2，设置flag `tang_yue_exam_easy`，触发简化版任务
3. **请求同学协助** → 好感+3，设置flag `tang_yue_exam_team`，触发组队任务（与同学联动）

**任务"实践考核"**（选择1后触发）：
- 目标：战斗胜利3场
- 奖励：经验500，金币300，唐月好感+15，称号"唐月的得意门生"

### 任务3：师徒抉择（好感≥80触发，完成任务2）

**触发方式**：完成任务2后，与唐月对话时触发事件

**事件内容**：
> 唐月看着你，眼神中带着期待。
> "你已经证明了自己的实力和心性。我正式问你——愿意成为我的弟子吗？这意味着更多的责任，也意味着更多的资源。"

**选择分支**：
1. **愿意拜师** → 好感+10，设置flag `tang_yue_mentor_formal`（正式师徒），触发导师线深化
2. **需要时间考虑** → 好感不变，设置flag `tang_yue_mentor_pending`，延迟决定
3. **婉拒（想走自己的路）** → 好感-5，设置flag `tang_yue_mentor_declined`，唐月尊重你的选择

**选择1的后果**：
- 导师修炼加成从10%提升到15%
- 解锁唐月专属技能传授
- 每月获得唐月的资源支持

## 四、可玩性分析

### 深度来源
1. **3个任务 × 3个选择 = 9种不同路线**
2. **选择影响后续**：任务1的选择影响任务2的难度和内容
3. **关系有实际回报**：好感30/50/80各解锁不同内容
4. **与现有系统联动**：导师线、影响力事件、战斗系统

### 与系别任务的区别
| 维度 | 系别任务（v0.57-v0.60） | 关系驱动任务（v0.61+） |
|------|--------------------------|------------------------|
| 触发 | 元素+等级 | NPC关系阈值 |
| 结构 | 线性（做X次Y） | 分支选择 |
| 后果 | 只有奖励 | 关系+flag+世界状态 |
| 重玩 | 无意义 | 不同选择不同体验 |
| 联动 | 无 | 导师线/事件/战斗 |

## 五、技术实现

### 事件数据
- 在events.js中添加3个关系事件（唐月的邀请/实践考核/师徒抉择）
- 每个事件有3个选择分支，设置不同flag
- 触发条件：requireFlag（前置任务完成）+ 关系阈值 + 概率

### 任务数据
- 在quests.js中添加对应任务（课后辅导/集体辅导/实践考核等）
- 任务触发条件：requireFlag（事件选择后设置）
- 任务奖励：经验/金币/好感/称号/技能点

### 称号系统
- 新增称号"唐月的得意门生"
- 称号在角色界面显示

## 六、验收标准

1. 唐月好感30时，修炼有概率触发"唐月的邀请"事件
2. 事件有3个选择分支，选择后设置对应flag
3. 选择1后触发"课后辅导"任务，目标与唐月对话3次
4. 选择3后触发"集体辅导"任务，目标与唐月+同学对话
5. 完成任务1后，好感50时触发"实践考核"事件
6. 完成任务2后，好感80时触发"师徒抉择"事件
7. 选择拜师后，导师加成提升，解锁专属内容
8. node --check语法通过
