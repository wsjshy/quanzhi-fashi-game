## 一、设计目标

现有悬赏系统只是一个简单的查看事件，没有实际的任务接取、追踪、完成机制。v3.12.0建立真正的猎魔悬赏系统：

1. **悬赏板**：猎者联盟大厅显示当前可用悬赏任务
2. **接取/完成/领奖**：完整的任务生命周期
3. **原著驱动**：悬赏目标基于原著妖魔，奖励符合原著设定
4. **材料循环**：悬赏奖励包括锻造材料，完善"猎魔→材料→锻造"循环
5. **等级分层**：奴仆级/战将级/统领级悬赏，难度和奖励递增

## 二、核心机制

### 2.1 悬赏任务结构

```javascript
{
    id: "bounty_001",
    name: "清剿独眼魔狼",
    targetEnemy: "one_eyed_wolf",  // 目标妖魔ID
    targetCount: 3,                // 需要击杀数量
    level: "servant",              // servant/warrior/commander
    reward: {
        gold: 30000,
        exp: 500,
        reputation: 10,           // 猎者联盟声望
        items: [                   // 材料奖励
            { itemId: "demon_core", count: 2 },
            { itemId: "wolf_fang", count: 1 }
        ]
    },
    expireDays: 3,                 // 悬赏有效期
    description: "近期独眼魔狼在博城郊外出没，已造成3起伤人事件。猎者联盟悬赏清剿。"
}
```

### 2.2 悬赏等级与奖励

| 等级 | 目标妖魔 | 击杀数 | 金币奖励 | 经验奖励 | 声望 | 材料奖励 |
|------|---------|-------|---------|---------|------|---------|
| 奴仆级 | 奴仆级妖魔 | 2-5只 | 1-5万 | 200-500 | 5-10 | 基础材料 |
| 战将级 | 战将级妖魔 | 1-3只 | 5-20万 | 500-1500 | 15-30 | 中级材料+精魄 |
| 统领级 | 统领级妖魔 | 1只 | 20-50万 | 1500-5000 | 50-100 | 高级材料+稀有物品 |

### 2.3 悬赏刷新机制

- 每天自动刷新3-5个新悬赏
- 已接取的悬赏保留，直到完成或过期
- 玩家可同时接取最多3个悬赏
- 悬赏有效期3天，过期自动消失

### 2.4 悬赏完成判定

- 玩家接取悬赏后，击杀目标妖魔时计数
- 计数达到目标数量后，悬赏状态变为"可领奖"
- 玩家返回猎者联盟悬赏板领取奖励
- 领取后悬赏完成，从列表移除

## 三、UI设计

### 3.1 悬赏板界面
- 左侧：当前可用悬赏列表（显示等级、目标、奖励、有效期）
- 右侧：选中悬赏详情（描述、目标进度、接取/领奖按钮）
- 顶部：已接取悬赏数量（x/3）

### 3.2 悬赏状态
- 可接取：显示"接取"按钮
- 进行中：显示击杀进度（2/3）
- 可领奖：显示"领取奖励"按钮（高亮）
- 已过期：显示"已过期"（灰色）

### 3.3 入口
- 猎者联盟大厅动作"📜 悬赏板"
- 点击后打开悬赏界面

---

## 四、原著契合度

- 猎者联盟是原著核心组织，悬赏任务是猎者主要收入来源
- 悬赏目标基于原著妖魔（独眼魔狼、巨眼猩鼠、骨刺狰等）
- 奖励符合原著设定（金币、材料、声望）
- 战将级以上悬赏需要相应实力，符合原著等级体系
