# v3.6.0 元素反应系统深化设计

> 版本：v3.6.0 | 状态：设计中（待对齐） | 日期：2026-09-07

## 一、现状分析

### 已有实现
- **4种元素反应**：感电（雷+水）、融化（火+冰）、蒸汽（火+水）、泥泞（土+水）
- 反应触发在 `battle.js checkElementReactions()` 中
- AI会优先选择能触发反应的技能
- 元素克制系统已有

### 存在问题
1. **反应种类少**：只有4种，冰+雷、风+元素等组合无反应
2. **反应无伤害**：除感电有DOT外，其他反应只改变状态，没有爆发伤害
3. **视觉反馈弱**：只有战斗日志文字，没有伤害数字或特效
4. **玩家无引导**：帮助文档没有元素反应说明，玩家不知道有这个机制
5. **反应逻辑分散**：checkElementReactions在battle.js中（约1700行），不利于维护

## 二、设计目标

1. **扩充反应类型**：从4种增加到8-10种，覆盖主要元素组合
2. **反应造成伤害**：每次元素反应触发额外伤害，提升策略深度
3. **强化视觉反馈**：战斗日志高亮+伤害数字显示
4. **玩家可感知**：帮助文档添加元素反应表，战斗中显示目标元素状态
5. **架构优化**：元素反应逻辑独立为模块，便于扩展

## 三、元素反应表

### 核心反应（8种）

| 反应名 | 触发条件 | 效果 | 伤害倍率 |
|--------|----------|------|----------|
| ⚡ 感电 | 雷 + 水(湿润) | 持续电击伤害，2回合 | 1.0x攻击力 |
| 🔥 融化 | 火 + 冰(冻结) | 解除冻结，本回合火伤+50% | 1.5x攻击力 |
| 💨 蒸汽 | 火 + 水(湿润) | 命中率-30%，2回合 | 0.8x攻击力 |
| 🪨 泥泞 | 土 + 水(湿润) | 速度-50%，2回合 | 0.6x攻击力 |
| ❄️ 超导 | 冰 + 雷(麻痹) | 防御-30%，3回合 | 1.2x攻击力 |
| 🌪️ 扩散 | 风 + 任意元素 | 将元素扩散到全体敌人 | 0.5x攻击力 |
| 💥 爆裂 | 火 + 土(石化) | 解除石化，造成范围伤害 | 2.0x攻击力 |
| ⚡ 静电 | 雷 + 冰(冻结) | 解除冻结，造成麻痹 | 1.0x攻击力 |

### 反应优先级
当多个反应可同时触发时，按伤害倍率从高到低选择：
爆裂(2.0) > 融化(1.5) > 超导(1.2) > 感电/静电(1.0) > 蒸汽(0.8) > 泥泞(0.6) > 扩散(0.5)

## 四、实施方案

### P0：反应伤害+视觉反馈（核心）
1. 修改 `checkElementReactions`，每次反应触发额外伤害
2. 战斗日志中元素反应用特殊颜色高亮（如紫色/金色）
3. 伤害数字显示反应伤害（如"⚡感电 +45"）

### P1：扩充反应类型
1. 新增超导、扩散、爆裂、静电4种反应
2. 为对应技能添加元素附着（确保冰系技能能冻结、雷系能麻痹等）

### P2：玩家引导+架构优化
1. 帮助文档添加元素反应表
2. 战斗UI显示目标当前元素状态（图标+名称）
3. 元素反应逻辑提取为独立模块 `battle-element-reactions.js`

## 五、数值平衡

- 反应伤害基于施法者攻击力，不享受暴击
- 反应伤害无视防御（固定伤害）
- 同一目标每回合最多触发1次反应
- 扩散反应只对敌方全体有效，不触发二次反应

## 六、与原著的契合度

《全职法师》中元素魔法确实有组合效果：
- 雷系在水中威力大增（感电）
- 火系融化冰系（融化）
- 土系在水中变成泥浆（泥泞）
- 风系可以扩散其他元素（扩散）

这些反应符合原著设定，不违背"小说驱动"原则。
