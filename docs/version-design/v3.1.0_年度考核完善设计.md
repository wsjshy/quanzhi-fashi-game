# v3.1.0 年度考核完善设计

> 版本：v3.1.0 | 状态：设计中 | 最后更新：2026-08-22

## 一、背景与问题

年度考核（big_event_annual_exam）是博城篇中期重要事件，但当前实现存在以下问题：

1. **评分计算逻辑缺失**：phase_2_result和phase_4_result仅提示"系统将根据你的等级、精神力和心境计算评分"，但实际没有实现评分计算
2. **星尘魔器分配过于简单**：starDustAssignByRank的auto评级仅按玩家等级（Lv15+=S），没有综合星感石和释放考核表现
3. **释放考核繁琐**：phase_3_release是battle类型打训练假人，对考核场景来说过于冗长
4. **奖励不完整**：仅有星尘魔器分配，缺少经验、金币、物品等基础奖励
5. **评级不透明**：玩家看不到具体分数和评级依据

## 二、设计目标

1. **完整的评分计算**：星感石测试（60%）+ 释放考核（40%），综合等级、精神力、心境、准备表现
2. **释放考核简化**：改为自动评分（根据技能数量和等级），可选战斗验证
3. **完整奖励发放**：按评级发放经验、金币、星尘魔器、物品
4. **评级透明化**：显示具体分数、各项得分、评级依据
5. **向后兼容**：旧存档和已有流程不受影响

## 三、评分计算设计

### 3.1 星感石测试评分（0-100分，权重60%）

```
基础分 = min(100, 等级 * 5)
精神力加成 = min(30, spirit * 2)
心境加成 = min(20, composure * 0.3)
准备加成 = {
  认真准备: +10
  和莫凡聊天: +5
  和穆白聊天: +5
  暗中观察: +5（但获得暗石线索）
}
暗石重考加成 = +15（如果发现暗石并重考）

星感石得分 = min(100, 基础分 + 精神力加成 + 心境加成 + 准备加成 + 暗石加成)
```

### 3.2 释放考核评分（0-100分，权重40%）

```
基础分 = min(80, 等级 * 4)
技能加成 = min(20, 已学技能数量 * 3)
心境加成 = min(15, composure * 0.2)
元素等级加成 = min(15, 最高元素等级 * 2)

释放考核得分 = min(100, 基础分 + 技能加成 + 心境加成 + 元素等级加成)
```

### 3.3 综合评分与评级

```
综合评分 = 星感石得分 * 0.6 + 释放考核得分 * 0.4

评级：
- S级：综合评分 >= 90
- A级：综合评分 >= 80
- B级：综合评分 >= 70
- C级：综合评分 >= 60
- D级：综合评分 < 60
```

### 3.4 评级展示

在phase_4_result中显示：
```
年度考核成绩公布

星感石测试：XX分（基础XX + 精神力XX + 心境XX + 准备XX）
释放考核：XX分（基础XX + 技能XX + 心境XX + 元素等级XX）
综合评分：XX分
评级：S/A/B/C/D

薛木生老师："XXX"（根据评级的评语）
```

## 四、释放考核简化

将phase_3_release从battle类型改为auto类型，自动计算释放考核得分。

**原因**：
1. 年度考核是剧情事件，不是战斗挑战
2. 打训练假人没有挑战性，反而拖慢节奏
3. 自动评分更符合"考核"的叙事感

**保留选项**：如果玩家想实际战斗验证，可以在debug模式中保留battle版本。

## 五、奖励发放设计

### 5.1 按评级奖励

| 评级 | 经验 | 金币 | 星尘魔器 | 其他 |
|------|------|------|----------|------|
| S | 200 | 300 | 高品质，30天 | 穆氏招揽触发 + 物品：星感石碎片 |
| A | 150 | 200 | 中品质，20天 | 穆氏招揽触发 |
| B | 100 | 100 | 普通，15天 | - |
| C | 50 | 50 | 无 | - |
| D | 20 | 20 | 无 | - |

### 5.2 星尘魔器分配

调用StarDustArtifactSystem.assignByRank(Player, rank, modifiers)
- S级：quality='high', days=30
- A级：quality='medium', days=20
- B级：quality='normal', days=15
- C/D级：不分配

### 5.3 穆氏招揽触发条件

S级或A级触发phase_5_recruit（穆氏招揽）
B级及以下跳过招揽，直接进入phase_6_end
