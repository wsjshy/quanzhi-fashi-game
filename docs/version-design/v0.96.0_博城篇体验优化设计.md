# v0.96.0 博城篇体验优化设计

## 一、优化目标

聚焦博城篇（第1-7章），把体验拉满，把流程完全摸透。
确保从觉醒仪式到离开博城的完整流程无断点、无卡点、有反馈、有引导。

## 二、阶段一：流程顺畅化（P0）

### 2.1 章节解锁逻辑梳理

**问题**：10个章节的解锁条件全部为"无"，玩家不知道什么时候进入下一章。

**方案**：为博城篇7个章节设置明确的解锁条件：

| 章节 | 解锁条件 |
|------|---------|
| 觉醒期 | 默认解锁 |
| 校园期 | 完成觉醒仪式任务 |
| 雪峰山历练 | 完成初识魔法任务 + 等级≥3 |
| 博城暗流 | 完成雪峰山历练任务 或 等级≥5 |
| 博城灾难 | 完成挑战幽狼兽任务 + 等级≥7 |
| 地圣泉 | 完成魔法决斗任务 |
| 离开博城 | 完成第二系觉醒任务 |

**实施**：在chapters.js中为每个章节添加unlockCondition字段，在story-chapter.js中实现解锁检查逻辑。

### 2.2 博城灾难触发条件明确化

**问题**：博城灾难大事件触发条件为"无"，玩家不知道如何触发。

**方案**：设置明确的触发前置：
- 完成"挑战幽狼兽"任务
- 等级≥7
- 在天澜魔法高中或博城市街有概率触发预警事件

**实施**：在big-events.js中设置triggerCondition，在game.js中实现触发检查。

### 2.3 行动反馈补充

**问题**：修炼/升级/逛街/酒馆等行动缺乏即时反馈。

**方案**：
- 修炼完成：显示"修炼完成！经验+X，状态：XXX"
- 升级：显示"升级到Lv.X！获得2属性点，全属性提升"
- 逛街：无论是否触发事件，都显示"你在博城市街逛了一圈，消耗了X体力"
- 酒馆：显示"你在酒馆喝了一杯，听到了一些传闻..."或触发猎魔任务

**实施**：在game.js的对应行动函数末尾添加UI.showMessage调用。

### 2.4 消息延迟修复

**问题**：消息弹窗延迟显示，修炼消息在后续操作后才弹出。

**方案**：检查消息队列的渲染逻辑，确保消息即时显示。
可能原因：消息被添加到队列但渲染函数未被调用，或渲染被其他操作覆盖。

**实施**：在game.js中检查showMessage和消息队列的调用时机。

### 2.5 新手引导优化

**问题**：觉醒后缺乏明确的目标引导，玩家不知道下一步做什么。

**方案**：
- 觉醒完成后显示"下一步：去找唐月老师了解魔法"
- 初识魔法任务完成后显示"下一步：去修炼提升等级，或去市街探索"
- 在主界面添加"当前目标"提示区域

**实施**：在quest.js或game.js中添加任务完成后的下一步提示。

## 三、阶段二：体验提升（P1）

### 3.1 NPC对话扩充
- 每个主要NPC至少5-10条对话
- 包含分支选择和条件触发
- 莫凡/唐月/穆宁雪优先

### 3.2 地点专属事件
- 确保随机事件正确绑定到地点
- 每个地点至少3个专属事件

### 3.3 任务多样化
- 增加采集/探索/解谜类任务
- 降低击杀对话占比

### 3.4 UI引导优化
- 事件与情报面板低等级时显示"等级X解锁"
- 未解锁地点显示解锁条件

### 3.5 酒馆/逛街功能完善
- 酒馆有概率触发猎魔任务或获得情报
- 逛街有概率触发随机事件或遇到NPC
