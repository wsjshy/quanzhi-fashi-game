## 一、为什么做这个

### 1.1 扩展关系网络
v0.63.0实现了穆白×张小侯的NPC间联动，验证了关系网络机制的可行性。现在扩展到原著中更核心的师生关系——唐月×穆宁雪。

### 1.2 原著背景
- 唐月是天澜魔法高中的实习老师，负责魔法实践课
- 穆宁雪是天澜魔法高中的学生，冰系天才
- 两人是师生关系，唐月对穆宁雪的天赋既欣赏又担忧（冰系的极致之路危险）

### 1.3 事件触发优化
黑盒测试发现：关系事件触发依赖NPC encounter随机性，玩家可能多次修炼都遇不到目标NPC。需要优化：
- 关系达到事件阈值后，提高该NPC的encounter概率
- 确保玩家能在合理次数内触发关系事件

## 二、事件触发优化（基础设施）

### 2.1 问题
- NPC encounter概率是固定的（0.2-0.6），与玩家关系无关
- 关系达到阈值后，玩家可能多次修炼都遇不到目标NPC
- 每个NPC每天最多遇到一次，进一步降低触发概率

### 2.2 优化方案
在`_checkNPCEncounter`方法中，检查该NPC是否有满足条件的关系事件。如果有，将encounter概率提高到0.8（确保大概率遇到）。

```javascript
// 检查该NPC是否有满足条件的关系事件
const hasPendingRelationEvent = this._hasPendingRelationEvent(npcId);
const encounterChance = hasPendingRelationEvent ? 0.8 : timeSlot.chance;
if (Math.random() > encounterChance) continue;
```

### 2.3 `_hasPendingRelationEvent`方法
遍历所有事件，检查是否有：
- npcId匹配
- minRelationship/minRelationships满足
- requireFlag满足（如果有）
- notFlag满足（事件未完成）
- activities为空或匹配

如果有满足条件的事件，返回true。
