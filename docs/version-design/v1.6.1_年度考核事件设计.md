# 年度考核事件 · 详细设计文档

> **版本**：v1.0 设计稿
> **对应原著**：第21-30章
> **优先级**：P1（博城篇中期重要事件，玩家参与感强）
> **设计原则**：玩家不是旁观者，而是考核的参与者；不是复刻莫凡的逆袭，而是创造玩家自己的考核故事

---

## 一、设计目标

1. **还原原著名场面**：星感石测试、魔法释放考核、暗石陷害、穆卓云招揽
2. **玩家有意义的选择**：隐藏实力/全力发挥、是否揭发陷害、是否接受招揽
3. **多结局重玩价值**：S/A/B/C/D不同评级，影响后续资源和剧情
4. **深化NPC关系**：与莫凡、穆白、唐月、穆卓云的互动影响关系
5. **引入新机制**：心境/定力系统（紧张影响释放成功率）、考核评分系统

---

## 二、触发条件与入口

### 触发条件
- 玩家等级 ≥ Lv.2
- 游戏内日期到达"考核日"（开学后约30天）
- 或通过debug面板快速触发

### 入口
- 天澜魔法高中 → 事件与情报 → "年度考核"
- 或 薛木生老师对话 → "参加年度考核"

---

## 三、事件结构（5阶段）

### 阶段1：考核前准备

**场景**：天澜魔法高中操场
**内容**：
- 薛木生老师讲解考核规则
- 穆宁雪到校演讲（全校轰动）
- 赵坤三挖苦莫凡/玩家（可选互动）
- 玩家可以选择：
  - 认真准备（+心境，释放成功率+10%）
  - 和同学聊天（+NPC关系，但无准备加成）
  - 暗中观察（有概率发现暗石陷害的线索）

**玩家选择与后果**：
| 选择 | 后果 |
|------|------|
| 认真准备 | 心境+，释放考核成功率+10% |
| 和莫凡聊天 | 莫凡好感+，了解莫凡的计划 |
| 和穆白聊天 | 穆白好感+（如果关系好），或被冷落 |
| 暗中观察 | 有30%概率发现"星感石似乎被动过手脚"的线索 |

---

### 阶段2：星感石测试（修为考核）

**场景**：考核现场，星感石
**机制**：
- 玩家有3次机会，取最好成绩
- 每次测试根据玩家等级+精神力+随机因素给出评分
- 评分等级：S（光芒外溢）/ A（明亮）/ B（正常）/ C（微弱）/ D（几乎无光）
- 心境影响：紧张会降低表现（-1级评分概率）

**评分计算**：
- 基础评分 = 玩家等级对应的修为表现
- Lv.1-2：C-B级
- Lv.3-4：B-A级
- Lv.5+：A-S级
- 心境加成：准备充分+10%概率升一级
- 紧张debuff：未准备+15%概率降一级

**暗石陷害事件**：
- 如果玩家与穆白关系差（好感<0），有概率被暗石陷害
- 陷害效果：第一次测试成绩强制降2级
- 如果玩家在阶段1发现了线索，可以选择：
  - 提醒考官（避免陷害，但穆白好感-）
  - 默默忍受（第二次/第三次测试正常，穆白好感不变）
  - 以牙还牙（需要特殊道具，反向陷害穆白）

**玩家选择与后果**：
| 选择 | 后果 |
|------|------|
| 全力发挥 | 获得真实评分，可能引起关注 |
| 隐藏实力 | 评分降1级，但不引人注目（扮猪吃老虎） |
| 发现陷害后提醒考官 | 避免陷害，穆白好感-10，唐月好感+5 |
| 发现陷害后默默忍受 | 第二次测试正常，穆白好感不变 |

---

### 阶段3：魔法释放考核

**场景**：考核现场，木偶靶
**机制**：
- 只有星感石测试B级以上的玩家可以参加
- 玩家释放自己的初阶魔法，考官根据以下维度评分：
  - 完成度（是否完整释放）
  - 速度（引导时间）
  - 威力（伤害值）
  - 稳定性（是否失控）
- 心境影响：紧张有概率释放失败（需要重测）
- 3次机会，取最好成绩

**评分标准**：
- S级：完美释放，威力超常，速度极快
- A级：顺利释放，威力不错
- B级：成功释放，中规中矩
- C级：勉强释放，威力不足
- 失败：引导中断，需要重测

**NPC互动**：
- 许昭霆释放雷印（S级，全校第一的有力竞争者）
- 穆白释放冰蔓（B级，世家子弟的稳定表现）
- 周敏释放火滋（B级，火系尖子生）
- 莫凡释放火滋（A级，如果玩家和莫凡关系好可以看到）

---

### 阶段4：成绩公布与暗石事件

**场景**：考核现场，成绩公布
**内容**：
- 公布综合评分（星感石60% + 释放考核40%）
- 如果发生了暗石陷害且玩家未揭发：
  - 唐月老师站出来质疑星感石有问题
  - 校长要求检查，发现暗石
  - 穆贺把事情推给设备故障，保住面子
  - 玩家可以选择重考（成绩重新计算）
- 如果玩家揭发了陷害：
  - 直接进入调查，穆白/穆贺受到处分
  - 玩家获得"正义"声望+
- 如果没有陷害事件：
  - 直接公布成绩

**综合评分等级**：
| 等级 | 奖励 | 后续影响 |
|------|------|---------|
| S | 尖子班资格+星尘魔器30天+全校第一声望 | 穆卓云招揽、穆白敌意、莫凡认可 |
| A | 尖子班资格+星尘魔器15天 | 正常资源分配 |
| B | 普通班+少量金币 | 无特殊 |
| C | 普通班+警告 | 需要努力修炼 |
| D | 留校察看 | 可能被请离（需要后续任务挽回） |

---

### 阶段5：穆卓云招揽（S/A级玩家触发）

**场景**：考核后，穆卓云单独找玩家谈话
**内容**：
- 穆卓云欣赏玩家的天赋，提出招揽
- 招揽条件：加入穆氏，获得星尘魔器+高级导师+修炼资源
- 玩家选择：

| 选择 | 后果 |
|------|------|
| 接受招揽 | 穆氏声望+20，获得星尘魔器，莫凡好感-10，后续穆氏剧情线 |
| 婉拒 | 穆卓云好感-5，但保持独立，莫凡好感+5 |
| 怒斥拒绝（需要勇气高） | 穆卓云大怒，穆氏声望-20，莫凡好感+15，触发决斗约定 |

**决斗约定**：
- 如果玩家怒斥拒绝，穆卓云提出让宇昂和玩家决斗
- 玩家可以接受或拒绝
- 接受：触发后续决斗剧情（地圣泉决斗事件）
- 拒绝：被穆氏看不起，但避免冲突

## 四、心境/定力系统（新机制）

### 设计说明
原著中张小侯因为紧张释放失败，唐月说"合格的魔法师不仅要有扎实的功底，还要有处事不惊的心境"。

### 机制
- 玩家有"心境"属性（初始50，范围0-100）
- 心境影响：技能释放成功率、考核表现、战斗中恐惧消退速度
- 提升心境的方式：
  - 认真准备（+10）
  - 经历战斗（每次战斗+2）
  - 特定天赋加成（如"处事不惊"天赋）
  - 唐月老师的指导（+15）
- 降低心境的方式：
  - 被陷害/被威胁（-10）
  - 面对强大妖魔（恐惧debuff）
  - 连续失败（-5每次）

### 在考核中的应用
- 心境≥70：释放考核成功率+15%，有概率超常发挥（+1级评分）
- 心境50-70：正常表现
- 心境<50：释放考核成功率-15%，有概率发挥失常（-1级评分）

## 五、与现有系统的集成

### 需要新增的系统
1. **考核评分系统**：多维度评分→等级→奖励
2. **心境/定力属性**：影响释放成功率和表现
3. **暗石陷害事件**：随机/条件触发的剧情分支

### 可以复用的系统
- 大事件系统（big-events.js，多阶段+分支）
- NPC关系系统（npc-state.js）
- 声望系统
- 战斗系统（释放考核可以用简化版战斗）
- 任务系统（考核后触发尖子班/星尘魔器任务）
