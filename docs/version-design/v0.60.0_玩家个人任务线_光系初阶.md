# v0.60.0 玩家个人任务线（光系初阶）

> 版本：v0.60.0
> 日期：2026-08-15
> 类型：内容开发
> 前置：v0.57-v0.59 火系/冰系/风系（框架已验证）

---

## 一、设计目标

扩展光系玩家专属任务线，围绕光系"净化、守护、感悟"的特点展开，深化与白阳（光系同学）的关系。

---

## 二、任务线设计

### 任务1：光明的净化（quest_light_purify）

- **触发条件**：光系玩家，等级≥5
- **发布者**：白阳
- **类型**：个人任务
- **目标**：修炼5次（光系需要净化心灵）
- **奖励**：经验100，金币50
- **剧情**：白阳注意到你在修炼光系时心有杂念，建议你多加练习。"光系的力量来自纯净，心不净，光不纯。"

### 任务2：光系的较量（quest_light_duel）

- **触发条件**：光系玩家，等级≥8，完成任务1
- **发布者**：白阳
- **类型**：个人任务
- **目标**：与白阳对话1次
- **奖励**：经验150，金币100
- **剧情**：白阳注意到你的光系进步，主动找你切磋。"你的光系...有点意思。要不要比比看，谁的光更纯？"

### 任务3：光明的感悟（quest_light_insight）

- **触发条件**：光系玩家，等级≥12，完成任务2
- **发布者**：白阳
- **类型**：个人任务
- **目标**：图书馆3次 + 修炼10次
- **奖励**：经验300，金币200，技能点1
- **剧情**：白阳建议你在图书馆查阅光系典籍，结合修炼感悟光明的真谛。"光的极致不是明亮，是驱散黑暗的勇气。"

---

## 三、技术实现

- 复用v0.57.0个人任务框架
- 任务数据添加到quests.js
- trigger字段：element: "light", minLevel, prerequisites
- 光系任务侧重修炼（净化心灵）

---

## 四、验收标准

1. 光系玩家等级5时自动触发"光明的净化"
2. 完成任务1后等级8触发"光系的较量"
3. 完成任务2后等级12触发"光明的感悟"
4. 非光系玩家不触发
5. 任务奖励正常发放
6. node --check语法通过
