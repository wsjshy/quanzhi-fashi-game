## 二、核心机制

### 2.1 触发条件
- 游戏第7天自动触发（或玩家等级达到5级）
- 在学校地点出现"📝 年度考核"特殊动作
- 点击后进入考核事件

### 2.2 考核流程

**阶段1：考核准备**
- 唐月老师介绍考核规则
- 玩家选择考核使用的系别（主修系/次修系）
- 选择考核策略（全力输出/精细控制/创意组合）

**阶段2：魔法释放**
- 玩家释放3次魔法
- 每次释放根据玩家属性、技能等级、策略计算得分
- 有小概率触发"超常发挥"或"失误"

**阶段3：评分与结果**
- 综合3次释放得分，计算总评
- 评分等级：S/A/B/C/D
- 根据评分获得不同奖励
- 触发对应剧情对话（唐月/穆白/其他学生的反应）

### 2.3 评分标准

| 评分 | 分数范围 | 说明 |
|------|---------|------|
| S | 90-100 | 完美释放，远超同年级水平 |
| A | 75-89 | 优秀释放，年级前列 |
| B | 60-74 | 良好释放，平均水平以上 |
| C | 40-59 | 及格释放，达到基本要求 |
| D | 0-39 | 不及格，需要补考 |

**评分维度**：
- 威力（40%）：基于魔法伤害
- 控制力（30%）：基于精神力和技能等级
- 稳定性（20%）：基于释放成功率
- 创意（10%）：基于策略选择和系别组合

### 2.4 奖励

| 评分 | 金币 | 经验 | 声望 | 特殊奖励 |
|------|------|------|------|---------|
| S | 50000 | 1000 | 学校+30 | 星尘魔器（7天）+ 唐月特殊对话 |
| A | 30000 | 700 | 学校+20 | 星尘魔器（3天） |
| B | 15000 | 400 | 学校+10 | 基础修炼资源 |
| C | 5000 | 200 | 学校+5 | 无 |
| D | 0 | 50 | 学校-5 | 补考提示 |

### 2.5 剧情分支

- **S级**：唐月震惊，穆白不服，全校议论。解锁后续剧情
- **A级**：唐月赞赏，穆白认可
- **B级**：正常表现，无人特别关注
- **C/D级**：唐月鼓励，建议多加练习

## 三、UI设计

### 3.1 考核准备界面
- 考核规则说明
- 系别选择（主修/次修）
- 策略选择（全力/控制/创意）
- 开始考核按钮

### 3.2 考核进行界面
- 当前是第几次释放（1/3）
- 释放动画/效果描述
- 本次得分和评价
- 累计得分

### 3.3 考核结果界面
- 总评分（大字显示S/A/B/C/D）
- 各维度得分明细
- 获得奖励
- 剧情对话/反应
- 确定按钮
