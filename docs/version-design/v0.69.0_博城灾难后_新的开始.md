## 一、为什么做这个

### 1.1 灾难后的情感过渡
博城灾难是重大事件，灾难后需要有情感过渡和剧情收尾。玩家在灾难中的表现应该得到体现和反馈。

### 1.2 玩家影响力的具象化
玩家在博城灾难三阶段中的选择（发现异常→预警准备→灾难降临）应该在灾难后得到具象化的反馈：
- 不同的结局定位（前线英雄/疏散英雄/揭秘英雄）
- 不同的准备程度（全面备战/自我提升/秘密调查/无准备）
- NPC对玩家的不同态度

### 1.3 为新地图铺垫
博城灾难后，玩家将离开博城，前往更广阔的世界。本版本作为过渡，为新地图和新剧情做铺垫。

## 二、事件设计

### 2.1 事件：灾难后的黎明

**触发条件**：
- requireFlag: bd_disaster_complete（灾难后任务完成）
- notFlag: bocheng_aftermath_event_done
- minLevel: 18
- weight: 40
- npcId: tang_yue

**事件描述**：
清晨的阳光照在博城的废墟上。空气中还弥漫着烟尘和魔法残留的气息。唐月老师站在临时安置点前，看到你走来，她的眼睛有些红肿，但表情坚定："你来了。昨晚...很多人活了下来，很多人没有。但你做了你能做的一切。"她递给你一封信，"这是学校的推荐信。博城已经不适合继续学习了，你应该去更广阔的地方。"

**选择分支（3个）**：

#### 选择1：询问博城的未来
- effects: { setFlag: ["bd_ask_future", "bocheng_aftermath_event_done"], reputation: 5 }
- resultText: 你问："博城...以后怎么办？"唐月望向废墟："会重建的。博城人不会被打垮。但你还年轻，不该被困在这里。去外面看看吧，变得更强，然后回来。"声望+5，你了解了博城的未来

#### 选择2：询问黑教廷的情况
- effects: { setFlag: ["bd_ask_blackchurch", "bocheng_aftermath_event_done"], npcOpinion: { tang_yue: 5 } }
- resultText: 你问："黑教廷...会被抓住吗？"唐月的表情变得严肃："他们跑了。但圣裁院已经介入调查。你如果有什么线索...可以告诉我。"唐月好感+5，黑教廷剧情线开启

#### 选择3：接受推荐信，准备离开
- effects: { setFlag: ["bd_accept_letter", "bocheng_aftermath_event_done"], exp: 150 }
- resultText: 你接过推荐信："我会的。"唐月拍了拍你的肩膀："去吧。记住，魔法的意义不是力量，而是守护。"经验+150，你准备离开博城

## 三、结局差异化体现

### 3.1 基于灾难结局的对话差异
事件的基础文本相同，但唐月的对话会根据玩家的灾难结局有细微差异：

**前线英雄（bd_hero_frontline）**：
- 唐月会提到"你在前线的表现，很多老师都看到了"
- 额外声望+5

**疏散英雄（bd_hero_evacuation）**：
- 唐月会提到"很多孩子因为你活了下来"
- 额外唐月好感+5

**揭秘英雄（bd_hero_investigate）**：
- 唐月会提到"你发现的线索很重要，圣裁院在跟进"
- 额外经验+100

### 3.2 技术实现说明
由于事件文本为固定内容，结局差异化通过以下方式实现：
1. 事件选择设置基础flag
2. 后续剧情根据玩家的组合flag给出差异化内容
3. 当前版本先实现基础事件和flag，后续版本可扩展文本差异化

## 五、长期影响（新地图铺垫）

### 5.1 离开博城
玩家完成本版本后，将获得离开博城的条件。后续版本可以开放新地图（古都、上海等）。

### 5.2 黑教廷剧情线
如果玩家选择"询问黑教廷的情况"（bd_ask_blackchurch）或有揭秘英雄结局（bd_hero_investigate），将开启黑教廷长期剧情线。

### 5.3 声望和人际关系
玩家在博城灾难中的表现将影响：
- 学校声望（推荐信的分量）
- 唐月等NPC的好感
- 后续遇到博城出身的NPC时的特殊对话
