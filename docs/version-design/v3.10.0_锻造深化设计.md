> **前置版本**：v3.9.0锻造系统

---

## 一、设计目标

v3.9.0实现了基础锻造系统，但存在以下问题：
1. 锻造品质完全随机，玩家无法影响结果，缺乏追求感
2. 锻造出不满意的词缀只能丢弃，无法补救
3. 玩家不知道材料从哪里获取

v3.10.0通过三个功能深化锻造系统：
1. **精魄注入**：锻造时消耗精魄提升高品质概率（符合原著精魄设定）
2. **装备重铸**：消耗材料重新随机词缀，给不满意的装备第二次机会
3. **材料来源提示**：锻造界面显示每种材料的获取来源

---

## 二、精魄注入系统

### 2.1 设计思路
原著中精魄是妖魔的灵魂结晶，蕴含强大能量。锻造时注入精魄可以提升魔具品质。

### 2.2 精魄类型与效果

| 精魄类型 | 效果 | 消耗数量 |
|---------|------|---------|
| 奴仆级精魄 | 优秀概率+15%，普通概率-15% | 1个 |
| 战将级精魄 | 稀有概率+10%，普通概率-10% | 1个 |
| 统领级精魄 | 史诗概率+5%，稀有概率+5%，普通概率-10% | 1个 |

### 2.3 使用方式
- 锻造界面增加"精魄注入"选项
- 玩家可选择注入1个精魄（不注入/奴仆级/战将级/统领级）
- 注入后品质概率重新计算，总和归一化
- 精魄在锻造时消耗

### 2.4 概率计算示例
基础概率：普通50%、优秀30%、稀有15%、史诗5%

注入奴仆级精魄后：
- 普通：50% - 15% = 35%
- 优秀：30% + 15% = 45%
- 稀有：15%
- 史诗：5%
- 总和：100% ✓

## 三、装备重铸系统

### 3.1 设计思路
玩家锻造出装备后，如果对词缀不满意，可以消耗材料重新随机词缀。

### 3.2 重铸规则
- 只能重铸背包中的装备（已装备的需先卸下）
- 重铸消耗：对应装备的基础材料x1 + 金币（装备售价的50%）
- 重铸后品质和词缀全部重新随机
- 重铸有小概率提升品质（+5%概率提升一档），大概率保持同品质
- 重铸不会降低品质

### 3.3 重铸示例
- 普通皮甲重铸：妖魔精核x1 + 草药x1 + 100金
- 重铸后：70%保持普通，25%变优秀，5%变稀有
- 优秀皮甲重铸：妖魔精核x1 + 草药x1 + 100金
- 重铸后：70%保持优秀，25%变稀有，5%变史诗

### 3.4 UI设计
- 背包界面增加"重铸"按钮（仅装备类物品显示）
- 点击后弹出重铸确认框，显示消耗和可能结果
- 确认后执行重铸，显示新的品质和词缀

## 四、材料来源提示

### 4.1 设计思路
玩家在锻造界面看到需要某种材料，但不知道去哪里获取。增加材料来源提示。

### 4.2 实现方式
- 每种材料配置`source`字段，说明获取来源
- 锻造界面鼠标悬停材料时显示tooltip
- 或在材料名称旁边显示小图标，点击显示来源

### 4.3 材料来源示例
| 材料 | 来源 |
|------|------|
| 妖魔精核 | 奴仆级妖魔掉落（独狼兽、山猿等） |
| 魔狼獠牙 | 魔狼类妖魔掉落 |
| 骨刺 | 骨刺狰掉落 |
| 冰晶石 | 冰系妖魔掉落/商店购买 |
| 精英核心 | 精英妖魔掉落 |
| 魔法水晶 | 商店购买/高级妖魔掉落 |
