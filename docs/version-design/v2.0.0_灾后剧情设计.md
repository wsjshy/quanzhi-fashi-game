# v2.0.0 灾后剧情设计

> 版本：v2.0.0 | 日期：2026-08-18 | 状态：设计中，待对齐确认

## 一、设计目标

博城灾难结束后，玩家面临灾后的审判、重建和去留抉择。这是博城篇的收尾，也是连接下一篇章（古都篇）的过渡。让玩家感受到灾难后的沉重和未来的无限可能。

### 原文依据
- 灾后博城荒凉，开始重建
- 黑教廷信息公开，审判会高层接手调查
- 唐月把信息递交审判会
- 斩空让莫凡去古都进修
- 玩家作为独立主角，有自己的选择

## 二、核心内容

### 2.1 灾后审判系统

**触发**：博城灾难结束后自动触发

**流程**：
1. 审判会调查员来到博城，询问灾难经过
2. 玩家可以选择提供多少证据（黑教廷徽章/宇昂身份/地圣泉守护等）
3. 根据提供的证据，审判会给出不同的调查结果
4. 玩家获得审判会声望和奖励

**证据类型**：
- 黑教廷徽章（击败宇昂/黑教廷执事获得）
- 宇昂身份确认（追击宇昂线）
- 地圣泉守护证明（地圣泉守护者结局）
- 暴躁之泉线索（提前识破阴谋）
- 阴谋调查报告（调查等级>50）

**审判结果**：
| 证据数量 | 结果 | 奖励 |
|---------|------|------|
| 0-1 | 审判会仅记录，无深入调查 | 基础奖励 |
| 2-3 | 审判会展开调查，穆氏被问询 | 审判会声望+20 |
| 4-5 | 审判会深入调查，黑教廷据点被端 | 审判会声望+50，稀有物品 |

### 2.2 去留抉择

**触发**：审判结束后，玩家面临选择

**选项**：
1. **留博城重建**：参与灾后重建，获得博城声望，解锁重建任务线
2. **去古都进修**：跟随斩空的推荐去古都（西安），解锁古都篇前置
3. **去明珠学府**：去上海明珠学府进修，解锁明珠篇前置
4. **暂时不定**：继续在博城探索，后续再决定

**影响**：
- 不同选择影响NPC关系（留博城→本地NPC+好感，离开→告别剧情）
- 解锁不同的后续篇章
- 获得不同的初始资源

### 2.3 NPC告别和关系结算

**根据灾难中的表现和关系，NPC有不同的告别对话**：
- 唐月：如果关系好，会特别叮嘱，提供审判会联系方式
- 张小侯：如果关系好，会依依不舍，约定再见
- 穆宁雪：根据关系，冷淡告别或点头致意
- 莫凡：背景NPC，可能在离开时偶遇

**关系结算**：
- 灾难中共同战斗的NPC好感+10
- 灾难中被玩家帮助的NPC好感+15
- 选择离开时，所有博城NPC好感锁定（后续篇章可重逢）

## 三、实施步骤

### 阶段1：灾后审判大事件
1. 新增大事件：big_event_post_disaster_judgment
2. 3-5个阶段：调查员到来→提供证据→审判结果→奖励
3. 根据玩家拥有的证据和flag动态调整

### 阶段2：去留抉择
1. 在审判结束后添加选择阶段
2. 4个选项，每个选项有不同的效果和后续解锁
3. NPC告别对话

### 阶段3：NPC关系结算
1. 根据灾难中的flag和关系调整NPC好感
2. 告别对话（根据关系等级不同）
3. 设置篇章完成flag

### 阶段4：文档和debug
1. 设计文档
2. debug快捷触发灾后剧情
3. 文档同步

## 四、待确认问题

1. **去留抉择的选项**：是否只做"留博城"和"去古都"两个核心选项，还是4个都做？
   - 方案A：2个核心选项（留博城/去古都），更聚焦
   - 方案B：4个选项，更自由

2. **灾后审判的复杂度**：是否需要完整的审判对话，还是简化为证据提交+结果？
   - 方案A：简化版（证据提交→结果→奖励）
   - 方案B：完整版（调查员对话→质询→证据→判决）

3. **版本规模**：v2.0.0是否包含全部3个模块，还是分批？
   - 方案A：全部包含（大版本，博城篇完整收尾）
   - 方案B：先做审判+去留（v2.0.0），NPC告别放v2.0.1

4. **后续篇章解锁**：选择去古都后，是否立即开始古都篇内容？
   - 方案A：只解锁前置，古都篇后续版本开发
   - 方案B：包含古都篇开篇内容
