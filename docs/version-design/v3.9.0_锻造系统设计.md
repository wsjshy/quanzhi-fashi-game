## 一、设计目标

1. **原著驱动**：符合原著中"魔石能源体系"和"精魄炼制魔器"的设定
2. **材料有用**：让妖魔掉落的材料（妖魔精核、骨刺、冰晶石等）有实际用途
3. **装备多样性**：锻造时随机生成品质和词缀，同一件装备每次锻造结果不同
4. **长期目标**：玩家收集材料锻造极品装备，有追求感

---

## 二、核心机制

### 2.1 锻造配方

每个配方包含：
- 产出装备ID
- 所需材料列表（材料ID + 数量）
- 金币消耗
- 解锁条件（等级/剧情进度）

### 2.2 锻造流程

1. 玩家选择配方
2. 检查材料和金币是否足够
3. 消耗材料和金币
4. 随机生成装备品质（普通50%/优秀30%/稀有15%/史诗5%）
5. 根据品质生成词缀
6. 装备放入背包

### 2.3 品质提升（可选，后续版本）

- 消耗精魄可以提升高品质概率
- 奴仆级精魄：优秀概率+10%
- 战将级精魄：稀有概率+10%
- 统领级精魄：史诗概率+5%

## 四、UI设计

### 4.1 入口

- 在博城市街地图添加"🔨 铁匠铺"地点
- 或在商店界面添加"锻造"标签

### 4.2 锻造界面

- 左侧：配方列表（显示装备图标、名称、解锁状态）
- 右侧：选中配方详情
  - 装备预览（基础属性）
  - 所需材料（当前数量/所需数量，不足标红）
  - 金币消耗
  - 品质概率说明
  - "锻造"按钮

### 4.3 锻造结果

- 显示锻造出的装备
- 品质颜色
- 词缀列表
- "放入背包"按钮

## 七、与现有系统的关系

- **装备词缀系统**：复用v3.5.0/v3.8.0的词缀生成逻辑
- **背包系统**：锻造出的装备放入背包，支持实例级词缀
- **材料系统**：消耗妖魔掉落的材料
- **商店系统**：锻造是商店购买之外的另一种装备获取途径
