# v0.74.0 装备强化系统扩展

> 版本：v0.74.0
> 日期：2026-08-16
> 类型：系统扩展 / 经济平衡
> 目标：让精英材料除出售外，还能用于装备强化提高成功率，增加精英狩猎意义和资源管理深度

---

## 一、设计背景

### 1.1 现状
- v0.14.0已有完整装备强化系统：金币消耗、成功率递减、保底机制（连续失败3次必成功）、失败降级
- v0.72.0新增3种精英材料（魔狼骨刺、精英核心、猩鼠尾），目前只有出售价值
- 精英材料缺少除出售外的用途，精英狩猎的长期动力不足

### 1.2 设计目标
- 精英材料用于强化时提供成功率加成，给玩家资源管理选择
- 不改变现有强化系统的核心机制（金币消耗、保底、失败降级）
- 材料是可选辅助，不是必需材料，避免复杂化
- 不同材料提供不同加成，稀有材料加成更高

---

## 二、设计方案

### 2.1 材料加成设计

| 材料 | 出售价格 | 强化成功率加成 | 稀有度 |
|------|----------|----------------|--------|
| 猩鼠尾（rat_tail） | 40金币 | +5% | 普通精英 |
| 魔狼骨刺（wolf_bone_spike） | 50金币 | +8% | 精英 |
| 精英核心（elite_core） | 200金币 | +15% | 稀有精英 |
| 妖魔精核（demon_core） | 50金币 | +3% | 普通材料 |

**加成规则**：
- 每次强化最多使用1个材料
- 材料加成是加法叠加：最终成功率 = 基础成功率 + 材料加成
- 成功率上限95%（避免100%必成失去紧张感）
- 保底机制仍然有效（连续失败3次必成功，与材料无关）

### 2.2 UI设计

在装备界面的强化按钮旁添加材料选择：
- 显示当前可使用的材料列表（玩家拥有的）
- 每个材料显示加成数值
- 玩家点击选择后，强化按钮显示"强化（使用XX，成功率XX%）"
- 不选材料则使用基础成功率

### 2.3 技术实现

**player.js扩展**：
- 新增`enhanceWithMaterial(slot, materialId)`方法
- 计算材料加成后的成功率
- 消耗材料和金币

**ui.js扩展**：
- 强化界面显示可用材料列表
- 材料选择交互
- 显示最终成功率

## 三、平衡验证

### 3.1 经济平衡
- 材料出售 vs 用于强化的选择：玩家需要权衡即时金币 vs 长期装备提升
- 精英核心200金币+15%加成，适合高等级强化（基础成功率低时价值更高）

### 3.2 强化体验
- 低等级强化（成功率>70%）：不需要材料，直接强化
- 高等级强化（成功率<50%）：使用材料提高成功率，减少挫败感
- 保底机制仍然是最终保障
