# v0.72.0 经济系统平衡

> 版本：v0.72.0
> 日期：2026-08-16
> 类型：系统平衡 / 体验优化
> 目标：降低新手期经济压力，让金币获取和消耗更平衡，增加有意义的金币消耗途径

---

## 一、当前经济系统问题

### 1.1 数据分析
- 妖魔金币奖励：65个妖魔，平均236金币，中位数90金币
- 物品价格：129个物品，平均319万金币（被高价物品拉高），中位数8000金币
- 新手期（Lv1-5）：基础药水25-35金币，基础装备100-180金币

### 1.2 问题识别
1. **新手期经济压力**：低等级妖魔金币奖励低（10-30金币），但药水和装备价格不低，新手可能缺钱
2. **金币消耗途径不足**：玩家获得金币后缺少有意义的消耗方式，容易导致金币膨胀
3. **价格分布不均**：部分物品价格过高（1亿金币），可能是测试物品或未平衡
4. **精英材料无用**：精英妖魔掉落的材料（wolf_bone_spike、elite_core等）目前没有用途

### 1.3 设计原则
- **新手友好**：Lv1-10经济压力小，药水和基础装备价格合理
- **渐进消耗**：随着等级提升，金币消耗途径逐渐增加
- **材料有用**：所有掉落材料都有实际用途（出售/制作/强化）
- **原著合理**：价格符合原著世界观（魔法世界的物价水平）

## 二、平衡方案

### 2.1 新手期经济减负

**降低基础消耗品价格**：
- 生命药水：25→20金币
- 魔法药水：35→25金币
- 体力药水：30→20金币
- 净化药水：60→40金币

**降低基础装备价格**：
- 基础法杖：120→80金币
- 基础法袍：100→70金币
- 魔法戒指：180→120金币

**提高低等级妖魔金币奖励**：
- Lv1-3妖魔：金币奖励+50%
- Lv4-6妖魔：金币奖励+30%

### 2.2 增加金币消耗途径

**装备强化系统**（新增）：
- 消耗金币+材料强化装备
- 强化等级：+1到+5
- 强化效果：攻击/防御/生命提升
- 强化费用：基础100金币，每级递增
- 材料：精英妖魔掉落的材料（wolf_bone_spike、elite_core等）

**修炼加速**（新增）：
- 支付金币可加速修炼（获得更多经验）
- 费用：每次50金币，经验+50%

### 2.3 精英材料用途

**材料出售价格**：
- wolf_bone_spike（骨刺）：50金币/个
- spider_silk（蛛丝）：30金币/个
- plant_core（植物核心）：80金币/个
- elite_core（精英核心）：200金币/个
- curse_crystal（诅咒结晶）：100金币/个
- golem_core（石魔核心）：60金币/个
- red_ling_crystal（赤凌晶）：70金币/个
- moon_stone（月能石）：150金币/个
- bewitch_gland（蛊惑腺）：120金币/个
- false_terror_seed（伪怖魔种子）：90金币/个
- evil_qi_core（煞气核心）：80金币/个
- flame_core（烈焰核心）：100金币/个

**材料用于装备强化**：
- 不同材料提供不同强化方向
- 骨刺：强化攻击力
- 蛛丝：强化闪避
- 精英核心：通用强化材料

## 三、技术实现

### 3.1 物品价格调整
修改`items.js`中对应物品的price字段。

### 3.2 妖魔金币奖励调整

### 3.3 材料出售价格
在`items.js`中为材料添加sellPrice字段，或在商店系统中添加材料出售功能。

### 3.4 装备强化系统（后续版本）
- 新增装备强化界面
- 强化逻辑：消耗金币+材料，提升装备属性
- 强化成功率：随等级递减
