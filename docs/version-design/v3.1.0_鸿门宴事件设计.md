# v3.1.0 鸿门宴事件设计

> 版本：v3.1.0 | 状态：设计中 | 最后更新：2026-08-22

## 一、背景

穆氏世家冲突线已有：年度考核招揽、决斗约定、地圣泉决斗。缺少中间的"鸿门宴"事件——穆氏在招揽失败后设宴试探玩家，是冲突升级的关键节点。

原著中穆卓云欣赏莫凡天赋欲招揽，被拒后设局。玩家视角下，鸿门宴是穆氏对独立玩家的施压和拉拢。

## 二、触发条件

- 年度考核完成（annual_exam_completed）
- 拒绝穆氏招揽（exam_result为refuse_polite或refuse_angry或duel）
- 等级>=5
- 地圣泉决斗前触发

## 三、事件流程

### 阶段1：邀请
穆氏管家送来请柬，邀请玩家赴宴。
- 选择：接受邀请 / 婉拒 / 带莫凡一起去

### 阶段2：宴会
穆卓云亲自出面，软硬兼施。
- 展示穆氏资源（星尘魔器、修炼室、导师）
- 暗示不加入的后果（资源封锁、人脉孤立）
- 提出条件：加入穆氏，之前的冲突一笔勾销

### 阶段3：试探
穆白/宇昂出场挑衅，测试玩家实力和态度。
- 选择：隐忍不发 / 言语反击 / 直接离席

### 阶段4：结局
根据玩家选择：
- 隐忍：穆氏认为玩家可塑，继续观望，声望+穆氏
- 反击：穆氏视玩家为威胁，关系恶化，但获得草根声望
- 离席：彻底撕破脸，触发后续冲突

## 四、效果设计

| 选择 | 效果 |
|------|------|
| 接受邀请+隐忍加入 | gold+300, mu_family+20, grassroots-10, flag: joined_mu |
| 接受邀请+反击 | exp+50, mu_family-15, grassroots+15, brave+10 |
| 接受邀请+离席 | exp+30, mu_family-25, grassroots+20, brave+15 |
| 婉拒邀请 | mu_family-5, grassroots+5 |
| 带莫凡一起去 | 特殊剧情，mo_fan+10, mu_family-10 |

## 五、与后续剧情联动

- 加入穆氏：地圣泉决斗时站在穆氏一方，莫凡关系下降
- 反击/离席：地圣泉决斗时莫凡主动邀请玩家助阵，草根声望加成
- 隐忍：地圣泉决斗时中立，可选择帮哪边
