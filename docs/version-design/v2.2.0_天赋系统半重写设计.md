# 天赋系统半重写设计方案 v2.2

> 日期：2026-08-19 | 状态：设计中，待对齐确认
> 参考：崩坏星穹铁道（专属资源/星魂）、宝可梦（特性/双属性组合）、传统RPG（天赋树/主动技能）

---

## 一、设计目标

### 解决的核心问题
1. **套路化**：每系都是"伤害+状态"的被动数值，缺乏特色
2. **趣味性不足**：全是被动效果，没有主动技能和操作决策
3. **战略性不够**：没有跨系组合、天赋协同、资源管理
4. **进化不透明**：数值叠加机制玩家难以理解

### 设计理念
- **每系有独特的"天赋资源"**：战斗中积累和消耗，增加操作深度
- **天赋三层结构**：基础被动 + 触发被动 + 主动技能
- **进化是机制解锁**：不是数值叠加，而是解锁新机制
- **跨系组合效果**：双系天赋触发协同，参考宝可梦双属性
- **天赋可配置**：双天赋装备、可重置，增加build多样性

## 二、核心机制设计

### 2.1 每系专属资源系统

参考星穹铁道的"宝石能量"、"兴致"等专属资源，每系天赋关联一个战斗资源：

| 系别 | 专属资源 | 积累方式 | 上限 | 消耗效果 |
|------|---------|---------|------|---------|
| 🔥 火系 | 燃点 | 火系攻击+1，暴击+2 | 10 | 满层爆炸（AOE）/ 消耗强化下一击 |
| ❄️ 冰系 | 寒意 | 冰系攻击+1，受击+1 | 8 | 满层冻结 / 破冰爆发（伤害提升） |
| ⚡ 雷系 | 电荷 | 雷系攻击+2 | 6 | 满层连锁（弹射3目标）/ 消耗麻痹 |
| 🪨 土系 | 岩力 | 受击+2，防御行动+3 | 10 | 释放岩击（高伤害）/ 生成护盾 |
| 💨 风系 | 风势 | 闪避+3，行动+1 | 8 | 满层连击（攻击2次）/ 风暴AOE |
| 💧 水系 | 潮汐 | 回合自动+2/-1（涨潮/退潮） | 6 | 高潮期伤害+50% / 低潮期回复HP |
| ✨ 光系 | 圣光 | 治疗+2，净化+3 | 8 | 圣光爆发（伤害+净化）/ 圣光护盾 |
| 🌑 暗系 | 暗影 | 暴击+2，击杀+5 | 6 | 暗影刺杀（必暴击）/ 诅咒蔓延 |
| 💚 治愈系 | 生命能量 | 治疗+2 | 10 | 群体治疗 / 紧急复活 |
| 🐺 召唤系 | 契约 | 召唤兽攻击+1 | 5 | 兽潮（召唤兽额外攻击）/ 守护替死 |
| 🌿 植物系 | 生长 | 回合自动+2 | 8 | 绽放（强力AOE）/ 缠绕（控制） |

**资源显示**：战斗UI中显示当前资源量和上限，玩家可以直观看到。

### 2.2 天赋三层结构

每个天赋包含三个层次的效果：

```
┌─────────────────────────────────┐
│  基础被动（常驻）                │
│  如：火系伤害+10%               │
├─────────────────────────────────┤
│  触发被动（条件触发）            │
│  如：燃点满层时爆炸             │
├─────────────────────────────────┤
│  主动技能（Lv5解锁，战斗中使用） │
│  如：消耗5燃点，造成150%火焰伤害 │
└─────────────────────────────────┘
```

**主动技能设计**：
- 每个天赋Lv5时解锁1个主动技能
- 消耗专属资源，不消耗MP
- 有冷却回合（避免滥用）
- 玩家在战斗中主动选择使用时机

### 2.3 进化机制重做

参考星穹铁道星魂系统，进化是**机制解锁**而非数值叠加：

| 阶段 | 等级 | 解锁内容 |
|------|------|---------|
| 觉醒 | Lv1 | 基础被动 + 专属资源系统 |
| 特性 | Lv3 | 触发被动（资源满层效果） |
| 进化 | Lv5 | 主动技能 + **分支选择**（2-3个方向） |
| 延伸 | Lv7 | 主动技能强化 / 新增触发被动 |
| 终极 | Lv10 | 机制质变（如资源上限+5、主动技能无冷却、双资源联动） |

**分支选择优化**：从简单的"输出向/功能向"改为**机制差异**：
- 火系分支A：爆炸流（满层爆炸，AOE为主）
- 火系分支B：燃尽流（持续燃烧，DoT为主）
- 火系分支C：烈焰强化（消耗资源强化普攻，单体爆发）

### 2.4 跨系组合效果

参考宝可梦双属性组合，当玩家同时装备两系天赋时，触发组合效果：

| 组合 | 名称 | 效果 |
|------|------|------|
| 🔥+💨 火+风 | 火焰风暴 | 燃烧扩散到相邻目标，风系技能附带燃烧 |
| ❄️+⚡ 冰+雷 | 超导 | 冻结目标受到雷系伤害+50%，麻痹时间+1回合 |
| 🔥+🪨 火+土 | 熔岩 | 燃烧变为真实伤害，土系护盾附带燃烧反伤 |
| 💧+❄️ 水+冰 | 极寒 | 冻结概率+20%，水系技能附带减速 |
| ✨+🌑 光+暗 | 混沌 | 暴击率+15%，伤害波动±30%（高风险高回报） |
| ⚡+💧 雷+水 | 感电 | 水系目标受到雷系伤害+30%，电荷积累速度+50% |
| 🪨+💨 土+风 | 沙暴 | 风系技能附带防御削减，土系技能命中率+15% |
| 💚+✨ 治愈+光 | 圣疗 | 治疗效果+25%，治疗时附带净化 |

**组合触发条件**：同时装备两系天赋，且两系天赋等级都≥3。

### 2.5 天赋系统扩展

#### 双天赋装备
- 玩家可同时装备**主天赋**和**副天赋**
- 主天赋：100%效果，主动技能可用
- 副天赋：50%效果，主动技能不可用（但触发被动有效）
- 跨系组合效果需要两系都装备

#### 天赋重置
- 消耗道具"洗练石"重置天赋分支
- 重置后保留等级，重新选择分支
- 增加试错空间，鼓励探索不同build

#### 天赋经验
- 使用对应系技能获得天赋经验
- 修炼该系魔法获得额外天赋经验
- 升级时播放进化动画，增加成就感

## 三、各系天赋重设计（示例）

### 3.1 火系天赋重做示例

**天赋名称**：烈焰之魂（普通，成长型）

**基础被动（Lv1）**：
- 火系伤害+10%
- 解锁专属资源「燃点」，火系攻击+1燃点，上限10

**触发被动（Lv3）**：
- 燃点满层时自动爆炸，对所有敌人造成80%攻击力火焰伤害，燃点清零

**主动技能（Lv5解锁）**：
- 名称：烈焰冲击
- 消耗：5燃点
- 效果：造成150%攻击力火焰伤害，附带3层燃烧
- 冷却：2回合

**分支选择（Lv5）**：
- **A. 爆炸流**：爆炸伤害+50%，爆炸后燃点保留3层
- **B. 燃尽流**：燃烧伤害+100%，燃烧变为真实伤害
- **C. 烈焰强化**：消耗3燃点强化下一次普攻，伤害+80%且必暴击

**延伸（Lv7）**：
- A：爆炸范围扩大，燃烧扩散
- B：燃烧上限+5层，满层时目标防御-30%
- C：强化普攻后获得1回合连击

**终极（Lv10）**：
- A：烈焰领主 - 爆炸无冷却，燃点上限+5
- B：熔岩君主 - 燃烧可暴击，暴击时爆炸
- C：炎暴 - 强化普攻变为AOE，击杀后重置冷却

### 3.2 冰系天赋重做示例

**天赋名称**：寒冰之躯（普通，成长型）

**基础被动（Lv1）**：
- 冰系伤害+10%
- 解锁专属资源「寒意」，冰系攻击+1，受击+1，上限8

**触发被动（Lv3）**：
- 寒意满层时冻结目标1回合，寒意清零

**主动技能（Lv5解锁）**：
- 名称：破冰一击
- 消耗：4寒意
- 效果：对冻结目标造成200%伤害，对非冻结目标造成100%伤害并+2寒意
- 冷却：2回合

**分支选择（Lv5）**：
- **A. 破冰流**：破冰伤害+50%，破冰后寒意+2
- **B. 冰封流**：冻结持续+1回合，冻结期间目标防御-20%
- **C. 霜盾流**：消耗寒意生成护盾，护盾量=寒意×10%最大HP

## 五、兼容性与迁移

### 现有天赋处理
- 现有天赋数据保留，新增字段标记为"v2格式"
- 旧格式天赋自动转换为基础被动
- 玩家已有天赋等级保留，重新选择分支

### 存档兼容
- 新增字段有默认值，旧存档可正常加载
- 天赋资源在战斗开始时初始化

## 六、待确认问题

1. **专属资源系统**：是否认可每系独特资源的设计？会不会太复杂？
2. **主动技能**：天赋主动技能是否需要？还是保持纯被动？
3. **双天赋装备**：是否需要？还是保持单天赋？
4. **跨系组合**：8组组合效果是否足够？还是更多？
5. **实施节奏**：v2.2.0先做火系+框架，还是一次性重做所有系？
6. **数值平衡**：专属资源的积累/消耗数值需要大量测试，是否接受先上线再调优？

---

**设计核心**：从"被动数值叠加"转变为"资源管理+主动决策+跨系协同"，让天赋系统真正影响战斗策略和build多样性。
