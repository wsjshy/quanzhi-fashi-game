# v1.8.0 城市猎妖任务系统设计

> **原文依据**：第55章城市猎妖队，徐大荒队长，莫凡加入；铭文女子中学妖魔事件
> **设计原则**：能落地+提高体验=做，复用现有系统，不重复造轮子

---

## 一、系统定位

城市猎妖任务是博城篇的核心玩法之一，让玩家体验"城市守护者"的身份。不是简单的打怪，而是有调查、组队、分工、结算的完整循环。

**和现有系统的关系**：
- 任务系统→猎妖任务（新任务类型）
- 战斗系统→组队战斗（NPC队友AI）
- 声望系统→猎者联盟声望
- 物品系统→精魄掉落
- NPC关系→徐大荒等猎妖队成员

---

## 二、核心玩法

### 2.1 加入城市猎妖队

**前置条件**：
- 等级≥5
- 完成年度考核（评级C以上）
- 在猎者联盟大厅和徐大荒对话申请

**加入流程**：
1. 和徐大荒对话，申请加入
2. 实力测试（和训练傀儡战斗，评级B以上通过）
3. 雷系法师优先通过（原文设定）
4. 通过后成为猎妖队见习成员

**猎妖队等级**：
- 见习成员：只能接低级任务
- 正式成员：可接中级任务
- 精英成员：可接高级任务，带队
- 队长：徐大荒（NPC）

### 2.2 猎妖任务流程

```
接任务 → 调查线索 → 组队 → 讨伐战斗 → 结算奖励
```

**接任务**：
- 在猎者联盟大厅的任务板接取
- 任务分3级：低级（城市小妖）、中级（潜伏妖魔）、高级（统领级）
- 每天刷新3个任务，可放弃但有冷却

**调查线索**：
- 部分任务需要先调查（去事发地点探索、和NPC对话）
- 调查充分→战斗中知道妖魔弱点（伤害+20%）
- 不调查直接去→正常难度

**组队**：
- 可以邀请猎妖队NPC队友（徐大荒、郭彩棠、肥石、小可、黎文杰）
- 最多带2个NPC队友
- NPC有自己的系别和技能，玩家可以选择分工（主攻/辅助/坦克）

**讨伐战斗**：
- 组队战斗，NPC队友AI自动行动
- 玩家可以指挥队友（集火/防御/救援）
- 战斗胜利→结算

**结算奖励**：
- 金币（任务报酬）
- 经验
- 猎者联盟声望
- 精魄（妖魔掉落，用于星尘魔器升级）
- 概率掉落装备/材料

### 2.3 组队战斗设计

**设计理念**：借鉴《最终幻想》《女神异闻录》等回合制游戏的组队玩法——有指挥但不完全控制，队友有AI自主性和性格。

**NPC队友**：

| NPC | 系别 | 定位 | 性格 | 战术倾向 |
|-----|------|------|------|---------|
| 徐大荒 | 火系 | 主攻 | 豪爽冲动 | 猛攻优先，血量低也不防御 |
| 郭彩棠 | 冰系 | 控制 | 冷静理性 | 控制优先，给敌人上debuff |
| 肥石 | 土系 | 坦克 | 憨厚可靠 | 防御优先，保护队友 |
| 小可 | 水系 | 辅助 | 温柔细心 | 治疗优先，队友血量低时加血 |
| 黎文杰 | 风系 | 机动 | 灵活多变 | 自由打法，根据情况调整 |

**两层指挥系统**：

#### 第一层：战斗前战术预设
接任务时选择队友，并设置每个队友的**战术倾向**：
- **猛攻**：优先输出，不管血量
- **平衡**：攻守兼备，血量低时防御
- **防御**：优先防御和保护队友
- **辅助**：优先治疗和上buff
- **自由**：AI根据性格自行决策（默认）

#### 第二层：战斗中临时指挥
玩家回合时，除了自己行动，还可以选择**"指挥"**（免费指令，不消耗回合）：
- **集火**：所有队友攻击玩家指定的目标
- **防御**：本回合所有队友优先防御
- **技能**：指定队友使用特定技能（如"小可，用治愈"）
- **自由**：取消指挥，恢复战术预设

**AI执行逻辑**：
- 队友优先执行玩家的临时指挥
- 如果没有临时指挥，按战术倾向行动
- 性格影响执行：徐大荒即使被指挥防御，也有30%概率继续攻击（符合豪爽性格）
- 小可即使被指挥攻击，队友血量低时也有50%概率改治疗（符合温柔性格）

**实现方式**：复用现有战斗系统，在battle-ai.js中添加队友AI和指挥逻辑，不造新引擎。

**战斗UI**：
- 战斗界面显示队友状态（头像/血量/蓝量）
- 玩家回合有"指挥"按钮，点击弹出指令菜单
- 队友行动时显示"徐大荒使用了火滋·灼烧"

### 2.4 精魄系统

**精魄类型**：
- 奴仆级精魄：低级妖魔掉落，星尘魔器升级基础材料
- 战将级精魄：中级妖魔掉落，星尘魔器升级高级材料
- 统领级精魄：高级妖魔掉落，稀有材料

**用途**：
- 星尘魔器升级（吸收精魄提升效果）
- 出售换金币
- 部分任务需要精魄作为道具

**实现方式**：复用现有物品系统，精魄作为物品类型，星尘魔器升级逻辑已有基础。

## 三、博城篇猎妖任务设计（首批3个）

### 任务1：铭文女子中学的妖魔（低级）
**原文依据**：铭文女子中学出现妖魔，莫凡因为叶心夏在该校而参与
- **目标**：清除潜伏在学校的妖魔
- **调查**：和学校门卫对话、检查教室
- **BOSS**：奴仆级妖魔（独眼魔狼幼崽/其他）
- **奖励**：金币100、经验50、猎者声望+10、奴仆精魄x1
- **特殊**：如果玩家认识叶心夏，有额外对话和好感

### 任务2：老街区的怪事（中级）
**原文依据**：黑教廷铺垫，城市中有可疑事件
- **目标**：调查老街区的异常，清除妖魔
- **调查**：多个线索点，调查充分发现黑教廷痕迹
- **BOSS**：战将级妖魔
- **奖励**：金币300、经验150、猎者声望+25、战将精魄x1
- **特殊**：调查充分→发现黑教廷线索（影响阴谋调查系统）

### 任务3：城市边缘的统领（高级）
**原文依据**：博城灾难前的妖魔异常
- **目标**：讨伐城市边缘的统领级妖魔
- **调查**：必须调查，否则难度极高
- **BOSS**：统领级妖魔（翼苍狼幼体/其他）
- **奖励**：金币800、经验400、猎者声望+50、统领精魄x1
- **特殊**：需要至少1个NPC队友， solo极难

## 四、和其他系统的联动

| 系统 | 联动方式 |
|------|---------|
| 博城灾难 | 猎妖队等级高→灾难中可调用猎妖队资源；有猎妖经验→恐惧等级-1 |
| 阴谋调查 | 猎妖任务中发现黑教廷线索→解锁阴谋调查事件 |
| 星尘魔器 | 精魄用于星尘魔器升级 |
| NPC关系 | 和猎妖队NPC组队提升好感，好感高解锁更强队友 |
| 声望系统 | 猎者联盟声望影响任务报酬、商店折扣、地点进入 |
