# v0.53.0 影响力事件链扩展IV（周敏）

> 版本：v0.53.0
> 日期：2026-08-15
> 定位：次要NPC周敏的影响力事件链，2个事件（次要NPC减少戏份）

---

## 一、设计原则

1. **次要NPC减少戏份**——周敏作为次要角色，仅2个事件
2. **不围绕莫凡**——事件中不提及莫凡
3. **人设符合**——周敏好强不服输，崇拜强者，看不起不上进的人
4. **flag驱动**——事件间有flag依赖

---

## 二、事件链：周敏的认可

### 事件1：火系的较量
- **触发**：修炼/找人聊天时
- **条件**：minRelationship 10, 玩家等级≥5, notFlag("zhou_min_noticed")
- **描述**：周敏路过，看到你在修炼火系魔法，停下脚步。"你的火系星子排列...还算稳。"她的语气带着一丝不服输，"要不要比比看谁的火系控制力更强？"
- **选择**：
  1. 好，比比看 → setFlag, npcOpinion +4, exp +15（周敏虽输但认可你的实力）
  2. 我还差得远，不敢比 → setFlag, npcOpinion +2（周敏觉得你谦虚，但有点失望）
  3. 火系不在于比，在于自己的节奏 → setFlag, npcOpinion +3, reputation +2（周敏愣了一下，若有所思）

### 事件2：强者的认可
- **触发**：修炼/找人聊天时
- **条件**：requireFlag("zhou_min_noticed"), minRelationship 20, 玩家等级≥8
- **描述**：周敏走到你面前，表情少了几分之前的不服气，多了几分认真。"你的进步速度...比我快。"她顿了顿，"我不会认输的，但...你确实很强。"这是她能给出的最高评价。
- **选择**：
  1. 彼此彼此，一起进步 → npcOpinion +5, reputation +3
  2. 谢谢，你也很强 → npcOpinion +3

---

## 三、验证标准

1. 周敏事件链：关系10+等级≥5触发事件1，setFlag后事件2可触发
2. 人设检查：周敏好强不服输，崇拜强者
3. 不围绕莫凡：事件中不提及莫凡
4. 冒烟测试：游戏不崩溃
