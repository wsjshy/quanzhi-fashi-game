# v3.1.0 暴躁之泉调查任务链设计

## 一、设计目标

还原原著博城篇暴躁之泉剧情，让玩家在博城灾难前调查暴躁之泉线索，向林雨欣预警，影响博城灾难的结局。

## 二、原著关键引用

- 暴躁之泉是黑教廷炼制的药剂，几乎可以和地圣泉以假乱真
- 效果：激化妖魔的野性，让它们变得近乎失去理智的杀戮
- 黑教廷将暴躁之泉洒在云雾中，大雨来临后成为催化剂，使得魔狼族群疯狂进攻博城
- 林雨欣发现了暴躁之泉，但没有意识到危险性，等到灾难降临才醒悟
- 唐月追捕朝赫是为了查暴躁之泉的由来

## 三、任务链设计

### 任务1：暴躁之泉踪迹
- 任务ID：quest_irritable_spring_trace
- 触发条件：完成雪峰山历练，等级≥6
- 任务目标：在雪峰山调查3次，发现暴躁之泉踪迹
- 任务描述：唐月老师说最近雪峰山的妖魔异动很不正常，让你去调查一下。你在雪峰山发现了一种诡异的液体痕迹，散发着令人不安的气息，与地圣泉的灵气相似但性质截然相反。
- 奖励：经验150，金币100，线索"暴躁之泉踪迹"
- 后续：解锁任务2

### 任务2：黑教廷据点
- 任务ID：quest_black_church_hideout
- 触发条件：完成任务1，等级≥7
- 任务目标：击败黑教廷成员，搜索据点
- 任务描述：根据暴躁之泉的线索，你找到了黑教廷的一个秘密据点。据点中有几名黑教廷成员在看守，你需要击败他们并搜索据点，找到更多关于暴躁之泉的线索。
- 奖励：经验200，金币150，物品"暴躁之泉样本"，线索"黑教廷据点"
- 后续：解锁任务3

### 任务3：向林雨欣预警
- 任务ID：quest_warn_lin_yuxin
- 触发条件：完成任务2，等级≥8
- 任务目标：与林雨欣对话，提交暴躁之泉样本
- 任务描述：你找到了暴躁之泉的样本，意识到这可能是黑教廷的阴谋。你决定向魔法协会的林雨欣预警，告诉她暴躁之泉的危险性。
- 奖励：经验300，金币200，声望"魔法协会+20"，线索"暴躁之泉预警"
- 后续：影响博城灾难结局

### 任务4：寻找解药
- 任务ID：quest_find_antidote
- 触发条件：完成任务3，等级≥9
- 任务目标：采集5株净化草，制作暴躁之泉解药
- 任务描述：林雨欣告诉你，暴躁之泉的解药需要净化草等材料。她让你去采集5株净化草，她会尝试制作解药，减轻博城灾难的影响。
- 奖励：经验250，金币150，物品"暴躁之泉解药"，声望"魔法协会+15"
- 后续：博城灾难中使用解药可减轻妖魔攻击

## 四、与博城灾难联动

- 完成任务3（向林雨欣预警）：博城灾难中妖魔攻击-10%，林雨欣会提前做好准备
- 完成任务4（寻找解药）：博城灾难中可使用暴躁之泉解药，妖魔攻击-15%，持续3回合
- 未完成任何任务：博城灾难正常难度，林雨欣在灾难中才醒悟
