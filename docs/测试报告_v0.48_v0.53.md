## 三、发现的Bug 🐛

### Bug 1：自动战斗第2回合卡住（P1）
- **严重程度**：P1（影响体验，但可手动操作绕过）
- **复现步骤**：
  1. debug触发战斗（独眼魔狼）
  2. 点击"自动"按钮开启自动战斗
  3. 第1回合正常执行
  4. 第2回合停在"你的回合"，不自动执行
- **预期**：自动战斗应持续执行直到战斗结束
- **实际**：第2回合卡住，需要手动点击技能才能继续
- **备注**：v0.47.1曾修复此问题（看门狗机制），可能在某些情况下仍未完全修复

### Bug 2：debug面板缺少NPC关系设置（P2，体验问题）
- **严重程度**：P2（影响测试效率，不影响正常游戏）
- **描述**：debug面板没有直接设置NPC好感度/信任度的功能，导致测试影响力事件链需要通过多次对话慢慢提升关系，效率极低
- **建议**：在debug面板的"玩家"或新增"NPC"标签中添加NPC关系设置功能

## 四、体验问题 💡

### 体验问题1：随机事件触发频率较高
- **描述**：连续修炼时多次触发"同修交流"等随机事件，打断修炼节奏
- **建议**：适当降低连续行动时的随机事件触发概率，或增加"今日不再提示"选项

### 体验问题2：张小侯称号提到莫凡
- **描述**：找人聊天列表中，张小侯的称号是"莫凡的死党"，提到了莫凡
- **建议**：改为更中性的称号，如"风系学生"或"活泼的同学"，符合"玩家有自己的人生，不围绕莫凡"的原则

### 体验问题3：属性点分配效率低
- **描述**：属性点只能逐个点击+按钮分配，25点需要点击25次，且每次点击后页面会滚动回顶部
- **建议**：增加"一键分配"或长按连续分配功能，或在debug面板中增加属性点清零功能
