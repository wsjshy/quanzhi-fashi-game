# v0.70.0 精英妖魔系统

> 版本：v0.70.2（时间线修正后）
> 日期：2026-08-16
> 类型：战斗系统深化 / 策略性提升
> 核心原则：**所有妖魔类型、技能、天赋严格来自《全职法师》原著，且严格遵循小说时间线——当前阶段只使用博城灾难及之前出现的内容**

---

## 一、为什么做这个

### 1.1 战斗策略性提升
当前战斗系统已有元素克制、元素反应、状态效果、精神力引导、打断机制等14项机制，但普通战斗太简单，玩家不需要策略就能赢，机制用不上。

精英妖魔系统在普通妖魔和BOSS之间增加有特殊机制的精英妖魔，让普通探索也有策略性，玩家需要根据精英类型选择技能和战术。

### 1.2 严格遵循原著+时间线
- 所有精英妖魔的种类、技能、天赋均来自《全职法师》原著设定，不编造
- **严格遵循小说时间线**：当前游戏只做到博城灾难及之前，只使用这个阶段出现的妖魔
- 后续剧情的妖魔先归档到`docs/小说拆解/待添加妖魔_后续剧情.md`，等拆解到对应阶段时再加入

## 三、精英妖魔设计（3种，全部来自博城灾难）

### 3.1 三眼魔狼（骨刺狰狼）

**原著依据**：博城灾难中翼苍狼的手下，战将级妖魔。三只眼睛几乎拥有270度视角，钢铁般结实的身躯，锋利的棱角骨刺。中阶魔法师若没有及时防备都会被一击毙命。

**精英机制**：
- **270度视角**：无法偷袭，玩家的"绕后"类技能无效
- **骨刺攻击**：普通攻击有30%概率触发骨刺，造成150%伤害
- **钢铁身躯**：物理伤害减免20%

**应对策略**：
- 用魔法攻击（无视物理减免）
- 用控制技能（眩晕/冰冻）限制其行动
- 元素克制：火系克制（狼族怕火）

**数据**：Lv12, HP300, 攻击35, 防御15, 速度18
**技能**：basic_attack, bone_spike, wolf_bite, wolf_howl
**弱点**：火系
**掉落**：wolf_bone_spike, demon_core, elite_core

### 3.2 进阶期独眼魔狼

**原著依据**：独眼魔狼中的进阶期个体，博城灾难中常见的精锐妖魔。力大敏捷，比普通独眼魔狼强大数倍，单独一只就足以威胁初阶魔法师。

**精英机制**：
- **进阶体魄**：物理伤害减免10%
- **敏捷**：闪避率+10%
- **先手优势**：先手概率+15%

**应对策略**：
- 用必中技能（无视闪避）
- 用控制技能限制其行动
- 火系技能克制

**数据**：Lv8, HP180, 攻击25, 防御8, 速度20
**技能**：basic_attack, wolf_bite, wolf_howl, dark_claw
**弱点**：火系
**掉落**：wolf_fang, demon_core, elite_core（低概率）

### 3.3 巨眼猩鼠王

**原著依据**：巨眼猩鼠群居群落的首领，博城灾难地下洞穴中的危险存在。体型比普通巨眼猩鼠大一圈，腥红光束威力更强，剧毒唾液。

**精英机制**：
- **剧毒唾液**：攻击有30%概率附加中毒
- **敏捷**：闪避率+15%
- **召唤小怪**：有20%概率召唤普通巨眼猩鼠助战

**应对策略**：
- 提升毒抗或准备解毒道具
- 用必中技能（无视闪避）
- 火系/光系技能克制

**数据**：Lv7, HP150, 攻击20, 防御6, 速度22
**技能**：basic_attack, rat_bite, dark_bolt, shadow_spike
**弱点**：火系、光系
**掉落**：rat_tail, demon_core, elite_core（低概率）

## 四、技术实现

### 4.1 数据结构
在enemies.js中为精英妖魔添加`elite`字段和`eliteMechanics`字段：

```javascript
three_eye_wolf: {
  id: "three_eye_wolf",
  name: "三眼魔狼",
  rank: "战将级",
  elite: true,
  eliteMechanics: {
    view_270: true,
    bone_spike_chance: 0.3,
    physical_reduction: 0.2
  },
  weakness: ["fire"],
  ...
}
```

### 4.2 战斗系统扩展
在battle.js中添加精英机制处理：
1. 战斗开始时检查妖魔是否为精英，显示精英提示
2. 应用精英被动机制（物理减免、闪避等）
3. 伤害计算时应用精英减伤/弱点
4. 回合开始时检查精英主动技能

### 4.3 调试支持
在debug.js的战斗标签页添加精英妖魔测试按钮，方便快速测试。

## 五、深度来源

1. **策略选择**：每种精英需要不同的应对策略，玩家需要根据精英类型选择技能
2. **元素克制深化**：精英的弱点让元素克制更有意义
3. **资源管理**：精英战斗需要更多MP和道具，玩家需要管理资源
4. **风险与回报**：精英更强但掉落更好，玩家可以选择挑战或逃跑
5. **原著还原**：所有妖魔和能力来自原著博城灾难篇，增强代入感
6. **渐进难度**：从奴仆级巅峰到战将级精英，逐步提升挑战

## 六、时间线原则（重要）

**当前游戏阶段**：博城灾难及之前

**允许使用的内容**：
- 博城灾难篇及之前出现的所有妖魔、技能、NPC、物品、剧情
- 原著中明确属于这个时间段的设定

**不允许使用的内容**：
- 明珠学院及之后出现的妖魔（如蛊惑魔蛛、伪怖魔、诅咒畜妖、禁月石魔、赤凌妖等）
- 后续剧情的NPC、物品、技能
- 尚未在小说中出现的编造内容

**后续内容处理**：
- 先归档到`docs/小说拆解/待添加妖魔_后续剧情.md`
- 等小说拆解到对应阶段时，再从归档中取出数据加入游戏
- 加入前需再次确认原著出处和能力描述
