# v0.70.0 精英妖魔系统

> 版本：v0.70.0
> 日期：2026-08-16
> 类型：战斗系统深化 / 策略性提升
> 核心原则：**所有妖魔类型、技能、天赋严格来自《全职法师》原著，不编造**

---

## 一、为什么做这个

### 1.1 战斗策略性提升
当前战斗系统已有元素克制、元素反应、状态效果、精神力引导、打断机制等14项机制，但普通战斗太简单，玩家不需要策略就能赢，机制用不上。

精英妖魔系统在普通妖魔和BOSS之间增加有特殊机制的精英妖魔，让普通探索也有策略性，玩家需要根据精英类型选择技能和战术。

### 1.2 严格遵循原著
所有精英妖魔的种类、技能、天赋均来自《全职法师》原著设定。不编造妖魔，不编造能力。

## 三、精英妖魔设计（第一批，6种）

### 3.1 三眼魔狼（骨刺狰狼）

**原著依据**：战将级妖魔，三只眼睛几乎拥有270度视角，钢铁般结实的身躯，锋利的棱角骨刺。中阶魔法师若没有及时防备都会被一击毙命。

**精英机制**：
- **270度视角**：无法偷袭，玩家的"绕后"类技能无效
- **骨刺攻击**：普通攻击有30%概率触发骨刺，造成150%伤害
- **钢铁身躯**：物理伤害减免20%

**应对策略**：
- 用魔法攻击（无视物理减免）
- 用控制技能（眩晕/冰冻）限制其行动
- 元素克制：火系克制（狼族怕火）

**出现条件**：
- 玩家等级≥10
- 探索/修炼时5%概率遭遇
- 战将级区域概率更高

**掉落**：
- 骨刺（材料，用于装备强化）
- 妖魔精核（高概率）
- 经验×1.5，金币×1.5

### 3.2 蛊惑魔蛛

**原著依据**：大战将，八足多眼甲壳，核心能力是蛊惑猎物。不需要凭空制造仇恨，只要把本就存在的情绪不断放大，就能让猎物互相攻击。

**精英机制**：
- **蛊惑**：每3回合有40%概率释放蛊惑，玩家进入"混乱"状态1回合
  - 混乱状态：玩家的技能有50%概率打错目标（对自己造成伤害）
  - 精神力越高，抵抗概率越高
- **甲壳**：受到的第一次伤害减免50%
- **八足**：闪避率+15%

**应对策略**：
- 提升精神力（抵抗蛊惑）
- 用单段高伤害技能破甲壳
- 用必中技能（无视闪避）

**出现条件**：
- 玩家等级≥12
- 探索时5%概率遭遇
- 洞穴/地下区域概率更高

**掉落**：
- 蛛丝（材料，用于装备制作）
- 蛊惑腺（稀有材料）
- 经验×1.8，金币×1.8

### 3.3 伪怖魔

**原著依据**：战将级巅峰，植物型妖魔。植物墙封死出口，扎根封锁拖拽。你以为自己进入了大楼，其实是走进了它的捕食范围。

**精英机制**：
- **植物墙**：战斗开始时生成植物墙，玩家每回合有30%概率被"封锁"（无法使用道具）
- **扎根拖拽**：每4回合释放拖拽，将玩家拉向自己，并造成伤害
- **植物再生**：每回合恢复5%最大HP
- **弱点**：火系伤害+50%（植物怕火）

**应对策略**：
- 必须用火系技能（伤害加成+阻止再生）
- 快速击杀（避免拖到后期）
- 准备足够的MP（持续火系输出）

**出现条件**：
- 玩家等级≥15
- 探索时3%概率遭遇
- 废弃建筑/森林区域概率更高

**掉落**：
- 植物核心（稀有材料）
- 伪怖魔种子（材料）
- 经验×2，金币×2

### 3.4 诅咒畜妖

**原著依据**：战将级，黑畜妖的升级版。黑教廷用人类活尸与妖的煞气混合制造，更贴近亡灵生物。是怨恨、愤怒、贪婪的化身。

**精英机制**：
- **诅咒**：攻击时有30%概率附加诅咒，降低玩家10%攻击力和防御力，持续3回合
- **亡灵特性**：对中毒/流血免疫，对光系伤害+50%
- **煞气护体**：受到的第一次状态效果（眩晕/冰冻等）免疫
- **狂暴**：HP低于30%时，攻击力+30%

**应对策略**：
- 用光系技能（亡灵克星）
- 避免用毒系/流血技能（无效）
- 控制HP，避免其狂暴后被秒杀

**出现条件**：
- 玩家等级≥13
- 探索时4%概率遭遇
- 黑教廷相关区域概率更高

**掉落**：
- 诅咒结晶（稀有材料）
- 煞气核心（材料）
- 经验×1.8，金币×1.8

### 3.5 禁月石魔

**原著依据**：战将级，石魔类妖魔。石肤高防御，与月能相关，夜晚更强。

**精英机制**：
- **石肤**：所有伤害减免30%
- **月能**：夜晚（游戏时间18:00-6:00）全属性+20%
- **投石**：每3回合释放投石，造成范围伤害并降低玩家命中率
- **弱点**：土系伤害+30%（同类相斥），雷系伤害+20%（导电）

**应对策略**：
- 用土系/雷系技能（克制石魔）
- 白天战斗（避免月能加成）
- 用破甲技能（无视石肤减免）

**出现条件**：
- 玩家等级≥14
- 探索时4%概率遭遇
- 山地/洞穴区域概率更高

**掉落**：
- 石魔核心（材料）
- 月能石（稀有材料）
- 经验×1.8，金币×1.8

### 3.6 赤凌妖

**原著依据**：小战将T1，4米高，凶悍善战，压制同阶。火系妖魔。

**精英机制**：
- **烈焰护体**：受到近战攻击时，反弹20%火系伤害
- **燃烧地面**：每2回合释放烈焰，地面燃烧3回合，玩家每回合受到火系伤害
- **高速移动**：闪避率+10%，先手概率+20%
- **弱点**：冰系伤害+50%，水系伤害+30%

**应对策略**：
- 用冰系/水系技能（克制火系）
- 远程攻击（避免烈焰反弹）
- 用控制技能（限制高速移动）

**出现条件**：
- 玩家等级≥11
- 探索时5%概率遭遇
- 火山/炎热区域概率更高

**掉落**：
- 赤凌晶（材料）
- 烈焰核心（稀有材料）
- 经验×1.5，金币×1.5

## 四、技术实现

### 4.1 数据结构
在enemies.js中为精英妖魔添加`elite`字段和特殊机制字段：

```javascript
three_eye_wolf: {
  id: "three_eye_wolf",
  name: "三眼魔狼",
  rank: "战将级",
  elite: true,
  eliteMechanics: {
    "270_view": true,        // 无法偷袭
    "bone_spike": 0.3,       // 30%概率骨刺
    "steel_body": 0.2        // 物理减免20%
  },
  weakness: ["fire"],        // 火系克制
  ...
}
```

### 4.2 战斗系统扩展
在battle.js中添加精英机制处理：
1. 战斗开始时检查妖魔是否为精英
2. 应用精英被动机制（石肤、甲壳、烈焰护体等）
3. 回合开始时检查精英主动技能（蛊惑、植物墙、投石等）
4. 伤害计算时应用精英减伤/弱点
5. 状态效果时检查精英免疫

### 4.3 遭遇系统
在game.js的探索/修炼方法中添加精英遭遇概率：
- 普通妖魔遭遇概率的基础上，有一定概率升级为精英
- 精英遭遇有特殊提示（"⚠️ 遭遇精英妖魔！"）
- 精英战斗BGM/UI特殊标记

### 4.4 掉落系统
扩展掉落系统，支持精英专属掉落：
- 精英材料（骨刺、蛛丝、植物核心等）
- 更高的经验和金币
- 稀有材料低概率掉落

## 五、深度来源

1. **策略选择**：每种精英需要不同的应对策略，玩家需要根据精英类型选择技能
2. **元素克制深化**：精英的弱点让元素克制更有意义
3. **资源管理**：精英战斗需要更多MP和道具，玩家需要管理资源
4. **风险与回报**：精英更强但掉落更好，玩家可以选择挑战或逃跑
5. **原著还原**：所有妖魔和能力来自原著，增强代入感
6. **渐进难度**：从奴仆级到战将级精英，逐步提升挑战
