## 二、世界设定提取

### 2.1 技能分级深化

**雷印第二级·狂策**：
- 效果：雷电蟒鞭抽打，多道打在目标身上留下雷电印痕
- 特殊机制：印痕相互传递电弧，持续电击目标生物
- 克制关系：专治纯粹靠身体力量的生物（肌肉麻痹、骨骼无法生长）
- 原文描述："和最初的雷印·蟒痕不同，这些如鞭子一般的雷电之印一旦有多道打在上面，并在那里留下雷电印痕之后，这些印痕会再相互传递电弧，持续的电击着目标生物"
- 原文描述："它那强有力的厚实肌肉和钢板之躯或许可以抵挡得了火滋·爆裂的强大破坏力，雷印的疯狂鞭策兴许也只是让它受一些皮外伤，然而它的肌肉绝对无法抵挡得了电击的麻痹和电弧不断的在它那沸腾的身体里传导"

**冰蔓分级**：
- 1级：冰蔓（基础冻结）
- 2级：冰蔓·凝结（飞霜蔓延，凝结下肢为冰棍）
- 3级：冰蔓·覆盖（大面积寒冰蔓延，冰冻一大片）
- 原文描述："其他人现在也不过是冰蔓的1级状态，你已经掌握了冰蔓·凝结，以你的修炼速度啊，用不了两年的时间，一定可以到达冰蔓的第3级形态，冰蔓·覆盖，那可是大面积的寒冰蔓延"

**地波分级**：
- 地波·挪移（基础位移）
- 地波·迟缓（地下波纹，迫使目标往远离方向挪动）

**水御分级**：
- 水御·化解（基础化解）
- 水御·守护（数条水绸带编织成水之衣甲）

### 2.2 星尘魔器分级系统

**凡级星尘魔器**：
- 滋养效果：被温泉浸泡，浑身随着舒服的热量和柔软的流淌而舒展开
- 作用：快速放松身体和精神，缓解修炼疲劳

**灵级星尘魔器**：
- 滋养效果：被柔软的蚕丝包裹，紧紧贴在身体，清爽舒服
- 额外作用：除了消除疲惫，还滋养星尘（相当于冥修）
- 原文描述："尽管他从没有接触过灵级的星尘魔器，但他已经明显感觉到那种滋养精力的效果必定是灵级星尘魔器的，甚至……除了让自己疲惫感迅速消除之外，莫凡感觉自己的星尘也在受到滋养，那种感觉就好像自己在冥修了"

**小泥鳅坠升级过程**：
- 吸收精魄后，小泥鳅坠跟小婴儿一样醒过来
- 轻轻颤晃的同时焕发出只在方圆一指的区域绽放出光芒
- 光芒粘稠无比，像蚕丝一样将黑不溜秋的坠子包裹起来
- 化茧重生，表层出现明显蜕变，不再锈迹斑斑，有几分玉石的光泽
- 完全蜕变后，胸膛位置不断传递非常舒服的能量

### 2.3 精魄/残魄收集系统

**残魄**：
- 价值：1万人民币一个
- 外观：微弱到快看不见的萤火虫芒，光芒特别浑浊
- 收集：小泥鳅坠很勉强吸取，聊胜于无的态度

**精魄**：
- 价值：500万人民币一个
- 外观：无比纯净的萤火芒
- 收集条件：只有亡灵系法师才具备采集能力，需要特殊收集器皿
- 消散时间：死亡生物的精魄不到3分钟内自行消散
- 出现概率：受到好东西滋养的妖魔（如偷吸地圣泉）死亡后出现精魄概率相当高
- 原文描述："由于精魄这东西只有亡灵系的魔法师才具备采集的能力，包括杨作河这位中阶法师假若没有带特殊的收集精魄器皿的话，也一样不可能看到无比纯净的萤火芒精魄"

**小泥鳅坠特殊能力**：
- 自动收集残魄和精魄
- 面对刚死亡的妖魔时有强烈反应，像敲打着某种别人听不见的音律呼唤
- 吸收精魄后会开心呢喃（像吃饱饭的小孩儿）
- 成长需要精魄（残魄效果有限）

### 2.4 地圣泉设定

**地圣泉**：
- 归属：穆氏家族修炼圣地
- 效果：相当于加强了不知多少倍的星尘魔器
- 作用：不单单缓解修炼疲劳，更可以让修炼速度飞驰
- 修炼方式：冥修或把控都完美
- 开启条件：不是想开启就能够开启的
- 机会：一辈子只有一次的绝佳修炼机会
- 宇昂的机会：成年礼结束后开启，在里面有整整一个星期的修炼时间
- 目标：冲击中阶法师的最佳机会
- 原文描述："星尘魔器你应该知道吧，这地圣泉就相当于一个加强了不知多少倍的星尘魔器，他不单单是缓解修炼疲劳，更是可以让修炼速度在这博城地圣泉滋养下飞驰的修炼圣地"

**地圣泉被偷吸**：
- 独眼魔狼和巨眼猩鼠偷吸了地圣泉的庞大能量
- 独眼魔狼因此具备进阶资本，变得异常强大
- 谁放出来的？（伏笔，后续博城灾难相关）

### 2.5 中阶魔法系统

**中阶法师特征**：
- 脚下有星图（奇炫无比）
- 双系（第二次觉醒）
- 中阶技能威力远超初阶

**水系中阶技能·暴浪·驱逐**：
- 效果：半空中出现骇然大浪，宛如决堤之水冲击目标
- 威力：将独眼魔狼从街道中央冲到街尾，灌满一整条老榕树街道
- 控制：暴浪宛如一条猛龙，根本没有卷到其他人
- 原文描述："看着那足以将一条街道给灌满的浪潮汹涌湍急而过"

**风系中阶技能·风盘·龙卷**：
- 效果：狂躁气流高速旋转，形成浑浊龙卷
- 威力：将动弹不得的独眼魔狼拽到空中，抛到二十多米高
- 后续：龙卷消散，妖魔从高空摔下，水泥地凹陷蜘蛛裂纹，粉身碎骨
- 原文描述："不是风轨那种柔和的风，更不是形成风轨那样仅仅是令人加快速度的风之通道，此时此刻莫凡可以明显感觉到狂躁的气流在前方旋转，高速的旋转"

### 2.6 寻妖粉道具

**寻妖粉**：
- 外观：像香囊，解开后出现晶莹的粉末
- 使用方式：一吹，飘散到空气中，缓慢洒落在区域
- 效果：对妖魔气息特别敏感，十天前妖魔留下的脚印都能粘附
- 原理：妖魔的气息魔法师平日里很难捕捉，尤其是已经离开此地的妖魔
- 定位：城管月黑风高、捕妖捉怪、必备良药

### 2.7 妖魔感知科技信号

**妖魔感知手机信号**：
- 能力：妖魔拥有感知魔法科技设备信号的能力
- 后果：调静音给城市猎妖队发求救短信，无异于给妖魔脑子里发了一个手机GPS定位，一秒就暴露
- 原文描述："这个世界的生物最不安套路出牌的就是它们拥有感知魔法科技设备信号的能力，所以你调静音给城市猎妖队发求救短信无异于给妖魔脑子里发了一个手机gps定位，一秒就暴露好吗"

### 2.8 城市警戒系统

**城市警戒**：
- 决定方：魔法协会、猎者联盟、政府联合商量
- 触发条件：妖魔在都市冒出频率异常高
- 顾虑：刚拉过一次警戒，时间间隔短再拉容易引起恐慌
- 原文描述："我们魔法协会已经在和猎者联盟商量了，政府那边也同样在考虑这件事，只是我们在不久前才拉响过一次警戒，时间间隔这么短再一次拉响，很容易引起恐慌"

## 三、NPC设定提取

### 3.1 宇昂（穆卓云养子）

**基本设定**：
- 身份：穆卓云养子，穆氏家族掌管接班人
- 法系：冰系（冰蔓·凝结，2级）
- 性格：阴沉、高瘦、骄傲、对自己修行不满意
- 目标：勤奋修炼是为了自己，没把决斗放在心上
- 原文描述："一名神色格外阴沉的高瘦男子"
- 原文描述："宇昂勤奋修炼是为了他自己，尽管自己养父卓云在一年后给自己安排了场魔法决斗，可宇昂真心没有把这件事放在心上"

**与莫凡的关系**：
- 最初轻蔑："还以为这家伙有多厉害，原来面对妖魔的时候跟一条吓破胆的老狗一样，真是滑稽"
- 后来嫉妒：看到莫凡（梵墨）受所有人关注，嘴角浮动，脸色更加阴沉
- 原文描述："纵然有冰系世家的光环，纵然在年轻一辈出类拔萃，可是雷系的光环依然能够令他黯然失色"

**穆卓云的真正目的**：
- 宇昂是穆宁雪的垫脚石
- 穆宁雪是穆卓云最完美的接班人，博城池子太小
- 需要培养一个真正的心腹，掌控好博城的这份固有的家底
- 原文描述："老谋深算的穆卓云是不会告诉宇昂，费这么大的资源来培养他和举荐他，他宇昂将来再风光、再位高权重也不过是另一个人的垫脚石，这个人就是他穆卓云的亲生女儿-穆宁雪"

**成年礼决斗**：
- 穆氏最隆重的仪式，少年强则家族强
- 宇昂成年礼要盛大、隆重、宴请宾客、一鸣惊人
- 决斗目的：以自己过人的实力折服在场的长辈和同辈，竖立威信，对将来把控这座城市大权顺利许多
- 原文描述："能够一口气将整个博城知名人物聚集在一个地方的机会可不算多，假如在这个成年礼上还有这样一个决斗环节，想必很多人对你会另有改观"

**基本设定**：
- 身份：穆氏家族家主，穆宁雪父亲，宇昂养父
- 性格：老谋深算、深谋远虑、八撇胡
- 目标：培养穆宁雪为完美接班人，宇昂为心腹掌控博城

**与莫凡的关系**：

- 原文描述："他现在已经是天澜魔法高中最出色的学生，备受邓凯、斩空、朱校长的关注，现在，哪怕我想对这小子使点手段，这几个人也未必会让我如愿了"

- 对莫凡的感情：历练后特别好，扭扭捏捏犹犹豫豫，偷偷看莫凡

**老街区事件**：
- 奶奶家住在榕树街，老城区要改建新小区
- 暑假频繁听到旁边工地有震响，工程队说晚上不施工

**后续**：

- 带奶奶跑，还想救老街区其他老人（善良）
- 在宿舍门口等莫凡，哭着感谢
- 原文描述："周敏毕竟还是花季少女，最早在历练时莫凡舍身救下大家，她就格外感动了，却碍于那少女的小骄傲不知道该怎么表达，这一次，又因为她奶奶的事差点让莫凡丢了性命，莫凡又一次将她和她奶奶救了出来，这份恩情都不知道要怎么报答了"

### 3.6 徐大荒（猎妖队队长）

**基本设定**：
- 身份：城市猎妖队队长，火系法师
- 技能：火滋·爆裂（第三级）
- 性格：严格、咆哮式批评、负责任、有气概

**守护街区**：
- 独眼魔狼强迫进阶，黎文杰建议逃跑
- 徐大荒勃然大怒："说得什么鬼话，给我转过头去看看你背后是什么！"
- 背后是繁华商业街区，有大量平民
- 决定不撤退，明知会死也要阻拦
- 原文描述："这座城市确实有比他们猎妖队更强的魔法师会出现，然而中阶魔法师不可能时时刻刻都保持警惕的，就算他们以最快的速度到了这里消灭掉这只独眼魔狼，那也绝无法避免这段时间独眼魔狼那肆无忌惮的屠杀"

**受伤**：
- 火滋·爆裂对独眼魔狼无效（安然无恙）
- 被独眼魔狼一爪撕开胸膛（从胸膛撕到腹部的大血痕）
- 小可水御·守护无效
- 重伤但活着（魔法师体质被星尘改变，换普通人直接挂了）
- 治愈系法师及时治疗

## 四、妖魔设定提取

### 4.1 独眼魔狼（普通）

**基本设定**：
- 类型：凶残妖魔，大都栖息在荒山野岭
- 特征：巨狼型脑袋，唯有一只独目，半直立状态（像人狼）
- 性格：对人类有天性的敌意，非常喜欢把人类作为食物，享受杀戮，贪婪、凶残
- 原文描述："独眼魔狼，这是在妖魔课上老师们无数次提到过的凶残妖魔，和巨眼猩鼠这种活在阴暗角落的生物不同，独眼魔狼大都栖息在荒山野岭，它们对人类有着天性的敌意，甚至非常喜欢把人类作为食物"

### 4.2 独眼魔狼（进阶期）

**特殊设定**：
- 来源：偷吸了博城地圣泉的庞大能量
- 体型：比普通独眼魔狼大两号左右
- 状态：正在进阶中，强迫进阶后气息暴涨
- 力量：极强，能无视火滋·爆裂，直接撕开水御·守护
- 速度：极快，20米1秒穿过，比汽车飞撞还可怕
- 敏捷：矫健无比跳跃在废墟之间，能跳过火焰墙
- 身体：厚实肌肉和钢板之躯，骨头硬（撞镰骨盾后脑袋出血还能站起来）
- 惧怕：雷系魔法（肌肉麻痹、骨骼无法生长）
- 进阶征兆：肌肉变透明，血管清晰可见高温炙热快速流淌，骨骼噼啪乱响，肩骨从肌肉里生长出来变成锋利棱角，脊梁骨生长穿透肌肉变成满是棘骨的背脊

**战斗表现**：
- 追出工地到老街，撞碎临时墙
- 撞镰骨盾被弹飞十来米，脑袋出血还能站起来
- 被两个冰系叠加冰蔓牵制，行动缓慢但能挣脱
- 强迫进阶后气息暴涨，冰蔓被蒸发
- 火滋·爆裂安然无恙
- 一爪撕开徐大荒胸膛（水御·守护无效）
- 被雷印·狂策压制，肌肉麻痹，骨骼生长回缩
- 适应雷印后再次蜕变
- 被暴浪·驱逐冲垮，从街道中央冲到街尾
- 被风盘·龙卷拽到20多米高空摔下，粉身碎骨

**掉落**：
- 精魄（价值500万，因为偷吸地圣泉受到好东西滋养）

## 五、地点设定提取

### 5.1 老榕树街区（榕树街）

**基本设定**：
- 位置：博城老城区
- 状态：拆迁废墟，投资方资金严重短缺，留下残桓断壁
- 规划：打算建造成一片新商业区
- 环境：灰尘弥漫，到处是工地临时围墙，坑坑洼洼，半拆迁房屋残骸，烂尾楼
- 居民：大部分搬离，某些流浪汉暂住危楼，剩下一些不愿意搬走的老人（如周敏奶奶）
- 夜晚：荒无人烟，远处灯火辉煌照耀不到，乌云遮蔽夜空，星芒无法驱散灵异氛围

**关键地点**：
- 周敏奶奶家（老宅子）
- 广场大工地（震颤区域）
- 烂尾商场楼（独眼魔狼藏身之处，楼层面积大，堆水泥袋工具废材料）
- 老榕树街道（半拆迁状态，过了就是繁华商业街区）

### 5.2 繁华商业街区

**位置**：老榕树街道对面，隔着几栋整修楼房
- 内容：居民楼、商铺、娱乐场所、广场
- 人群：看电视的一家老小，准备七夕礼物的女孩们，悠闲散步的老夫妻
- 意义：猎妖队不撤退的原因，大量平民无自保能力

### 5.3 穆氏庄园

**场景**：
- 蔚蓝色私人游泳池
- 人工园林
- 别致小院子（古风茶屋，在欧式大庄园里显得奇怪）
- 主人房

## 六、玩家可介入点

### 6.1 老街区调查（第63章）

**玩家介入方式**：
1. 周敏主动找玩家帮忙（如果玩家和周敏关系好）
2. 玩家独自在老街区探索时发现异常
3. 猎妖队任务分配（如果玩家是猎妖队成员）

**玩家选择**：
- 答应帮忙 / 拒绝 / 要求报酬
- 带寻妖粉 / 不带（影响调查效率）
- 白天去 / 晚上去（影响遭遇概率）

**体验目标**：
- 悬疑探索感
- 周敏关系提升
- 寻妖粉道具使用教学

### 6.2 独眼魔狼遭遇（第64-65章）

**玩家介入方式**：
1. 和周敏一起调查时遭遇
2. 独自探索时遭遇
3. 路过老街区时被卷入

**玩家选择**：
- 悄悄观察 / 直接战斗 / 逃跑
- 用手机通知猎妖队（会暴露位置！）/ 不用手机
- 保护周敏 / 自己先跑

**体验目标**：
- 惊悚感（发现吃人的妖魔）
- 紧张追逐战
- 道具使用（火焰墙阻隔）
- 机制教学（妖魔感知手机信号）

### 6.3 镰骨盾防御（第66章）

**玩家介入方式**：
1. 玩家有防御魔具时体验
2. 玩家没有防御魔具时需要其他方式躲避
3. 郭彩棠及时出现救援

**玩家选择**：
- 正面抵挡 / 侧面躲避 / 继续逃跑
- 使用防御魔具 / 不使用（影响受伤程度）

**体验目标**：
- 防御魔具体验
- 危机救援感
- 郭彩棠关系建立

### 6.4 猎妖队团队战斗（第67-68章）

**玩家介入方式**：
1. 作为猎妖队成员参与
2. 作为外援参与（变装隐藏身份）
3. 旁观者（不推荐，体验差）

**玩家选择**：
- 主动出击 / 待命 / 逃跑
- 使用什么技能（根据法系）
- 是否保护队友

**体验目标**：
- 团队配合感
- 绝望感（徐大荒被撕开胸膛）
- 元素克制体验（雷系专治力量型）

### 6.5 精魄收集（第70章）

**玩家介入方式**：
1. 玩家有小泥鳅坠（或类似收集器皿）时自动收集
2. 玩家没有收集器皿时无法收集（精魄3分钟内消散）
3. 玩家可以看到精魄（如果有特殊能力）

**玩家选择**：
- 立即收集 / 先检查尸体 / 先照顾队友

**体验目标**：
- 收获感（500万精魄）
- 特殊能力展示
- 信息差（其他人不知道精魄价值）

### 6.6 星尘魔器升级（第70章后）

**玩家介入方式**：
1. 玩家有成长型星尘魔器（如小泥鳅坠）时体验升级
2. 玩家没有成长型星尘魔器时无法体验
3. 升级过程自动触发（吸收精魄后）

**体验目标**：
- 成长感（凡级→灵级）
- 效果提升（滋养星尘=冥修）
- 长期目标（继续收集精魄升级）

### 6.7 周敏感谢（第70章后）

**玩家介入方式**：
1. 玩家救了周敏和她奶奶后，周敏在宿舍门口等
2. 玩家没有参与救援时，周敏不会有这个互动

**玩家选择**：
- 安慰 / 开玩笑 / 冷淡

**体验目标**：
- 关系提升

## 八、系统机制识别

### 8.1 技能分级系统（深化）

**已识别的技能分级**：
- 火系：灼烧→焚骨→爆裂
- 冰系：冰蔓→凝结→覆盖
- 雷系：蟒痕→狂策→？
- 风系：疾行→闪步→？
- 土系：挪移→迟缓→？
- 水系：化解→守护→？

**设计建议**：
- 每个系初阶技能分3级
- 每级有不同效果和名称
- 2级技能通常有特殊机制（如雷印狂策的电弧传递）
- 3级技能通常是大范围或高伤害（如火滋爆裂、冰蔓覆盖）

### 8.2 星尘魔器分级系统

**分级**：
- 凡级：缓解疲劳
- 灵级：缓解疲劳+滋养星尘（相当于冥修）
- 后续可能有更高等级（魂级？神级？）

**成长型星尘魔器**：
- 小泥鳅坠是成长型
- 需要精魄升级
- 升级过程：化茧重生→表层蜕变→效果提升
- 设计建议：玩家可以有自己的成长型星尘魔器

### 8.3 精魄/残魄收集系统

**收集方式**：
- 小泥鳅坠自动收集
- 亡灵系法师用特殊器皿收集
- 精魄3分钟内消散

**用途**：
- 成长型星尘魔器升级
- 可能有其他用途（如召唤系？）

**经济价值**：
- 残魄1万
- 精魄500万
- 设计建议：游戏内经济系统要平衡

### 8.4 妖魔进阶机制

**进阶条件**：
- 偷吸地圣泉等好东西
- 被逼迫时强迫进阶

**进阶效果**：
- 体型变大
- 力量暴涨
- 肌肉变透明，血管可见
- 骨骼生长（肩骨、脊梁骨刺出）
- 挣脱控制（冰蔓被蒸发）

**进阶压制**：
- 雷系魔法可以压制进阶（肌肉麻痹，骨骼生长回缩）
- 但妖魔会适应电击，再次蜕变

### 8.5 元素克制深化

**已识别的克制关系**：
- 雷系克制力量型生物（肌肉麻痹）
- 冰系克制速度型生物（冻结减速）
- 火系克制植物型（燃烧）
- 水系克制火系（灭火）
- 土系克制雷系（绝缘）
- 风系克制土系（吹散）

**设计建议**：
- 不同妖魔类型有不同弱点
- 玩家需要根据妖魔类型选择技能
- 增加战斗策略性

### 8.6 中阶魔法系统

**中阶法师特征**：
- 双系（第二次觉醒）
- 脚下星图
- 中阶技能威力远超初阶

**已识别的中阶技能**：
- 水系：暴浪·驱逐
- 风系：风盘·龙卷
- 后续可能有其他系中阶技能

**设计建议**：
- 玩家后期可以达到中阶
- 中阶技能要有震撼感
- 中阶法师是重要NPC

1. **玩家视角优先**：每个事件都分析了玩家可介入方式和选择，不是只描述莫凡的经历

3. **三标记清晰**：必做/建议做/可选做，优先级明确

5. **伏笔追踪**：识别了6条重要伏笔，关联后续剧情

### 11.2 方法论可优化的地方

1. **技能分级表格化**：可以整理一个完整的技能分级表，方便后续开发参考
2. **妖魔类型分类**：可以按类型（力量型/速度型/植物型等）分类，关联元素克制
3. **地点连通性**：可以标注地点之间的连通关系，方便地图设计
4. **NPC关系图**：可以整理NPC之间的关系网，方便社交系统设计
5. **时间线标注**：可以标注事件发生的时间（高三开学/暑假等），方便剧情阶段管理
