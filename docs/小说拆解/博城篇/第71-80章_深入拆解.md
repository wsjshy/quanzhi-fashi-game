## 二、世界设定提取

### 2.1 星尘魔器分级系统（深化）

**凡级星尘魔器**：
- 滋养效果：被温泉浸泡，浑身随着舒服的热量和柔软的流淌而舒展开
- 作用：快速放松身体和精神，缓解修炼疲劳
- 效果：让魔法师可以持续修炼更长时间（莫凡一天修炼12小时）

**灵级星尘魔器**：
- 滋养效果：被柔软的蚕丝包裹，紧紧贴在身体，清爽舒服
- 额外作用1：不冥修的时候，星尘也会缓慢增长
- 额外作用2：冥修的时候，星尘会以平常更高效率的增长
- 原文描述："灵级的星尘魔器不单单是让莫凡可以不间断的冥修之外，还能够一定程度上直接滋养星尘。不冥修的时候，星尘也会缓慢增长。冥修的时候，星尘会以平常更高效率的增长！"

**小泥鳅坠升级过程**：
- 吸收精魄后，小泥鳅坠跟小婴儿一样醒过来
- 轻轻颤晃的同时焕发出只在方圆一指的区域绽放出光芒
- 光芒粘稠无比，像蚕丝一样将黑不溜秋的坠子包裹起来
- 化茧重生，表层出现明显蜕变，不再锈迹斑斑，有几分玉石的光泽
- 完全蜕变后，胸膛位置不断传递非常舒服的能量

**设计建议**：
- 星尘魔器分级：凡级→灵级→魂级→神级（后续可扩展）
- 每级效果差异明确：凡级=延长修炼时间，灵级=被动增长+修炼效率提升
- 成长型星尘魔器（如小泥鳅坠）需要精魄升级
- 玩家可以有自己的成长型星尘魔器，长期成长目标

### 2.2 星尘→星云晋升设定

**初阶法师**：
- 精神世界形成的系被称之为星尘
- 星尘内的星子连成星轨，便是初阶魔法
- 星子蜕变到第3级之后，离中阶法师比较近了

**中阶法师**：
- 精神世界的星尘化作了星云，一个看上去更加绚丽璀璨的星之区域
- 星云比星尘更加庞大，蕴藏更多魔能，游荡更多星子
- 星云内的星子连成星图，便是中阶魔法
- 中阶法师脚下有星图（释放中阶魔法时）
- 原文描述："星尘内的星子连成星轨，便是初阶魔法！星云内的星子连成星图，便是中阶魔法！"

**中阶魔法威力**：
- 水系中阶暴浪·驱逐：足以灌满一条街道的浪潮
- 风系中阶风盘·龙卷：将妖魔拽到20多米高空摔下
- 和初阶技能根本不是一个层次

**设计建议**：
- 玩家后期可以达到中阶
- 中阶技能要有震撼感（大范围、高伤害）
- 星图展示是中阶法师的视觉标志
- 晋升中阶需要：星子3级+星尘化作星云+第二次觉醒（双系）

### 2.3 引导觉醒系统

**基本设定**：
- 绝大多数人第一系觉醒都是元素魔法
- 总会有一些特例（如叶心夏初阶觉醒治愈系）
- 通过某种特殊的东西进行觉醒引导，有一定概率觉醒特定魔法系
- 原文描述："绝大多数人第一系的觉醒都是元素，但总会有一些特例，另外我听说通过某种特殊的东西进行觉醒引导的话，是有一定的概率觉醒特定魔法系的"

**觉醒规则**：
- 初阶：一系（随机，元素为主，特例可觉醒白/黑/次元）
- 中阶：双系（第二次觉醒，可引导觉醒特定系）
- 高阶：三系（第三次觉醒）

**莫凡的计划**：
- 中阶第二次觉醒时引导觉醒暗系（暗影系）
- 需要收集引导物质

**设计建议**：
- 引导觉醒是玩家中后期的重要目标
- 引导物质需要收集（稀有物品/任务奖励）
- 不同系需要不同引导物质
- 觉醒结果有概率性，增加期待感
- 玩家可以选择觉醒方向（元素/白/黑/次元）

### 2.4 地圣泉争夺系统

**地圣泉**：
- 归属：博城特殊资源
- 效果：相当于加强版星尘魔器，让修炼速度飞驰
- 作用：不单单缓解修炼疲劳，更可以让修炼速度飞驰
- 机会：一辈子只有一次的绝佳修炼机会
- 开启：不是想开启就能够开启的
- 修炼时间：整整一个星期
- 目标：冲击中阶法师的最佳机会

**争夺规则**：
- 专门提供给即将升入魔法大学的学生
- 非常有限，每一届只能够为一名学生开启
- 学校学生和魔法家族、世家子弟都要竞争争夺
- 已经很多年魔法学校的学生没有拿到这个唯一资格了（被家族子弟承包）
- 决斗胜者获得地圣泉修炼机会

**世家优势**：
- 世家可以将资源集中在一个出色子弟身上
- 得到的熏陶和训练不是学校大锅饭能够提供的
- 装备优势：魔具、魔器数量多

**设计建议**：
- 地圣泉是博城篇的重要奖励
- 玩家可以代表学校或世家参与争夺
- 决斗是主要争夺方式（PVP-like，NPC对战）
- 获得地圣泉后可以快速提升实力（一周修炼=数月效果）
- 世家vs学校的势力之争是博城篇的重要主题

### 2.5 技能魔具系统

**履魔具（印地波技能）**：
- 类型：土系魔具，印上了地波技能
- 效果：凭空多出一个土系地波技能，身形平行挪动四五米
- 限制：每使用一次都需要用魔石重新充能一次才可以继续使用
- 原文描述："履魔具，还是一个印上了地波技能的土系魔具！凭空多出了一个土系的地波技能……还好这印上了技能的魔具每使用一次都需要用魔石重新充能一次才可以继续使用"

**魔具vs魔器**：
- 魔具：印上技能的装备，使用后需要充能（如履魔具、镰骨盾）
- 魔器：星尘魔器，辅助修炼（如小泥鳅坠）
- 宇昂成年礼上穆卓云送了多件魔具和魔器

**设计建议**：
- 技能魔具是重要装备系统
- 不同部位的魔具可以印不同技能（鞋=位移，盾=防御，戒指=攻击等）
- 使用后需要充能（魔石消耗），增加策略性
- 稀有魔具可以让玩家凭空多出技能，丰富战斗选择
- 世家子弟装备优势是重要设定

### 2.6 技能灵活运用机制

**火滋·灼烧的多种用法**：
1. **直接攻击**：往敌人身上抛去（最常见用法）
2. **火焰墙**：释放在一定区域造成持续燃烧，封路和阻隔
3. **自我保护**：直接让火滋滑落到脚下，凭借本身对自己火焰的抵抗相当于给自己施加一层火焰保护，粉碎冰系魔法师冰蔓的冻结作用

**原文描述**：
- "事实上火滋的灼烧效果其实有很多用途，比如说释放在一定区域造成持续的燃烧形成一片火焰的话就形成了一道封路和阻隔的火墙，而像莫凡这样直接让火滋滑落到脚下，凭借着本身对自己火焰的抵抗相当于给自己施加了一层火焰的保护，这火焰的保护至少可以粉碎掉冰系魔法师冰蔓的冻结作用"
- "在技能如此匮乏的阶段里，如何灵活的运用技能是一门很深的学问"

**设计建议**：
- 同一技能有多种用法（攻击/防御/控制/辅助）
- 玩家可以选择技能释放方式（目标/区域/自身）
- 技能克制关系（火滋破冰蔓）
- 鼓励玩家创新用法，而不是固定套路
- 技能等级提升后解锁更多用法

### 2.7 冰蔓分级（完整）

**冰蔓1级**：
- 基础冻结，范围一整片
- 站在冰蔓区域3秒钟下半身被冻成冰棍

**冰蔓2级·凝结**：
- 飞霜蔓延，凝结下肢为冰棍
- 渗透效果：在冰蔓区域时间越长，肌肉和骨骼越僵硬

**冰蔓3级·覆盖**：
- 大面积寒冰蔓延，冰冻一大片
- 狂雪降临，温度骤降到连火焰都无法持续燃烧
- 整个决斗场茫茫一片，大雪寒冰冷酷无情
- 不管躲到决斗场任何一个地方都会在几秒钟后冻成冰
- 原文描述："冰蔓·覆盖简直就是一场冰灾落下，火焰都给熄灭了"

**宇昂的成就**：
- 18岁掌握3级冰蔓·覆盖
- 很多老魔法师到了四五十岁也都会吹嘘他2级的冰蔓技能
- 很多冰法师一辈子都跨入不到3级境界
- 郭彩棠到现在都没有掌握3级冰蔓

## 三、NPC设定提取

### 3.1 朱校长

**基本设定**：
- 身份：天澜魔法高中大校长
- 性格：半隐士，威望极高，最得民众之心，语重心长
- 立场：培养草根魔法师，挖掘没有背景的出色魔法师
- 与穆卓云关系：博城两个老对头，草根魔法vs世家魔法师的代表
- 原文描述："朱校长在博城的威望非常高，毕竟他是最得民众之心的，很多草根魔法师出人头地都离不开朱校长的支持"

**对莫凡的态度**：
- 和邓凯一直对莫凡很上心，派人留心照料
- 年度考核3S+历练灭幽狼兽，如获珍宝
- 希望莫凡在决斗中获胜，但也知道难度很大
- 语重心长教导："天赋很重要，修炼也很重要，更重要的是审时度势，别做无意义的事"

**设计建议**：
- 朱校长是学校势力的代表
- 玩家可以获得朱校长的支持和资源
- 朱校长vs穆卓云的势力之争是博城篇重要主题
- 朱校长的教导是玩家成长的指引

### 3.2 邓凯

**基本设定**：
- 身份：博城猎者联盟大长老
- 实力：在杨作河（中阶法师）之上
- 立场：完全站在学生这一边
- 与莫凡关系：当初站出来帮莫凡的人

**对莫凡的态度**：
- 帮莫凡拖了两年时间（把事情往切磋上引）
- 知道宇昂修为突飞猛涨，莫凡未必是对手
- 安慰莫凡：胜负不用看得太重，穆氏报复不用担心
- 做决斗裁判，位置可以马上出手应对意外

**设计建议**：
- 邓凯是猎者联盟势力的代表
- 玩家可以获得邓凯的支持
- 邓凯实力强大，是重要NPC
- 决斗裁判角色

### 3.3 斩空

**基本设定**：
- 身份：军方总教官，博城城市真正守护战神
- 实力：这群人中实力最强劲的魔法师
- 性格：猥琐帅大叔，被少妇围绕，笑眯眯，但认真时眉宇间透着认真
- 立场：超脱世俗，不怕任何人，"谁动他的兵，分分钟杀到他们家去"

**对莫凡的态度**：
- 已经不是第一次要拉莫凡入他的队
- 承诺：军部支撑魔法大学大开销，政府部门保你，看哪个二世祖不满都可以踩
- 被莫凡回绝后："今天你点头，以后摊上大事总教官铁定帮你摆平。既然你这么倔，你被宇昂打个半死我也不管了"
- 神秘提示：一手掌摁在莫凡肩头，"不入我队也行，帮我个小忙。你和宇昂那小子决斗的时候多留意一下。"
- 没说留意什么，就被老熟人叫走了

**伏笔**：
- 斩空让莫凡决斗时多留意什么？（后续剧情揭示）
- 可能和宇昂的魔具、穆氏的阴谋、或博城灾难有关

**设计建议**：
- 斩空是军方势力的代表，实力最强
- 玩家可以选择加入军方或拒绝
- 斩空的神秘提示是重要伏笔任务
- 斩空的保护是玩家的后盾

### 3.4 穆宁雪

**基本设定**：
- 身份：穆卓云亲生女儿，穆氏最完美的接班人
- 实力：太出色，小小博城已经不是她该争夺的了
- 性格：冷漠，清灵好听的声音，对莫凡有感情
- 与穆卓云关系：不是很好，穆卓云揪着莫凡不放她不满

**对莫凡的保护**：
- 问了心夏找到莫凡，劝他明天别去
- "宇昂会对你下狠手，他对我父亲言听计从，任何对我父亲不利的哪怕只是一句骂他都会嫉恶如仇，不死不休"
- 计划："躲过了这劫，马上到魔法大学去，你在大学的四年我会慢慢掌控家族里的权力，到时候你在回博城没有人会拿你怎么样"
- 底线：对穆卓云说"那叫宇昂适可而止！"

**穆卓云的真正目的**：
- 成年礼本来准备给穆宁雪的，但她太出色
- 给宇昂，宇昂死心塌地，将来可以成为穆宁雪和大世家其他系子弟相争的左膀右臂
- 穆宁雪是穆卓云最完美的接班人，博城池子太小
- 宇昂是穆宁雪的垫脚石

**设计建议**：
- 穆宁雪是重要NPC，对玩家有感情
- 玩家可以选择接受穆宁雪的保护或坚持决斗
- 穆宁雪vs穆卓云的家庭矛盾是重要剧情
- 穆宁雪的实力和地位是玩家的潜在盟友

### 3.5 莫家兴

**基本设定**：
- 身份：莫凡父亲，司机/跑车
- 性格：乐观派，憨然笑容，单纯直白，为儿子骄傲
- 外貌：黝黑干瘦了很多，三年没有停止为家奔波

**对莫凡的爱**：
- 特意来接莫凡放学
- 想筹钱给莫凡买星尘魔器（不知道莫凡已经有了）
- "你的钱自己留着，魔法师要钱的地方多着呢"
- 卡里有十来万（莫凡汇的）+跑车八年存的八万=二十万，能买个魔具
- 对决斗的态度：托穆氏老人家劝宇昂放点水，莫凡就是去给成年礼添彩头
- 觉得这是天大好事，能在博城有头有脸人物面前展示自己
- 高兴地跟旁边穆氏老员工说"那是我儿子"

**原文描述**：
- "魔法替代了科学，但莫家兴还是和一位再平常不过的父亲一样单纯、直白"
- "至少，自己对得起莫家兴当初毫不犹豫将自己送入魔法学校的决定！"

**设计建议**：
- 莫家兴是玩家的情感支柱
- 父爱的展现是重要剧情
- 玩家可以通过努力让父亲过上好日子
- 莫家兴的乐观和单纯对比世家的复杂

### 3.6 宇昂（深化）

**基本设定**：
- 身份：穆卓云养子，穆氏家族掌管接班人
- 法系：冰系（冰蔓·覆盖，3级）
- 性格：阴沉、高瘦、骄傲、对穆卓云言听计从、嫉恶如仇、不死不休
- 外貌：换上特制衣装后宛如王子，白如雪衣裳上有家族与冰系魔图相融合的图案

**实力**：
- 18岁掌握3级冰蔓·覆盖（很多冰法师一辈子达不到）
- 修为在这两年突飞猛涨，再加上家族提供的实战演练
- 装备：多件魔具和魔器（穆卓云成年礼送的）
- 履魔具：印上地波技能，凭空多出位移技能

**决斗表现**：
- 握手时手掌心凝结寒冰，寒冷之气要入侵莫凡骨髓
- "你真是一个什么都不懂的小杂鼠。不过没关系，我会把你脑子里面进的水全部冻成冰"
- 冰蔓·凝结（2级）被莫凡火滋·灼烧破解
- 用履魔具躲避火滋·焚骨
- 释放冰蔓·覆盖（3级），整个决斗场变成冰灾，莫凡守护火焰熄灭

**设计建议**：
- 宇昂是博城篇的主要对手
- 3级冰蔓+多件魔具的装备优势是重要挑战
- 玩家需要用策略和技能灵活运用来战胜
- 宇昂的阴沉和嫉恶如仇是人设特点

### 3.7 唐月老师（伏笔）

**基本设定**：
- 身份：天澜魔法高中老师
- 特殊表现：对穆卓云那番话有些感冒，饮酒的时候都在翻白眼
- 伏笔：唐月的真实身份（审判会？），对穆卓云的态度暗示了什么

**设计建议**：
- 唐月的身份是重要伏笔
- 对穆卓云的态度暗示后续剧情
- 玩家可以逐渐发现唐月的真实身份

## 七、系统机制识别

### 7.1 星尘魔器分级系统

**分级**：
- 凡级：缓解疲劳，延长修炼时间
- 灵级：缓解疲劳+被动增长+修炼效率提升
- 后续可扩展：魂级、神级

**成长型星尘魔器**：
- 小泥鳅坠是成长型
- 需要精魄升级
- 升级过程：化茧重生→表层蜕变→效果提升

**设计建议**：
- 玩家可以有自己的成长型星尘魔器
- 长期成长目标
- 收集精魄的动力
- 不同等级效果差异明显

### 7.2 引导觉醒系统

**觉醒规则**：
- 初阶：一系（随机，元素为主）
- 中阶：双系（第二次觉醒，可引导）
- 高阶：三系（第三次觉醒）

**引导觉醒**：
- 需要特殊引导物质
- 有概率觉醒特定系
- 不同系需要不同引导物质

**设计建议**：
- 引导觉醒是中后期重要目标
- 引导物质收集是任务动力
- 觉醒结果概率性增加期待感
- 玩家可以选择觉醒方向

### 7.3 地圣泉修炼系统

**效果**：
- 相当于加强版星尘魔器
- 修炼速度飞驰
- 一周修炼=数月效果
- 冲击中阶的最佳机会

**争夺**：
- 一年一人
- 学校vs世家决斗争夺
- 胜者获得

**设计建议**：
- 地圣泉是博城篇重要奖励
- 获得后可以快速提升实力
- 争夺过程是重要剧情
- 世家vs学校的势力之争

### 7.4 技能魔具系统

**类型**：
- 履魔具：印位移技能（地波）
- 盾魔具：印防御技能（镰骨盾）
- 其他部位：可印不同技能

**限制**：
- 使用后需要魔石充能
- 不能无限使用
- 增加策略性

**设计建议**：
- 技能魔具是重要装备系统
- 丰富战斗选择
- 世家子弟装备优势
- 魔石消耗是经济系统

### 7.5 技能灵活运用机制

**同一技能多种用法**：
- 直接攻击
- 区域释放（火墙、冰面）
- 自我保护（火焰护体）
- 控制（减速、冻结）

**技能克制关系**：
- 火滋破冰蔓（火焰融化冰霜）
- 雷系克力量型（肌肉麻痹）
- 冰系克速度型（冻结减速）

**设计建议**：
- 鼓励玩家创新用法
- 技能释放方式选择
- 技能克制关系
- 以弱胜强的策略性

### 7.6 PVP决斗系统

**规则**：
- 裁判（邓凯）
- 点到为止
- 意外时裁判可以马上出手

**流程**：
- 握手（可以暗中较量）
- 裁判宣布开始
- 多阶段战斗
- 胜负判定

**设计建议**：
- PVP-like NPC对战
- 多阶段战斗设计
- 装备和技能的策略性
- 万众瞩目的仪式感

### 7.7 势力之争系统

**博城四大势力**：
- 学校（朱校长）：草根魔法师
- 世家（穆卓云）：贵家子弟
- 猎者联盟（邓凯）：猎人势力
- 魔法协会（杨作河）：官方势力
- 军方（斩空）：最强战力

**势力之争**：
- 地圣泉资格争夺
- 人才争夺（斩空拉拢莫凡）
- 政治较量

**设计建议**：
- 玩家可以选择阵营
- 影响NPC关系
- 影响剧情分支
- 势力平衡是博城篇重要主题
