## 二、8维度拆解

### 维度1：世界设定

**新增/深化设定**：

1. **年度考核制度**：
   - 两项考核：第一项星尘测试（绝大多数学生只要这项通关），第二项释放考核（尖子生，约100人）
   - 星感石测试：手掌放上去，集中精神冥修，星感石印射光芒，考官评分
   - 每个学生3次机会，以最强一次为准
   - 评分等级：D/C/B/A/A+/S（S为最高，光芒外溢）
   - 全校通报请离制度：星尘几乎没有增长的学生会被全校通报请离（一届未必有一个，用于鞭策后进生）
   - 考核结果决定：分班（尖子班/普通班）、星尘魔器分配时间、是否被请离

2. **星感石**：
   - 黑色鹅卵石大小，西瓜那么大，石墩托着
   - 根据测试者星尘光辉强弱印射光芒
   - 可以被暗石干扰（暗石吸走能量，让光芒黯然）
   - 考核后会重新检查，防止作弊

3. **暗石**：
   - 作弊工具，放在星感石下，吸走能量让光芒黯然
   - 可以把C级成绩拉到D甚至更低
   - 被唐月通过感应发现

4. **尖子班制度**：
   - 年度考核后按成绩分班
   - 尖子班福利：星尘魔器分配时间、更好的修炼资源、唐月任实践课老师
   - A级以上有望进种子班/尖子班

5. **穆氏世家结构**：
   - 穆卓云：家主，跺跺脚博城震三震，掌握家族大权
   - 穆贺：校董，三把手/四把手，穆白叔叔，穆阳（穆白父亲，过世）的弟弟
   - 穆宁雪：穆卓云女儿，15岁被帝都魔法学府破格录取，家族骄傲
   - 穆江铭：穆卓云长子，家族嫡系子弟
   - 穆白：旁系子弟（穆阳儿子），寄人篱下，渴望进入核心
   - 家仆体系：赵坤三家是穆氏家仆，整个城区以前都是穆氏家的

6. **帝都魔法学府（苍明学府）**：
   - 国内最好的魔法学府
   - 博城每届能考上几个就了不起
   - 穆宁雪15岁破格录取（没经历魔法高级预备部）
   - 初阶雷印释放在那里只是基本功

7. **猎者联盟**：
   - 邓凯：猎者联盟高层，天澜高中校董，所有校董中修为最高、实力最强
   - 猎者联盟有校董席位

8. **考核作弊与公正**：
   - 校董可以通过权力安排考试顺序、安插考官
   - 秃顶考官是穆贺的人
   - 但有唐月这样正直的老师可以发现问题
   - 校长在证据面前会要求公正处理

**对游戏的意义**：
- 年度考核是博城篇第一个大玩法节点，需要完整实现（星感石测试+释放考核+评分+分班+奖励）
- 暗石陷害是剧情关键，需要在游戏中体现（玩家可以选择是否揭露/帮助莫凡）
- 尖子班制度影响玩家后续资源获取，需要实现
- 穆氏世家结构是博城篇核心社会关系，需要在NPC关系中体现

**玩家视角关键**：
- 玩家不是莫凡，不会有莫凡的S级逆袭和完美释放
- 玩家的考核成绩取决于玩家自己的修炼进度和选择
- 玩家可以选择是否介入莫凡被陷害的事件（帮助揭露或旁观）
- 玩家的成绩决定自己的分班和资源，不影响莫凡的剧情
- 玩家可以与穆白/许昭霆竞争，也可以选择合作
- 穆卓云可能根据玩家成绩决定是否招揽玩家（如果玩家表现足够好）

#### 🆕 需新增

1. **星感石测试玩法**
   - 年度考核第一项：手掌放星感石→集中精神→光芒评分
   - 评分等级：D/C/B/A/A+/S，S级有光芒外溢特效
   - 3次机会，取最强一次
   - 可以被暗石干扰（剧情事件）

2. **释放考核玩法**
   - 年度考核第二项（尖子生）：完整释放系技能
   - 评分根据释放流畅度、威力、稳定性
   - 只有掌握7颗星子的学生可以参加
   - 加分项，影响最终排名和奖励

3. **年度考核完整剧情线**
   - 考核前：赵坤三嘲讽、穆白挑衅、穆宁雪出场
   - 考核中：何雨A→张小侯A+→许昭霆雷印→穆白3S→莫凡被陷害B→唐月发现暗石→莫凡重考S→完美火滋
   - 考核后：穆卓云招揽莫凡、穆白崩溃、分班结果、星尘魔器分配
   - 玩家可以在各个节点选择介入或旁观

4. **暗石陷害事件**
   - 穆白/穆贺在星感石下放暗石，吸走能量
   - 唐月通过感应发现异常
   - 玩家可以选择是否帮助揭露
   - 重考后莫凡S级逆袭

5. **尖子班/分班系统**
   - 年度考核后按成绩分班
   - 尖子班福利：星尘魔器时间、唐月辅导、更好资源
   - 被请离：成绩过低（D级以下）会被学校请离
   - 玩家的分班影响后续游戏内容

6. **穆氏世家关系系统**
   - 穆卓云/穆贺/穆宁雪/穆白/穆江铭等家族成员
   - 家仆体系（赵坤三家）
   - 家族资源分配（修炼资源、星尘魔器）
   - 玩家可以选择是否与穆氏合作/对抗

7. **考核作弊与公正机制**
   - 校董权力可以影响考核（安排顺序、安插考官）
   - 正直老师可以发现问题（唐月）
   - 玩家可以选择是否揭露作弊
   - 影响剧情公正度和NPC关系

#### ✂️ 需裁剪

1. **秃顶考官**：不需要完整NPC，作为事件中的功能性角色即可
2. **其他校董**：不需要完整对话树，通过集体出场体现
3. **其他班级学生**：不需要完整NPC，通过环境台词和集体反应体现
4. **穆江铭**：本章节只提及未出场，不需要立即做NPC，后续篇章再展开

### 维度8：玩家视角反思

**关键原则**：玩家不是莫凡，玩家有自己的人生。

1. **考核成绩**：玩家不应该有莫凡的S级逆袭。玩家的成绩取决于自己的修炼进度：
   - 努力修炼的玩家：B-A级，可能进尖子班
   - 普通玩家：C-B级，普通班
   - 不修炼的玩家：D级，可能被请离
   - 玩家不应该轻易达到S级（那是莫凡的主角光环）

2. **暗石陷害**：暗石是针对莫凡的，不是针对玩家。玩家可以选择：
   - 发现异常并告诉唐月（获得唐月好感、莫凡感激）
   - 旁观（不影响剧情，但错过机会）
   - 帮助穆白隐瞒（获得穆白/穆贺好感，但违背正义）
   - 玩家不应该是被陷害的对象（那是莫凡的剧情）

3. **穆卓云招揽**：穆卓云招揽的是莫凡（因为莫凡S级+火系是穆氏缺少的）。玩家如果表现足够好（A级以上+火系），也可能被穆卓云关注，但不应该轻易获得与莫凡同等的待遇。

4. **与穆白的竞争**：玩家可以与穆白竞争，但不应该复刻莫凡的"超越穆白"剧情。玩家的竞争应该是基于自己的实力和选择：
   - 玩家成绩比穆白好：穆白嫉妒玩家，可能针对玩家
   - 玩家成绩比穆白差：穆白无视玩家，或把玩家当背景
   - 玩家可以选择与穆白合作（如果玩家也是穆氏旁系）或对抗

5. **与穆宁雪的关系**：玩家不应该与穆宁雪有莫凡那样的复杂过去。玩家与穆宁雪的关系应该是：
   - 普通同学/校友（远远观察）
   - 如果玩家表现极好，可能被穆宁雪注意到
   - 玩家不应该轻易与穆宁雪建立亲密关系（那是莫凡的线）

6. **唐月的辅导**：唐月的辅导对所有达到条件的学生开放（掌控7颗星子）。玩家也可以获得，不需要"抢"莫凡的机会。

7. **年度考核后的分流**：
   - 尖子班玩家：获得更多资源、唐月辅导、星尘魔器时间
   - 普通班玩家：正常资源，需要更努力
   - 被请离玩家：游戏结束或转线（不推荐，应该避免）
   - 玩家的分流决定后续游戏内容的差异

## 四、方法论反思与优化

### 本次拆解发现的方法论问题

1. **大事件的剧情节点设计**：年度考核是持续10章的大事件，有多个剧情节点（出场→配角展示→阴谋→转折→高潮→收尾）。游戏设计时需要把这些节点转化为可交互的剧情阶段，而不是简单的"触发事件→结束"。
2. **玩家在大事件中的定位**：大事件的主角是莫凡（S级逆袭），玩家是旁观者/参与者。需要明确玩家在每个节点可以做什么、不能做什么，避免玩家"抢"莫凡的主角光环。
3. **NPC群像的处理**：年度考核有大量NPC出场（穆宁雪、穆卓云、穆贺、穆白、赵坤三、何雨、张小侯、许昭霆、唐月、薛木生、邓凯等）。需要严格区分core/background/functional，避免每个NPC都做完整对话树导致负担过重。
4. **数值与剧情的平衡**：年度考核有明确的数值（评分等级、星子数量、排名），但这些数值是为剧情服务的（莫凡S级逆袭）。玩家的数值不应该影响莫凡的剧情，但应该影响玩家自己的分流和资源。
5. **伏笔的密度**：年度考核章节埋了大量伏笔（莫凡隐藏实力、穆白嫉妒、穆卓云招揽、唐月身份、穆宁雪过去等）。游戏设计时需要有节奏地揭示这些伏笔，不能一次性全部抛出。

### 方法论优化建议

1. **新增"大事件剧情节点设计模板"**：大事件需要拆解为多个剧情节点，每个节点有明确的触发条件、玩家可介入点、NPC反应、后续影响。
2. **新增"玩家在大事件中的定位规范"**：明确玩家是旁观者/参与者/主角，玩家的选择影响自己的线，不影响莫凡的主线剧情。
3. **新增"NPC群像分层处理规范"**：大事件中的大量NPC按core/background/functional分层，core做完整对话树，background做环境台词+关键对话，functional只做事件中的临时角色。
4. **新增"数值与剧情分离原则"**：NPC的数值（莫凡S级）是剧情固定的，玩家的数值影响玩家自己的线，两者互不干扰。
5. **新增"伏笔揭示节奏表"**：大事件中的伏笔需要有明确的揭示节奏（哪些在本事件揭示，哪些在后续事件揭示，哪些在篇章结尾揭示）。

## 五、总结

第21-30章是博城篇第一个大高潮事件（年度考核），是经典的"扮猪吃老虎+逆袭"叙事结构。整个事件持续10章，节奏层层递进，有多个剧情节点和大量NPC出场。

**对游戏的核心价值**：
1. 年度考核是博城篇第一个大玩法节点，需要完整实现（星感石测试+释放考核+评分+分班+奖励+剧情）
2. 暗石陷害+唐月发现+莫凡S逆袭是关键剧情，需要在游戏中体现（玩家可选择介入）
3. 分班系统影响玩家后续资源获取，需要实现
4. 星尘魔器分配是核心成长系统，需要完善
5. 穆氏世家结构是博城篇核心社会关系，需要在NPC关系中体现

**玩家视角关键**：
- 玩家不是莫凡，不会有S级逆袭
- 玩家的成绩取决于自己的修炼进度
- 玩家可以选择是否介入暗石陷害事件
- 玩家的分班决定自己的后续资源，不影响莫凡的剧情
- 玩家不应该轻易获得与莫凡同等的待遇（穆卓云招揽、穆宁雪关注等）

**下一步**：继续拆解第31-40章（年度考核后续+地圣泉+修炼期），然后基于全部拆解结果制定博城篇内容完善计划。
