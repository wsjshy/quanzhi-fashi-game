## 二、世界设定提取

### 2.1 宇昂是黑教廷卧底（重大揭示）

**宇昂身份**：
- 穆卓云养子，穆氏家族重点培养对象
- 真实身份：黑教廷卧底，十年前就派到穆卓云身边潜伏
- 一直言听计从，一直跟伺候亲爹一样伺候着穆卓云
- 就为了博取他的信任，就是为了在那天拿下地圣泉
- 结果莫凡破坏了他十年潜伏的计划

**宇昂的脸**：
- 左脸颊皮肤近乎腐烂，感觉是被什么强酸物资泼过
- 眼球长在没有皮的眼眶上，看上去更加吓人
- 右脸完整，莫凡见过
- "我这张脸，就是拜你所赐！"
- 撒朗大人将他的脸压在鬼酸水里

**撒朗**：
- 黑教廷红衣执事
- 宇昂的上级
- 将宇昂脸压在鬼酸水里的人
- 那个男人是宇昂这辈子见过最可怕的人
- 宇昂不敢违抗撒朗，若是让撒朗大人知道，就不是毁掉他另一半脸的问题了

**黑教廷完整计划**：
- 激怒翼苍狼（虐杀翼苍狼幼崽）
- 挖掘地下入口（巨眼猩鼠挖地道）
- 狂暴泉水（暴躁之泉洒在云雾中，大雨催化）
- 偷换地圣泉（宇昂进入地圣泉偷换）
- 一切的一切都在黑教廷的掌控之中
- 原本应该宇昂这个黑教廷卧底进入到地圣泉内，轻松偷换地圣泉
- 结果那个人变成了莫凡，于是他们彻底摧毁博城的计划可以说是无法彻底完成了

**宇昂的动机**：
- 进入地圣泉的人应该是他，应该是他
- 只要他将地圣泉交给撒朗大人，他就能够成为黑教廷的执事
- 他为了这个计划付出了多少？十年
- 现在我也要让你尝尝这个滋味，不单单是脸，我要让你全身都浸泡在鬼酸水里，把你变成一只奴隶一样的黑畜妖

**设计建议**：
- 宇昂是博城篇的重要反派
- 黑教廷卧底身份的重大揭示
- 十年潜伏的隐忍和疯狂
- 脸被毁的复仇心理
- 撒朗的恐怖（后续篇章重要反派）
- 黑教廷完整计划的揭示
- 玩家遭遇宇昂时的应对

### 2.2 十只黑畜妖追杀

**黑畜妖设定深化**：
- 黑教廷的标志
- 其实根本就不是召唤兽，而是用人类活尸与一种妖的煞气混在一起的生物
- 更贴近亡灵生物
- 这些东西就是怨恨、愤怒、贪婪的化身
- 被黑教廷的人掌握了命脉之后便任意驱使着
- 它们本身喜欢杀戮之外，更有一个巨大的嗜好，那就是它们自己变成这副人鬼模样便希望把所有人也变成它们这种黑暗奴隶
- 这种嫉恶如仇更会传染，使得它们锲而不舍
- 战斗力介于巨眼猩鼠和独眼魔狼之间
- 在偷袭和追踪方面，更比那两者可怕得多
- 十只懂得相互协作进攻的黑畜妖可怕程度超过了十只独眼魔狼

**追杀过程**：
- 宇昂周围一共聚集了十只这种黑教廷怪物
- 由此可见他对莫凡的杀心是有多重
- 这一群分派到他这里的黑畜妖是撒朗吩咐下来让他们保护妖魔入口
- 可眼下看到莫凡这个家伙，宇昂已经连理智都没有了，无论如何都要将他彻底杀死
- 宇昂："黑畜妖是追踪的好手，它们逮到你后，会将你的皮一块块剥下，将你的骨一根根挑出，将你的器官一个个挖出，所以，好好享受吧，逃，你是怎么都不可能逃得出这十只黑畜妖的！！"

**电梯井逃亡**：
- 莫凡冲入到了电梯处，强行掰开了电梯门
- 电梯明显是在最底层，莫凡果断的跳入到几乎悬空的电梯井里
- 然后迅速的顺着电梯井垂下来的缆绳往上爬
- 刚往上爬了三米不到，下方就出现了一声难听的尖叫
- 正是一只黑畜妖也跳入到黑漆漆的电梯井内
- 电梯井内空间是有限的，那只黑畜妖并没有抓住缆绳，结果直接坠落到电梯井最底部
- 紧随其后，第二只黑畜妖也跳了进来
- 有了前面那只直接落下去的教训，这只黑畜妖倒是利用那爪子抓住了缆绳，然后凭借着强壮的前肢竟然往上攀爬的飞快

**电击对付黑畜妖**：
- "妈的，给老子下去！"莫凡骂了一句
- 他的双手紧紧的握住电缆，手指缝间一道道电弧迅速的沿着他的手掌传递到了这根明显有裸露的电缆上
- 电弧迅速往下传递，那只爪子几乎要抓到莫凡的黑畜妖遭受到突如其来的电击之后，前肢明显的那么一缩
- "吱~~~~~~~~~~~！"黑畜妖出了一声尖叫，身躯迅速的砸落了下去
- 正好就砸在了那只刚想要顺着电缆往上爬的第一支黑畜妖身上

**黑畜妖智慧（分兵）**：
- 穿过钢化玻璃电梯外层，莫凡发现这些黑畜妖竟然拥有一定的智慧
- 在发现莫凡可以使用雷电之力迫使它们无法跟着攀爬之后，这些黑畜妖做了一个让莫凡非常骂娘的行为——它们直接走楼梯！
- 大购物商场的设计一般都是自动扶梯和电梯同时具备的
- 它们将其中4只黑畜妖留在了电梯口，守着躲入到钢化玻璃电梯井内的莫凡
- 另外6只集体狂奔，朝着另一个方向的自动扶梯奔逐而去
- 显然是要到2楼、3楼的地方守着莫凡
- 电梯井的钢化玻璃它们或许很难摧毁，但电梯门基本上可以掰开的
- 要是被它们上下守住，莫凡小命肯定不保了

### 2.3 主控室监控找叶心夏

**主控室**：
- 购物商城的3楼有一个非常严密的控制室
- 当初和心夏来这里逛的时候自己找厕所，就差点闯到别人控制室里去了
- 那里的材质远比其它屋子厚实的多
- 若是能够躲到那里去，黑畜妖短时间伤不了自己
- 问题是，黑畜妖得爪子相当锋利，汽车的铁皮都能够一爪撕开
- 所以除非是那种特质的保险库它们无能为力之外，像这种民用的控制房不可能一直抵挡得了整整十只妖魔的冲击
- 总而言之，能拖一时，是一时！

**监控系统**：
- 控制室内其实就是监控室
- 整个购物广场的摄像头若是正常使用的话，都会在监控室上显示
- 而主控室的发电又往往是自有的发电机
- 那些摄像头在商场断电之后应该还能够正常使用
- 摆在他面前是宛如蜜蜂窝一样的监控电脑屏幕
- 基本上整个购物广场都尽收眼底，包括地下一层的沃尔玛超市

**找到叶心夏**：
- 超市很大，再加上那些货架排排列列，不少地方都挡住了视线，一眼扫去似乎根本没有看到任何一个人影
- 不对，这里有动静！
- 忽然，莫凡通过俯视的摄像机看到了一个缓缓蠕动的东西，从监控的角度来看，那好像是从沃尔玛货仓的地方爬出来的
- 莫凡又很快的找到了沃尔玛货仓的监控，却骇然的发现货仓的一个排污管道处竟然钻出了一只身上沾满血液的巨眼猩鼠！
- 地下世界就是巨眼猩鼠的巢穴，只要有通口它们都会钻到陆地上
- 此刻明显是有两只巨眼猩鼠通过那排污管道进入到了沃尔玛超市之中
- "还好心夏不在，不然就危险了……心夏，你到底在哪啊？"
- 当第二遍将沃尔玛超市的监控再扫一遍的时候，莫凡忽然锁定了一辆停靠在大饮料冰柜旁边的轮椅！！
- 莫凡立刻瞪大了双眼，尝试着将那个监控画面给拉近来
- 这个操作不算太难，莫凡很快找到了，当画面拉近的时候，莫凡更加确信那就是心夏的轮椅！
- 心夏不在轮椅上！！
- 莫凡感觉心脏好像被什么狠狠的刺中了一般，脑子里一片混乱
- 难道她……
- "恩，这是什么？？"刚刚如遭霹雳的时候，莫凡又无意间发现轮椅旁竖立的大冰柜内有什么东西在晃动
- 莫凡急忙将目光转向另外一个监控屏幕，并且再一次将镜头拉近来
- 屏幕之中，莫凡非常惊愕的发现就在那原本存放冷冻奶制品的大冰柜内竟然蜷缩着一个穿着素裙的黑长发女孩
- 轮椅就在旁边，冰柜里却躲着一个人，她一定是心夏，一定是她，纵然看不清她的脸庞，莫凡此刻也能够相当肯定！
- 太好了，真是太好了
- 莫凡差点眼眶都湿了

**叶心夏躲冰柜**：
- 她一个人在这个沃尔玛超市，很显然之前那批从沃尔玛逃出的人将她一个人遗弃在了这里
- 也幸好她被遗弃在这里，否则就和之前那批人一样全部惨死在巨眼猩鼠的獠牙之下
- 为了让自己的体温不会被巨眼猩鼠这种冷血动物感知到，她躲入的冰柜温度相当低
- 冰柜周围都是结着霜冰的
- 她，已经在瑟瑟发抖了
- 看到心夏这样无助的一人在沃尔玛超市里，看着她为了求生的瑟瑟颤抖的蜷缩在冰柜之中，莫凡心都要碎了

**两只巨眼猩鼠**：
- 从监控这里看到那两只沾满人血的巨眼猩鼠已经步入到叶心夏躲藏的那片鲜奶区域的时候
- 莫凡感觉自己的心脏噗咚噗咚的跳动了起来
- 试想想，冰柜里就躲着自己内心最重要的人，两只可以瞬间要她性命的巨眼猩鼠就在旁边游荡
- 这一幕又通过监控完全落在自己眼中，在只剩下咬紧牙关默默祈祷之时，那种紧张和不安会被无限放大，让人浑身都被汗毛竖立！！
- 那两只巨眼猩鼠并没有发现躲在冰柜里的叶心夏
- 但它们摆明了要在肉柜那边好好享受一番，短时间根本不可能离开沃尔玛超市
- 叶心夏不可能在那冰柜里躲超过半个小时！

### 2.4 冲击中阶（星尘化星云）

**决定冲击**：
- 不行，决不能这样！！
- 无论是自己所处的险境，还是叶心夏在躲避在躲避着死亡的步伐，光靠祈祷、等待就必定没有活路
- 门，很快就会被突破
- 叶心夏更不可能一直躲在那低温的冰柜里，没有氧气，更可能被活活的冻死在里面
- 那可是温度极低的冻奶冰柜啊！
- 狠狠的一咬牙，莫凡却不知他的唇角已经被自己咬破了
- 他死死的拽紧了拳头
- 他很明白自己再等待下去，只会让叶心夏离死亡更近一分
- 终于，莫凡猛的坐了下来，紧紧的闭上了自己的眼睛！！

**小泥鳅坠吸纳地圣泉**：
- "小泥鳅，我让你吸纳掉了所有的地圣泉……现在，我会尽我自己一切的努力去突破，请你把能够为我提供的所有能量全部赐给我！！"
- 莫凡看似对小泥鳅坠说道，其实也是在狠狠的对他自己说
- 之前在地厅的时候莫凡就多次冲击中阶魔法师而没有成功
- 这一次，他要借助小泥鳅坠的力量
- 地圣泉确实是被喝掉了，这点莫凡没有撒谎，只是不是莫凡自己喝掉，而是被小泥鳅坠彻底吸纳
- 莫凡现在要在这短短的时间里冲击一次自己的修为
- 但这一次，已经不容许他再失败！！！

**突破过程**：
- 紫色的星尘，红色的星尘，它们同时散发着时强时弱的光辉
- 在这两个星尘之外，一层淡淡的光幕将它们包裹着，而从星尘内部绽放的光辉正是要冲破这朦胧的光幕
- 光幕像蛋壳，像蚕蛹，包裹着即将破茧而出的能量
- 它们看上去在魔能的冲击下纹丝不动，却因为内部能量的翻涌出现了明显的肿胀
- "给老子破！！！"莫凡在内心呐喊着
- 胸前，小泥鳅坠的光辉就宛如是注入到了莫凡星尘之中的冲破之力，它们从原本的四面八方散发到忽然间的凝聚！
- 就像无数条小小的河流它们汇聚在一条江河之中，寂静的江河顿时奔涌，滚滚水浪冲击着河岸的堤坝！！
- 外层的蚕蛹终于出现了裂缝，蜘蛛纹呈现一种不规则的方式朝着周围扩散，裂纹变得越来越大
- 要成功了，要成功了！！
- 莫凡内心开始激动了起来，只不过在疯狂冲击着下一个境界的时候，莫凡可以感觉到自己精神承受着巨大的能量反弹，反弹得头疼欲裂
- 换作平常，莫凡相信自己根本无法坚持下去，反馈回来的精神冲击时而像一柄柄剑贯穿脑部，又像风暴下的海洋，翻涌碰撞
- 这种精神痛楚是莫凡在修炼过程中从未品尝过的，它比耗尽所有精力的那种疲惫强千倍百倍，它像梦魇之中的折磨和摧残……
- 而只要在这个过程中，你的精神有一点点的松懈，有稍稍的放弃，那么所有的攻势都将瞬间消散，一切又要从头开始！！
- 莫凡感觉脑子要爆炸了，青筋更是遍布了他的脸庞，可他不敢放下
