2. 每拆解完1章，更新本进度总览的状态
3. 发现系统机制时，记录到「系统机制识别记录」中

### 拆解完成后必须做
1. 更新本进度总览的章节状态
2. git commit 拆解记录文件
3. 在TODO.md中更新拆解进度

### 转化为游戏内容后必须做
1. 在本进度总览中标记「已转化」
2. 更新对应的数据文件
3. git commit 代码和文档
