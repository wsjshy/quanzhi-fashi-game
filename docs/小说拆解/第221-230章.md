## 第225章 诅咒气息黑畜妖

### 剧情
- 牧奴娇分析考核规则：**送到驯兽铁笼才算完成**，意味着会变成学生间抢夺
- 莫凡去医院看张璐璐，得知许昭霆跟踪的是"学员"
- 黑教廷在明珠有内奸棋子
- 莫凡不通知审判会（怕打草惊蛇让许昭霆没救）
- 张璐璐回住处，夜里遭黑畜妖袭击
- 张璐璐逃到屋顶，3-4只黑畜妖追来
- **诅咒气息黑畜妖**出现：更丑陋更强，脸上有未腐烂的皮，被诅咒黑气笼罩
- 诅咒黑畜妖反而攻击其他黑畜妖，保护张璐璐

### 世界观
| 设定 | 内容 |
|------|------|
| 考核规则 | 送到驯兽铁笼才算完成，可抢夺 |
| 黑教廷渗透 | 在明珠学府有长期潜伏的棋子 |
| 诅咒黑畜妖 | 比普通黑畜妖更强，保留部分意识 |

## 第226章 亲手杀了她

### 剧情
- 诅咒黑畜妖秒杀其他黑畜妖（撕成两半、爪芒X字切割）
- 诅咒黑畜妖痛苦但不攻击张璐璐
- 宇昂出现在天台：解释诅咒畜妖需要强大体魄+充满怨恨的灵魂
- 宇昂用灵魂锁链控制诅咒畜妖，逼它杀张璐璐
- 诅咒畜妖=许昭霆！他挣扎、自伤抵抗控制
- 宇昂鞭打诅咒畜妖，享受折磨

### 关键设定
- **诅咒畜妖**：黑畜妖的强化版，需要强大体魄+怨恨灵魂
- **灵魂锁链**：黑教廷控制黑畜妖的方式，连帕特农都无法解除
- **许昭霆保留意识**：但身体被控制，无法自杀

## 第227章 被咒法的许昭霆

### 剧情
- 唐月联系莫凡，告知**黑畜妖真相：它们是被咒法奴役的活人！**
- 莫凡意识到许昭霆可能被变成黑畜妖，赶去救张璐璐
- 天台：许昭霆（诅咒畜妖）在张璐璐面前，爪子贯穿了她
- 张璐璐认出许昭霆，不再恐惧
- 宇昂留下两人"最后谈话"后离开
- 许昭霆咬断自己手腕（抵抗控制的极端方式）
- 莫凡赶到，许昭霆从腹中掏出一块皮革——**神侍者的名字**！
- 神侍者：与撒朗直接接触的黑教廷高层

### 世界观（极重要）
| 设定 | 内容 |
|------|------|
| **黑畜妖本质** | 被黑教廷咒法奴役的活人，不是妖魔！ |
| **诅咒畜妖** | 强化版，保留部分意识和记忆 |
| **帕特农神庙** | 12位选女姬被弑，神女缺位，无法解救 |
| **神侍者** | 黑教廷高级成员，直接接触撒朗 |
| **灵魂奴役** | 连帕特农都无法解除的咒法 |
