## 可游戏化元素

### ⭐ 系统机制（最高优先级）
1. **技能等级/进阶系统**
   - 初阶技能分多个等级（灼烧→焚骨→爆裂）
   - 每级效果和威力完全不同
   - 通过使用/修炼提升技能等级
   - **可玩性评分**：5/5 - 核心成长系统
   - **当前状态**：已有熟练度系统，可深化为等级系统

2. **环境互动战斗系统**
   - 利用地形和环境物品战斗
   - 钟乳石、落石、陷阱等
   - 不同环境有不同可互动元素
   - **可玩性评分**：4/5 - 增加战斗策略性
   - **当前状态**：暂无

3. **历练/考核评分系统**
   - 根据表现给S/A/B/C/D评分
   - 评分影响奖励和声望
   - 多个评分维度（战斗、勇气、智慧、团队等）
   - **可玩性评分**：4/5 - 增加目标感和重玩价值
   - **当前状态**：暂无

4. **召唤兽系统**
   - 召唤师与召唤兽心灵感应
   - 召唤兽死亡召唤师受精神创伤
   - 召唤兽可以升级、学习技能
   - **可玩性评分**：5/5 - 召唤系核心玩法
   - **当前状态**：暂无

5. **心理素质/勇气系统**
   - 面对妖魔时的恐惧值
   - 恐惧值越高，施法成功率越低
   - 经历战斗后恐惧值会降低（勇气提升）
   - **可玩性评分**：3/5 - 增加真实感
   - **当前状态**：暂无

## 备注

1. **防重复检查**：
   - 主要NPC（莫凡、张小侯、穆白、许昭霆、周敏、王三胖、斩空、唐月、薛木生、赵坤三）都已存在
   - 主要地点（雪峰山、百草谷、雪峰山驿站）都已存在
   - 基础技能（风轨、雷印、火滋、冰蔓、地波、光耀等）都已存在
   - 幽狼兽作为敌人已存在

2. **重要设定**：
   - 火滋分三级：灼烧（第一级）→ 焚骨（第二级）→ 爆裂（更高阶）
   - 植物系妖魔怕火，抗雷
   - 召唤师与召唤兽有心灵感应，召唤兽死亡召唤师受精神创伤
   - 面对真正的妖魔时，新手法师很难释放魔法（恐惧影响）
   - 斩空是风系高阶法师（有风之翼），同时火系也很强

3. **剧情关键点**：
   - 莫凡的火滋已经达到焚骨级别（第二级）
   - 莫凡用智慧（烧断钟乳石）而非纯力量击败了幽狼兽
   - 斩空对莫凡的表现非常满意，给了S级评分
   - 悬赏任务的魔具奖励本来是象征性的，没想到莫凡真完成了

4. **系统机制启发**：
   - 技能等级系统可以基于现有的熟练度系统深化
   - 环境互动可以增加战斗的策略性和趣味性
   - 评分系统可以给玩家明确的目标和反馈
   - 召唤兽系统是召唤系的核心玩法，需要重点设计
