### 1.2 日常系统问题分析

**当前问题**：
1. **"日"的定义不明确**：游戏内时间的"天"还是现实时间的"天"？
2. **签到条件不明确**：玩家不知道签到需要什么条件，什么时候重置
3. **每日任务不清晰**：任务目标、进度、奖励展示不直观
4. **功能深度不足**：只有签到和简单每日任务，缺少长期目标

**设计方案**：
1. **明确"日"的定义**：基于游戏内时间（Player.day），每天0点重置
2. **签到UI优化**：
   - 显示当前第几天
   - 显示今日是否已签到
   - 显示连续签到天数和累计奖励
   - 签到条件：每天第一次打开日常界面自动签到
3. **每日任务UI优化**：
   - 显示3个每日任务（击杀/修炼/探索）
   - 每个任务显示进度条（x/目标）
   - 完成后显示"领取奖励"按钮
   - 显示重置时间（游戏内第几天）

### 1.3 功能合并建议

- **声望** → 合并到角色属性面板的"声望"标签
- **帮助** → 合并到设置或暂停菜单
- 减少右侧菜单项，让核心功能更突出

## 二、UI布局优化

### 2.1 设计原则（参考成熟游戏经验）

1. **拇指热区原则**：高频操作放在屏幕下方拇指可及区域
2. **信息层级**：核心信息（HP/MP/等级/时间）在顶部，次要信息折叠
3. **三触达原则**：任何功能最多3次点击到达
4. **上下文敏感**：根据当前场景显示相关功能，隐藏不相关功能
5. **视觉引导**：用颜色/大小/动画引导玩家注意力

### 2.2 当前布局问题

- 右侧菜单功能过多（11项），核心功能不突出
- 顶部状态栏信息密集，但缺少优先级区分
- 行动列表没有按重要性排序
- 缺少快速访问常用功能的快捷方式

### 2.3 优化方案

**右侧菜单分级**：
- **核心区**（始终显示）：角色、背包、任务、保存
- **扩展区**（折叠/更多）：情报、声望、成就、妖魔图鉴、日常、帮助
- **快捷区**：休息到明天（独立按钮，更醒目）

**顶部状态栏优化**：
- 左侧：大地图 + 地点名称 + 探索状态
- 中间：时间 + 日期
- 右侧：HP/MP/体力/等级/金币（精简显示）

**行动列表优化**：
- 按重要性排序：修炼/探索 > 采集 > 休息 > 其他
- 高价值行动高亮显示
- 已探索行动降低视觉权重

## 三、装备强化继承系统

### 3.1 问题分析

**玩家心理**：
- "低级装备不舍得强化，想留给高级装备"
- 导致前期装备不强化，战斗困难
- 强化资源囤积，体验下降

**成熟解决方案**（参考龙之谷、神泣纷争等）：
- **强化继承**：换装备时，旧装备的强化等级可以转移到新装备上
- 玩家可以放心强化过渡装备，换装备时不浪费

### 3.2 设计方案

**强化继承规则**：
1. **同部位继承**：武器→武器，防具→防具，饰品→饰品
2. **无损继承**：强化等级100%转移，不损耗
3. **消耗**：少量金币（基础100金币，随强化等级递增）
4. **原装备**：强化等级清零，装备保留（可出售或继续继承）
5. **材料不继承**：强化时消耗的材料不返还，但强化等级转移

**UI设计**：
- 在背包/装备界面添加"强化继承"按钮
- 选择旧装备（有强化等级）和新装备（同部位）
- 显示继承预览：旧装备+5 → 新装备+5
- 确认消耗金币后完成继承

**玩家体验**：
- 前期放心强化低级装备，提升战斗力
- 换装备时一键继承，没有浪费感
- 强化资源持续投入，不会囤积
