# 战斗系统开发Todo清单

## 总体目标
打造一个**深度贴合原著**、**有策略性**、**有成就感**的战斗系统。
不是简单的数值比拼，而是真正的魔法对决。

**核心开发模式：小说驱动，看到一个加一个。**
从小说里发现什么，就实现什么。不固定数量，不设上限。

## 二、已实现的效果类型（10种）

### 基础属性类
- [x] passive_bonus - 被动属性加成（攻击/防御/速度/HP/闪避）
- [x] all_stats_bonus - 全属性加成

### 伤害相关类
- [x] damage_reduction - 伤害减免（物理/魔法）
- [x] damage_reflect - 伤害反弹
- [x] weakness - 弱点伤害（特定属性伤害增加）

### 攻击相关类
- [x] first_strike - 首次攻击特效（必暴击/伤害加成）
- [x] bleed_on_hit - 攻击造成流血
- [x] multi_hit - 多段攻击

### 防御相关类
- [x] control_immune - 控制免疫

### 回复相关类
- [x] regen - 回合结束恢复HP

### 动态效果类
- [x] blood_rage - 血怒（血量越低攻击越高）

## 开发原则（时刻牢记）

1. **小说驱动** - 从小说里发现什么，就实现什么
2. **数据优先** - 能用数据实现的就用数据
3. **模块化新增** - 新效果类型独立模块
4. **逐步完善** - 不追求一步到位
5. **可复用** - 每个效果类型都设计成可复用的
6. **看到一个加一个** - 不固定数量，不设上限
