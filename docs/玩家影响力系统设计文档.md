# 玩家影响力系统设计文档

## 一、核心设计理念

### 1.1 问题背景
小说《全职法师》的主角是莫凡，所有剧情都围绕他展开。但在我们的游戏中，玩家不是莫凡，而是一个自创角色。

**核心问题**：如何让玩家在不是莫凡的情况下，依然有强烈的代入感和影响力，而不是仅仅作为旁观者？

### 1.2 设计思路："平行轨迹，交织影响"
玩家不是莫凡，但玩家的行为会真实地影响这个世界，甚至在某些关键节点改变莫凡的命运轨迹。

- **平行轨迹**：玩家有自己的成长线，不一定跟着莫凡走
- **交织影响**：玩家与原作剧情交织，产生化学反应
- **真实反馈**：玩家的每一个行为都会产生真实的世界反馈

---

## 二、五大影响力维度

### 2.1 势力声望影响力 ⭐⭐⭐
玩家可以在五大势力中建立声望，不同声望等级会解锁不同的内容。

#### 五大势力
1. **天澜魔法高中**
   - 声望等级：普通学生 → 班级代表 → 年级尖子 → 学生会成员 → 学生会长
   - 影响：可以影响学校决策、组织活动、获得特殊资源

2. **穆氏家族**
   - 声望等级：外门弟子 → 内门弟子 → 核心成员 → 长老
   - 影响：可以调动家族资源、影响家族决策

3. **猎魔者公会**
   - 声望等级：实习猎者 → 正式猎者 → 精英猎者 → 猎王
   - 影响：可以发布悬赏、调动猎者队伍、获得稀有情报

4. **魔法协会**
   - 声望等级：见习法师 → 正式法师 → 高级法师 → 魔法议员
   - 影响：可以影响魔法法规、获得官方资源

5. **军法师**
   - 声望等级：新兵 → 士官 → 军官 → 将军
   - 影响：可以调动军队、影响军事决策

#### 声望获取方式
- 完成势力任务
- 为势力做出贡献
- 参加势力活动
- 帮助势力成员

#### 声望作用
- 解锁势力专属内容
- 获得势力专属奖励
- 可以使用势力资源
- 影响势力决策

---

### 2.2 NPC关系影响力 ⭐⭐⭐
玩家与每个NPC都有独立的关系值，关系不同，NPC的行为也不同。

#### 三维关系值
1. **好感**：NPC对玩家的喜欢程度
2. **信任**：NPC对玩家的信任程度
3. **熟悉度**：NPC对玩家的了解程度

#### 关系等级
- 陌生人 → 认识 → 普通朋友 → 好朋友 → 挚友 → 生死之交
- 敌对 → 厌恶 → 冷淡 → 普通 → 友好 → 亲密

#### 关系影响
- **可以拯救某些NPC的命运**：比如提前警告某个NPC，让他避开死亡结局
- **可以改变NPC之间的关系**：比如撮合某两个NPC，或者让两个NPC反目
- **可以获得NPC的帮助**：关系好的NPC会在关键时刻帮助玩家
- **可以影响NPC的成长**：比如指导某个NPC修炼，让他变得更强

---

### 2.3 世界状态影响力 ⭐⭐⭐
玩家的行为会改变世界状态，产生真实的反馈。

#### 世界状态指标
1. **区域安全度**
   - 玩家猎杀妖魔越多，该区域越安全
   - 安全度高的区域：NPC活动频繁、商店商品丰富、遇敌率低
   - 安全度低的区域：NPC稀少、商店关门、遇敌率高

2. **区域繁荣度**
   - 玩家做任务、消费越多，该区域越繁荣
   - 繁荣度高的区域：商店折扣、更多NPC、更多活动
   - 繁荣度低的区域：物价上涨、NPC稀少

3. **妖魔活跃度**
   - 玩家破坏妖魔巢穴，妖魔活跃度下降
   - 玩家长时间不猎杀妖魔，妖魔活跃度上升
   - 活跃度高：更强的妖魔出现、更多的妖魔袭击

4. **舆论风向**
   - 玩家的行为会影响人们对某些事情的看法
   - 比如玩家做了很多好事，人们会更信任魔法师
   - 比如玩家做了很多坏事，人们会更害怕魔法师

---

### 2.4 剧情分支影响力 ⭐⭐
在关键剧情节点，玩家的选择会导致不同的分支。

#### 分支类型
1. **if线剧情**
   - 比如："如果博城灾难时玩家提前预警了"
   - 比如："如果玩家阻止了宇昂的阴谋"
   - 比如："如果玩家救了某个本该死的NPC"

2. **多结局系统**
   - 每个大事件都有多种结局
   - 结局取决于玩家的行为和选择
   - 不同结局有不同的奖励和后续影响

3. **蝴蝶效应**
   - 玩家的一个小选择，可能在后期产生大影响
   - 比如：玩家救了一个小角色，后期这个小角色会帮玩家大忙
   - 比如：玩家得罪了一个小角色，后期这个小角色会给玩家制造麻烦

---

### 2.5 个人成就影响力 ⭐⭐
玩家有自己的成就系统，记录玩家的传奇经历。

#### 成就类型
1. **个人称号**
   - 比如："博城守护者"、"最年轻的高阶法师"、"猎魔者传奇"
   - 称号有特殊效果，或者只是荣誉象征

2. **个人传说**
   - 玩家的事迹会被人们传颂
   - NPC会提到玩家的事迹
   - 新NPC会因为玩家的名声而有不同的反应

3. **个人雕像/纪念碑**
   - 在某些地方会有玩家的雕像
   - 玩家可以看到自己的成就被记录下来

4. **历史记载**
   - 玩家的事迹会被载入史册
   - 游戏结束时会有玩家的历史评价

---

## 三、与莫凡的互动设计

### 3.1 亦敌亦友的关系
- 玩家可以选择和莫凡做朋友，也可以选择做对手
- 不同的关系会导致不同的互动模式
- 玩家和莫凡可以互相竞争，也可以互相帮助

### 3.2 关键节点的干预
- 在某些关键节点，玩家可以选择干预莫凡的命运
- 比如：莫凡被穆家刁难时，玩家可以选择出手相助
- 比如：博城灾难时，玩家可以选择和莫凡一起战斗，或者走自己的路

### 3.3 不同的成长路径
- 玩家不一定非要走莫凡的路
- 玩家可以成为军法师、猎魔者、魔法协会官员等等
- 每条路都有自己的精彩

## 五、设计原则

### 5.1 避免旁观者感
玩家有自己的目标和成长线，不是跟着莫凡跑。

### 5.2 真实的影响力
玩家的行为会真实地改变世界，而不是走过场。

### 5.3 重玩价值高
不同的选择、不同的势力、不同的关系，每次玩都不一样。

### 5.4 保留原作魅力
莫凡依然是那个莫凡，但玩家可以从不同角度体验这个世界。

### 5.5 符合小说设定
全职法师的世界观本来就有很多势力和成长路径，玩家完全可以走自己的路。

## 六、技术实现要点

### 6.1 数据结构
```javascript
// 势力声望
reputation: {
  school: 0,        // 天澜魔法高中
  mu_family: 0,     // 穆氏家族
  hunter: 0,        // 猎魔者公会
  magic_assoc: 0,   // 魔法协会
  military: 0       // 军法师
}

// 世界状态
worldState: {
  bo_city: {
    safety: 50,     // 安全度 0-100
    prosperity: 50, // 繁荣度 0-100
    demonActivity: 50 // 妖魔活跃度 0-100
  }
}

// NPC关系
npcRelations: {
  mofan: {
    favor: 0,       // 好感 -100到100
    trust: 0,       // 信任 0-100
    familiarity: 0  // 熟悉度 0-100
  }
}
```

### 6.2 触发机制
- 玩家行为触发声望/关系/世界状态变化
- 达到阈值时触发特殊事件或解锁内容
- 关键节点的选择影响剧情分支

### 6.3 存档兼容
- 新增字段，旧存档自动初始化为默认值
- 版本号升级，确保迁移正确

## 七、优先级评估

**优先级：P1**

理由：
1. 这是游戏的核心特色之一，显著提升玩家体验
2. 可以解决"玩家不是莫凡"的代入感问题
3. 增加重玩价值，延长游戏寿命
4. 符合开放世界的设计理念

**建议开发时机**：
- 基础系统完善后（v0.9.0左右）
- 先做势力声望系统，这是最基础也最容易实现的
- 然后逐步扩展其他维度
