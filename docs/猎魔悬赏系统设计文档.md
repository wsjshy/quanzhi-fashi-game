## 一、系统定位

猎魔悬赏系统是猎者联盟发布的官方悬赏任务机制，玩家接取悬赏后击杀目标妖魔，完成后返回领奖。它完善了"猎魔→材料→锻造"的游戏循环，为玩家提供了明确的猎魔目标和稳定的材料/金币获取途径。

### 设计目标
1. **悬赏板**：猎者联盟大厅显示当前可用悬赏任务
2. **接取/完成/领奖**：完整的任务生命周期
3. **原著驱动**：悬赏目标基于原著妖魔，奖励符合原著设定
4. **材料循环**：悬赏奖励包括锻造材料，完善"猎魔→材料→锻造"循环
5. **等级分层**：奴仆级/战将级/统领级悬赏，难度和奖励递增

### 与其他系统的关系
- **锻造系统**（v3.9）：悬赏奖励的材料用于锻造装备
- **战斗系统**：击杀目标妖魔时自动更新悬赏进度
- **声望系统**：完成悬赏获得猎者联盟声望
- **任务系统**：悬赏是独立于主线/支线任务的系统，有自己的UI和进度追踪

## 二、核心机制

### 2.1 悬赏任务结构

每个悬赏任务定义在 `src/data/bounties.js` 中：

```javascript
{
    id: "bounty_001",
    name: "清剿独眼魔狼",
    targetEnemy: "one_eyed_wolf",  // 目标妖魔ID
    targetCount: 3,                // 需要击杀数量
    level: "servant",              // servant/warrior/commander
    reward: {
        gold: 30000,
        exp: 500,
        reputation: 10,           // 猎者联盟声望
        items: [                   // 材料奖励
            { itemId: "demon_core", count: 2 },
            { itemId: "wolf_fang", count: 1 }
        ]
    },
    expireDays: 3,                 // 悬赏有效期
    description: "近期独眼魔狼在博城郊外出没，已造成3起伤人事件。猎者联盟悬赏清剿。"
}
```

### 2.2 悬赏等级与奖励

| 等级 | 目标妖魔 | 击杀数 | 金币奖励 | 经验奖励 | 声望 | 材料奖励 |
|------|---------|-------|---------|---------|------|---------|
| 奴仆级 | 奴仆级妖魔 | 2-5只 | 1-5万 | 200-500 | 5-10 | 基础材料 |
| 战将级 | 战将级妖魔 | 1-3只 | 5-20万 | 500-1500 | 15-30 | 中级材料+精魄 |
| 统领级 | 统领级妖魔 | 1只 | 20-50万 | 1500-5000 | 50-100 | 高级材料+稀有物品 |

### 2.3 悬赏刷新机制

- 每天自动刷新3-5个新悬赏
- 已接取的悬赏保留，直到完成或过期
- 玩家可同时接取最多3个悬赏
- 悬赏有效期3天，过期自动消失

### 2.4 悬赏完成判定

```
玩家接取悬赏 → 击杀目标妖魔时自动计数（battle-end.js）
→ 计数达到目标数量 → 悬赏状态变为"可领奖"
→ 玩家返回猎者联盟悬赏板 → 领取奖励
→ 悬赏完成，从列表移除
```

### 2.5 悬赏状态流转

| 状态 | 说明 | 操作 |
|------|------|------|
| 可接取 | 悬赏板显示，未接取 | 点击"接取" |
| 进行中 | 已接取，击杀进度未完成 | 显示进度x/y |
| 可领奖 | 击杀进度完成 | 点击"领取奖励" |
| 已完成 | 奖励已领取 | 从列表移除 |
| 已过期 | 超过3天未完成 | 自动消失 |

## 三、UI设计

### 3.1 悬赏板界面

- **左侧**：当前可用悬赏列表（显示等级、目标、奖励、有效期）
- **右侧**：选中悬赏详情（描述、目标进度、接取/领奖按钮）
- **顶部**：已接取悬赏数量（x/3）
- **双标签**：可接悬赏 / 进行中

### 3.2 入口

- 博城市街地图添加"📜 悬赏板"动作
- 点击进入悬赏板界面

### 3.3 战斗中的进度提示

- 击杀目标妖魔时，战斗结算界面显示"悬赏进度更新：xxx 2/3"
- 完成悬赏时显示"悬赏完成：xxx，可返回领奖"

## 七、存档数据

悬赏系统的玩家进度存储在 `GameState.player.bounties` 中：

```javascript
bounties: {
    active: [           // 进行中的悬赏
        {
            id: "bounty_001",
            progress: 2,      // 已击杀数量
            acceptedDay: 5,   // 接取日期
            expireDay: 8      // 过期日期
        }
    ],
    completed: [        // 已完成的悬赏ID（防止重复接取）
        "bounty_002"
    ],
    lastRefreshDay: 5   // 上次刷新日期
}
```
