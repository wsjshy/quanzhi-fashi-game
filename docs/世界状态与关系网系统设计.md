# 世界状态与关系网系统设计

## 一、设计理念

游戏世界不是静态的，而是随着玩家的选择动态变化的。玩家的每一个决定都可能产生蝴蝶效应，影响 NPC 的命运、势力的平衡、甚至整个世界的走向。

**核心原则**：
- 没有绝对正确的选择，每个选择都有得有失
- NPC 有自己的性格、目标和记忆，不是任务发布机器
- 世界有自己的运行规律，玩家只是其中的一份子
- 选择的后果可能在很久之后才显现

---

## 二、世界状态系统 (WorldState)

### 2.1 整体结构

```
WorldState
├── globalFlags       // 全局剧情标记
├── time              // 时间状态
├── reputations       // 各势力声望
├── worldEvents       // 已发生的世界事件记录
├── activeEvents      // 进行中的事件
├── npcStates         // 所有 NPC 的状态
└── relationshipMap   // NPC 之间的关系矩阵
```

### 2.2 全局标记 (globalFlags)

用于记录世界层面的状态变化。

**数据格式**：
```javascript
{
  // 示例
  "bo_city_disaster_warning_1": true,    // 博城灾难第一次预警已发布
  "mo_fan_expelled": false,              // 莫凡是否被开除
  "mu_family_relation": "neutral",       // 穆家对玩家的整体态度
  "black_church_appeared": false,        // 黑教廷是否出现过
  "xuefeng_mountain_demon_increase": 0.5 // 雪峰山妖魔活跃度 (0-1)
}
```

**命名规范**：
- 用下划线分隔的小写英文
- 前缀表示类别：`event_`（事件）、`npc_`（NPC相关）、`faction_`（势力相关）、`location_`（地点相关）
- 布尔值用 is/has/should 等前缀

## 三、NPC 状态系统 (NPCState)

每个 NPC 都有独立的状态数据，记录他们对玩家的态度、个人目标、记忆等。

### 3.1 基础数据结构

```javascript
{
  // 对玩家的关系
  opinion: 0,              // 好感度 (-100 到 100)
  trust: 0,                // 信任度 (-100 到 100)
  respect: 0,              // 敬重度 (-100 到 100)
  fear: 0,                 // 畏惧度 (0 到 100)
  relationship: "stranger", // 关系等级：stranger/acquaintance/friend/close_friend/lover/enemy/rival

  // 性格特质 (0-1，越高越明显)
  personality: {
    brave: 0.5,            // 勇敢 - 懦弱
    kind: 0.5,             // 善良 - 残忍
    honest: 0.5,           // 诚实 - 狡猾
    impulsive: 0.5,        // 冲动 - 谨慎
    loyal: 0.5,            // 忠诚 - 背叛
    arrogant: 0.5,         // 傲慢 - 谦虚
    greedy: 0.5,           // 贪婪 - 慷慨
    curious: 0.5           // 好奇 - 保守
  },

  // 个人状态
  currentLocation: "tianlan_school",  // 当前位置
  currentGoal: "study",               // 当前目标
  health: 100,                        // 健康状态
  morale: 100,                        // 士气/心情

  // 记忆系统
  memories: [
    {
      id: "memory_001",
      type: "favor",          // 记忆类型：favor/insult/help/hurt/event
      content: "玩家帮我捡了书",
      effect: { opinion: +5 },
      timestamp: { day: 3, period: "afternoon" },
      importance: 0.3,        // 重要程度 (0-1)，影响遗忘速度
      remembered: true
    }
  ],

  // 个人标记
  flags: {
    "has_met_player": true,
    "gave_quest_1": false,
    "knows_player_secret": false
  },

  // 已知信息
  knownInfo: [
    "player_is_fire_mage",
    "player_level_3"
  ]
}
```

### 3.2 关系等级说明

| 等级 | 英文 | 好感度范围 | 说明 |
|------|------|-----------|------|
| 陌生人 | stranger | -20 到 20 | 刚认识，客气但有距离 |
| 熟人 | acquaintance | 20 到 40 | 认识，会正常交流 |
| 朋友 | friend | 40 到 60 | 朋友，愿意帮忙，会分享一些信息 |
| 好友 | close_friend | 60 到 80 | 好朋友，愿意冒险帮忙，分享秘密 |
| 挚友 | best_friend | 80 到 100 | 生死之交，可以托付后背 |
| 敌对 | enemy | -20 到 -50 | 敌对，会找麻烦 |
| 死敌 | rival | -50 到 -100 | 死敌，不惜代价对付你 |

### 3.3 性格特质说明

每个性格特质都是一个 0-1 的数值，0.5 是中性。

**性格影响**：
- 对话选择的倾向
- 对事件的反应方式
- 战斗中的行为模式
- 对玩家行为的评价标准

**例子**：
- 高 `brave` 的 NPC：遇到危险会冲上去，看不起懦弱的行为
- 高 `kind` 的 NPC：乐于助人，对残忍的行为反感
- 高 `loyal` 的 NPC：重视承诺，对背叛极度反感
- 高 `arrogant` 的 NPC：看不起弱者，对强者才会尊重

## 四、关系网系统 (RelationshipMap)

记录 NPC 之间的关系，形成一个复杂的关系网络。

### 4.1 数据结构

```javascript
{
  // 莫凡与穆宁雪的关系
  "mo_fan-mu_ningxue": {
    npcA: "mo_fan",
    npcB: "mu_ningxue",
    relationship: "rivals",       // 关系类型
    opinionAtoB: -30,             // A 对 B 的好感度
    opinionBtoA: -20,             // B 对 A 的好感度
    history: [                    // 关系历史
      {
        event: "初次见面",
        effect: { opinionAtoB: -10, opinionBtoA: -5 },
        timestamp: { day: 1 }
      }
    ],
    flags: {
      "childhood_acquaintance": true
    }
  },

  // 莫凡与唐月的关系
  "mo_fan-tang_yue": {
    npcA: "mo_fan",
    npcB: "tang_yue",
    relationship: "teacher_student",
    opinionAtoB: 60,
    opinionBtoA: 50,
    history: [],
    flags: {}
  }
}
```

### 4.2 关系类型

- `family` - 家人
- `friends` - 朋友
- `close_friends` - 密友
- `rivals` - 对手
- `enemies` - 敌人
- `lovers` - 恋人
- `teacher_student` - 师生
- `colleagues` - 同事
- `allies` - 盟友
- `strangers` - 陌生人

### 4.3 关系的动态变化

玩家的行为可以影响 NPC 之间的关系：

**例子**：
- 玩家在莫凡面前说穆宁雪坏话 → 莫凡对穆宁雪的好感度变化（取决于莫凡对玩家的信任度）
- 玩家帮莫凡和穆宁雪化解矛盾 → 两人关系改善
- 玩家挑拨离间 → 两人关系恶化

**影响公式**（简化版）：
```
关系变化 = 玩家行为影响 × (信任度 / 100) × 性格修正系数
```

## 五、势力声望系统 (ReputationSystem)

玩家在各个势力中的声望，影响 NPC 对你的态度、商店价格、任务接取等。

### 5.1 势力列表（示例）

| 势力 ID | 名称 | 说明 |
|---------|------|------|
| `tianlan_school` | 天澜魔法高中 | 学校 |
| `mu_family` | 穆氏家族 | 博城名门 |
| `hunters_union` | 猎人联盟 | 猎者组织 |
| `black_church` | 黑教廷 | 反派组织 |
| `military` | 军方 | 官方军队 |
| `pathenon` | 帕特农神庙 | 治疗势力 |

### 5.2 声望等级

| 等级 | 声望值范围 | 效果 |
|------|-----------|------|
| 仇恨 | -100 到 -50 | 见你就打，商店不卖东西 |
| 敌对 | -50 到 -20 | 态度恶劣，价格翻倍 |
| 冷淡 | -20 到 0 | 态度冷淡，价格上浮 |
| 中立 | 0 到 20 | 正常对待 |
| 友好 | 20 到 50 | 态度友好，价格优惠 |
| 尊敬 | 50 到 80 | 受到尊敬，特殊折扣 |
| 崇拜 | 80 到 100 | 奉为偶像，特殊待遇 |

### 5.3 声望的影响

- **商店价格**：声望越高，价格越低
- **任务接取**：高声望才能接高级任务
- **NPC 态度**：同势力 NPC 初始好感度更高
- **特殊权限**：进入某些区域、使用某些设施
- **事件触发**：声望达到一定程度触发特殊事件

## 六、记忆系统 (MemorySystem)

NPC 会记住玩家做过的事，这些记忆会影响他们对玩家的态度。

### 6.1 记忆类型

| 类型 | 说明 | 例子 |
|------|------|------|
| `favor` | 帮了 NPC | 帮他捡东西、救他一命 |
| `insult` | 冒犯了 NPC | 骂他、嘲笑他 |
| `help` | 共同经历 | 一起战斗、一起冒险 |
| `hurt` | 伤害了 NPC | 打他、背叛他 |
| `event` | 共同见证的事件 | 一起经历了某个大事件 |
| `secret` | 知道了 NPC 的秘密 | 发现了他的秘密 |
| `promise` | 承诺 | 答应了某事，是否兑现 |

### 6.2 记忆的遗忘

记忆会随着时间逐渐淡化，重要的记忆保留更久。

**遗忘公式**（简化版）：
```
记忆强度 = 初始强度 × (1 - 0.01 × 天数) × 重要程度
```

当记忆强度低于阈值时，NPC 就"忘记"了这件事。

### 6.3 记忆的触发

某些对话或事件会"触发"NPC 的记忆，让他们想起某件事，从而改变态度。

**例子**：
- 玩家提到"上次你帮了我" → NPC 想起那件事，好感度临时提升
- 玩家做了类似的事 → NPC 想起以前的事，对比评价

## 七、事件链系统 (EventChainSystem)

大事件不是突然发生的，而是有一个逐渐发展的过程。每个事件都有前置铺垫、发展过程、高潮、结局。

### 7.1 事件链结构

```javascript
{
  id: "bo_city_disaster",
  name: "博城灾难",
  description: "黑教廷策划的博城妖魔之乱",
  importance: 1.0,

  // 事件节点
  nodes: {
    // 节点 1：初期异常
    "phase_1_anomaly": {
      name: "异常迹象",
      trigger: {
        day: 30,                // 第 30 天开始
        probability: 1.0
      },
      condition: {},
      effects: {
        globalFlags: { "xuefeng_mountain_demon_activity": 0.3 },
        worldEvent: "demon_activity_increase"
      },
      // 玩家可以接触到的铺垫渠道
      playerHints: [
        { type: "npc_dialogue", npc: "tang_yue", chance: 0.5 },
        { type: "random_event", location: "xuefeng_mountain", chance: 0.3 },
        { type: "announcement", location: "tianlan_school", chance: 0.4 }
      ],
      nextNodes: ["phase_2_warning"]
    },

    // 节点 2：预警
    "phase_2_warning": {
      name: "危机预警",
      trigger: {
        afterNode: "phase_1_anomaly",
        delayDays: 10
      },
      condition: {},
      effects: {
        globalFlags: { "xuefeng_mountain_demon_activity": 0.6 }
      },
      playerHints: [
        { type: "npc_dialogue", npc: "mo_fan", chance: 0.7 },
        { type: "shop_change", shop: "magic_shop", change: "price_up" },
        { type: "npc_movement", npc: "tang_yue", newLocation: "xuefeng_mountain" }
      ],
      nextNodes: ["phase_3_outbreak"]
    },

    // 节点 3：爆发
    "phase_3_outbreak": {
      name: "灾难爆发",
      trigger: {
        afterNode: "phase_2_warning",
        delayDays: 5
      },
      condition: {},
      effects: {
        globalFlags: { "bo_city_disaster_happened": true },
        locationState: { "bo_city": "disaster" }
      },
      // 根据玩家之前的准备，有不同的结局分支
      branches: {
        "well_prepared": {
          condition: {
            playerLevel: 5,
            hasItems: ["super_health_potion", 5],
            hasAllies: ["mo_fan"]
          },
          outcome: "survive_well"
        },
        "somewhat_prepared": {
          condition: {
            playerLevel: 3
          },
          outcome: "survive_hard"
        },
        "unprepared": {
          condition: {},
          outcome: "barely_survive"
        }
      },
      nextNodes: ["phase_4_aftermath"]
    }
  },

  // 起始节点
  startNode: "phase_1_anomaly"
}
```

### 7.2 玩家的作用

玩家可以通过自己的行为影响事件链的发展：

1. **发现线索**：通过探索、对话收集信息
2. **提前准备**：买药水、升级、找帮手
3. **警告他人**：告诉 NPC 危险即将来临（信不信取决于好感度）
4. **改变走向**：某些关键选择可以改变事件的发展方向
5. **参与其中**：在事件中扮演重要角色

### 7.3 多结局设计

每个大事件都有多个可能的结局，取决于玩家的选择和准备：

- **最佳结局**：玩家提前发现，做好充分准备，甚至帮助别人
- **普通结局**：玩家有所准备，勉强度过
- **糟糕结局**：玩家没准备，损失惨重
- **隐藏结局**：玩家发现了事件的真相，改变了历史

## 八、数据存储格式规范

### 8.1 文件结构

```
content/
├── world/
│   ├── world-state.json       // 初始世界状态
│   └── factions.json          // 势力数据
├── npcs/
│   ├── mo-fan.json            // 莫凡的完整数据
│   ├── mu-ningxue.json        // 穆宁雪的完整数据
│   └── ...
├── relationships/
│   └── relationship-map.json  // NPC 关系网
├── events/
│   ├── chains/                // 事件链
│   │   ├── bo-city-disaster.json
│   │   └── ...
│   └── random/                // 随机事件
│       └── ...
└── dialogues/
    ├── mo-fan.json            // 莫凡的对话树
    ├── mu-ningxue.json        // 穆宁雪的对话树
    └── ...
```

### 8.2 版本兼容

- 所有数据格式都有 `version` 字段
- 新增字段要有默认值
- 废弃字段保留但标记为 deprecated
- 提供数据迁移工具

## 九、扩展原则

1. **增量式扩展**：每次只加一小部分内容，测试稳定后再加下一部分
2. **向后兼容**：新内容不破坏已有存档
3. **数据驱动**：所有内容都通过数据文件添加，不改代码
4. **模块化**：每个 NPC、每个事件都是独立的模块
5. **可组合**：事件之间可以互相触发，形成复杂的剧情网

---

## 十、后续扩展方向

1. **NPC 日常作息** - NPC 有自己的日程，在不同时间出现在不同地方
2. **NPC 间互动** - NPC 之间会自己发生事件，不只是和玩家互动
3. **动态世界** - 世界会自己发展，玩家不在的时候也在变化
4. **多周目** - 通关后可以重开，继承部分东西，体验不同选择
5. **声望系统深度化** - 声望影响更多内容，有专属任务和装备
