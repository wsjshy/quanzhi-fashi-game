# 战斗系统完整玩法逻辑统计

## 一、战斗核心机制总览

### 1.1 战斗基础
- **战斗类型**：回合制（速度高者先行动）
- **战斗单位**：玩家 vs 敌人（妖魔/法师）
- **核心资源**：HP（生命值）、MP（魔法值）
- **战斗目标**：将对方HP降为0

### 1.2 战斗流程
```
战斗开始
    ↓
先手判定（速度高者先动）
    ↓
玩家回合 / 敌人回合
    ├─ 选择行动（攻击/技能/防御/道具/逃跑）
    ├─ 执行行动
    ├─ 结算伤害/效果
    └─ 检查战斗是否结束
    ↓
回合结束
    ├─ 状态效果结算（DOT/HOT）
    ├─ 天赋效果结算
    └─ 检查战斗是否结束
    ↓
下一回合
    ↓
战斗结束（胜利/失败/逃跑）
```

## 二、玩家行动选项

### 2.1 普通攻击
- **消耗**：无
- **效果**：基础物理伤害
- **特点**：稳定，不耗MP
- **适用**：MP不足时、补刀时

### 2.2 释放魔法
- **消耗**：MP
- **效果**：根据技能不同，有伤害/治疗/buff/debuff等
- **特点**：伤害高、有特殊效果，但消耗MP
- **分类**：
  - 初阶魔法：瞬发，消耗低
  - 中阶魔法：需要引导，消耗中等
  - 高阶魔法：引导时间长，消耗高，伤害高

### 2.3 防御
- **消耗**：无
- **效果**：防御力翻倍，受到伤害减半
- **特点**：保命用，减少伤害
- **适用**：敌人要放大招时、血量低时

### 2.4 使用道具
- **消耗**：道具数量
- **效果**：恢复HP/MP、解除状态、临时增益等
- **特点**：有限次数，关键时刻用
- **适用**：紧急恢复、解除负面状态

### 2.5 逃跑
- **消耗**：无
- **效果**：有概率逃离战斗
- **特点**：不一定成功，失败会浪费回合
- **适用**：打不过时、不想打时

### 2.6 召唤兽技能（召唤系）
- **消耗**：MP
- **效果**：召唤兽攻击/技能
- **特点**：召唤系专属
- **适用**：召唤系法师

## 三、伤害计算逻辑

### 3.1 基础伤害公式
```
基础伤害 = max(1, (攻击力 - 防御力 × 0.5) × 技能倍率)
```

### 3.2 伤害修正顺序
1. **元素克制修正**
   - 克制：伤害 × 1.5
   - 被克制：伤害 × 0.7
   - 同系抗性：伤害 × 0.8

2. **天赋/弱点修正**
   - 弱点伤害：特定属性伤害增加
   - 伤害减免：物理/魔法伤害减免

3. **状态效果修正**
   - 燃烧/冰冻等状态的影响

4. **防御姿态修正**
   - 防御时：伤害 × 0.5

5. **随机浮动**
   - 伤害 × (0.85 ~ 1.15)

6. **暴击修正**
   - 暴击时：伤害 × (1.5 ~ 2.0)

### 3.3 命中/闪避
- 基础命中率：90%
- 闪避率：受速度、天赋、状态影响
- 命中判定：随机数 > (命中率 - 闪避率) = 未命中

## 四、状态效果系统

### 4.1 伤害型DOT（持续伤害）
- **灼烧**：火系，每回合损失HP
- **中毒**：毒系，每回合损失HP，可叠加
- **流血**：物理，每回合损失HP
- **腐蚀**：每回合损失防御

### 4.2 控制型
- **眩晕**：跳过回合
- **冰冻**：跳过回合，受到火伤害增加
- **麻痹**：50%概率跳过回合，速度降低
- **石化**：跳过回合，防御增加
- **睡眠**：跳过回合，被打醒

### 4.3 减速型
- **减速**：速度降低30%
- **束缚**：不能逃跑，速度降低50%
- **嘲讽**：只能攻击释放者

### 4.4 属性降低型
- **攻击降低**：攻击力-20%
- **防御降低**：防御力-20%
- **精神降低**：精神力-20%

### 4.5 增益型
- **攻击提升**：攻击力+30%
- **防御提升**：防御力+30%
- **速度提升**：速度+30%
- **护盾**：吸收一定伤害

## 六、敌人AI系统

### 6.1 AI类型（6种）
- **aggressive（激进型）**：优先攻击，血量低也不退缩
- **defensive（保守型）**：血量低时会防御、恢复
- **controller（控制型）**：优先使用控制技能

- **kiter（游击型）**：打一下跑一下，保持距离
- **tactical（战术型）**：根据情况选择最优策略

### 6.2 Utility AI（效用系统）
- 给每个可能的行动打分
- 选择分数最高的行动
- 评分因素：
  - 自身状态（HP/MP/buff/debuff）
  - 对手状态（HP/MP/buff/debuff）
  - 技能效果（伤害/治疗/控制/DOT）
  - 元素克制
  - 技能冷却
  - MP消耗

## 十、精神力对抗系统

### 10.1 精神力的作用
精神力是战斗中的重要属性，影响多个核心机制：
1. **引导速度**：精神力越高，引导魔法越快
2. **打断能力**：精神力越高，越容易打断对方的引导
3. **抵抗控制**：精神力越高，越不容易被控制

### 10.2 引导速度
- **公式**：引导时间 = max(1, floor(基础引导时间 × (100 - 精神力 × 0.5) / 100))
- **效果**：精神力100时，引导时间减半
- **适用**：玩家和敌人的引导都受精神力影响

### 10.3 打断机制
- **基础打断概率**：20%
- **精神力修正**：(攻击者精神力 - 防御者精神力) × 0.5%
- **范围**：最低10%，最高60%
- **触发条件**：攻击命中且对方正在引导

### 10.4 控制抵抗
- **适用状态**：眩晕、冻结、麻痹、束缚、致盲、减速
- **抵抗公式**：每点精神力抵抗0.3%
- **最低命中**：50%
- **效果**：精神力越高，越不容易被施加控制状态

## 十一、元素反应系统

### 11.1 元素反应概述
不同元素的攻击与目标已有的元素状态结合，会产生特殊的元素反应，增加伤害或附加特殊效果。

### 11.2 已实现的元素反应（9种）

| 反应 | 攻击元素 | 目标状态 | 伤害加成 | 特殊效果 | 消耗状态 |
|------|---------|---------|---------|---------|---------|
| **蒸发** | 火 | 潮湿 | +30% | 无 | 消除水状态 |
| **融化** | 火 | 冻结 | +30% | 无 | 消除冰状态 |
| **超载** | 火 | 感电/麻痹 | +25% | 无 | 消除雷状态 |
| **扩散火** | 火 | 风 | +15% | 无 | - |
| **感电** | 雷 | 潮湿 | +20% | 附加麻痹 | 消除水状态 |
| **超导** | 雷 | 冻结 | +15% | 降低防御20%（3回合） | 消除冰状态 |
| **冻结反应** | 冰 | 潮湿 | +20% | 附加冻结 | 消除水状态 |
| **泥浆** | 土 | 潮湿 | +10% | 附加减速30%（2回合） | - |
| **扩散水** | 风 | 潮湿 | +15% | 无 | - |

### 11.3 元素反应的策略意义
- 玩家可以通过元素组合打出更高伤害
- 控制类反应可以改变战斗节奏
- 需要考虑元素释放的顺序
- 多系法师有更多的元素反应组合
