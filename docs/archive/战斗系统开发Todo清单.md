# 战斗系统开发Todo清单

## 总体目标
打造一个**深度贴合小说**、**有策略性**、**有挑战性**的战斗系统。
不是简单的数值比拼，而是真正的魔法对决。

**核心开发模式：小说驱动，看到一个加一个。**
从小说里发现什么，就实现什么。不固定数量，不设上限。
**严格按小说来，不要自己编。非原著内容必须标记。**

- confuse - 混乱
- bind - 束缚
