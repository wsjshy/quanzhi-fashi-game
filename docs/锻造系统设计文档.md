## 一、系统定位

锻造系统是装备获取的核心途径之一，用妖魔材料+金币锻造装备，让猎魔获得的材料有实际用途，形成"猎魔→材料→锻造→装备"的完整游戏循环。

### 设计目标
1. **原著驱动**：符合原著中"魔石能源体系"和"精魄炼制魔器"的设定
2. **材料有用**：妖魔掉落的材料（妖魔精核、骨刺、冰晶石等）有实际用途
3. **装备多样性**：锻造时随机生成品质和词缀，同一件装备每次锻造结果不同
4. **长期目标**：玩家收集材料锻造极品装备，有追求感

### 与其他系统的关系
- **猎魔悬赏**（v3.12）：悬赏奖励包括锻造材料，完善材料获取途径
- **装备词缀系统**（v3.5）：锻造产出的装备随机生成品质和词缀
- **装备掉落随机化**（v3.8）：锻造是装备获取途径之一（另两个：商店购买、BOSS极低概率掉落）
- **精魄系统**：妖魔掉落精魄，用于锻造时注入提升高品质概率

## 二、核心机制

### 2.1 锻造配方

每个配方定义在 `src/data/forge-recipes.js` 中，包含：
- `id`：配方唯一ID
- `outputItem`：产出装备ID
- `materials`：所需材料列表（`{ itemId, count }`）
- `goldCost`：金币消耗
- `unlockLevel`：解锁等级

### 2.2 锻造流程

```
玩家选择配方 → 检查材料和金币 → 消耗材料和金币
→ 选择是否注入精魄（v3.10）→ 随机生成装备品质和词缀
→ 装备放入背包 → 显示锻造结果弹窗
```

### 2.3 品质与词缀

锻造时随机生成装备品质：
| 品质 | 基础概率 | 词缀数量 |
|------|---------|---------|
| 普通 | 50% | 0-1个 |
| 优秀 | 30% | 1-2个 |
| 稀有 | 15% | 2-3个 |
| 史诗 | 5% | 3-4个 |

词缀从 `src/data/affixes.js` 的6前缀+6后缀中随机选取，详见[装备词缀系统设计文档.md](装备词缀系统设计文档.md)。

### 2.4 精魄注入系统（v3.10.0新增）

锻造时可消耗精魄提升高品质概率：
| 精魄等级 | 效果 |
|---------|------|
| 奴仆级精魄 | 优秀概率+15%，普通概率-15% |
| 战将级精魄 | 稀有概率+10%，普通概率-10% |
| 统领级精魄 | 史诗概率+5%，稀有概率+5%，普通概率-10% |

锻造界面实时显示注入后的品质概率。

### 2.5 装备重铸系统（v3.10.0新增）

消耗金币重新随机装备词缀：
- 70%概率保持当前品质
- 25%概率提升一档品质
- 5%概率提升两档品质
- 词缀全部重新随机
- 背包界面装备卡片有"重铸"按钮

## 六、原著依据

- 原著中魔法师使用魔石、精魄炼制魔器是常见设定
- 妖魔材料（核心、皮毛、爪牙、精魄）在原著中有实际用途
- 装备获取途径符合原著：商店购买为主，锻造/炼制为辅，极少数特殊掉落
- 不为了游戏性强行添加妖魔掉落现成装备
