# 测试文件目录

这里存放项目的测试和调试页面。

## 文件说明

- `test-debug.html` - 完整的引擎模块加载测试，可用于调试各系统是否正常
- `test.html` - 最简单的浏览器/JS可用性测试
- `test-player.html` - Player模块单独测试
- `test-load.html` / `test-load2.html` / `test-load3.html` / `test-load4.html` - 早期的脚本加载顺序测试

## 使用方法

直接双击HTML文件在浏览器中打开即可。

注意：这些是早期开发时的测试文件，部分可能已过时。新的调试建议使用 `test-debug.html` 或在游戏内通过全局错误捕获查看。
